# 教育固定配置目录与使用者选择

本增量消费原 T1 审计及不可变组合，不改变题本、计分、报告、刺激或注册素材。新 manager 发行服务仍未挂路由；管理员目录、预览、发行/撤权界面另待实现。

发行可记录管理员指定的业务名称，名称进入完整幂等意图和不可变 T1 审计；改名需新发行。单一未命名精确配置可用；多条未命名或同名项明确不可选择，具备不同名称的项按名称呈现，不猜 latest。测试中的短/长名称是同一现有报告上的合成标签，不是新增两份 R 的证明。

目录沿用当前作者/学校/产品资格，原来源头查询按页聚合最多 129 条 typed 授权头，仅对实际显示的 40 项批量核原 manager、委托、入口批准和期限，41st cursor 哨兵不挤占授权预算。原依据撤销的 typed 项禁用；合法 legacy 保持原路径。没有逐卡编译、完整报告 body 或授权缓存；溢出明确提示缩小搜索/整理配置。查询数和延迟仍需同环境基线，未声称性能已合格。

新配置卡显示业务名称，使用者不选 C/P/R；选择后轻量 selectedBinding 随保存和重新读取保留，轮廓显示管理员固定配置。旧私有、公库、公共来源及认知流程保留原协议，本阶段不把 cognition profile 算作已固定。

实际检查：13 个来源/历史身份单测、2 个超额批量负例、5 个 PostgreSQL 目录场景、1 个非 UTC 有效期场景、2 个公共来源 PostgreSQL 回归、4 个 UI 场景通过。后端与时区测试闭包、前端类型检查退出 0；限定前端 lint 退出 0，存在原有两项 hook warnings（未变更的45/130行），无错误。初次 flatMap 类型推断错误以显式可选 DTO 修正。证据见相邻 verification.json。证据打包原脚本误要求 lint 日志为空而停止，业务代码已提交；本次补齐真实 warning 记录，不将其改称零 warning。

时间 JSON 显式按 UTC 输出，避免非 UTC Mac/云节点按当地时间解析数据库字符串。Asia/Shanghai 下十分钟真实合法使用权实际保存并读回验证，不依赖多年宽期限。旧5项目录和2项legacy不改写为最后SQL重新执行；后续 shown-page/UTC 差异由新时区场景执行最终 SQL，旧评分/任务提交不重放。
