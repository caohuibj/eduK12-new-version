## 1. 目标、基线与不做事项

管理员在合法范围内为使用者选择量表 C/P/R 或认知 profile，形成固定使用版本。
使用者只见工具名称、用途、报告样式等业务信息，直接建任务；不要求理解技术版本、
再次选择 R/profile 或编辑后台定义。被试流程无感，历史报告不漂移。

顺序：共同契约 → 量表四入口 → 认知四入口。复用既有权限、组合、release、
snapshot 和冻结系统，不另造权限中心、数据库体系、评分/认知/报告引擎；
不默认双份 PDF 归档。启动时重核远端 main，若变化须审阅有关差异。
旧审查不能冒称覆盖新基线。保护现有合法个人量表、自评及作答许可。

## 2. 业务定义与最小共同契约

- C：题本及计分定义；P：解释阈值、分档等参数；R：报告定义，含短/长图文。
  R 不改变 C 计分。
- 认知 profile：复用实际存在的 experience/research/其他合法 profile；同时锁定
  config、engine/scoring、profile/report 定义版本，不能只锁同名 profile。
- 不可变 artifact：精确 C/P/R 或认知依赖闭包，含 schemaVersion、来源、内容 hash、
  必要执行/报告版本及来源记录；优先复用已有 combination/release/snapshot。
- 授权修订：引用 artifact，记录入口、issuer 及依据、recipient/合法组织范围、
  状态/有效期、lineage、requestId、审计。变更配置新建修订，不覆盖已引用内容。
- 任务 `selectedBinding`：草稿创建即明确绑定授权修订/artifact 及身份/hash。
  同工具多个可用授权时由管理员设置默认或明确业务名称；仍歧义则要求管理员处理，
  不以 latest 猜测，不迫使使用者选择技术字段。
- 记录名/表名由实现决定，须证明身份、引用链、审计、历史可读性；
  不为名义一致重构既有四套业务模型。

管理员可手选合法存在、获准用于目标入口的组合。专业适配以提示和推荐为主，
不建自动专业裁决系统。保存时一次执行机械检查：版本存在且批准/发布有效、
发行者及入口范围正确、C/P 计分兼容、R 所需指标存在、实际必需分档可由 P 提供、
附件/依赖可解析、hash 完整。没有任何分档并非一概错误。
失败给具体缺项；成功绑定精确输入 hash 留证。列表/报告不重复专业审查，
发布核当前权限和完整性，不重新选择配置。

## 3. 角色、范围与自我授予

| 角色 | 职责 | 边界 |
| --- | --- | --- |
| 系统管理员 | 版本审批、适用入口批准、全局治理 | 不代入口管理员发使用权 |
| Training 入口管理员 | 在本入口分配已批准配置 | 当前入口及目标资格；不沿用 cognitive ADMIN bypass |
| Survey 入口管理员 | 给合法研究者分配 | 研究者资格、入口及撤权检查；不跨入口借权 |
| School 平台 manager | 向管理范围内学校心理教师分配 | 正式入口资格、既有精确委托，闭合批准→分配依据→使用权 |
| Teacher 平台 manager | 向本校 productAdmin 分配 | 精确委托及学校产品资格；manager 不等于 productAdmin |
| 心理教师 / 本校 productAdmin | 以已选配置建任务 | 不增加编辑、再授权、系统审批、所有个人报告访问权 |
| 其他成员/被试 | 按既有参与、任务、个人许可作答 | 作答、建任务、作者资格、报告读取分开检查 |

STANDARD 建任务与 custom-library 成员使用资格分别适配；不能互相泛化。
不能借本次作者/建任务限制撤销现有合法作答。School/Teacher 若 allowedProducts 或
委托 UI 不能表达所需范围，补最小合法闭环及测试，不能硬写数据库绕审批。

selfGrant 不一概禁止、不因同人放行：分别验证 issuer 资格/精确委托/范围与
recipient 入口/学校/产品/状态资格；现有政策允许且双边合法时允许并审计 selfGrant。
身份不足明确拒绝，不临时补角色；个人报告访问另核。

## 4. 三时间冻结与生命周期

**T1 保存配置及授权**：选择工具/组合/profile、业务预览及专业提示 → 一次机械验证 →
保存不可变闭包/hash → 发锁定目标、入口、依据的授权修订。幂等冲突比较完整配置、
目标及依据，不只比 resourceId。升级只新增 artifact/修订。

**T2 草稿及发布**：创建草稿即保存 selectedBinding。使用者只改合法任务信息，
不改 C/P/R/profile。管理员更新后旧草稿仍指旧 binding；失效时给业务提示，
显式新建或替换并审计，不隐藏切换。发布在事务/既有并发控制中核当前权限、
任务及绑定完整性，从已验证 artifact 复制/引用，不查 latest 或同名 profile 重算。
认知完整保留 resolved config、指标、质量、报告、展示语、算法及版本；已发布不可覆盖。

**T3 START/admission**：保留每次 attempt 独立 seed、随机化、presentation、runtime
snapshot、重试/恢复和 attemptEpoch；不把授权级 seed 共享给所有被试。
使用任务绑定版本，按原入口权限矩阵核入场，不查最新内容。

开发前记录普通撤权对新授权/新草稿、旧草稿发布、已发布未启动、新 START、
已开始续答、已完成报告的现有矩阵，保留入口差异。紧急停用是独立政策。
普通撤权不改历史定义或结果。历史报告按数据读取权限读冻结结果/定义，不依赖当前
使用 grant、不查最新 R、不自动降级。保留 renderer/schema 兼容，不承诺每次渲染
字节完全一致。缺旧快照保留显式 legacy/缺失状态，不补当前模板伪造历史。

## 5. 四入口 UI 与最小接入面

统一交互语义，不强制重写页面：对象→工具→推荐/手选 C/P/R 或 profile→
业务报告预览/提示→保存授权。技术 ID/hash 放详情和审计，展示配置业务名、用途、
报告样式、状态、目标；可看旧修订，更改注明仅影响后续绑定。

- Training 量表：接通普通 resourceId 管理 UI 与 standard-combination binding；
  覆盖 COURSE 及现有匿名投放/作答，不以仅 COURSE 冒充完成，保留私有量表。
- Survey 量表：复用 exact source grant，补选择/锁定与简化消费者；
  导入、复制、发布不能丢原始来源身份。
- School 量表：STANDARD 精确 U/source 管理闭环及消费者去技术选择；
  customLibrary 与 STANDARD 两条路径分别回归。
- Teacher 量表：同上，保护个人量表/自评及本校 productAdmin 边界，不虚构学校。
- 认知四入口：按实际 config/profile 支持逐项补最薄 adapter，改为精确 profile grant；
  使用者不再选择 profile，每个入口独立通过才报完成。

专业不匹配清晰提示，可忽略/确认；机械不可执行阻止保存。
缺素材显示尚未装载/不可选，不伪装已授权可运行。

## 6. 旧 grant 与迁移

只读盘点 schema/version/null：精确旧授权、resourceId-only legacy、旧发布任务、
旧草稿、个人许可。有可信历史证据才能通过幂等迁移建立 binding 并记录来源；
无证据不能回填当前 standard/R/profile。旧发布/开始/完成继续读旧快照，不强制重新授权。
无精确证据的 legacy 保留原合法行为并提供显式升级；新精确创建不冒充 legacy 已冻结。
迁移先 dry-run/计数，按正式迁移/import 路径在授权环境执行，不写生产、伪造 trial 或
直接 SQL 填内容绕审批。回滚新创建开关/路由，不删除新任务已引用 artifact。

## 7. 素材与证据复用

manifest 包含 source commit/tree 完整 SHA、路径/SHA256、工具/C/P/R/profile 身份/hash、
预期入口、原审计/单测/seed 证据及缺口。确认云端可取得精确 SHA；缺件明确报告。
import 后正常读取 API/受控只读检查数量、身份、hash、ONLINE/可用状态、依赖及入口范围。
迁移成功不是内容验收；六 R/profile 逐项验，未得来源不算覆盖。

只有文件、依赖版本、测试代码/路径、有关开关相同且证据可追溯，才复用纯内容/
计算/seed 证据。显示同名不算同输入。权限/UI/集成/环境/迁移/新适配仍需在本 PR
对应环境实跑。变化只使受影响证据失效，不要求无关全系统复验。

## 9. 性能、测量及回滚

先在 main 同环境/数据规模/冷热/并发建立对照：列表、保存授权、建草稿、发布、START、
报告回读 p50/p95、查询数、payload、快照字节、错误率。少量实际小/中/大代表组合及
多接收者批量，不能编造当前毫秒数。

工程讨论目标：目录按页批量，不逐卡解密/编译，不退化 N+1，初始目标每页最多增加
两次批量查询；START/报告不新增远端调用或专业重算，热 p95 初始目标不恶化超过 10%。
这两项不是新硬门禁：同环境测量及噪声分析后决定，超出定位并提供替代证据。
保存授权承担一次结构验证/编译，多接收者共享不可变 artifact，不逐人复制大对象；
保留必要历史快照。缓存 hash 校验、容量有界，不能绕当前权限/撤权，不跨身份误共享。
冷启动/首次保存独立测量；复用现有 observability，不建性能平台。
显著回归先修批量/查询/重复冻结，必要时按入口回退新建路径，保留 frozen 读取。
