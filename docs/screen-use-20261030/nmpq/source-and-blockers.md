# NMP-Q-20｜来源与升级路径（catalog-only）

- 工具：Yildirim C, Correia AP. (2015). Exploring the dimensions of nomophobia: Development and validation of a self-reported questionnaire. Computers in Human Behavior 49:130–139。20 题 4 成分（无法沟通/放弃便利/无法获取信息/失去连接），7 点计分总分 20–140，被引千次级。
- 阻塞：题文在 Elsevier 订阅文章内；作者条款未归档。
- 升级：①归档作者/出版商条款 → ②逐字誊录立 DRAFT → ③中文版另立新版本。
- 边界：NMP-Q 测手机不可及时的焦虑感受，与问题性使用（SAS-SV/MPATS）相邻不同构念；与 dass21 焦虑维为情境特异 vs 泛化关系。
