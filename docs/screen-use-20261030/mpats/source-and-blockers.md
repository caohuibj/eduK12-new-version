# MPATS-16｜来源与升级路径（catalog-only）

- 工具：熊婕, 周宗奎, 陈武, 游志麒, 翟紫艳. (2012). 大学生手机成瘾倾向量表的编制. 中国心理卫生杂志 26(3):69–72。16 题 4 维（戒断症状/突显行为/社交抚慰/心境改变），5 点计分；国内问题性手机使用研究中使用最广的本土量表之一。
- 阻塞：16 题原文在《中国心理卫生杂志》付费墙（CNKI）内；期刊/作者授权未取得；四维逐题归属与总分算法须以原文核对，不凭二手材料立键。
- 升级：①库负责人经 CNKI 获取原论文并归档 → ②向作者/期刊取得使用授权（或确认学术使用条款）→ ③逐字誊录并冻结四维计分键 → ④立 zh-CN 可执行 DRAFT（原版即中文，无翻译环节，中文路径最短）。
- 中学生适用：原编制为大学生样本，中学生应用文献较多；年龄带按应用证据登记。
