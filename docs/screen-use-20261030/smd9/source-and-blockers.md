# SMD9｜来源与升级路径（catalog-only）

- 工具：van den Eijnden RJJM, Lemmens JS, Valkenburg PM. (2016). The Social Media Disorder Scale. Computers in Human Behavior 61:478–487。按 DSM-5 IGD 九标准改编；9 题短版（每标准一是/否题）+ 27 题长版；荷兰青少年样本（10–17 岁）验证，被引约 1,730。青少年专用，与 K-12 高度匹配。
- 阻塞：作者自存档全文在 Utrecht 机构库（绿色 OA，dspace.library.uu.nl），本环境 SSL 失败不可达；第三方转传不作依据；绿色 OA 的再分发边界与作者分发条款须归档确认。
- 升级：①从可达网络取用 Utrecht 自存档或作者分发的量表件并归档 → ②逐字誊录 9 题（是/否两选项 responseSet，score 0/1）→ ③立 DRAFT；27 题长版为独立精确版本。
- 边界：与 IGDS9-SF 同源自 IGD 九标准但对象不同（社交媒体 vs 游戏），不合并计分。
