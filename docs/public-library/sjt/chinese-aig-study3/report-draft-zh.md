# 中文描述性报告草案（平台新编，非作者原报告）

## 平台新编指导语（非作者原施测导语）
下面是40个假设情境。请逐题选择最接近你通常会采取的反应的一项。这里不把选项判定为正确或错误。请按自己的实际倾向作答，而不是选择你认为更受欢迎的回答。每题选一项。本草案不提供未完成侧面的分数，也不做缺失插补。

## 报告模板
本次结果描述你在这些假设情境中的自报反应倾向，不是能力或行为优劣评定。

- 自我意识：{self-consciousness}/8，来自 N_01–N_08。
- 乐群性：{gregariousness}/8，来自 E_01–E_08。
- 观念开放：{openness to ideas}/8，来自 O_01–O_08。
- 依从性：{compliance}/8，来自 A_01–A_08。
- 自律性：{self-discipline}/8，来自 C_01–C_08。

每个侧面的数值是该侧面8题中选择作者计为1分的反应次数。数值较大只表示本套情境中更多选择了对应特质方向的反应，不表示更正确、更成熟、更优秀或更健康。五项分别解释，不合成为总分，也不跨侧面排名。

这里的“自我意识”对应 self-consciousness，不是一般意义上的自我觉察能力；五个侧面不代表完整大五人格。没有部署常模、百分位或高低切点，不能据此判断异常、诊断、选拔、录取或录用。对具体生活决策，不应把计分方向当作行为建议。

本版本原生中文题目由作者用大型语言模型生成，并在 Study3 真人样本中研究；不能因此宣称所有生成题库都已验证。结果受情境、理解、自我呈现和样本局限影响；依从性、自律性的一致性与部分效度证据有限。建议仅作为自我反思或研究讨论线索。
