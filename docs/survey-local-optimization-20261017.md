## 实验方法与适用范围

Node 24.21.0、PostgreSQL 17.11、Redis 8.0.2、UTC。本云端隔离合成库，loopback HTTP；同一编译器/配置分别编译基线和候选，单并发，后台重任务关闭。24 或 240 个 SCALE 题 + 17 个 FORM 题；匿名、非 flow、ALL_AT_ONCE。每个比较共享同一实际冻结问卷和输入；只改变新鲜首次完成是否追加 GENERAL 请求。
HTTP 使用带观察器 ABBA，再无观察器 ABBA；每块每夹具首样本独立保留，后续6暖样本。每变体每场景12暖样本、2首样本。配对差按对应AB/BA块相同序号计算，不使用独立中位数之差冒充配对收益。首样本是在进程重启后的该夹具首条，之前路由/模块、OS与数据库缓存可能已暖，不是全机器冷启动。
观察器只记请求类别、SQL事件类别/表引用数量、CPU时间、内存和纯函数次数，不记录SQL、参数、答案或凭证。导出测试独立串行运行，24种组合，12个交替ABBA/BAAB循环；cold-first使用新子进程，但已加载模块/构造夹具；计时与hash计数观察分开。

## 内存与不确定性

观察链heapUsed前后净差中位：24题4.52→3.41MiB，240题18.29→14.43MiB。候选部分样本因GC为−51.3MiB左右；这些不是精确分配、峰值、每参与者常驻内存或可乘并发的成本。API RSS约349–370MiB，含整应用与V8容量；2ms采样漏同步峰值。CPU为请求窗口整个API进程增量，观察器有开销。单并发、合成题集与短样本不支持学校峰值容量、生产吞吐、机器采购或固定百分比承诺。
