## 撤权语义

grant/revoke 与 tokenVersion 在一个事务中提交，无权限 TTL 缓存。提交后开始的下一次认证数据库读取即看到新版本，旧会话返回 401；重新登录后已撤销入口返回 403。浏览器样本从发起撤权 POST 到随后拒绝 GET 共 `35.85 ms`，包含两个 HTTP 请求及提交开销，不能当作精确 commit→deny 延迟或生产 SLA。

已经完成认证的在途普通业务请求可以完成；本实现不声称撤回已发送的数据或取消所有在途 SQL。关键授权、研究者/教育授权事务通过用户/授权行锁与撤权排序；导出在最终发布事务中持有用户共享锁并核对版本，撤权后不能发布旧任务。重新授权会产生新版本，不能复用旧版本任务。需要更强的全业务在途取消语义时应另行设计，不能通过长时间全局持锁假称即时撤销。
