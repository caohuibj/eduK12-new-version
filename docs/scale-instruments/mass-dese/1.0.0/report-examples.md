# Massachusetts DESE：按接收者区分的待审反馈文案

本文件是文案样例，不是已安装的报告版本或真实测量结果。当前全部子项为目录候选，无可执行 C/P/R；不能从这些样例生成报告。以后只复用现有报告版本、接收者授权及普通组合问卷。不得因为写了学生文案就向学生或教师开放原本不可见的数据。以下“一般/较困难体验”仅表示示例情境，不是分段阈值、常模或新分类。

学生填答者与报告接收者分别核定：学生可见内容须经当前版本的学生接收者授权；教师只可见已授权且满足既有匿名、发布、最小人数条件的群体汇总。原学生题本与协议明确承诺教师不看个人答案。未经核实的现有披露模式不能被当作已满足此承诺；不新增披露规则或擅自改原承诺。开放回答可能辨认个人或涉及敏感经历，不能不加区分直接给教师。

## 学生接收者：3–5 年级

**一般体验，证据足够且获准显示时：** 你的回答说了说你在课堂里的感受。有些做法可能正在帮助你学习。这不是考试，也不是给你或老师排好坏。你可以想一想：哪一次讲解或帮助最有用？下次需要时，可以试着说：“我想再看一个例子。”这只是一次感受记录，不能说明每一天都一样。

**较困难体验，同样的可见条件：** 你提到有些课堂经历让学习不太容易。这不说明你笨、能力差，也不需要你一个人解决。可以选一件小事：说清“我卡在哪一步”，或向你信任的大人讲讲需要什么帮助。如果遇到让你觉得不公平、不舒服或不安全的对待，可以请可信的大人支持你；你不需要自己去和老师争辩。系统不能只凭这些回答判断发生了什么或谁好谁坏。

**证据不足：** 这次信息还不够，我们不能据此说你的课堂体验怎么样。看不懂或不想回答的题可以留空，不用猜，也不用为了得到结果补选。你仍然可以向可信的大人提出学习需要；不需要先有一个分数。

## 学生接收者：6–12 年级

**一般体验，证据足够且获准显示时：** 这些回答反映了你这次感受到的课堂和学习经历，不是对你能力的评价。可以找一个确实帮助你的做法，并在需要时具体表达，例如：“这次反馈让我知道怎么修改，我还想了解下一步。”一次反馈不能概括整门课，也不能确定体验的原因。

**较困难体验，同样的可见条件：** 你描述了某些学习支持还没有满足需要的经历。较不积极的体验不等于你学习能力差，也不表示责任在你。可以选择一个安全可行的行动：提出一个具体疑问；表达希望获得的讲解或反馈；向可信任的成人寻求支持。涉及不公平或不当对待时，不要求你自行对抗教师。问卷不能判定教师好坏，也无法确认事件原因。

**证据不足：** 当前作答不能支持稳定的解释，系统不补零、不据缺失答案推测你的感受。你可以保留未作答部分，并按自己的意愿表达实际遇到的困难。一次信息不足不代表你的意见不重要。

## 教师接收者：学生版的授权群体汇总

**一般体验，满足既有群体发布条件时：** 本次汇总中，若干课堂实践得到了较积极的反馈。可选择一个学生感到有帮助的具体做法，在下一阶段继续使用，并结合课堂观察核对。汇总表达的是这批学生在本次施测中的感受，不是教师质量等级、能力排名或教学因果结论。

**较困难体验，同样的可见条件：** 部分学生可能尚未获得足够清晰的讲解、反馈或参与支持。先查看获准呈现的分项分布和有效回答数，选择一项可调整的课堂做法，例如增加一个示例或明确修改步骤；之后在可比条件下再收集反馈。不要寻找“谁给了低评价”，也不要把体验归咎于学生态度或能力。不能由此单独判断教学水平或确定原因。

**证据不足或未满足现有发布条件：** 当前信息不足以形成可解释的群体反馈，暂不显示分项结论、排名或个人意见。不把未显示解释成零分或没有问题。可核对施测安排、学生是否理解题目，以及现有匿名与发布条件；不能降低既有最小人数或披露要求来凑出报告。

## Staff 和无分表单

Staff Survey 的填答者是教职工，评价对象是管理者；不能套学生版语气，也不等于教师自评。获准的管理者群体摘要应讨论管理实践与改进；未满足现有发布条件时不显示结论。若日后另有教师自评模块，报告仍面向获准的教师接收者，不能由本工具推导自评功能。

K–2 讨论提纲：只保存主持人按实际讨论得到的事实/描述；不为儿童生成量表分数、维度画像或好坏标签。适龄确认语可为：“谢谢你说说上课的感受。有想不明白或需要帮助的地方，可以告诉你信任的大人。”没有讨论资料时显示“本次没有可整理的讨论记录”，不生成推测分析。

各正式版本附带的可选开放评论：保持可选、无计分；缺失不是零分，不进入任何量表总分。仅在现有授权允许时显示必要描述，不把敏感原话直接并入教师汇总，也不从自由文本自动推导学生标签。没有可见内容时显示无分完成状态或“没有可显示的描述”，不套评分报告。
