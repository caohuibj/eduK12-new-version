# 原件计分与结构审核

实际读取的文件是官网十个学生表单、两个 Staff 表单、三个施测协议、K–2 讨论协议和 December 2014《Student Feedback Survey (SFS) Technical Report: Survey Development and Internal Validation》。原件指纹见 source-evidence.json；本页不复制题文。没有把网页摘要当作计分手册。

当前 3–5 Standard 的题项键前说明仍提到 46 题，但实际作答区及条目键只有 40 题。这是原文件内部的版本残留，不能依据“46”补造六题。当前其余三个 Standard/Short 的题数与 2014 报告也不同；没有版本变更说明与完整映射前，不能继承该报告的全部信效度结果或历史模型参数。所有当前学生候选用途证据标为 `EVIDENCE_UNKNOWN`，没有承认未知的当前版本验证。

学生题本是四级同意度。2014 技术报告 §5.2 明确采用最低同意程度 0、随后 1、2、最高同意程度 3 的编码；这是**历史研究的项目编码范围 0–3，较高代表更积极的课堂实践感受**，不是 1–4，也不是学生能力。报告没有授权用本轮较短题本套历史 Rasch 参数；§6.2 当时明确不建议产出 Rasch 标化分，建议看项目频数/均值与反馈模式。没有据此安装新 scorer、总分、常模、阈值或转换表。

反向：所读当前学生作答题与条目键未发现明确反向计分标记，2014 报告未提供一份供当前各表单使用的反向键。故本轮记录“当前反向键待正式核定”，不凭否定词（例如不放弃、不浪费时间）猜反向，也不为鼓励学生而反转方向。计分参数版本保持 null。

缺失：两个学生施测协议都允许不理解或不愿回答时跳过，开放评论也可留空。不得把空白当作 0（0 本身是有效的不同意端点）。有效项目数/分母、最低可解释作答量、缺失模式和班级发布条件未在所读材料中形成可直接导入当前版本的完整契约，保持未安装；不添加自己的比例或人数阈值。证据不足只能如实说明，不能显示低体验分数。

Staff：原表有五级同意度及独立“不适用”选项，与学生四级不同。尚未确认该当前 Staff 版本正式数值编码、反向键、维度汇总算法及缺失/不适用分母；不套学生 0–3 编码，不把“不适用”当作中点或 0。原管理协议范围为学校校长、副校长和其他学校领导，参与者为有相应执照/岗位的教职工。内容覆盖 Standard I、II、IV，不能误补不存在的 Standard III 分量表。

拆分限制来自技术报告 §6.2，须优先于“按标准名称能分组”的直觉：当时 Standard I 的分量表信度不足，尤其 3–5；Short 设计为整体概览，不建议按 Standard 或 Indicator 拆报，因为条目不足。报告中的三个相关潜在维度只是进一步验证的信号，不能包装成当前 Mini 或三条已验证可单独施测量表。目录中 `reportPlan.dimensionLabels` 是待审内容映射标题，不是已安装 score keys。

报告也限制成长推断：§6.2 将工具视为某时点课堂体验的快照，并提醒项目均值/频数受样本组成影响。不能把重复施测的普通均值变化宣称教学质量提升；3–5 Short 的改变敏感性尤其没有足够证据。没有跨工具总分、教师排名或“优秀/差劲”标签。

许可再核：2014 技术报告自身给出署名、非商业教育用途复制许可；其 Item Acknowledgements 同时列出来自 TRIPOD（Ferguson）和 ESSCES（Peoples 等，2014）的项目。整份技术报告可阅读不等于本平台拥有这些第三方项目在当前表单中的改编、翻译或收费再分发许可。必须逐项核定来源链；这为本轮仅推元数据提供了具体依据。

未来合法取得并核定当前版本后，继续复用既有计分和报告能力：按真实项目编码验证端点、缺失与有效 0、版本错配、不适用、反向键及代表性输出；无分评论/K–2 只走 Form。当前没有可执行定义，故评分 fixtures、真实评分报告及隔离库安装不运行，也不声称通过。报告草案的三种情境是文案检查，不是计分分段。
