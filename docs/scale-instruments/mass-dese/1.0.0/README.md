## 本批范围与版本

## 原生量表与无分表单的拆分原则

1. 每种官方长短/Mini 表单保留原组卷和顺序，分学段、填答者、语言与原件指纹。Standard 与 Short 不能互换；Mini I & II 不能直接拼接 Mini I 和 Mini II 得到，也不能宣称 Mini 是已验证的独立量表。
2. 原题本的 Standard I / II、各 Indicator 只是内容映射线索；候选子维度保留在母表单内。若要独立施测须另核证据，不能因能计算某组均值就拆成正式独立量表。
3. 各表单附带的可选自由评论另作无分 Form 候选，并保持与所选版本的关系。K–2 讨论提纲作主持人记录的无分 Form，保存事实或描述，无量表分数和评分报告。许可未清前不把原文题目塞进 Form payload，也不制造空壳假装已导入。
4. Staff 是教职工反馈管理者实践，填答者与评价对象均不同，不混学生版、不当作教师自评。现有教育适用性 schema 未表达该管理者关系时不强塞学生评教声明或扩展 schema。
5. 母工具无需新增引擎或权限。可选普通组合为“本学段一种官方学生表单 + 同版本可选无分评论”；K–2 单独讨论记录；Staff 另组。不得把长短版、两个学段、学生与 Staff 一起求总分。候选尚不可引用为可执行组合依赖，所以本轮不创建不可运行的 Bundle。

## 计分、缺失与报告边界

原学生表单使用四级同意度，不是学生成绩。缺失允许保留：管理协议要求不理解或不愿回答时可跳过；不能把空白补为零、默认中点或不同意。本轮不自创缺失比例、最低有效人数、反向题、维度总分/均分公式或阈值。详见 [scoring-review.md](scoring-review.md) 的原件核定结果与版本差异。

学生填答、学生接收者和教师接收者分别管理。学生反馈按学段描述学习经历，给可行的小行动；不诊断、不评判教师好坏、不让学生承担不当对待的责任。教师只看授权且符合现有匿名/发布条件的群体改进反馈。完整的一般体验、较困难体验、证据不足和无分情形样例见 [report-examples.md](report-examples.md)。样例不含伪造得分，也不改变计分方向或自动开放任何结果。
