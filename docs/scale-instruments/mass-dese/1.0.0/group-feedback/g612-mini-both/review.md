# Massachusetts DESE · 6–12 年级学生 迷你卷 I 与 II

![中学师生正从走廊进入教室，准备开始分组学习。](./hero.webp)

## 从一个课堂环节连起目标与机会

固定 12 题合并版让课程安排与参与体验出现在同一份反馈里。可以选一个具体环节来解释逐题分布，例如从课前活动过渡到课堂讨论。

## 跟着题号读一行

同一版、同一群组逐题汇总。比例的分母为该题的有效作答人数。空白单独记数；教职工版另列不适用。没有有效作答时，比例显示为横线。这份报告用于讨论教学或管理实践。

从原题号定位到该题，再按官方选项顺序看人数与有效比例。遇到回应较少或分布较散的题，结合课堂观察了解背景。

## 下一步可以试试

邀请学生用不同方式说出活动目的，观察他们如何进入任务。选一个小改动，再用课堂作品和下次反馈检查。

## 发布状态与原件

供6–12 年级学生所在班级的教师查看群体反馈。表单为 12 道编号题。可选评论按原施测说明另行处理。

这是供具备授权的管理员制作匿名群体统计的独立报告。题号对应原版。施测题本及其中文改编另行授权；本包没有题文、个人答案、评论原文或评分。

正式量表计分待核。合并版高年级12题的独立验证及正式计分说明；不套低学段或两套 Mini 单独模型。
