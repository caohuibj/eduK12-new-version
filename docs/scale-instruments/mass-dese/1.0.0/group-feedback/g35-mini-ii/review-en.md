# Massachusetts DESE · Grades 3–5 students Mini Standard II

![Pupils use different materials to take part in the same activity.](./hero.webp)

## Give every pupil a way into the task

Pupils may need different ways into the same activity. These 10 questions help you notice whether the classroom offers routes that pupils can actually use.

## How to read a row

This is an item-by-item summary for one cohort and one form. Percentages use the number of valid responses to each item. Blank responses are counted separately, as are not-applicable responses on staff forms. A dash denotes a percentage with no valid responses. Use the report for a conversation about teaching or leadership practices.

Find the original item number, then read the counts and valid percentages in the original order. Use classroom or workplace observations to put sparse or mixed feedback in context.

## One change to try

Offer two routes into one familiar task, such as looking at an example or trying it first. Use what you observe to decide whether both routes should stay.

## Source and release status

The intended reader is the teacher of the class supplying the aggregate feedback for grades 3–5 students. The form has 10 numbered items. Handle optional comments separately under the administration protocol.

This separate report is for authorized administrators working with anonymous group counts. Item numbers refer to the official form. Administration and translation rights are separate. No questionnaire items, individual answers, comment text or scores are included.

A scoring release requires version-specific evidence. This report keeps ordinal response categories separate from numerical scores and from other form versions.
