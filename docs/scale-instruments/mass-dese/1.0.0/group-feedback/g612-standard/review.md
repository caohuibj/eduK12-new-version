# Massachusetts DESE · 6–12 年级学生 标准卷

![中学生分组探究，同伴交流，把想法记录在共享材料上。](./hero.webp)

## 把分布带回一堂实际的课

45 道原题给出学生经历的多个观察点。看到相近或分开的分布时，先对照课程任务、当天参与情况和学生作品，看看这一行可能在提醒什么。

## 跟着题号读一行

同一版、同一群组逐题汇总。比例的分母为该题的有效作答人数。空白单独记数；教职工版另列不适用。没有有效作答时，比例显示为横线。这份报告用于讨论教学或管理实践。

从原题号定位到该题，再按官方选项顺序看人数与有效比例。遇到回应较少或分布较散的题，结合课堂观察了解背景。

## 下一步可以试试

在一门课里挑两道值得了解的题。找一个相关的作业或讨论片段，再决定下次收集哪一点观察。

## 发布状态与原件

供6–12 年级学生所在班级的教师查看群体反馈。表单为 45 道编号题。可选评论按原施测说明另行处理。

这是供具备授权的管理员制作匿名群体统计的独立报告。题号对应原版。施测题本及其中文改编另行授权；本包没有题文、个人答案、评论原文或评分。

正式量表计分待核。DESE 最终 45 题与 2014 年 56 题对照及当前计分契约；不能沿用早期 Rasch 模型。
