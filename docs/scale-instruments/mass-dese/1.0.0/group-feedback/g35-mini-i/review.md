# Massachusetts DESE · 3–5 年级学生 迷你卷 I

![老师展示课堂目标，学生对照具体的活动材料。](./hero.webp)

## 让孩子看见这节课要学到什么

这 8 道题围绕课程、教学与评价。把每题反馈和一项具体课堂活动对照，看看目标、例子或反馈在什么时候帮助学生明白下一步。

## 跟着题号读一行

同一版、同一群组逐题汇总。比例的分母为该题的有效作答人数。空白单独记数；教职工版另列不适用。没有有效作答时，比例显示为横线。这份报告用于讨论教学或管理实践。

从原题号定位到该题，再按官方选项顺序看人数与有效比例。遇到回应较少或分布较散的题，结合课堂观察了解背景。

## 下一步可以试试

把一个学习目标配上一份看得见的示例，让孩子用自己的话说说做到什么样算完成。

## 发布状态与原件

供3–5 年级学生所在班级的教师查看群体反馈。表单为 8 道编号题。可选评论按原施测说明另行处理。

这是供具备授权的管理员制作匿名群体统计的独立报告。题号对应原版。施测题本及其中文改编另行授权；本包没有题文、个人答案、评论原文或评分。

正式量表计分待核。Mini I 在历史报告中未作为独立验证版，需当前 Mini I 独立证据及精确聚合键。
