# Massachusetts DESE · 3–5 年级学生 短卷

![小学课桌旁，一张匿名课后反思便签静静放着。](./hero.webp)

## 用一次短反馈找到下节课的起点

一张短卷像课堂的速写。用 20 道题看到学生此时的经历，再挑一个能验证的小问题。每道题有自己的有效人数，少量回收先作线索。

## 跟着题号读一行

同一版、同一群组逐题汇总。比例的分母为该题的有效作答人数。空白单独记数；教职工版另列不适用。没有有效作答时，比例显示为横线。这份报告用于讨论教学或管理实践。

从原题号定位到该题，再按官方选项顺序看人数与有效比例。遇到回应较少或分布较散的题，结合课堂观察了解背景。

## 下一步可以试试

选一个学生意见不同的地方，把活动开头改成一句话加一个实例。下次比较学生能否更快说出要做哪一步。

## 发布状态与原件

供3–5 年级学生所在班级的教师查看群体反馈。表单为 20 道编号题。可选评论按原施测说明另行处理。

这是供具备授权的管理员制作匿名群体统计的独立报告。题号对应原版。施测题本及其中文改编另行授权；本包没有题文、个人答案、评论原文或评分。

正式量表计分待核。终版 20／历史 25 对照与当期项目编码确认。原报告不支持短卷按 Standard/Indicator 分拆，也缺可靠变化阈值。
