# Massachusetts DESE｜12 份群体反馈报告

这是供有权查看匿名汇总的教育者使用的独立报告包。每版保留原编号、选项顺序、适用群组和官方原件指纹。十个学生版本按学段与表单区分。教师作为接收者时看同一班级的群体反馈。两个教职工版本的评价对象是学校管理者，保留五级同意度与单独的不适用。

## 使用

1. 从 `index.json` 找到实际用过的表单，按官方链接或组织留存原件核对文档 SHA-256。使用对应的 `item-counts.csv`，同一份输入汇总同一版和同一群组。每个编号一行，填入各档人数和空白数。教职工版另录不适用。源文件名称、题号和档位都应该对应同一原卷。
2. 确认输入仅含匿名人数合计。按原施测说明确定可展示的群组；能反推出个人时保留在授权范围内。自由评论需另按原协议保护身份，并从这份汇总中排除。
3. 用 Node 输出所选语种的 Markdown 报告，在各表单目录另有配图、审阅稿和一项可操作的讨论建议。输出放在报告包根目录时，配图按相对路径显示。

```sh
node render-report.mjs zh-CN ./g35-standard/item-counts.csv > feedback-zh-CN.md
node render-report.mjs en ./g35-standard/item-counts.csv > feedback-en.md
```

四档或五档的人数按题展示。该题有效人数是原同意度选项的合计。空白和不适用只单列人数。无有效答案的行用横线表示比例。报告模板中的空白输入是待填项，真实为零的计数请填写 0。

## 适用范围

本包公开原创报告、通用响应类别和匿名统计模板。原题、译本和正式量表计分不在本包内。每份报告均可用独立中文或英文渲染，中文是报告译文。需开展数字施测或向外提供题本及其中文工作译本时，继续按对应原件确认授权。若需要个体分数、标准聚合或变化判断，具体计分与来源缺件见上层 `scoring-review.md`。
