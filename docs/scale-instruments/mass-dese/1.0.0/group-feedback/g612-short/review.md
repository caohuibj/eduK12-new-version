# Massachusetts DESE · 6–12 年级学生 短卷

![课将结束时，一名中学生回看材料并写下反思。](./hero.webp)

## 给课末回看留五分钟

这 20 道题是一张简要课堂反馈。把每题的档位分布与有效人数放在一起读，选择一个能联系课堂实践的发现带去下一次备课。

## 跟着题号读一行

同一版、同一群组逐题汇总。比例的分母为该题的有效作答人数。空白单独记数；教职工版另列不适用。没有有效作答时，比例显示为横线。这份报告用于讨论教学或管理实践。

从原题号定位到该题，再按官方选项顺序看人数与有效比例。遇到回应较少或分布较散的题，结合课堂观察了解背景。

## 下一步可以试试

请学生在课末写下「清楚的一步」和「还不清楚的一步」，用不记名的方式比较是否呼应你看到的逐题分布。

## 发布状态与原件

供6–12 年级学生所在班级的教师查看群体反馈。表单为 20 道编号题。可选评论按原施测说明另行处理。

这是供具备授权的管理员制作匿名群体统计的独立报告。题号对应原版。施测题本及其中文改编另行授权；本包没有题文、个人答案、评论原文或评分。

正式量表计分待核。实际 20／历史 25 对照，及获认可的版本内项目编码；不能混 3–5 短卷或作分标准诊断。
