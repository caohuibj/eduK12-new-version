# Massachusetts DESE · 3–5 年级学生 标准卷

![小学教室里，学生在几个活动角动手和讨论。](./hero.webp)

## 问问课堂里哪一步更容易跟上

把一节课想成一条小路。学生的反馈可以告诉我们，哪一段好走，哪一段需要一个更清楚的提示。这份 40 题报告把声音放回各道题，便于结合最近的课堂片段理解。

## 跟着题号读一行

同一版、同一群组逐题汇总。比例的分母为该题的有效作答人数。空白单独记数；教职工版另列不适用。没有有效作答时，比例显示为横线。这份报告用于讨论教学或管理实践。

从原题号定位到该题，再按官方选项顺序看人数与有效比例。遇到回应较少或分布较散的题，结合课堂观察了解背景。

## 下一步可以试试

选一道分布较分散的题，回看最近一次讲解或过渡。下节课先示范一遍，再请学生描述自己接下来要做什么。

## 发布状态与原件

供3–5 年级学生所在班级的教师查看群体反馈。表单为 40 道编号题。可选评论按原施测说明另行处理。

这是供具备授权的管理员制作匿名群体统计的独立报告。题号对应原版。施测题本及其中文改编另行授权；本包没有题文、个人答案、评论原文或评分。

正式量表计分待核。DESE 最终 40 题与历史 46 题逐题映射及删除记录；若要分量表，需当前版验证、具体指标公式或官方聚合键。
