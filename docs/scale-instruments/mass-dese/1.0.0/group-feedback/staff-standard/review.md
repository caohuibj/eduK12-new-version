# Massachusetts DESE · 教职工 标准卷

![教职工围桌讨论工作支持和协作流程。](./hero.webp)

## 把管理反馈带到一次有议程的对话

65 道题记录教职工对学校管理实践的感受，涉及原卷中的标准 I、II 和 IV。把每一行放回实际的协作、沟通和支持情境，看看哪一点值得团队进一步了解。

## 跟着题号读一行

同一版、同一群组逐题汇总。比例的分母为该题的有效作答人数。空白单独记数；教职工版另列不适用。没有有效作答时，比例显示为横线。这份报告用于讨论教学或管理实践。

从原题号定位到该题，再按官方选项顺序看人数与有效比例。遇到回应较少或分布较散的题，结合课堂观察了解背景。

## 下一步可以试试

选一道有效作答较充分、意见分布值得了解的题。会上围绕可观察的流程讨论，听取不同岗位需要，各记下一项可以调整的做法。

## 发布状态与原件

教职工匿名反馈学校管理实践，供校内改进。表单为 65 道编号题。可选评论按原施测说明另行处理。

这是供具备授权的管理员制作匿名群体统计的独立报告。题号对应原版。施测题本及其中文改编另行授权；本包没有题文、个人答案、评论原文或评分。

正式量表计分待核。Staff Standard 65 的官方数值编码、反向、维度聚合、有效答题分母与不适用跳答说明。学生历史技术报告不涵盖此卷。
