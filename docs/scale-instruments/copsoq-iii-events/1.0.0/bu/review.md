# COPSOQ III · 欺凌经历

![两位同事私下交谈，桌上放着梳理时间的纸卡。](hero.webp)

区分过去一年欺凌经历与另一道日常体验题

过去十二个月的欺凌暴露、仅在有经历后报告的来源，以及有关不公平批评／被欺凌／当众难堪的另一道频次题，各回答不同的问题。应分别呈现，让重复发生的体验可见。

## 怎样读报告

- 有效频次以答出原版五档之一的人数为分母。分别列每天、每周、每月、几次和没有发生。空白及明确拒答分开保留；没有发生是一个有效的原始回答。
- 来源题只在四档肯定频次之一作答后显示。来源百分比以至少选择一个有效来源的人数为分母；一人可选多个来源，各来源比例相加可能超过 100%。未显示、已显示但未答、明确拒答分别记录。
- 原版顺序为 BU1、条件显示的 BU3、独立的 BU2。BU2 保留附录所列可选不适用项，并在描述性汇总中记为结构性缺失，有效分母排除这一项。
- 结果反映成年人对工作场所经历的自报分布。避免对个人、团队或来源角色排序，报告中保留小样本与可能再识别的限制。

## 可考虑的下一步

梳理支持渠道时，可从应对反复困扰的保护措施着手。BU2 中没有上级或同事的答项单列不适用，不能计入有效频次或当成从未遇到。

在适用范围内报告分布，由获授权研究人员查看；对外仅提供充分汇总、无法合理识别个人的材料。原始作答、IP、联系方式及事件原文不进入此图文报告。

## 版本与来源
