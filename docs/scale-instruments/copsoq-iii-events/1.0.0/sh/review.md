# COPSOQ III · 不受欢迎的性关注

![两位成年人准备在一间安静的房间坐下来交谈。](hero.webp)

能否在保密条件下获得支持

问题保留附录对不受欢迎性关注的表述。分类结果描述自报经历，能帮助研究者了解支持渠道是否容易找到和使用。

## 怎样读报告

- 有效频次以答出原版五档之一的人数为分母。分别列每天、每周、每月、几次和没有发生。空白及明确拒答分开保留；没有发生是一个有效的原始回答。
- 来源题只在四档肯定频次之一作答后显示。来源百分比以至少选择一个有效来源的人数为分母；一人可选多个来源，各来源比例相加可能超过 100%。未显示、已显示但未答、明确拒答分别记录。
- 结果反映成年人对工作场所经历的自报分布。避免对个人、团队或来源角色排序，报告中保留小样本与可能再识别的限制。

## 可考虑的下一步

如果公开讨论可能让人联想到具体同事，先省略细分图和故事。对求助有需要的参与者提供说明清楚的保密渠道，并让其决定何时和谁谈。

在适用范围内报告分布，由获授权研究人员查看；对外仅提供充分汇总、无法合理识别个人的材料。原始作答、IP、联系方式及事件原文不进入此图文报告。
