# TFALS 教师反思反馈草案

以下为项目原创文案，尚未绑定运行报告版本。填答者与报告接收者均为教师本人；日后只有既有报告版本/接收者授权允许时才呈现。管理者只可在既有授权、匿名、发布及最小人数条件下查看汇总，不能默认取得个体答案。没有学生填答对应版或学生报告；不能把教师自评文字套给学生。

示例场景是文案检查用情境，不能由当前目录自动计算。正常/困难不设自创分界；缺失、授权或题本不足时不输出维度分数。数字只有在原计分合同核实并安装后才可出现。

|维度|正常/较顺利情境|困难情境|信息不足|
|---|---|---|---|
|概念素养|你的回答显示，你能为形成性评价找到清楚的理由。下一次备课可挑一个学习目标，写下要收集什么学习证据，并观察它是否帮助你决定下一步。|这些回答提示，有些评价概念还需要结合实例理解。这不能证明你教学能力差。可先和可信同事一起看一份匿名作业，分别说说你们发现了什么、还需要什么证据。|目前的信息不足以形成概念素养画像。可暂留空白，或在准备好后补充；不把未答当作不会。|
|实践素养|你对把评价用于课堂活动较有把握。可选一次反馈活动，看看学生是否理解并实际用上建议，保留一个小例子供下次反思。|你可能知道目标，却在落实时遇到时间、任务或支持方面的困难。先选一个小步骤：给一次反馈留出学生回应的时间，并记录什么帮助了他们。自报素养并不等于课堂效果。|现有回答还不足以描述这一方面。可先收集一个课堂案例；不补零、不推断教学质量，也不生成与TFAPS互换的分数。|
|社会情绪素养|你注意到评价中的情绪与关系。可尝试一次简短、可选择是否回答的课后询问，了解学生对反馈的感受，再决定是否调整表达。|评价中的情绪、公平与沟通可能需要更多支持。可与可信同事讨论一个去标识案例，先找出可改善的沟通步骤；不要求教师独自承担环境中的所有困难。|目前无法形成可靠画像。保留不确定性，可以先检查沟通与隐私安排，再决定是否补充作答；不贴人格或心理标签。|

公共提示：这是对你自述素养的反思，不是课堂观察、教学质量鉴定或学生学习成效证明。可选一个行动尝试，不必一次改变所有方面。再次填写时保留相同版本和条件，也不能仅凭分数变化断言教学改善。
