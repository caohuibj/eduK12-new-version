# DMEE-Class-T 中文独立工作译本

这里有按原版最终分组对应的八份中文 Form 和一份 55 题中文全卷。中文与作者英文版分开保存，保留原题代码、顺序、七档选项位置和缺失行为。完整表及八分组描述包互为选用方式，同一轮无需重复填写。

根据作者 2023 年论文及开放许可附录 S1 与 S5 翻译和核对，© Christophe Dierendonck，CC BY 4.0。项目改动为简体中文翻译、无分表单说明及独立图文反馈。原研究用法文施测，译本没有建立教育群体等值性。

选用的表单按索引由既有原始 Form 接口提交，供系统审核。新建 Survey 波次时沿现有方式使用同一 Form 定义和索引中的 instrument key。既有授权接收者可将波次题项汇总下载，在获授权的本地目录执行。

```sh
node report-summary.mjs retained55 path/to/survey-item-analysis.json
```

程序复用英文表单的类别报告转换，严格核对中文题文、选项及文件摘要。逐题报告有效频次、新增缺失类型不计算总分、因素分或教师等级。留空仍为缺失。原研究个体 ESEM 参数仍待材料。
