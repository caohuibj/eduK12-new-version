# DMEE-Class-T｜策略示范｜教师自评频次导读｜中文工作译本

## 让看不见的判断变得可讨论

![老师在桌边示范材料的用法，学生认真观察。](../descriptive-reports/modeling/hero.webp)

示范一个答案容易看到步骤，示范一段判断则能让学生知道为什么选这一步、卡住时如何换法。这个分组记录你怎样使解题或完成任务的过程可观察。

## 怎样读结果

这个分组有 6 道频次题。汇总按每题列出原版七种选项的人数和比例，分母为该题已有有效选择的人数。未作答、未显示和拒答分别记录。没有有效选择时，留空比例。

一项做法出现得少，可能与课时、任务、教学阶段或资源有关。可以先找出值得讨论的一项做法，再对照课堂观察或学生作品理解背景。教师自报频次只说明这次记录到的实践，无法替代学生的实际学习经历。

## 下次试一件小事

挑一个常卡住的步骤，示范时说出自己如何在两种做法间选择。随后换一个相近例子请学生说明会保留哪一步、改哪一步，观察他们能否在例子变化后使用策略。

## 题本与适用范围

依据 2023 年 Dierendonck 补充材料 S1 的题文和七级频次制作简体中文工作译文，按 S5 最终分组，原题号 25、26、27、28、29、30。图文为项目原创，供成年教师自我反思。研究以法文施测，中文版及分组单独使用的测量等值尚未建立。本导读只展示逐题类别结果，不计算 ESEM 因素分数、教学质量分或综合排名。
