# DMEE-Class-T：教师自评母工具

本包包含 **9 份真实原生无计分 Form**：最终结构的八个分组表单及完整 55 题表单。八个对应的 Scale 目录保留为计分候选，不提供伪造的 ESEM 分数。原生 Form 已通过隔离库创建、现有标签写入和回读；均为 DRAFT、未公开。隔离验证不是生产导入，也不是人类独立审评或公共库发布。

本包版本 `1.0.0` 是平台内容准备版本；来源研究版本为 2023，不能把平台版本说成作者新修订版。原研究用法文施测，作者英译没有独立英文验证。本轮原生 Form 采用 **作者英译题文及 S1 英文频率锚点**；法文原题已取得，但所读 S1 没给法文锚点的精确措辞及完整施测脚本，暂不伪造已核法文施测版。项目新写的可跳过、隐私和用途指导语已明确标识为平台说明。

## 为什么此轮用 Form

原论文分析使用 WLSMV/ESEM，因素具有大量交叉载荷；S5 是标准化载荷/独特性，不是可直接代入单个教师答案的因素分数系数。所读正文和 S1–S8 没有提供完整的个体因素分数实现参数、原始数据文件或经作者指定的简单总分/均分规则。因此八个 Scale 目录不安装 scoring executable；不会把载荷当权重、把负交叉载荷当反向键，或把普通均分说成原 ESEM 因素分。

这不是因为缺常模、中文验证或独立施测验证而阻止计分；具体缺项是**原研究个体 ESEM 计分复现所需完整参数/程序**。有完整题文和选项，故按用户要求向实际可用推进为无分 Form，保留频率类别和原题文。没有构造模型分、跨因素总分、跨工具总分或教师排名。

S1 的频率选项为 1–7，对应 never、rarely、sometimes、regularly、frequently、very frequently、systematically。Form 用稳定的字符串选项键保存这些类别，没有 `score` 字段。空白保留为缺失，不记 0 或默认中点；允许跳过是本平台无分反思表单的明示安排，不能冒称原研究的正式缺失计分规则。论文中的 pairwise present 属于研究估计处理，不能直接迁移为个人得分缺失策略。

## 原组卷与普通组合

完整 55 题表单保留原题号的数值顺序，推荐作为默认完整版本。八个分组 Form 是按最终目标因素拆出的描述性摘录，可按实际需要选择；未声称拆开后具有与整体模型相同的独立施测效度。该限制不阻止其合法无分描述用途。

普通组合有两种互斥选择：“完整 55 题 Form”，或“同一语言的若干分组 Form”。不把完整表与八组重复放入同一次组合，不用母工具名计算一个总体教学质量分。原论文没有提供本轮可直接复制的学生或观察者平行题表，故未擅自改人称制造学生版。

## 报告与可见条件

这是教师自报课堂实践频率，不能单独证明实践质量、学生感受、学生成绩或因果效果。原研究分析 1,418 位卢森堡基础学校教师，与另一个教师自报 CSS-T 比较，并非独立观察或学习增益验证。法文结果不直接代表作者英译、中文或中国教师群体。

Form 在既有路径显示原始选项/缺失及完成信息，`COLLECTION_ONLY`，不生成评分报告。仅向既有授权接收者呈现；新文案不开放原本不可见的内容、不复制学生个体资料。教师成长文案、一般/困难/信息不足示例和各分组微行动见 [report-examples.md](report-examples.md)，它们是待审说明，不是因素阈值或自动分类算法。
