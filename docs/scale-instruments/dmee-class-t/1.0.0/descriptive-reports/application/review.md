# DMEE-Class-T｜应用练习｜教师自评频次导读

## 把会听懂变成试着用

![学生使用图纸和模型实践，老师在旁协助。](./hero.webp)

讲解结束并不代表每个人都有过独立尝试的机会。这个分组关注学生怎样练习、复用所学，以及你如何了解他们在应用时遇到的问题。

## 怎样读结果

这个分组有 7 道频次题。汇总按每题列出原版七种选项的人数和比例，分母为该题已有有效选择的人数。未作答、未显示和拒答分别记录。没有有效选择时，留空比例。

一项做法出现得少，可能与课时、任务、教学阶段或资源有关。可以先找出值得讨论的一项做法，再对照课堂观察或学生作品理解背景。教师自报频次只说明这次记录到的实践，无法替代学生的实际学习经历。

## 下次试一件小事

选一项贴近目标的短练习，再给一个条件略有变化的小例子。对照两份作品，看看哪些做法能迁移、哪些地方仍需要提示，避免单用完成速度判断理解。

## 题本与适用范围

对应 2023 年 Dierendonck 补充材料 S1 的作者英译题文和七级频次选项，题项按 S5 最终分组，原题号 31、32、33、34、35、36、37。图文为项目原创，供成年教师自我反思。研究以法文施测，独立英文分组的测量等值尚未建立。本导读只展示逐题类别结果，不计算 ESEM 因素分数、教学质量分或综合排名。
