# DMEE-Class-T｜提问｜教师自评频次导读

## 留出时间，看见理由

![围桌讨论中，学生开口说明，老师倾身听。](./hero.webp)

问题既可以核对答案，也可以听到学生怎样想。这个分组记录你如何提出问题、给出思考空间及邀请不同学生解释。回答的热闹程度和理由的清楚程度需要分别观察。

## 怎样读结果

这个分组有 7 道频次题。汇总按每题列出原版七种选项的人数和比例，分母为该题已有有效选择的人数。未作答、未显示和拒答分别记录。没有有效选择时，留空比例。

一项做法出现得少，可能与课时、任务、教学阶段或资源有关。可以先找出值得讨论的一项做法，再对照课堂观察或学生作品理解背景。教师自报频次只说明这次记录到的实践，无法替代学生的实际学习经历。

## 下次试一件小事

预留一个需要说明理由的问题。提问后先留出安静思考的时间，让学生写一句理由，再选两种思路谈一谈。记录一个自己原先没有想到的解释。

## 题本与适用范围

对应 2023 年 Dierendonck 补充材料 S1 的作者英译题文和七级频次选项，题项按 S5 最终分组，原题号 18、19、20、21、22、23、24。图文为项目原创，供成年教师自我反思。研究以法文施测，独立英文分组的测量等值尚未建立。本导读只展示逐题类别结果，不计算 ESEM 因素分数、教学质量分或综合排名。
