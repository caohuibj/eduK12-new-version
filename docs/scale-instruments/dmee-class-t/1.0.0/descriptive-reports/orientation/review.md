# DMEE-Class-T｜目标导向｜教师自评频次导读

## 先让学生看见要去哪里

![老师展示两张卡片，学生围在桌边看向共同材料。](./hero.webp)

有时学生已经按步骤做起来，却很难说出这一步和学习目标有什么关系。这个分组记录你如何引入目的、解释任务为什么值得做，以及怎样确认学生自己的理解。

## 怎样读结果

这个分组有 7 道频次题。汇总按每题列出原版七种选项的人数和比例，分母为该题已有有效选择的人数。未作答、未显示和拒答分别记录。没有有效选择时，留空比例。

一项做法出现得少，可能与课时、任务、教学阶段或资源有关。可以先找出值得讨论的一项做法，再对照课堂观察或学生作品理解背景。教师自报频次只说明这次记录到的实践，无法替代学生的实际学习经历。

## 下次试一件小事

在本周选定一项任务，开始时用一句话说清要解决的问题，结束前邀请一两位学生用自己的话说说任务为什么这样安排。下一次备课时，只调整一个让人困惑的连接点。

## 题本与适用范围

对应 2023 年 Dierendonck 补充材料 S1 的作者英译题文和七级频次选项，题项按 S5 最终分组，原题号 1、2、3、4、5、6、7。图文为项目原创，供成年教师自我反思。研究以法文施测，独立英文分组的测量等值尚未建立。本导读只展示逐题类别结果，不计算 ESEM 因素分数、教学质量分或综合排名。
