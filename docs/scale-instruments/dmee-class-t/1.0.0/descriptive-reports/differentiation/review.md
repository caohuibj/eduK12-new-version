# DMEE-Class-T｜差异化｜教师自评频次导读

## 共同目标，可以有不同入口

![学生使用不同材料完成共同活动，老师在桌边支持。](./hero.webp)

同一个目标对不同学生的困难点可能不同。这个分组关注你如何根据当下需要调整例子、材料、任务或协助方式，同时给不同学生保留参与和进步的机会。

## 怎样读结果

这个分组有 6 道频次题。汇总按每题列出原版七种选项的人数和比例，分母为该题已有有效选择的人数。未作答、未显示和拒答分别记录。没有有效选择时，留空比例。

一项做法出现得少，可能与课时、任务、教学阶段或资源有关。可以先找出值得讨论的一项做法，再对照课堂观察或学生作品理解背景。教师自报频次只说明这次记录到的实践，无法替代学生的实际学习经历。

## 下次试一件小事

从近期一次活动找出一个参与障碍，只调整一处支持，例如加一个图示、分步提示或替代表达方式。观察谁更容易开始以及是否仍有人需要其他入口。不要用一次表现固定分组。

## 题本与适用范围

对应 2023 年 Dierendonck 补充材料 S1 的作者英译题文和七级频次选项，题项按 S5 最终分组，原题号 8、16、17、38、43、44。图文为项目原创，供成年教师自我反思。研究以法文施测，独立英文分组的测量等值尚未建立。本导读只展示逐题类别结果，不计算 ESEM 因素分数、教学质量分或综合排名。
