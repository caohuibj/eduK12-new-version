# COPSOQ III 中国医疗 S1 · 身体暴力

![在员工休息区，一位同事向坐着的人询问是否需要帮助。](hero.webp)

安排清楚事后支持的路径

频次和来源分别描述工作场所身体暴力的自报经历。相同频次的事件也可能需要不同的医疗或安全支持，类别分布无法判定个人的伤害程度。

## 报告怎样读

- 以选出 S1 五档之一的人数为频次分母。保留每天、每周、每月一次、数次和不是的原顺序。拒答和未答单列。
- 四种肯定频次触发来源题。来源以至少选择一个有效类别的受访者为分母，一人可选多类。未显示、显示后未选择和明确拒答分别记录。
- 按原类别分别报告，不合成总分。对外仅共享不可识别个人的汇总资料。

## 可考虑的下一步

整理现场安全、医疗协助与事后支持的联系人和保密步骤。开展复盘时，由当事人决定是否由信任的人陪同。

## 版本与出处

适用于成年医疗工作者的非商业研究。公开附件 S1 中文原题分项，独立于论文最后施测的 89 题版。

S1 中文题干见 PDF 第 10 页，中文选项见第 15 页。采用同主题原创插画，中文报告为独立编写。
