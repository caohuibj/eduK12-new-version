# COPSOQ III 中国医疗 S1 · 不愉快的取笑

![一位同事在长椅上留出位置，邀请另一位同事坐下来谈。](hero.webp)

留意当事人感到不愉快的经历

取笑可能发生在非正式交流或交班中。理解当事人的体验，有助于讨论哪些团队交流方式需要改进。发生频次和来源类别分别回答不同的问题。

## 报告怎样读

- 以选出 S1 五档之一的人数为频次分母。保留每天、每周、每月一次、数次和不是的原顺序。拒答和未答单列。
- 四种肯定频次触发来源题。来源以至少选择一个有效类别的受访者为分母，一人可选多类。未显示、显示后未选择和明确拒答分别记录。
- 按原类别分别报告，不合成总分。对外仅共享不可识别个人的汇总资料。

## 可考虑的下一步

科室可以先约定如何提出停止请求和反馈不适。讨论采用去身份的例子，让有过相关经历的人自行决定是否分享。

## 版本与出处

适用于成年医疗工作者的非商业研究。公开附件 S1 中文原题分项，独立于论文最后施测的 89 题版。

S1 中文题干见 PDF 第 9、10 页，中文选项见第 15 页。采用同主题原创插画，中文报告为独立编写。
