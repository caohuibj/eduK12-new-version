# COPSOQ III 中国医疗 S1 · 冲突和争吵

![三位同事在桌边一起梳理争议经过。](hero.webp)

先看分歧出现在哪项工作

这道题记录卷入冲突或争吵的频次。排班、交接与信息传递都可以是进一步核对的方向。单题回答无法说明冲突起因和责任。

## 报告怎样读

- 以选出 S1 五档之一的人数为频次分母。保留每天、每周、每月一次、数次和不是的原顺序。拒答和未答单列。
- 本条原版只设频次题，报告保持一张分类频次表。
- 按原类别分别报告，不合成总分。对外仅共享不可识别个人的汇总资料。

## 可考虑的下一步

可选一个容易产生分歧的工作接口，梳理什么时候交接、由谁确认以及意见不一致时怎样协调。

## 版本与出处

适用于成年医疗工作者的非商业研究。公开附件 S1 中文原题分项，独立于论文最后施测的 89 题版。

S1 中文题干见 PDF 第 9 页，中文选项见第 15 页。采用同主题原创插画，中文报告为独立编写。
