# COPSOQ III 中国医疗 S1 · 欺凌

![两位同事私下交谈，桌上放着梳理时间的纸卡。](hero.webp)

把过去一年的经历和另一道频次题分开看

BU1 涵盖过去一年的欺凌经历，BU3 询问有过经历时涉及的关系，BU2 则独立询问不公正批评、欺凌或当众揭短。三部分分别报告。

## 报告怎样读

- 以选出 S1 五档之一的人数为频次分母。保留每天、每周、每月一次、数次和不是的原顺序。拒答和未答单列。
- 四种肯定频次触发来源题。来源以至少选择一个有效类别的受访者为分母，一人可选多类。未显示、显示后未选择和明确拒答分别记录。
- BU2 独立显示，保留 S1 五档及「我没有领导/同事」。按 S1 第 16 页脚注，此项不适用类别作为结构性缺失，有效频次分母排除该类别。
- 按原类别分别报告，不合成总分。对外仅共享不可识别个人的汇总资料。

## 可考虑的下一步

可先检查工作中反复发生的困扰是否有安全的记录和求助方式。BU2 无领导或同事的类别记为不适用，独立保留。

## 版本与出处

适用于成年医疗工作者的非商业研究。公开附件 S1 中文原题分项，独立于论文最后施测的 89 题版。

S1 中文题干见 PDF 第 11 页，中文选项见第 15 页。BU2 可选缺失档另见第 16 页开头。采用同主题原创插画，中文报告为独立编写。
