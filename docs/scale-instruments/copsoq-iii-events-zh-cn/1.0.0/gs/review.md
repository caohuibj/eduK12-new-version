# COPSOQ III 中国医疗 S1 · 流言和诽谤

![一位成年人在工作场所的桌边写下自己的观察。](hero.webp)

把可核实的事实和传闻分开

交班群或科室讨论里，一句话有时会被反复转述。此题只记录医疗工作场所中流言和诽谤的频次，并在有经历时了解相关角色。

## 报告怎样读

- 以选出 S1 五档之一的人数为频次分母。保留每天、每周、每月一次、数次和不是的原顺序。拒答和未答单列。
- 四种肯定频次触发来源题。来源以至少选择一个有效类别的受访者为分母，一人可选多类。未显示、显示后未选择和明确拒答分别记录。
- 按原类别分别报告，不合成总分。对外仅共享不可识别个人的汇总资料。

## 可考虑的下一步

复盘沟通渠道时，把可核实的事实、转述和实际影响分开。进一步核实时，用能保护参与者的流程，避免在例会上追问个人身份。

## 版本与出处

适用于成年医疗工作者的非商业研究。公开附件 S1 中文原题分项，独立于论文最后施测的 89 题版。

S1 中文题干见 PDF 第 9 页，中文选项见第 15 页。采用同主题原创插画，中文报告为独立编写。
