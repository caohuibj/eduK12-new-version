# 俄勒冈职业兴趣量表（ORVIS，92题中文工作译稿）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## 所有示例共同的限制说明

- 这份中文题本是尚未验证的工作译稿。结果只整理这一次的兴趣自述，不测能力、人格好坏或职业适配，也不能决定选科、升学、录用、晋升或职业资格。兴趣会随体验与环境改变。
- 研究样本为美国社区成人及加拿大大学新生；不外推为中国常模或中小学生适用性证据。
- 八个维度分别看，没有总分、阈值、常模百分位或职业适配率；均分使用原1–5喜欢程度单位，不能当能力排名。
- 原文没有明确缺失算法；本项目要求92题完整才生成可解释画像，不用中立替代不知道/没回答。
- 部分北美职业名称和情境尚未本地文化适配；陌生并不意味着不适合，也不要求为了算分而猜答。

完整结果字段见report-example.json；本MD仅文字摘要。
