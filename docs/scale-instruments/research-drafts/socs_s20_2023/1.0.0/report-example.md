## 识别自己的痛苦

这部分关注你是否能留意到自己的痛苦，例如察觉情绪变沉、发现自己正在勉强支撑，或认出不舒服刚出现时的迹象。能否注意到这些变化会受到当时的忙碌程度和处境影响，回答并不评价你是否足够敏感或坚强。你可以回想最近一个不太顺利的时刻，看看自己是在什么时候发现难受的。下次有类似感觉时，先用一个简单的词描述它，给自己留一点辨认需要的时间。

- 最近你在什么时候注意到自己有些难受？
- 用一个简单的词描述当时的感受。

## 理解痛苦是共同经历

这部分关注你是否理解，痛苦、失落与不顺利也是许多人会经历的事情。想到这一点，有时能让人少一些孤立感，但每个人的处境和所需支持仍然不同，不必用“别人也这样”来压下自己的感受。可以回想一次你觉得只有自己遇到困难的时候，看看有没有可信任的人也分享过相似经历。下一次感到孤单时，试着对自己说一句承认困难的话，再决定是否愿意向合适的人寻求理解。

- 有没有一种经历让你觉得自己并不孤单？
- 先承认困难，再考虑向合适的人寻求理解。

## 关怀受苦的自己

这部分关注当你遇到困难或对自己失望时，是否仍愿意以关心和温和的态度回应自己。有时善待自己很自然，有时却很难做到，这些回答只是整理你描述的回应方式，不是给你的品格打分。你可以想一想，如果一个你关心的人正经历类似处境，你会怎样和他说话。下次发现自己责备自己时，试着换一句既承认问题、又给自己留有照顾空间的话，看看这样的说法是否适合当时的你。

- 如果是你关心的人遇到同样的事，你会怎样回应？
- 尝试用一句温和而实际的话回应自己。

## 容纳不舒服的感受

这部分关注面对难受的情绪时，你是否愿意让感受存在，同时保留一点选择怎样回应的空间。容纳情绪并不要求你独自忍耐所有困难，也不代表情绪应该马上消失。不同情境下，暂停、休息或寻求支持都可能合适。可以回想一次情绪出现却没有完全带着你走的经历，看看当时什么帮助了你。下一次有轻微不安时，先辨认感受，再选择一件眼前能够做到的、照顾自己的小事。

- 什么帮助你在情绪出现时保留一点选择空间？
- 辨认感受后，选择一件能照顾自己的小事。

## 采取行动照顾自己

这部分关注当自己痛苦或遇到困难时，你是否尝试采取行动照顾自己。这样的行动可以很小，例如休息片刻、减少一个不必要的负担，或向合适的人说明自己的需要，不要求你立刻解决困难的原因。回答会受到现实条件影响，并不衡量你是否已经把一切处理好。可以想一想，最近什么事情让你稍微好受一点。下次遇到相似处境时，选一个可行的小行动，做完后再看看是否需要调整或求助。

- 最近哪一件小事让你稍微好受一些？
- 选一个可行的小行动，做完后看看是否需要调整。
