# 教师主观幸福感问卷（TSWQ，中文工作稿）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## minimum

### 在学校有没有“自己人”的感觉

这里关注你是否觉得被接纳、被关心、被尊重，以及能否自在地做自己。它不是受欢迎程度排名。例如，遇到难题时是否有人愿意听你说，表达不同意见时能否仍被尊重。一次不顺利的互动不能代表整个月，也不应让一个结果定义你与学校的关系。这是一张观察近况的便条，不是给自己贴标签的结论。

- 在学校里，谁或哪种场景最让你感到被支持？还有哪种支持你希望获得？
- 选一位可信同事，从一次简短交流开始，具体说说最近需要什么帮助。

### 你对自己教学的信心与成就感

这里记录的是你自己感受到的教学信心与成就，不是对实际教学质量的考试。忙碌时期信心变化也很常见。例如，一次讲解终于让学生明白，或一个尝试暂时没有达到预期，都可能影响当下的信心。可以回看具体经历，同时留意教学资源与同伴支持，而不是把感受当成绩。这是一张观察近况的便条，不是给自己贴标签的结论。

- 过去一个月，有没有一个学生理解了新内容、一次互动更顺畅的小片段？
- 记下一件具体有效的小做法，下周有机会再试一次；需要时与同伴讨论教学支持。

### 这个月的教师生活，感觉怎么样

把归属感与教学信心放在一起，帮助你回顾这个月的工作体验。两部分值得分别看，不能只用一个数字定义自己。例如，你可能对教学很有成就感，却仍希望在学校里得到更多支持；也可能归属感不错，但最近教学遇到了挑战。分开观察这两部分，比寻找一条及格线更有帮助。这是一张观察近况的便条，不是给自己贴标签的结论。

- 你更想先改善支持感，还是找回教学中的小成就？
- 只选一个可以改变的小环节，过一段时间再回顾它对自己的影响。

这是一份待人工审校的中文工作稿，不是临床诊断，不评价教师能力，不用于绩效问责、录用或学校排名。结果反映这次自述体验；中文分数不能自动与国外样本比较。
