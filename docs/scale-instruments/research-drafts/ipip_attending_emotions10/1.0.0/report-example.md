## 情绪关注：你会不会留意心里的变化

这一项关注你是否留意、思考自己的情绪。分数越高，表示这次更认可关注情绪的描述。它有点像注意到心里的“天气”正在变化，但不测你能否把天气变晴。关注得多，不一定调节得更好；关注得少，也不能直接说能力不足。

- 回想最近一次情绪变化：你先注意到身体的感觉、脑中的想法，还是想做某件事的冲动？
- 用一个词给当下感受命名，如“有些紧张”或“有点期待”，再把注意力带回眼前的一件小事。不必追着每种情绪反复分析。
