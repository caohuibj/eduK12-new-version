# IPIP消极情绪表达10题（研究译稿）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## 阅读前的限制说明（本包所有示例共用）

- 中文研究译稿尚待人工审校与目标人群验证，目前仅供成人研究与自我了解。
- 习惯、文化、关系安全感和具体场合都会影响表达。这个中文工作译稿尚待审核与验证，没有诊断分界值，也不能据此判断情绪控制能力。
- 目前没有依据划分高低或人群排名；原英文研究的数据不是本中文版本的效度证明。
- 10题需完整回答；漏答不当作零分，也不代填。

以下为实际结果的文字摘要；完整质量、分数与限制字段见同目录 report-example.json。

## midpoint

### 消极情绪的外在表达：从日常经历看自己的习惯

这份回答关注的是：难过、害怕或生气时，别人有多容易看见你的感受。它不是在判断你是不是“情绪不好的人”。计分方向越高，表示这些感受越容易通过表情或行动流露；越少外露，也不等于更平静或更会调节。表达得多或少都没有统一的好坏答案。

- 想想最近一次不开心：你想让别人理解什么？你实际表达出来的内容，和心里想说的一样吗？
- 可以试着把“你怎么总这样”换成“刚才发生这件事时，我有些生气，我希望……”。表达感受不等于吼叫、威胁或伤害别人；情绪很强时，先暂停一下也可以。

仅供成人研究和描述性自我了解，不用于心理诊断、能力鉴定或高风险决策。
