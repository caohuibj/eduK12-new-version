# 父母养育倦怠评估（PBA-23，2018版中文工作稿）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## minimum

### 养育中的疲惫与消耗

下面的例子不表示你已有这些感受；若与你不符，可以跳过建议，保留现有的支持。关注照顾孩子时的疲惫、难恢复，以及只能靠惯性撑着的感受。它不是勤奋或责任心的证明。例如，日常照顾还没开始就觉得电量见底，休息后也不容易恢复。这提醒你看看任务和支持是否失衡，而不是要求你证明自己还能撑多久。它只整理这次自述体验，不能单凭结果判断原因或给自己贴标签。

- 如果照顾孩子让你感到消耗，哪一件日常任务最费力？有没有一件可以暂时减量或请人接手？
- 如果你需要分担，可以把一个具体任务交给愿意协助的成年人，例如今天的一次接送，让自己有一段真正不用负责的休息。

### 你是否觉得，自己不像从前那个父母了？

下面的例子不表示你已有这些感受；若与你不符，可以跳过建议，保留现有的支持。关注你对过去和现在的自己的感受差异。这些自我评价可能很严厉，但不是对你真实价值的裁决。例如，发现自己不再像从前那样耐心时，可能会把变化全归咎于自己。可以同时看看睡眠、工作、家庭分工与可获得的帮助，不必把暂时的处境等同于个人价值。它只整理这次自述体验，不能单凭结果判断原因或给自己贴标签。

- 如果一位朋友处于同样处境，你会怎样对他说？那句话也可以留给自己。
- 记下一个你仍在努力的小事实，不要求把它变成“正能量”；再向可信的人说出一项实际需要。

### 养育中难以承受的感受

下面的例子不表示你已有这些感受；若与你不符，可以跳过建议，保留现有的支持。关注难以承受、难以应付，以及和孩子相处时快乐变少的体验。承认这种感受，不等于不爱孩子。例如，原本能应付的小事如今也让你难以承受，和孩子相处时轻松的时刻变少。如果你有这些感受，它们值得被听见，但问卷不能据此判定你会做什么，也不是一份好父母或坏父母的裁决。它只整理这次自述体验，不能单凭结果判断原因或给自己贴标签。

- 如果你正感到难以承受，此刻最需要减少的是任务、冲突，还是一个人承担的时间？
- 如果你有“我受不了了”的感受，可以把它翻译成一个具体求助：“今晚能否由你照顾孩子一小时？”如果这种感觉持续，可以安排专业支持。

### 日常照顾之外，亲近变难了吗？

下面的例子不表示你已有这些感受；若与你不符，可以跳过建议，保留现有的支持。关注是否只够完成必要事务、很难再表达爱意。这记录的是当下可用的情感精力，不是亲子关系的最终结论。例如，接送、吃饭和睡前安排还能完成，但额外聊天或表达亲近变得费力。可以先关心自己是否有足够的恢复与分担，而不是逼迫自己立刻表现得更热情。它只整理这次自述体验，不能单凭结果判断原因或给自己贴标签。

- 在不勉强自己的前提下，什么样的小互动还比较轻松？
- 如果你愿意，尝试一次低负担的连接，例如一起安静坐一会儿；不必完成一场“完美陪伴”。若连这也困难，先找人帮你休息。

### 整体看看养育中的消耗

下面的例子不表示你已有这些感受；若与你不符，可以跳过建议，保留现有的支持。这四个角度合起来描述你的养育体验，不是诊断，也不是养育能力总分。不同维度题数不同，不直接比较原始分数大小。有时，最先需要改变的不是再学一条育儿技巧，而是让负担真正有人分担。可以从具体生活场景寻找支持线索，低结果也不能证明所有困难都不存在，高结果同样不能替代专业了解。它只整理这次自述体验，不能单凭结果判断原因或给自己贴标签。

- 读完四个主题，哪一个最希望先得到支持？
- 只选一个最可行的小改变，和愿意帮助你的人商量。
- 感到耗竭不是道德缺点，也不必独自扛着。如果这些感受持续、影响睡眠和日常照顾，或让你很难承受，可以找可信的人分担，并向心理健康专业人员求助。若你担心当下无法保障自己或孩子的安全，请优先让可信的成年人协助照顾，并及时寻求当地紧急帮助。
