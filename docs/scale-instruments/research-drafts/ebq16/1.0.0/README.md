**工具：** `ebq16_zh_cn_research@1.0.0`，依据Becerra/Preece/Gross(2020)原文16题，严格保留交错顺序。原版为[CC BY4.0](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0231395)，简体中文题本和报告是独立平台工作稿，未经译审或中国成人验证。

**报告：** 源码定义中七项分数有对应的原始分数描述，不造百分位、临床切点、高低等级或可靠变化。每题须完整作答，译审、真实数据库与双入口使用均未运行。
