# 合成回答的实际报告样例

报告版本：1.0.3。此处正文直接来自实际buildScaleResult结果；合成回答不是个人真实测量，也不是带常模分档的个性化诊断。完整技术结果见[report-result.synthetic.json](report-result.synthetic.json)。

## 觉得不舒服情绪是否可以改变

难过、担心或生气的时候，有人会觉得“这种感觉一来就没办法了”，也有人相信情绪会随着行动和环境慢慢变化。这组回答关注你通常怎么看待这件事，并不是检查你最近有没有控制住情绪。想法可能来自过去的经历，也可能随着新的体验改变。你可以回想一次情绪稍微松动的时刻，看看当时的休息、谈话或处境变化，是否给了你一点帮助。

最近一次不舒服时，有什么事情让情绪逐渐发生变化？

可以先给感受命名，再选择休息、沟通或做一件小事，不必强迫它消失。

## 觉得愉快情绪是否可以改变

开心、轻松或满足的感觉，有时来得自然，有时也会随着一天的经历起起落落。这组回答关注你认为这些感受是否能够发生变化，并不是在问你最近有多快乐。快乐不需要时时保持，暂时没有好心情也不是失败。可以留意一个让自己稍微舒服的日常片段，例如散步、听歌或和熟悉的人说说话，再看看什么条件让这样的片段更容易出现。

一次开心的时刻是怎样出现又自然变化的？

允许愉快情绪自然起伏，不把一直开心当成任务。

## 觉得不舒服情绪是否有用

不舒服的情绪有时像一盏提醒灯，让我们注意到一件在意的事、一个没有满足的需要，或一处需要调整的地方。这组回答关注你是否觉得这些情绪也可能有作用。看到作用，不代表必须喜欢难受，更不代表要一直忍着。你可以挑一个最近的感受，轻轻问自己：它在提醒我什么？有没有一个照顾自己的小行动，是现在就能尝试的？

哪次负面情绪曾让你注意到自己需要什么？

尝试询问“这份感受想提醒我什么”，但不必遵从每一个冲动。

## 觉得愉快情绪是否有用

高兴、愉悦或满足，有时会让人更愿意靠近他人、尝试一件事，或停下来享受当下。这组回答关注你怎样理解这些感受的作用。它们并不是越多越好，也不是只有开心才算生活得好。不同的情境里，感受可能带来不同的信息。可以回想一次让你觉得有意义的愉快经历，看看它帮助你注意到了什么，以及你是否愿意为类似的片段留一点空间。

积极情绪何时帮助你休息、联结或继续做事？

留意生活中一件带来满足的小事，不用靠问卷证明它有价值。

## 对情绪可调节性的整体看法

这一部分把你对不同情绪能否改变的看法放在一起。它记录的是一种看法，而不是实际调节情绪的成功率。相信情绪可能变化，不等于必须立刻把它赶走；觉得某种感觉难改变，也不等于自己不够努力。你可以先看看眼前有哪些可以调整的小条件，例如睡一会儿、换个环境，或找一个愿意听你说话的人，再慢慢观察自己的体验。

有没有哪种情绪你曾觉得永远不会改变，后来却出现了变化？

选择一种负担小、环境允许的应对办法，不将情绪变化速度当作成绩。

## 对情绪是否有用的整体看法

这一部分关注你怎样理解不同情绪在生活中的作用。舒服和不舒服的感受，都可能在某些时候传递信息，也都可能让人有些困惑。没有必要急着给情绪分成“有用”和“没用”两堆。可以回想最近的一件事，看看某种感受有没有让你更清楚自己在意什么，或者提醒你需要休息、沟通或改变做法。理解自己的体验，比给它打一个好坏标签更有帮助。

同一种情绪在不同情境中可能有什么不同作用？

区分感受发出的信号与实际要采取的行动，允许自己慢慢判断。

## 整体情绪信念

把这些回答放在一起，可以看看你通常怎样理解情绪：它会不会改变，又可能给生活带来什么。这不是一张情绪能力成绩单，也不是对最近心情的判断。你不需要追求某个数字，更不必要求自己随时积极。可以把情绪想成提示灯，先看看它提醒了什么，再决定怎样回应。留意一条愿意重新想想的看法，从一个贴近日常的小体验开始就可以了。

选择一条最犹豫的题目：哪些经验塑造了你的看法？

可以记一次情绪随着事情进展的变化，只观察，不要求分数提高。
