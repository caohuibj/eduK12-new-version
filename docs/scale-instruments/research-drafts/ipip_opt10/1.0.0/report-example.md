## 乐观倾向：你怎样看待眼前与未来

这一项关注你对未来、生活积极面和自身状态的看法。分数越高，表示这次回答更偏向积极预期。期待与担忧可以同时存在，例如，盼着一件事有好结果，也为可能的困难做准备。报告不要求你一直积极，也不能用来判断是否抑郁。

- 想一件你正在期待或担心的事：哪些判断有事实支持，哪些还只是暂时的猜想？
- 把这件事分成两栏：“我能做一点什么”和“暂时不由我决定什么”。从第一栏选一个小行动，第二栏可以先留着，不急着想通一切。
