# 总体生活满意度简表（1题）（中文研究译稿）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## minimum

### 给近来的生活拍一张“全景照”

这道题记录的是您此刻对整段生活的总体感受，不是对人生是否成功的判决。不同生活领域可能一边顺利、一边吃力，一句话并不能说完所有经历。选择越靠近“完全满意”，表示您这次对生活的总体评价越满意；这不是需要追求满分的考试。

- 最近哪件小事让您觉得生活还不错？
- 挑一个最在意的小方面，定下本周可以完成的一步，例如留出十分钟休息或与信任的人聊聊。过段时间再回看感受，不必追着数字跑。
