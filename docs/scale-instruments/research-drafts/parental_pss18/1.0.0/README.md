# PSS-18｜亲职压力18题独立简体中文研究工作稿1.0.0

## 准确工具与原题本
Berry & Jones（1995）的Parental Stress Scale 18题，不是Cohen的Perceived Stress Scale，不能借用后者PSS10的十题、计分和参照值。权威正式原表与计分：https://www.corc.uk.net/media/2764/parent-stress-scale-fillable-pdf.pdf（1–3页施测表及第4页反向计分）。

请父母或照护者回想与自己的孩子通常的关系；可以针对一名孩子，或对多个孩子整体作答，但在同次施测中应保持明确参照对象。不是孩子本人施测；CORC没有将孩子年龄限定在某一个狭窄年龄组，适用策略只要求PARENT作答者。技术身份还需实际核查其照护关系。

## 作者定义的唯一总分
- 原始选项1–5：非常不同意、不同意、不确定、同意、非常同意。
- 正向亲职满足/关爱原题号 **1、2、5、6、7、8、17、18** 在求和前按6−原分反向；其他10题保留原分。
- 18题求和理论18–90，较高表示更多报告亲职角色压力；不生成未经确认的分维，不贴“合格家长”、临床轻中重/诊断/中国常模。
- 完整18题才计算总分；缺题返回null、不插补，为本站保守工作稿策略，非作者原版正式缺失值方法。
