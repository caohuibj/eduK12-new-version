## 共感愉悦：别人的开心会怎样传到你这里

这一项关注你在别人开心、庆祝时，是否也感受到愉快。分数越高，表示这次更认可被他人的快乐感染的描述。有的人会一起欢呼，有的人会安静地听完好消息；外在反应与内心感受也未必一样。分数不能判断你是否关心别人，更不代表整体共情或照顾能力。

- 最近有人向你分享好消息时，你心里有什么反应？你怎样让对方知道自己听见了？
- 下次听到好消息，可以问一句：“哪一部分让你最开心？”给对方一点继续分享的空间，不需要勉强自己表现出同样强烈的情绪。
