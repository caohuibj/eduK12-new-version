# 哥本哈根倦怠量表（CBI，中文工作稿）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## minimum

### 整体的身体与情绪疲惫

关注的不只是上班累不累，也包括整体的身体和情绪疲惫。它不会告诉你疲惫一定来自哪里。例如，一天还没结束就觉得精力见底，或明明停下来了，身心仍难以恢复。它提醒你关注恢复条件，但不能单凭这些回答确定原因。这是一张观察近况的便条，不是给自己贴标签的结论。

- 最近哪些时段最容易没电？休息后是否稍有恢复？
- 选一个最容易坚持的恢复时段，先保护十分钟；若疲惫持续或影响生活，可寻求专业评估。

### 工作带来的消耗

看看工作是否正在挤占恢复空间。感到耗竭不等于你不够努力，也不等于教学能力差。例如，下班后脑子仍被工作占满，原本留给生活的力气所剩不多。可以把任务量、可支配时间和可获得的支持一起考虑，而不只要求自己再努力一点。这是一张观察近况的便条，不是给自己贴标签的结论。

- 最消耗你的，是任务量、节奏，还是总要保持在线？
- 记录一项最消耗精力的工作，与可信同事或负责人商量减量、调整优先级或增加支持。

### 与服务对象互动时的消耗

长期面对他人的需求也会消耗精力。这描述互动体验，不是在评价学生或责怪任何人。例如，连续回应学生或其他服务对象的需求后，会格外需要安静和休息。这种体验不等于你不关心他们，关注互动中的支持条件往往更有帮助。这是一张观察近况的便条，不是给自己贴标签的结论。

- 哪些互动后你最需要缓一缓？什么支持能让你更好地恢复？
- 尝试在高负荷互动后留一个短暂停顿，并讨论可获得的同伴支持与合理边界。

这是一份待人工审校的中文工作稿，不是临床诊断，不评价教师能力，不用于绩效问责、录用或学校排名。结果反映这次自述体验；中文分数不能自动与国外样本比较。
