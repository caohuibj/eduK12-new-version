## 证据不等价

- 研究实际施测语言：日语；Table 1 英文为作者发表的表述；现中文为平台工作稿，不是日本研究的直接受试题本，也非已有验证中文版本。
- 原样本日本成年人20–98岁N=4000，不能把作者的内部一致性/结构效度机械称为中国或K12已验证。
- 无可靠原始中文常模、诊断界值/ROC、百分位或最小临床重要变化的可直接适用证据，运行 ReferenceSet 留空。
