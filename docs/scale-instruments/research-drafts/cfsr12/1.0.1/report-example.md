# 合成回答的实际报告样例

报告版本：1.0.2。此处正文直接来自实际buildScaleResult结果；合成回答不是个人真实测量，也不是带常模分档的个性化诊断。完整技术结果见[report-result.synthetic.json](report-result.synthetic.json)。

## 停止无效的应对办法

压力下，我们有时会反复使用同一个办法，即使它已经不太管用。这组回答关注你能否察觉这种情况，并停下来换个做法。就像钥匙打不开门时，可以试试另一把，换的是办法，并不等于放弃想做成的事情。现实中的时间、精力和支持也会影响选择。你可以回想最近一次卡住的经历：继续重复原来的办法，究竟是在帮忙，还是让自己更累了？

回想最近一次事情没按计划发展：你有没有发现某个办法越来越不管用？是什么迹象让你察觉到的？

可以先问自己“继续做同一件事有帮助吗？”如果没有，再选择一个负担较小的调整，不要求立刻放弃正在努力的目标。

## 在受阻时尝试其他办法

原来的办法没有带来变化时，能想到另一条路，有时会让人多一点选择。这组回答关注你会不会寻找和尝试别的应对办法。换办法不一定要大刀阔斧，也可以只是把一件事拆小、换个时间做，或找人一起想想。疲惫和现实限制都可能让变通变难，不必因此责备自己。可以先想一个负担较小的调整，再观察它是否更适合眼前的情况。

最近遇到的一个难题，还有哪些没试过的做法？有没有一种办法需要别人提供信息或帮助才能实行？

下次遇到卡住的事情时，可以先写出两个可选择的小步骤，评估各自所需的时间与支持，再选一个适合当下条件的。

## 觉察应对办法是否奏效

我们常常需要回头看一眼，才知道自己刚才做的事情有没有帮助。这组回答关注你是否会留意应对的效果，以及自己究竟想改善什么。它更像给行动留一个回看点，而不是要求你每次都立刻找到正确答案。有些改变需要时间，也有些难题需要外界支持。你可以为最近的一项行动想一个看得见的小目标，过些时候再看看，哪些地方有变化、哪些地方还需要帮助。

你通常怎样知道自己采取的做法是否有效？有没有一些短期看不出变化、需要更长时间观察的事情？

可以给一项应对行动设一个可观察的小目标，过一段时间回看，而不是只看自己当时有没有紧张或难过。

## 阅读边界

- 这份结果整理的是你对自己习惯或看法的描述，不能代替对实际生活情况的了解。
- 中文题目为平台工作译稿，目前不适合用来给人与人之间排高低。
- 不能单凭这份结果判断疾病、能力或一个人的价值。
- 没有回答的题目不会自动算成最低分；信息不足时，相关结果会提示无法解释。

用于成年人的自我了解与日常反思，不是考试，也不能用于诊断。中文为平台工作译稿。
