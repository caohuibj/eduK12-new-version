# 单一总和与无常模参数

最终5项对应原论文Table1作者加粗的1/4/5/8/9，平台重编号为BPSES_01–05。每题原同意度值1–5、等权、identity，无反向；总分=五个原值之和，范围5–25，不改为均分。不输出Knowledge/Ability/Outcome三个分量表。

公式事实由原作者指定的CORC目录明确“sum all five items”与原论文最终五题范围5–25核对。原论文Methods中的三个triad求和是初始9项，不能冒称最终5项公式原句；初始反向3/6/7已全部删除。

原作者未指定个人缺答处理。本项目保守采用complete_required，缺一题则total=null，不补零、不插补、不改变分母。研究的EM与pairwise分析不是个人施测协议。

无临床cutoff或可绑定中国常模：referencePolicy=none，references=[]，report为score_only且bands=[]。原样本平均/理论中点均不是人群界值。参数计划文档独立1.0.0，但当前none运行结构不提供参数version身份，不能虚构runtime独立参数版本。
