## 理解自己引导孩子行为的信心

这五个回答整理你对引导孩子行为的信心，包括是否觉得自己知道该怎么做、能否付诸行动，以及相信自己的做法能够带来影响。这是你对自身的描述，不能凭此判断实际教养能力，也不能把孩子的表现归因于家长是否足够有信心。压力、支持条件和孩子当时的需要，都可能影响回答。可以回想一次相处较顺利的场景，留意当时你做了什么、有哪些支持。若你愿意，下次选一件可掌握的小事，例如在平静时用一句简短的话说明一项约定，再观察它是否适合你们；遇到困难时也可以和可信任的人商量。
