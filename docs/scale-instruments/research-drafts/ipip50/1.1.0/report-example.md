# 本地合成报告示例（报告版1.0.1）

- 宜人性：30（可取10–50，不是人群等级）
- 尽责性：30（可取10–50，不是人群等级）

## 外向性：你怎样参与人际互动

这一项关注你在交谈、聚会和受到关注时的习惯。分数越高，表示这次回答更接近主动交谈、积极参与社交的描述。喜欢热闹、偏爱安静，或在不同场合切换，都可以结合自己的生活来理解。不必把自己固定归为某一种人。面对喜欢的话题，你也可能比平时更愿意开口。

- 回想一次让你自在的相处：是很多人一起聊，还是和熟悉的人慢慢聊？换一个场合，你的表现会有什么不同？
- 下一次交流时，选一种你愿意尝试的参与方式：主动问一个问题，或留出一段安静倾听的时间。观察哪种节奏更适合当时的你。

## 宜人性：你怎样留意他人的感受

这一项关注你对他人感受、需要和关系的关注。分数越高，表示这次回答更认可关心、体谅他人的描述。理解别人和表达自己的需要可以同时发生。分数不能评定一个人的善良程度，不把分数当作固定标签。例如，意见不同时，可以既听见对方，也说清自己的边界。

- 最近一次意见不同时，你注意到了对方的什么需要？你自己的需要有没有被说出来？
- 找一次低压力的交流，先确认对方的意思，再补充自己的需要，例如：“我听到你在意的是……我也希望……”。

## 尽责性：你怎样把事情安排好

这一项关注准备、秩序和完成事情的习惯。分数越高，表示这次回答更认可有准备、有条理的描述。比如，出门前核对物品、开始任务前列个清单，都可能与这些习惯有关。忙碌程度和可用资源也会影响表现，分数不能用来判定你是否可靠。

- 想一件最近顺利完成的事：是提前准备、清楚的步骤，还是别人提供的支持帮了你？
- 给手头一件事写下“下一步做什么”和“做到哪里就算完成”。先试一次，再按实际情况调整，不必把每件小事都变成计划。

## 情绪稳定性：压力来时，你怎样感受

这一项关注平时的担忧、紧张和情绪变化。分数越高，表示这次较少认可题目中的紧张、担忧等描述。它记录的是你的自我感受，不能判断是否存在心理困扰。请把分数和真实处境放在一起看，不必要求自己始终平静。赶进度和休息充分的时候，感受也可能很不一样。

- 最近一次压力出现时，最先让你注意到它的是什么：身体感觉、反复的念头，还是行为上的变化？
- 为一次压力情境记下三件事：发生了什么、我有什么感受、什么支持可能有帮助。若困扰持续影响生活，可以寻求专业支持。

## 智性／想象力：你怎样与新想法相遇

这一项关注你对观念、思考、语言和想象活动的兴趣与自我感受。分数越高，表示这次更认可相关描述。比如，对一个问题继续追问“还有别的解释吗”，就是可供回想的日常情境。它不测智商，也不评定学习潜力。阅读故事、动手尝试或讨论点子，都可能是探索的方式。

- 最近有什么问题、故事或点子让你愿意多想一会儿？你更喜欢抽象讨论，还是从具体例子出发？
- 选一个有点好奇的问题，找一个新例子或不同解释。给自己几分钟探索，看看兴趣在哪里，不把它变成必须完成的挑战。
