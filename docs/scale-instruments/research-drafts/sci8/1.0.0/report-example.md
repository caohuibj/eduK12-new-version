# 本地合成报告示例

- 最近的睡眠状况：16（理论范围 0–32；不是常模等级）

## 最近，睡眠怎样影响了你？

这些回答把过去一个月的入睡、夜间醒来、睡眠感受和白天生活放在一起看。分数越高，表示这次回答呈现的睡眠状况相对更好；它不是对作息自律的评分，也不能确定你是否有失眠障碍。比如，有人躺下很久才睡着，有人夜里醒后难再入睡，也有人主要感到白天精力不足。把最困扰自己的部分说清楚，比追求一个漂亮分数更有帮助；即使分数较高，真实的不舒服仍值得被认真对待。

- 过去一个月，最难受的是入睡、夜里醒来，还是白天受影响？有没有相对轻松的一晚，当时有什么不同？
- 可以简单记录几天的睡眠和白天感受。若困扰持续或明显影响生活、安全，可带着记录与专业人员讨论，不必等分数越过某条线。
