# IPIP他人痛苦情绪反应10题（研究译稿）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## 阅读前的限制说明（本包所有示例共用）

- 中文研究译稿尚待人工审校与目标人群验证，目前仅供成人研究与自我了解。
- 来源英文研究中，这组题回答的一致程度有限，因此更适合谨慎探索，不适合据此给个人贴标签或做重要决定。中文译稿尚待审核与验证，没有项目常模或诊断分界值。
- 目前没有依据划分高低或人群排名；原英文研究的数据不是本中文版本的效度证明。
- 10题需完整回答；漏答不当作零分，也不代填。

以下为实际结果的文字摘要；完整质量、分数与限制字段见同目录 report-example.json。

## midpoint

### 面对他人痛苦时的情绪反应：从日常经历看自己的习惯

这份回答像一张情绪观察便签：当你看到别人难过、动物受伤，或遇到紧张场面时，自己的心情会怎样跟着变化？计分方向越高，表示自己的情绪更容易被这些场景触动；保持平静不代表冷漠，容易难过也不自动代表更善良或更会帮助别人。

- 回想一次别人向你诉苦：你既听到了对方的需要，也留意到自己的感受了吗？你的反应是否让你更能陪伴对方？
- 下次听到难过的事情，可以先问一句“你希望我陪你听一听，还是一起想办法？”如果自己也被情绪淹没，允许短暂休息，再决定能提供什么帮助。

仅供成人研究和描述性自我了解，不用于心理诊断、能力鉴定或高风险决策。
