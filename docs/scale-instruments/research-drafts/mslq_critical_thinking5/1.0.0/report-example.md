不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## minimum

### 在“知道答案”之外，再问一步

这份简表关注在选定课程里，您是否会查看依据、比较解释，并发展自己的想法。它记录您报告的学习做法，不是智力或辩论能力测试。平均分越高，表示您在这门课中报告了更多这类做法。不同课程的教学方式、任务和熟悉程度都可能让回答不同，不宜把一次结果当成固定能力。比如读到一个结论时，顺手追问“依据是什么？”或者“有没有另一种解释？”，就是把知识拿来进一步思考。

- 回想这门课最近的一段材料：哪个观点让您信服？您依靠的是证据、例子，还是对说话者的信任？
- 选一个刚学到的结论，写下一条支持它的理由，再试着找一个可能的不同解释。暂时没有答案也没关系，可以把问题带到下一次讨论。
