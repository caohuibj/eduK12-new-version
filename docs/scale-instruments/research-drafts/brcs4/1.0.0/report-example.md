面对困难时的应对做法

这份回答整理的是你通常怎样面对困难：会不会尝试不同办法、怎样看待自己的反应，以及能否在损失之后寻找可做的事。现实中的压力大小、可用资源和身边的支持，都会影响这些做法能否用得上。有时先休息或向人求助，也是在照顾自己。可以选一件最近遇到的小困难，回想已经尝试过什么，再找一个自己承受得起的下一步。不必强迫自己立刻从困难中找到好处，也不用凭一次回答判断自己够不够坚强。

- 回想最近一件困难：哪些部分你能稍作改变，哪些部分需要时间、资源或他人的帮助？
- 把能做的部分写成一个很小的动作，例如先收集一条信息、尝试另一种办法，或联系一个能商量的人。
- 如果事情太重，可以先找可靠的人一起分担；不需要独自承担所有损失，也不必急着要求自己积极起来。

这份回答反映你当下对通常做法的看法，也会受到处境和可用支持的影响。
