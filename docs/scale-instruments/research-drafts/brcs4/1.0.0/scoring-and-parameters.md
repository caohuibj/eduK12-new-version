# 计分与参数

4题无反向、等权。每项1–5，求和4–20；更多表示本次自述更符合这些应对做法，不是生活压力的反向指标或稳定能力测定。五点形式/求和见2016原作者共同论文正文与2017正文；不是2016四档改编的0–3/0–4编码。

缺失：本平台保守complete_required，全4题才算；不填零、不把缺失当最低分、不按比例外推。该规则是平台选择，不宣称作者验证的缺失规则。无答或任一题缺失总分null且不出解释；非法/重复/未知答案拒绝。

参数决策（研究记录）1.0.0：`none`，不建/激活/绑定ReferenceSet；报告score_only，不分档。4–20是理论范围，12是算术中点，不是中国平均数/常模/经验阈值。第三方4–13/14–16/17–20分档、德国百分位与2016Rasch参数均不绑定，不做人与人排名。缺少真实本地常模不阻止DRAFT内容加工。

版本分离：instrumentVersion=1.0.0（题文/构念/响应身份），scoringVersion=1.0.0，localizationVersion=1.0.0，reportVersion=1.0.0。参数none当前无独立可执行version字段，只在本研究记录追溯parameter-decision 1.0.0；不改schema/引擎、不伪造独立参数轴已实现。指导语instructionVersion=1.0.0仅sidecar PREPARED。
