## 任务自我效能：遇到事情时，你有多少把握

这一项关注你对完成任务、判断情况和寻找办法的信心。分数越高，表示这次更认可“我能处理好”的描述。开始一件熟悉的事和面对全新任务时，把握可能不同。信心与实际能力有关，但并不相等；这个分数也不评价个人价值。

- 回想最近一次有把握完成的任务：信心来自经验、充分准备，还是知道可以向谁求助？
- 把一件想做的事拆出一个能开始的小步骤，并写下可能用到的信息或支持。做完后记录具体做法，给下一次留下可参考的经验。
