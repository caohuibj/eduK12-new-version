# DERS-16｜Bjureberg 2016 独立简体中文工作稿 1.0.0

## 精确版本
原论文：Bjureberg等（2016），https://pmc.ncbi.nlm.nih.gov/articles/PMC4882111/，其Appendix收录准确英文16题及原题号归属。不是另一个Kaufman DERS-SF18、不是Victor/Klonsky18题短式，也不是DERS36原版；**16题版没有觉察Awareness维度，全部题不反向计分**。

表中1–5为出现频率，并标出相应范围：
1 Almost never（0–10%）、2 Sometimes（11–35%）、3 About half the time（36–65%）、4 Most of the time（66–90%）、5 Almost always（91–100%）。
无固定最近一周回忆期，部分题强调情绪难受时。
