## minimum

### 过去两周紧张与担忧体验：了解近来的自己

这份记录关注过去两周的紧张、担忧和难以放松等感受。它描述这段时间的经历，不给你贴上人格或疾病标签。数值较高，表示这些问题在你的回答里出现得更频繁。它不能单独说明原因，也不等于诊断。可以想想：最近有没有一件已经处理完的小事，仍在脑海中反复盘旋，让你难以放松？具体场景比一个分数更有助于把困扰说清楚。

- 记下一件最近最影响生活的具体情形，以及当时需要什么帮助。
- 如果这些感受持续或影响工作、休息和关系，可以与合格专业人员讨论。
