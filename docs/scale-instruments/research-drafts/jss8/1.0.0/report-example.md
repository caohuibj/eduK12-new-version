### 自己处于不利位置

留意自己吃亏时，什么最容易触动您。在这个视角下，越同意题目，表示这次越认可自己会因这些不公平情境而受到触动。同一件事，站在吃亏的人、旁观的人、获益的人或做出行为的人位置上，感受可能不同。这份问卷帮您留意这些差别，不会把四种感受加成一个“人品分”。感受强烈不证明一定会采取行动，反应较轻也不能直接解释为不关心。
