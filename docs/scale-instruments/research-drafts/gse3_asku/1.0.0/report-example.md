## 应对困难的信心：非商业研究描述

这份小问卷关注的是：遇到难题时，你对“自己能想出办法”有多大信心。三道题的平均分在1到5之间；分数越高，表示你这次越认同自己能应对困难，并不是说实际能力一定更强。比如，接到一项没做过的任务，有人会先想“我可以试着拆成几步”，也有人会先想“我还需要更多准备”。这些想法都可能随经验、时间和支持而变化，没有必要据此给自己贴标签。目前这份中文工作译稿还缺少充分验证，所以不把你分成高、中、低，也不拿国外人群的平均分给你排名。

- 想想最近一次有点棘手、但最后处理好了的事情：你做了什么？有没有人或工具帮上忙？这些支持同样算数。
- 下次遇到难题时，不妨先列出“我已经会的”“我还需要的”和“今天能做的一小步”。这不是提高问卷分数的练习，而是给自己找一个更容易开始的入口。
