# 计分参数与阈值状态

| 参数 | 本包实现 | 依据/边界 |
|---|---|---|
| 作答 | 1–5，五个文字锚点 | 官方题本1436 p3 |
| 题数 | 3 | 官方原序，全部正向 |
| 反向项 | 无 | 不套用GSE10或C1键 |
| 合成 | 三题等权均值 | 文档1435 p4 |
| 有效范围 | 1–5 | 理论范围，不是常模 |
| 精度 | 内部不先舍入；显示最多2位小数 | 例1、2、2得到5/3，显示约1.67 |
| 缺失 | 任一题缺失不给均分，不补零 | 原文建议完整三题才合成；研究级缺失方法不在个人报告执行 |
| 临床阈值 | 未建立，不启用 | 未找到适用于本中文译稿的诊断界线 |
| 高低等级/百分位 | 不启用 | 3只是理论中点，不是判定线 |
| 外部样本 | UK n468，均值3.78、SD0.94；DE n474，均值3.99、SD0.67 | 英德18–69岁母语在线配额样本，仅出处记录，非中国/学生常模 |

来源：[官方文档](https://access.gesis.org/zis/1435)、[官方题本](https://access.gesis.org/zis/1436)。参数完整不意味着必须存在阈值；没有支持证据的阈值明确留空，不用量尺等分线或外国样本平均值代替。
