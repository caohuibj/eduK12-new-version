# 凯斯勒心理困扰量表（K6，作者官网普通话版）（研究呈现）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## minimum

### 过去30天困扰体验：了解近来的自己

这份小记录关注过去一个月里，紧张、沮丧和做事费劲等感受出现得有多频繁。它像一张近况快照，不是给你下结论，也不评价你是否坚强。数值越高，表示这些困扰在这次回答里出现得越频繁。它无法单独说明原因，也不能据此判断是否患病。可以回想最近一件平常的小事：它是否比以前更费力？是偶尔如此，还是常常如此？具体例子往往比分数更有助于理解自己。

- 记下一件最近最费劲的事，以及当时让你稍微轻松一点的条件。
- 如果困扰持续或妨碍日常生活，可以与可信赖的人或合格专业人员谈谈。
