# 计分与三个版本

内容/本地化：独立CHIME-S24中文工作稿1.0.0，计分scoringVersion=1.0.0，与英语S1相连、独立版本序列。参数：parameterPlanVersion=1.0.0，状态NONE_SCORE_ONLY；现有referencePolicy.type=none无独立parameter version字段，该差异只记录，不改引擎。报告：reportVersion=1.0.0。三轴不互相替代。

六点原值1–6；第8、9、22、23、24题反向x′=7−x，其余x′=x。按S1题序八维为1–3、4–6、7–9、10–12、13–15、16–18、19–21、22–24。每维D=Σx′/3；总分T=Σ全部24题x′/24。总分允许且与八维均分的均值相等（每维等题量）；不以求和或2023长版Rasch转换冒充本版计分。反向题“几乎从不”会变为6，不能把所有原值1当作全维最低。

原作者未说明漏答阈值。平台保守complete_required：某维三题缺一该维null，总分缺任一题null；完整其他维仍可计算，整体质量invalid且实际buildScaleResult抑制解释；这是引擎行为，不能将缺失当1或0，也不声称作者已验证此漏答策略。所有题可跳过用于如实保存漏答事实。非法值、未知题号、重复作答由引擎拒绝。

实际原始分1–6用于反思；无常模、临床阈值、高低级别或百分位；不复制外国分布到中国人群。score_only使每项解释无分段、无标签。经验开放反向聚合只描述自述倾向，不建议忍受伤害或停止必要照护。
