# 实际生成的合成报告样例

本页正文直接来自buildScaleResult，报告版本1.0.0。合成回答只用于核对评分与解释，不代表个人真实结果。完整技术字段见[report-result.synthetic.json](report-result.synthetic.json)。

## 调整眼前的处境

情绪不舒服时，有时能先动一动眼前的处境：换个沟通方式、调整安排，或在合适的时候缓和气氛。这部分关注你是否会想到这种做法，不是说所有问题都能由你改变。很多限制来自工作、关系或环境，也需要别人一起参与。可以回想一次让自己紧绷的情境，分清哪些是暂时改不了的，哪些还有一点余地。先选择一个可行的小调整，比要求自己立刻开心更实际。

最近一个让你情绪起伏的情境里，什么还有一点可以调整的余地？

挑一个自己确实能调整的小环节，试一次，再看看实际效果。

## 让注意力换个落点

强烈情绪出现时，注意力有时会被牢牢拉住，也有时能先转向别的线索。这部分关注你平时怎样安放注意力，不是在要求逃避问题或假装没有情绪。暂时把目光移开，和以后再回来处理，可以同时存在。你可以观察什么时候换个落点让自己更有余地，什么时候反而把重要事情拖住。方法是否合适，要结合当时的任务和自己的感受，而不只是看用得多不多。

什么时候转移注意力给了你缓冲，什么时候让事情一直悬着？

先做一个能暂时安顿自己的小动作，并约定什么时候回来处理重要的事。

## 换个角度想一想

同一件事，换个角度理解，感受有时也会跟着变化。这部分关注你会不会尝试重新看待情境，不是要把坏事硬想成好事，也不是否认已经受到的影响。比如，先区分“我知道的事实”和“我猜测的意思”，可能让事情更清楚。可以挑一件负担较小的日常烦恼，试着找出另一个同样说得通的解释。是否有帮助，仍要看现实有没有支持这种理解。

对最近的一件小烦恼，你知道哪些事实，又猜测了哪些意思？

写下一个同样有现实依据的其他解释，不强迫自己接受它。

## 把情绪先留在心里

有些场合，我们会先把情绪放在心里，没有马上表现出来。这样做可能是为了保护关系、争取时间，或因为当时不方便表达。这部分关注这种做法有多符合你，并不意味着表达越多越好，也不意味着少表达就是做错了。你可以留意，暂时不说之后，自己有没有找到合适的地方整理感受。需要时，可以选择一个安全的时机，向愿意倾听的人说一点，而不是一次交代所有事情。

当你把感受留在心里时，之后通常怎样照顾这些感受？

找一个安全、合适的时机，向信任的人表达一点真实感受。

## 阅读边界

- 这份结果整理的是你对自己体验和做法的描述，不能代替对实际处境的了解。
- 不能仅凭回答判断疾病、人格、能力或一个人的价值。
- 中文题目为平台工作译稿，没有可直接拿来给中国人群排高低的依据。
- 不同时间、不同处境的回答可能变化；不能只凭分数变化断定某种练习或方法有效。
- 没有回答的题目不会算成最低分；信息不足时，本次报告不作解释。
