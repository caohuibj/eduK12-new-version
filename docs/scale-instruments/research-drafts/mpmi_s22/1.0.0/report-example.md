# 合成回答的实际报告样例

报告版本：1.0.0。此处正文直接来自实际buildScaleResult结果；合成回答不是个人真实测量，也不是带常模分档的个性化诊断。完整技术结果见[report-result.synthetic.json](report-result.synthetic.json)。

## 记住要做的事

这些问题关注你在日常生活中，能不能在合适的时候想起原本打算做的事，例如回电话、还东西或赴约。它记录的是你对自己习惯的描述，不能代替实际的记忆测试。忙碌、疲惫、事情是否重要，以及有没有合适的提醒，都可能影响回答。不必用一次结果给自己贴上“记性好”或“记性差”的标签。可以挑一个最近差点忘记的小事，想想当时是什么帮你记住了它。

最近一次你及时想起要做的事，是什么线索提醒了你？

选一件小事，把它和一个稳定的日常动作联系起来，比如出门前看一眼待办清单。

## 在脑中过一遍

有些人会在脑中把待办事项过一遍，想象做事的步骤，或在开始一天前先排一排。这部分关注你有多常使用这些心里的小提醒，并不是越常想就一定越好。当事情很多时，反复惦记也可能让人觉得累。你可以观察这种做法什么时候帮到了自己，什么时候需要换一种更轻松的提醒办法。选择一个适合自己的方法，比要求自己始终记着所有事情更实际。

在脑中排练事情时，你是更清楚了，还是更容易反复担心？

明天开始前，只挑一件重要的小事，在脑中想一遍第一步怎么做。

## 借助身边的提醒

清单、日历、便条或提前放好的物品，都可以替我们承担一部分记事的负担。这部分关注你有多常借助身边的提醒，并不表示依赖提醒就是记性不好。就像出门前把要带的东西放到顺手的位置，一点准备有时能减少临时找东西的麻烦。你可以试着把提醒放在真正会看到、也方便行动的地方。方法是否合适，要看它有没有帮到自己的日常生活，而不是看用了多少种工具。

你现在的提醒，通常是在什么地方、什么时刻被自己看见的？

把一件要做的事写下来，放在行动前会看见的地方，试一天再调整。

## 阅读边界

- 这是一份日常习惯的自我描述，不能用来判断是否患有记忆方面的疾病。
- 中文题目是平台工作译稿，目前没有适合直接与中国人群比较的依据。
- 少量漏答时，只按已经回答的题目整理结果；信息不足时会提示，不能把没回答当作很少发生。

用于回顾成年人的日常记事与提醒习惯，不是考试，也不能用于诊断。中文为平台工作译稿。
