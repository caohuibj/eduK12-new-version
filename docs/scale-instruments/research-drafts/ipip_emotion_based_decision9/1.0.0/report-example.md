# IPIP情绪导向决策9题（研究译稿）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## midpoint

### 感受与逻辑的决策偏好：从日常经历看自己的习惯

做决定时，你更容易先问“我有什么感受”，还是“事实和理由是什么”？这份回答描述你通常偏向哪种参考方式，不评判哪种方式更聪明。计分方向越高，表示你越倾向依据感受做决定；较低则更倾向依据事实与逻辑。两者都可能提供有用信息，结果不是决策能力的好坏标签。

- 想一想最近一次选择：当时有哪些事实？又有哪些感受或期待？它们是互相支持，还是指向不同方向？
- 下次面对一个日常小选择，可以分别写下“已知事实”和“我的感受”，再看看是否还有需要了解的信息。无需强迫自己只选一种依据。

仅供成人研究和描述性自我了解，不用于心理诊断、能力鉴定或高风险决策。
