# 本地合成报告示例

- 手机使用带来的困扰：30（理论范围 10–60；不是常模等级）

## 手机使用与生活节奏

手机可以帮我们联系朋友、查资料，也可能悄悄挤占原本想做的事。分数越高，表示这次回答呈现的手机使用相关困扰越多；它不能判断你是否成瘾，也不是在评价你够不够自律。比如，原本只想看一眼消息，却停留得比计划更久，可能让学习、休息或与人相处受到影响。比起一个标签，更值得留意的是这些具体片段：什么让你拿起手机，又有哪些时刻你希望把注意力留给别的事。

- 回看自己比较认同的几句话：是在等待消息时反复查看，还是原本只想看一眼却停不下来？如果是在躲开无聊、压力或孤单，此刻除了手机，你还需要什么？
- 选一个想拿回注意力的小片段，例如写作业前十分钟。试着集中查看不紧急的通知，或把手机放远一点；把它当成小实验，不要求一次完美。
- 若手机使用持续影响睡眠、学习、人际关系，或让你很难受，可以和信任的家人、老师或专业人员讨论。帮助的目标是改善生活，不是责备。

- 这是独立中文工作译稿，仍待人工审校、认知访谈和本地验证；当前仅限八年级研究。
- 原韩国初二研究的男/女参考分界仅作外部档案，本报告不按性别自动套用，不诊断成瘾或给学生贴好坏标签。
