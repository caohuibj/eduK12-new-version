# 本地合成报告示例

以下由实际 buildScaleResult 生成；全题选择3，仅演示格式，不是真实参与者数据。

- 对正面表现的自我描述：3（理论范围 1–5；不是常模等级）
- 对不理想行为的承认：3（理论范围 1–5；不是常模等级）

## 你会怎样描述自己做得好的地方？

这几道题问到争论时保持客观、压力下友好待人，以及认真听别人说话。你越同意这些说法，表示越常把自己描述为始终有这些正面表现，并不能据此断定你在夸大或说谎。比如，工作汇报时我们可能先想到顺利完成的部分，而和熟悉的人复盘时更容易讲到困难。描述自己会受到场合、心情和题目理解的影响；试着回到具体经历，比给自己一个笼统评价更有帮助。

- 回想一次争论或忙碌的场景：当时哪些表现做得不错，哪些地方和理想中的自己不一样？
- 下次复盘时，可以各写一件做得好的事和一件想改进的事，用具体经历代替“我总是”或“我从不”。

## 也给不完美的经历留一点位置

这几道题涉及占便宜、乱扔垃圾，以及期待回报才帮助别人等不太理想的经历。回答越同意，只表示你越承认题目提到的行为，并不表示你越会隐瞒，也不能反过来把不同意当成不诚实。人们对这些情境的理解和回忆可能不同，愿不愿意谈及它们也受安全感影响。这不是一份好人或坏人的成绩单，更不能凭几道题决定别人的回答是否应该被丢弃。

- 如果某句话让你想到具体经历，可以想想当时发生了什么，而不急着给自己贴标签。
- 选择一件自己愿意改进的小事，例如更清楚地表达期待、处理好垃圾或尊重别人的边界；不必为了证明诚实而勉强承认没有发生的事。

- 这是独立中文工作译稿，仍待人工审校和本地验证，仅供成人研究与自我了解。
- 英国和德国成人研究中的平均值仅作出处记录，不能当作中国人的标准答案；本报告不作高低分级、排名或风险判断。
- 六题都需完整回答才提供完整报告；两个方面分开看，不合成总体诚信分。漏答不补零、不猜测。
- 不能用于诊断、重要选拔、对个人诚信作结论或自动剔除研究参与者。
