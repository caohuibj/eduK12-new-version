# 走神问卷（5题）（中文研究译稿）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## minimum

### 看看注意力什么时候悄悄拐了弯

这份问卷关注做事时，思绪转向其他内容的频繁程度。走神不等于懒惰，也不能据此判断有没有注意力障碍。回答反映的是您对平时走神的感受；平均分越高，表示您报告这些情况更常发生。它不是某一节课的专注监测，也不直接代表学习能力。比如眼睛还在读下一行，脑子却已经想到另一件事；发现后回头重读，就是一种常见情境。

- 想想最近一次走神：当时任务是否单调、是否疲劳，或者是否有事情一直挂在心上？
- 下一次开始任务前，先写下眼前这一小步要做什么。发现走神时，记下待会再想的事，再把注意力轻轻带回当前一步。

仅供成人研究与非诊断自我了解；中文研究译稿尚待验证，不用于心理诊断、学生筛选或能力排名。
