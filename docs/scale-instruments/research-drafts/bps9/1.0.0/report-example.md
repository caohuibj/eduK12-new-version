## 上床前的收尾习惯

这份回答关注的是从“还想再做一会儿”到“准备上床”之间的那段时间。有时我们已经想休息，却被一件小事接着另一件小事拖住。它不是在给自律打分，也不能说明睡不着的原因。工作、照护责任和生活安排都可能影响上床时间。可以回想一个常见的晚上，找出最容易让自己停不下来的环节，再选一个负担很小的收尾动作。一次回答不必变成对自己的评价。

最近一次比打算更晚上床，拖住你的是必须完成的事，还是可以留到明天的事？

今晚试着设一个收尾信号：把还想做的事记下来，再开始原本打算的睡前准备。

让收尾动作尽量省事，例如提前准备好明早要用的物品；是否有帮助，过后再看。

- 这份结果整理的是你对平时习惯的描述，不能代替对实际生活安排的了解。
- 不能仅凭回答判断失眠、身体健康、自律程度或一个人的价值。
- 中文题目为平台工作译稿，目前不适合用来给人与人之间排高低。
