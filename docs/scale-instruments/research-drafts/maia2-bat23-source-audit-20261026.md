- 响应量尺为 0（Never）到 5（Always），9 个反向题是 **5、6、7、8、9、10、11、12、15**，转换为 `5 - raw`；每个维度只平均自身题目，不生成整体总分、轻中重标签或临床阈值。
- 完整作答是**本项目待审的保守缺失策略**，不是凭官方文本推出的经验缺失准则。成人样本不能外推 K12，翻译后也不自动享有原版信效度。

## B. BAT 工作相关英文核心 23 题：版本不得混用

**锁定候选身份：** Schaufeli、Desart、De Witte 的 BAT **工作相关（work-related）Core Symptoms 23题**，不是一般情境版、学生版、12题短版，也不包含 10 条续发症状。核心题号 1–23，维度为 Exhaustion（1–8，8题）、Mental Distance（9–13，5题）、Cognitive Impairment（14–18，5题）、Emotional Impairment（19–23，5题）。

官方来源：

1. [BAT 官方使用条件](https://burnoutassessmenttool.be/start_eng/)
2. [BAT 官方手册与各语言题本入口](https://burnoutassessmenttool.be/handleiding_vragenlijst_eng/)
3. [官方英文题本](https://burnoutassessmenttool.be/wp-content/uploads/2020/08/BAT-English.pdf)
4. [官方中文题本](https://burnoutassessmenttool.be/wp-content/uploads/2020/08/BAT-Chinese.pdf)
5. [Schaufeli 等 2020 原研究与 Appendix B](https://doi.org/10.3390/ijerph17249495)
6. [BAT User Manual v2.0](https://burnoutassessmenttool.be/wp-content/uploads/2020/08/User-Manual-BAT-version-2.0.pdf)

- 核心 23 题的五级频率选项计分 1–5；不反向。四个分量表各自取题目均值；**总体得分对全部23条题目取均值**，不能对四维均值简单等权平均，因为维度题数是 8/5/5/5。对完全回答的合成向量总均值应为 `(8*E + 5*M + 5*C + 5*A)/23`，E/M/C/A 为各维均分。
- 官方英文 PDF 同时给出工作版和一般版，且包含短版标记与 10 条续发症状；必须分开辨识。官网另有学生版，不能因为系统服务教师与学校就把成人工作版视为 K12 学生工具。
- **权利交叉核验：** 官方首页虽表示 BAT 非专有、可免费使用且无需事先请求使用许可，但明确要求**不可修改该工具并注明原论文**。2020 年原研究及其附录采用 CC BY 4.0；另一方面，独立 BAT User Manual v2.0 首页印有 All rights reserved / 未获书面许可不得复制该手册的声明。原论文附录、官方问卷 PDF、独立手册不是同一个权利载体；不能据论文许可整册搬运，更不能把自译题本叫作官方/作者批准的中文版。最终公开打包须另核原表与翻译衍生物适用的条件。
- **新增发现：** 官网已提供中文 BAT 工作相关及一般性两套题本，不能先入为主地采用独立中文工作翻译。当前官方中文 PDF 的一般性版页中，若干精神疏离题仍描述“工作”，与一般版的上下文存在明显张力；不能替作者擅改或把它与英文工作相关版混合。须单独固定“中文版具体载体/使用人群/结构/授权”并检查官方译文版本是否有对应信效度。
- 暂不采纳 OpenScales BAT12/BAT23 实现，交接已有其题数/续发症状混入等错误证据。没有中国成人/教师验证参数时不得挪用比利时或荷兰常模、筛查线、临床诊断标签。材料中出现的截止点属于外部样本规则，不是本工具在目标系统的自动参数。

**BAT 当前结果：** 官方使用条件/英文 PDF/官方中文题本入口核对 PASS；23题与8/5/5/5/总题目均值静态公式 PASS；中英文精确题文逐题人工对齐、译本科学验证、公开分发许可范围的最终裁决 PENDING；系统 source、评分 golden、真实报告正文、隔离数据库、API 和双入口浏览器 NOTRUN。
