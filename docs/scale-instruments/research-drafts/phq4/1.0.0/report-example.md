## 过去两周：这些困扰占了多少生活空间

总分把过去两周四种困扰的出现频率加在一起；分数越高，表示这次回答中，这些困扰出现得更频繁。请同时留意它们是否影响休息、工作和日常活动。分数不能确定是否患有某种疾病；分数较低，也不意味着真实的难受不值得关注。这份中文研究译稿不自动划分风险等级。

- 过去两周，哪一种困扰最占用你的时间或精力？有没有一些时刻相对轻松，当时有什么不同？
- 可以简单记下困扰出现的时间、情境和对生活的影响。若它们持续或已经影响日常生活，可把这些记录带给有资质的心理健康专业人员讨论，不必等分数达到某条线。

## 焦虑相关体验：紧张和担心是否经常出现

这一项只看过去两周的紧张、不安，以及难以停止或控制的担心；分数越高，表示这些体验在这次回答中出现得更频繁。它不能确定是否患有焦虑障碍，也不代表你“想太多”。这份中文研究译稿不自动套用原版研究的筛查分界，请把结果和实际生活影响一起看。

- 担心出现时，你还能把注意力转回手头的事情吗？它有没有影响睡眠、工作或与人相处？
- 试着记下一次担心的内容和它带来的影响。若担心持续、难以摆脱或影响生活，可以寻求专业支持；不需要先证明自己“足够严重”。

## 抑郁相关体验：心情与兴趣最近怎样

这一项只看过去两周的低落、沮丧或无望感，以及对事情缺少兴趣或乐趣的体验；分数越高，表示这些体验在这次回答中出现得更频繁。它不能确定是否患有抑郁症，也不能靠分数排除其他困扰。这份中文研究译稿不自动套用原版研究的筛查分界。

- 最近有没有哪些原本愿意做的事，变得难以提起兴趣？这些变化怎样影响了你的日常生活？
- 可以把最近心情、兴趣和日常活动的变化记下来，与可信赖的人或专业人员谈谈。若困扰持续或影响生活，不必等到分数达到某个界线再求助。
