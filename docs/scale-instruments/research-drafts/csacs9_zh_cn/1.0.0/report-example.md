# 中文以己为景量表（C-SACS，最终9题版）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## minimum

### 起伏中稳住自己

这部分看看情绪和想法像浪一样涌来时，你能否找到一点平静，不急着跟它们较劲。例如，发现自己正在担心，却仍能留意当下要做的一小步。它不是要求你把情绪压下去，也不是每次都必须冷静。一次烦乱不能说明你做得不好，回答只是你对自己常见体验的描述，没有公认的及格线。

- 最近一次烦乱时，你是否曾给自己留过一个停顿？当时有什么帮助？
- 可以试着对一个缠住自己的念头加一句“我注意到，我现在有一个……的想法”，再选择眼前一件小事去做。如果练习让你更不舒服，就先停止，转而看看身边的物品或感受脚踩地面；持续困扰可向合适的专业人员寻求支持。

### 退一步看见自己的经历

这部分关注你能否在经历变化时，保留一个观察自己的角度。例如，除了“我正在难过”，也留意“我正在觉察难过”。经历会变化，你不必把某一刻的念头当成自己的全部。这不是让你变得疏离、假装没有感受，也不是测量有没有更高境界。它只提供一种回顾经历的视角，不定义你是谁。

- 有没有一个念头让你觉得“这就是全部的我”？换个角度观察它，会有什么不同？
- 可以试着对一个缠住自己的念头加一句“我注意到，我现在有一个……的想法”，再选择眼前一件小事去做。如果练习让你更不舒服，就先停止，转而看看身边的物品或感受脚踩地面；持续困扰可向合适的专业人员寻求支持。

### 给念头和情绪留一点空间

这份问卷关注的不是你有没有烦恼，而是烦恼出现时，你能否一边觉察它，一边保留一点选择空间。结果只是这次的自我描述，不是心理疾病诊断，也没有公认的好坏分界。两个方面可以分开阅读，但题目数量不同，不宜直接用两组总和比较强弱；更有用的是找到一个贴近生活、值得继续观察的小情境。

- 这两个生活主题中，哪个更贴近你最近的体验？有没有题目没能表达的部分？
- 可以试着对一个缠住自己的念头加一句“我注意到，我现在有一个……的想法”，再选择眼前一件小事去做。如果练习让你更不舒服，就先停止，转而看看身边的物品或感受脚踩地面；持续困扰可向合适的专业人员寻求支持。
