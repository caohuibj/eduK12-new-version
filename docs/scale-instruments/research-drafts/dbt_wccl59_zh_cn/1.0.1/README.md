# DBT-WCCL 59：英语原版直译简体中文研究工作稿 1.0.1

## 版本纠偏理由

上一版 `dbt_wccl59_zh_cn_research@1.0.0` 根据官方繁体版本间接适配，有发生语义偏移的可能。例如第2题“值得庆幸的事情”不能变成“懂得感恩”的人格自评，第6题英文是避免使别人产生疏离感而不是简单的“被排挤”，第57题必须保留**主动比较**这一行为。本版从原始英文重新完整翻译59题，并**保留1.0.0不覆盖历史**。同时官方繁体版 `dbt_wccl59_zh_tw_official_research@1.0.0` 保持原样。

## 两份唯一的本版语言和计分依据

1. 英文正式题本：https://depts.washington.edu/uwbrtc/wp-content/uploads/DBT-WCCL.pdf
2. 英文正式计分说明：https://depts.washington.edu/uwbrtc/wp-content/uploads/Scoring-description-for-the-DBT-WCCL.pdf

英文原题逐题编号与本版本DBTWC01～DBTWC59一一对应；英语原文不另外在公开仓库全量复制，审校人员应以UW官方PDF为准。**繁体题本及早期简体译稿均未作为本版的翻译中间材料。**

## 测量与计分保持

- 过去一个月、0 Never Used／1 Rarely Used／2 Sometimes Used／3 Regularly Used（每周至少4～5次）；不按是否奏效来选择频率。
- DSS技能使用38项、DCS1非建设性应对15项、DCS2责怪他人6项，各均分0–3。59题全不反向，无虚构59题健康总分或临床切点。
- 作者最低有效题数为DSS30、DCS110、DCS24；平台仍按各维**完整作答**规则算均分。这是较保守的平台选择，并非作者规定。
- 版本记录：measurement=1.0.1、scoring=1.0.0（完全未改）、localization=1.0.1（由英文直译）、report=1.0.1（来源与局限改写）；不创造常模。
- 本版处于DRAFT/CANDIDATE；缺少专业语言翻译审校、反向翻译、认知访谈及中文目标人群信效度验证。并不因为作者研究英语原版有效就推定这份简体翻译有效。

## 语言审校重点

- 第2题：不能把Counted my blessings转为人格特质“懂得感恩”；要强调回想自己值得庆幸的经历。 当前工作译稿：“回想自己生活中值得庆幸的事情。”
- 第6题：Alienate others是人与人产生疏离感，不是单纯“被排挤”；避免抹掉关系疏远含义。 当前工作译稿：“注意自己的回应方式，避免因此让别人对自己产生疏远感。”
- 第9题：Get centered强调在行动前让自己稳定下来，不虚构正式冥想技能施用。 当前工作译稿：“采取行动前，先试着让自己平静、稳定下来。”
- 第13题：Treated myself表示犒劳自己吃美味食物，不能写成须表现良好才得到的奖励。 当前工作译稿：“犒劳自己，吃一些特别好吃的东西。”
- 第17题：Forceful偏向有魄力、敢于主张，不是身体力量更大。 当前工作译稿：“希望自己能够更坚强、更乐观、更有魄力。”
- 第27题：Doubling my efforts包含“加倍”程度，不能仅写成普通更努力。 当前工作译稿：“清楚有哪些事情需要做，于是加倍努力，争取把事情处理好。”
- 第37题：按英文保留eat/drink/smoke/take medications并列，不自行诊断滥用药物。 当前工作译稿：“试着通过吃东西、饮酒、吸烟、服药等方式，让自己好受一些。”
- 第40题：Felt good to the touch是触感带来的舒适，不应泛化为任何心理自我照料。 当前工作译稿：“用触感舒适的事物安慰自己（例如泡泡浴或拥抱）。”
- 第48题：查明他人的责任，不自动等同于责怪他人——原计分维度按作者评分键。 当前工作译稿：“查明这件事还有谁应该承担责任。”
- 第57题：Compared myself是主动做社会比较；上轮简体“想到有人比自己困难”遗漏关键动作。 当前工作译稿：“把自己与那些处境不如自己的人作比较。”
- 第59题：Not burn bridges强调不切断未来可能的后路与选择，不能误解为不采取行动。 当前工作译稿：“尽量不要断掉自己的后路，而是为以后的选择留有余地。”
