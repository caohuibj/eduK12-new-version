## 从“想做”到“开始做”：你的日常节奏

这一项关注你怎样开始任务、做好准备并落实计划。分数越高，表示这次更认可容易开始、较少拖延的描述。比如，同样是整理资料，第一步清楚时可能很快动手，任务含糊或疲惫时则可能卡住。结果不能把你分成勤快或懒惰的人，也不能判断是否有注意力或执行功能方面的障碍；理解当时的任务和支持条件更有帮助。

- 想一件最近容易开始的事和一件拖着没做的事：第一步是否清楚？材料、时间、体力或情绪有什么不同？
- 为眼前一件事写一个小到可以立即着手的动作，比如“打开文档，写下标题”，并提前放好所需材料。观察哪种安排更容易开始，不拿问卷分数责备自己。

- 这份中文研究译稿仍待人工审校和适用人群验证，目前只供成人研究和自我了解。
- 没有可靠依据划分高低或排名，也不能借用Grit、BSCS或其他工具的分界。
- 任务不清楚、疲劳、情绪和可用支持都可能影响回答；不能据此评价人品、努力程度或做临床诊断。
- 10题都需完整回答；漏答不当作零分，也不代填。不用于学生筛选、教师考核或重要选拔。
