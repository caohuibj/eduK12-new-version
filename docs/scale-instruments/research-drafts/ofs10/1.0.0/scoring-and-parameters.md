# 计分、独立参数计划与解释边界

内容1.0.0、计分1.0.0、本地化1.0.0、报告1.0.0；参数计划文档1.0.0。身份为ofs10_zh_cn_research，不能继承IPIP_OPT10/LOT-R的版本或证据。

正式2018英文Correction key和西语Clave de corrección一致：原响应1–5，第6题反向为6−x，其余保持原值；10题等权**求和**，唯一`openness_to_future`总分10–50，不换均分/0–40，不造五维分数。五个理论内容域每域选两题是内容覆盖，最终支持的是单因子。更多表示这次自述更积极地面向未来，不等于未来会成功、没有疾病或稳定的乐观人格。

原作者未给个体缺失折算公式。当前`complete_required`为平台保守规则：缺任意一题则总分null、质量invalid，不给报告解释，不补0、均值或按比例外推；原文不完整数据比例不足7%不能作为个人允许缺失阈值。required题属性让研究编辑器提示完整答卷，并非声称原作者要求不可跳题。

原研究存在总和37.5至38的临床/社区ROC分类候选界点（灵敏度.70，特异度.74，AUC .774）。这是西班牙两招募组的横断面区分结果，社区样本未排除心理问题，不是中国诊断阈值。本包不创建ReferenceSet、不绑定外国语言切点/百分位，referencePolicy={type:none}，报告仅score_only，无bands或高低标签。

none参数没有独立参数身份/version的引擎字段；parameter-plan.json只是单独追踪1.0.0的准备档案，runtimeIndependentParameterVersionSupported=false，不伪称参数版本已在运行时绑定。

年龄资格为18岁以上成人自评；minInclusive216个月是平台保守研究使用边界，原文未规定。缺龄必须INDETERMINATE并拒绝当成已适龄，教师/家长代评不适用。指导语当前仅PREPARED sidecar，尚未运行时接入，此差异不隐藏。
