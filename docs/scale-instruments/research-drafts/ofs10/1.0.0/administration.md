# 独立指导语与施测

成人自评。18岁是平台保守边界，不是原作者验证的年龄界值；原研究未给统一最小/最大年龄。缺少月龄时资格为INDETERMINATE，不能猜测成人或放行为可用。预计约3分钟为平台估计。

原英文指导语完整工作翻译：

下面是一些陈述，你可能会在不同程度上认同它们。请根据以下选项，选择你对每项陈述的同意或不同意程度。

选项为：1＝非常不同意，2＝有些不同意，3＝既不同意也不反对，4＝有些同意，5＝非常同意。

答案没有对错，重要的是你的想法。不必花很长时间琢磨句子的确切意思，请选择第一时间最符合你想法的答案。

原件没有固定回忆天数，不能自行添加近7天或1个月。固定10题顺序与五个文字锚点，无门题、注意检查或其他非计分题需要移除。

当前source schema无独立instruction字段。完整指导语保存在`administration-sidecar.prepared.json`，状态PREPARED_NOT_RUNTIME_CONNECTED，**尚未接入运行时**；不塞入第一题，不声称产品已经支持完整指导语。研究使用前须由研究者单独呈现此说明。原英文和西语全文及翻译选择见bilingual-content.json。
