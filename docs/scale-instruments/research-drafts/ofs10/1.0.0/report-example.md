此刻怎样面向未来

这份回答关注你怎样看待尚未发生的生活：是否对未来保留一些期待，能否设想计划、相信自己可以面对障碍，以及怎样容纳好事和坏事都可能发生的不确定。它把这些体验汇在一起，供你回顾自己的想法，而不能预言未来会怎样。现实中的压力、资源、健康状况和身边的支持，都可能影响你的回答。暂时没有方向、担心失控或不想立刻做计划，也可能与眼前的处境有关。可以从一件仍有一点在意的小事开始，看看现在有什么是自己能做、也愿意做的；不必要求自己马上乐观起来。

想到接下来的一件小事，你期待什么，又担心什么？哪些部分能由自己稍作准备，哪些需要时间或支持？

选一个不太费力的小计划，写下明天能做的第一步，例如了解一条信息、准备一件物品，或找人商量；再给自己留一个可以调整计划的余地。

如果眼前的压力让你很难设想未来，可以先处理最需要照顾的一件事，或与信任的人谈一谈，不必独自承担。
