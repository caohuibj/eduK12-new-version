# 本地合成报告示例

以下由实际 buildScaleResult 生成；全题选择中间选项，仅演示格式，不是真实参与者数据。

- 联结不足的感受：6（理论范围 0–6；不是常模等级）
- 亲近与陪伴的不足感：3（理论范围 0–3；不是常模等级）
- 可依靠联结的不足感：3（理论范围 0–3；不是常模等级）

## 你想要的联结，和眼下感受到的联结

孤独感不只取决于身边有多少人：有时缺的是一位能说心里话的人，有时缺的是遇事可以依靠的支持。回答汇总越高，表示这次呈现的联结不足线索越多，不是给你贴上不合群的标签。比如，身处热闹的聚会也可能觉得无人理解，而一次安静的谈话却可能让人安心。请把结果当成理解自己需要的起点，不必把交朋友的数量当任务，也不用责怪自己为什么会有这些感受。

- 现在更想要的是有人陪伴、有人理解，还是遇事有人可依靠？
- 从一个小动作开始：约信任的人聊近况，或参加一项愿意重复去的活动。重视关系质量，不给自己规定朋友数量。

## 有没有可以说心里话的亲近感？

这一部分关注空虚、缺少陪伴和被拒绝的感受。回答汇总越高，表示这些体验在本次回答中出现得更多，但它不说明别人一定不喜欢你，也不是对你社交能力的判断。有时经历搬家、关系变化或忙碌的一段时间，熟悉的亲近感会暂时变少。先承认自己想被理解、被接纳的需要，再看谁能提供一点合适的陪伴，往往比强迫自己立刻热闹起来更温和。

- 最近有没有一次谈话让你觉得被理解？那个人或那种相处方式有什么特别？
- 可以向一个可信的人表达一个具体需要，例如想聊十分钟，或希望对方先听你说完；也可以选择适合自己的支持渠道。

## 遇到事情时，有哪些联结可以依靠？

这一部分关注你是否感到有人可信、亲近，以及遇到困难时有谁可以依靠。回答汇总越高，表示本次回答中的可依靠联结不足线索更多，并不是说身边人数越多就一定越好。比如，不同的人可能分别适合聊工作、分享心情或帮一个实际的小忙。支持不必都由一个人提供，也不是只靠你单方面努力就能得到；寻找合适的关系和环境，需要时间与双方的回应。

- 当你需要聊天、具体帮助或一起做事时，分别会想到谁？还有哪类支持暂时缺少？
- 挑一段愿意维护的关系，从一次可行的联系开始。若暂时没有合适的人，可以寻找稳定的社区活动或专业支持，不必一次解决所有关系问题。
