# IPIP同情关怀10题（研究译稿）：真实引擎合成示例

不是用户作答；覆盖极值与独立计分向量。不含常模分档，任何有效向量都使用描述性反馈。数值仍保留于底层，未改变UI。

## midpoint

### 对他人处境的关切：从日常经历看自己的习惯

看到别人处境艰难时，你通常会怎样回应？这份回答关注你表达的同情和关怀倾向，不是给一个人的善良程度打分。计分方向越高，表示你在这些题目中表达了更多关怀和同情。但回答也会受价值观、社会经历和措辞理解影响，不能据此判断你是否真正帮助过别人。

- 回想最近听到别人困难时的情景：你先注意到什么？哪些回应是对方真正需要、你也愿意提供的？
- 如果愿意，可以从一句不急着评判的询问开始：“你希望我听你说，还是一起想办法？”关心别人也可以保留自己的边界。

仅供成人研究和描述性自我了解，不用于心理诊断、能力鉴定或高风险决策。
