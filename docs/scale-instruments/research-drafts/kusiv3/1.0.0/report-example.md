# 本地合成报告示例

以下由实际 buildScaleResult 生成；全题选择3，仅演示格式，不是真实参与者数据。

- 对他人的信任预期：3（理论范围 1–5；不是常模等级）

## 你通常怎样看待别人的善意？

这三道题像一张小小的合影：记录你此刻对“别人一般能不能信任”的看法，不是给你贴上天真或多疑的标签。更愿意相信别人，可能让合作更容易开始；多留一点心，也可能是在保护自己的边界。合适的做法往往取决于眼前的人和事，而不是把信任越多当成越好。例如，和新同事分工时，可以先约定一件小任务，看看对方是否按时完成，再决定下一步合作。信任不必一次全给，也不必永远关门。分数越高，表示这次回答越倾向于认为他人通常可信，并不说明某个具体的人一定安全可靠。

- 回想一次别人兑现承诺的经历，再想一次让你失望的经历：这两件事有哪些不同？
- 下一次合作先说清楚任务、时间和边界，用实际表现慢慢积累信任。 遇到借钱、隐私或安全问题，核实信息和保留拒绝权始终重要。
