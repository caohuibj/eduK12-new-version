# 指导语与施测边界

请以当前一门大学在线或混合课程为参照，整份回答围绕同一课程。该课程选择句为平台适用性整理，无固定回顾期。

## motivation：SRLO_01–SRLO_17

作者表：The following questions ask about your motivation for and attitudes about this course. Remember there are no right or wrong answers, just answer as accurately as possible. Use the scale below to answer the questions. If you think the statement is very true of you, select 7; if a statement is not at all true of you, select 1. If the statement is more or less true of you, find the number between 1 and 7 that best describes you.

平台工作译文：以下问题询问你对这门课程的学习动机和态度。没有对错之分，请尽可能准确地作答。若某句话非常符合你的情况，选7；若完全不符合，选1；若介于两者之间，请从1到7中选择最能描述你的数字。

## learning_strategies：SRLO_18–SRLO_44

作者表：The following questions ask about your learning strategies used in this course. Remember there are no right or wrong answers, just answer as accurately as possible. Use the scale below to answer the questions. If you think the statement is very true of you, select 7; if a statement is not at all true of you, select 1. If the statement is more or less true of you, find the number between 1 and 7 that best describes you.

平台工作译文：以下问题询问你在这门课程中使用的学习策略。没有对错之分，请尽可能准确地作答。若某句话非常符合你的情况，选7；若完全不符合，选1；若介于两者之间，请从1到7中选择最能描述你的数字。

七点1–7：1完全不符合我，2、3、4、5、6仅数字，7非常符合我。作者正式表两端为Not at all true of me / Very true of me；论文Methods写not at all very true of me多very，端点依据正式作者表冻结。无非计分门题、停止规则；两组必要指导语独立保留。

旧schema无instruction字段，administration-sidecar.prepared.json是PREPARED_NOT_RUNTIME_CONNECTED，不能声称运行时已展示或把说明塞入第一题。12分钟是平台估计。

适用性情境常量仅为项目政策：UNIVERSITY_ONLINE_OR_BLENDED_CURRENT_COURSE。当前UI是否传入此值NOTRUN，未声称已接入；缺失情境应为INDETERMINATE，不能默认为大学课程。
