Builder 独立读取了 XML 的 permissions、§2、§3 及 Table 2，而非仅复制交接摘要。
Table 2 每行首列 `<break/>` 后的九条中文与 source、双语记录逐字比对。
XML 直接支持单因子、0–4 总和 0–36、全正向、样本及内部一致性。
补充 DOCX 未含中文施测页的结论来自研究 worker 对实际文件的检查；文件 hash 独立核对。
完整五档英文锚点来自 researcher 的 2018 Appendix A 核查，不假称2022刊出全部锚点。

## 权利链

- XML permissions 指定 CC BY-NC 4.0；Table 2 / 表注未出现另署第三方版权或排除条款。
- §2.2.3 说明由研究团队译制、原 RES 作者参与委员会与回译核对；不是只凭“文章 OA”推断题本权利。
- 权利结论限于本次 RES 中文题文；不覆盖文章提到的其他量表。
- 保留2022作者署名、版权、许可及改动说明；源目录单独列明题文不是 MIT。
- `redistribution: restricted` 配合 `NON_COMMERCIAL` 表示有条件的非商业公开再分发，不代表商业许可。
