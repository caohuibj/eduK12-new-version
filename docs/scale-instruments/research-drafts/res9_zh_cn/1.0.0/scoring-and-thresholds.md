# 计分与无阈值声明

## 唯一分数

`resilience_total = RES_01 + … + RES_09`。
每题只能是整数 0、1、2、3、4；每题权重为 1，无反向题，总分 0–36。
来源：Qing 等（2022）§2.2.2 明确写总和分及范围；§3.2 / Table 2 支持中文版单因子。
较高表示对自身通常应对困难资源的评价较积极，不是客观能力证明。

不沿用 2018 英文/荷兰文的 self-confidence、self-efficacy 两个子量表。
不删除第 4 题，不采用开发阶段其他题数，不增加雷达图维度。

## 保守平台缺失规则

九题答全才计算总分。少一题或全漏答时总分为 `null`、质量为 `invalid`，不产生解释。
不插补、不按比例推算；这是平台政策，不冒称原作者发表的缺失规则。
未知题码、重复题码、越界、非整数或未知选项必须拒绝，不能默认为 0 分。

| 合成输入 | 期望总分 |
|---|---:|
| 全 0 | 0 |
| 全 4 | 36 |
| 全 2 | 18 |
| 0,1,2,3,4,0,1,2,3 | 16 |
| 八题 2 分 / 全漏答 | 不可计分 |

## 没有可用个体阈值

`thresholdStatus = NO_VERIFIED_CUTOFF`。没有在该中文版中建立的临床截点、
高/中/低分档、百分位常模、可靠变化界值或最小重要差异。
研究中出现的 PCL-5 33 分属于另一量表，不能移植给 RES。

`report.interpretations[].bands = []`；`referencePolicy = {"type":"none"}`；
`executable.references = []`；`catalog.referenceApplicability = []`。
原始分数可供透明核对，不生成风险颜色、等级、个体排名或诊断标签。

## 外部研究人群不是常模

2016 年中国大陆成人便利样本 N=484；2022 年发表。女性、年轻、高教育、汉族居多。
源研究描述总分均值 22.43、标准差 5.64；仅在 `external-reference-dossier.json`
保存作研究背景，不进行 z 分、百分位或“高于平均”的个体解释。
同样不将性别均值、相关系数或中介模型转换为个人判断。
无中文版重测研究、跨语言测量等值或 K12 证据，不能仅用一次分数变化声称效果。
