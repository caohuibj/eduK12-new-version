# RES 简体中文 9 题数字化候选

`res9_zh_cn@1.0.0`，内容/计分/报告/本地化版本均为 `1.0.0`。
状态为 **CANDIDATE / PILOT / DRAFT**；首次内容落库须保持 **HIDDEN**，不发布、不激活。

本包采用 Qing 等（2022）Table 2 已发表中文题干，不是新译的九条题干。
但中文响应标签和独立指导语是**平台工作翻译**，数字呈现与新增报告待审，
不能称为原作者逐字验证的完整中文施测页。

## 已准备

- 九条中文题干逐字保留、固定题序；第 6 题保留原文“很好的”。
- 单因子总分：九题各 0–4 分直接相加，范围 0–36，无反向题、无子量表。
- 完整作答才计分；六个 golden cases 包含两端、中点、混合、漏一题及全漏答。
- 成人自陈边界，现有 eligibility 策略的最低月龄为 216；年龄未知不能据此视为符合。
- 只允许非商业使用；题文不受仓库 MIT 许可证覆盖。
- 无可信临床阈值、分档、常模百分位或最小重要差异。不激活任何 ReferenceSet。
- 通俗、非诊断、无等级报告；例子明确是合成内容示例，不冒充运行输出。

## 文件导航

- `bilingual-content.json`：逐题中英对应及平台施测文字的独立来源标记。
- `administration.md`：独立指导语和响应选项；未拼入首题，未连接新引擎字段。
- `scoring-and-thresholds.md`：计分、缺失规则、无阈值和不使用外部常模说明。
- `external-reference-dossier.json`：仅作研究记录的成人样本参数，不用于个体比较。
- `report-example.json` / `report-example.md`：合成例子与普通读者反馈。
- `reviewed-source-pack.md` / `references.md`：逐源审阅、许可、定位和待审边界。
- `research-handoff.json`：研究 worker 原始交接输入；其中建议 key 不是本包最终 key。
- `local-validation.json`：本包静态源对照证据；不包含尚未运行的引擎/数据库结果。

## 本轮执行边界与后续最小检查

修改组件 → 仅本包 source、内容单测和研究稿；
必需检查 → 题文/题序、单因子正向加总、漏答/非法值、许可、成人资格、无阈值参考；
主要位置 → 本工作树做只读静态源对照，新 main 隔离环境执行单测及原有草稿落库/拒绝激活检查；

预算 → 静态检查约 1 分钟，单测及有限运行检查由集成人记录实际耗时，失败只查受影响项。

```sh

  --reporter=json --outputFile=/path/to/isolated-evidence/res9-unit.json
```
