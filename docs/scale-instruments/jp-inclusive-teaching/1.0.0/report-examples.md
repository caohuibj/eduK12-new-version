# 教师发展性反馈草案

以下中文是项目原创报告文案，不是量表题文翻译或已验证中文版；尚未安装运行报告版本。填答者为小学教师，接收者为本人；未来仅沿用现有报告版本和接收者授权。学校人员只能按现有汇总、匿名、发布及最小人数规则查看获准的结果，不能因本项目自动获取个人答案。

没有取得原生学生对应版，不制作学生报告。三个“顺利/困难/信息不足”情境供文案审核，不能当作分数分界：没有常模或临界值支持自动贴标签。高分是更多报告相关行为，不等于教师更优秀。

|分组|较顺利的情境|困难的情境|信息不足|
|---|---|---|---|
|全体支持|你描述了一些支持全班共同参与的做法。可选一次活动，观察不同孩子是否都找到参与的机会，并记下一个需要调整的小环节。|有些做法可能暂时受到时间、班级情况或资源的限制。先挑一个小步骤，与同事讨论怎样让一次活动更容易参与；这不能说明你不关心学生。|现有作答还不足以描述这一方面。可先保留空白，准备好后再补充；不把缺失当作没有实践。|
|桥接支持|你关注孩子之间的理解与共同参与。可用不涉及个人诊断或家庭信息的通用语言说明支持安排，并留意孩子是否感到被尊重。|沟通支持需要有时很难，尤其要兼顾学生意愿与隐私。可以请可信同事一起讨论一个去标识案例，选择一种尊重孩子的表达；不需要把个别孩子的经历公开给全班。|作答或情境信息不足，暂不推断你是否擅长沟通。可先查看现有支持与保密安排，再决定是否继续反思。|
|个别支持|你报告了针对具体需要提供支持的做法。可选一个小调整，与相关支持人员一起观察是否帮助孩子参与，并尊重孩子和家庭的反馈。|支持个别孩子可能需要团队、时间与资源。先记录一个具体障碍，再向可信同事或支持人员提出可执行的帮助请求；不要求你独自承担系统中的所有困难。|目前不能形成充分的个别支持画像。可以先收集一个不含身份信息的案例，不补零，不据此诊断教师、孩子或家庭。|

公共说明：这是教师对自身行为的描述，不能替代课堂观察、学生体验或学习结果。最低选项还含有条件性的意向，不能直接解释为“从未行动”。本工具尚未取得平台内容使用授权，目前不提供实际分数报告。未来若获准施测，缺失处理须清楚告知；再次填写也不能仅凭分数变化断言教学改善。
