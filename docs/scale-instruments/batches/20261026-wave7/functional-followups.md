# 本批质量边界及功能线后续项

本批不修改引擎、schema、审批、共享过滤器或PR356。以下为独立复核要求的可操作交接，不能当作已实现，也不因辅助文献/ReferenceSet未创建新增发布门禁。

1. **独立none参数版本**：当前source支持计分/报告/本地化/目录版本，none参数没有独立运行时parameterVersion。参数方案仅研究文档标1.0.0，实际无阈值、无常模、无ReferenceSet，不说“阈值参数齐全”。后续在功能线定义none/经验性预设/实证参考三种参数记录的独立冻结身份；经验预设须记录依据、人群、粗估性质，可正式发布，但不得宣称中国常模或诊断准确性。
2. **基于回答的描述反馈**：当前score_only配置对同一维度各分数给相同反思文字，是实际生成的通俗反思报告，尚非个性化结果解释。后续可依据精确版本的题目选项、实际作答频率和本人纵向记录提供描述性反馈；先逐工具制定规则与报告新版本及黄金样例，不拿理论中点/原研究均值自动切高低。若有适用的原作者经验界值，记录来源、人群与适用版本，和报告版本分别冻结，不承诺诊断或干预疗效。
3. **指导语独立呈现**：目前独立指导语只在PREPARED sidecar，未接系统运行消费者。不能把指导语塞入第一题，也不能声称问卷UI已经完整施测。功能线需在两个入口使用同一冻结内容指导语版本并验证；后台计分成功不替代浏览器证据。
4. **题本与报告语言分开**：audience-report-gate将report.locale和measurement.versionAxes.locale强制一致。BAT原纯中文反馈实际被拒，保留失败。当前包提供真实英文主文+中文对照，合同en；不是悄悄把中文QC标en。后续支持独立报告语言/版本选择及相应受众内容契约，由功能线开发。无需为本次英文包改引擎。
5. **同一工具多内容版本的入库/升级**：现materialize以code唯一，已有1.0.0时请求1.0.1会DEPLOYMENT_VERSION_CONFLICT。新修订包可被registry读取、计分和生成实际结果，但不能因此宣称已在已有目录行完成升级。隔离数据库实际断言此拒绝并保留旧定义/快照。后续明确版本共存或受控升级与历史作答绑定，不删除旧行、不覆盖旧版本事实来绕过拒绝。
6. **标签实际检索消费**：本批source中的八轴/中文事实标签与快照一致，但浏览器检索、授权筛选、分析索引和RES非商业关键词问题仍归功能线。标签不能单独充当作者许可或部署授权；此内容分支不修共享过滤器。

这些项的开发节奏等待独立审核后安排。本轮不展开下一批量表。
