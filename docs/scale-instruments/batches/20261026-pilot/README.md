## 三版本实施边界

测量内容（含计分）、参数、报告分别记录；翻译工具与原语言工具保持独立身份。旧版文件和历史结果保留。经验预设参数可作为正式版本，不以缺少本地实测常模自动阻断。

本批CFS-R、EBQ继续采用原始分数解释，不为凑参数编造分档。当前系统对无ReferenceSet的score_only配置没有独立参数版本绑定，属于功能差异，不能用批次清单字段冒充已实现。
