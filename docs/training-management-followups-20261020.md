# Training 管理体验本地修订

来源：2026-10-20 至 21 日本地 Training 对话。本轮继续课程整合主线，同时完成检索、分页、导航及新增布局要求。仅更新 Mac 本地；独立目录已整合新的远端 main，详见 `training-main-integration-20261021.md`；当前本地服务仍为 Mac 完成版本。未更新或合并 PR #319，未部署生产。

## 已完成

- 课程页仅保留一个统计入口，页签名称为“信息统计”。界面按“选择前后测评 → 选择指标 → 生成分析”引导，说明发布版本、分组、基线与随访。唯一版本/分组自动选好，数值指标仍由教师勾选；匹配、权限和披露规则不变。
- “课程管理”位于“信息统计”右侧，集中承载管理学员、测评入口、课程说明和原有课程设置。移除右侧常驻管理栏，主内容使用整行宽度；原有轮换课程码、暂停报名、结束课程确认流程不变。
- 课程码与复制在课程标题旁展示；首页卡片在名称附近展示课程码。标题、课程码、说明、状态与管理操作分层对齐。复制仅由用户点击触发，失败提供手动复制提示；卡片链接内不嵌套复制按钮。
- 页签增加留白、边框选中态及键盘焦点；390px 下五个页签保持同一行，无页面横向溢出。
- 检索区默认收起，点击“检索与筛选”展开，收起时显示已应用条件。作业、打卡、课程测评和全部测评支持标题、全部匹配的标签、日期范围组合；作业/打卡区分创建与截止时间，测评采用创建时间。日期按浏览器时区转换，包含结束日。
- 仅提交筛选才发起查询。Training 控件默认每页 20，可选 10/20/50，服务端强制最多 50 条、500 页；筛选改变回第一页。既有其他测评管理客户端的 25 条默认保留。
- 查询在服务端完成，不只过滤当前页。每次替换当前页，忽略过期响应。作业/打卡摘要省略正文、题目 JSON 和附件签名，编辑/复制之前读取并核对完整详情；读取失败不打开空编辑器。
- 课程页只请求当前页签内容；分析与进度继续按需读取。教师权限直接用课程关系条件，避免为摘要列表预先读取所有课程 ID。停止为新管理界面预取全部标签候选。
- 测评标签是独立管理元数据，可在列表中编辑；服务端核对资源所有者与之前的标签值，冲突须刷新，不改写发布修订、评分和冻结策略。
- 标准 Training 页面增加可折叠顶部导航；深页保留安全的内部返回地址。课程页签、筛选、页码通过 URL 传递至编辑、结果及报告返回链。聚焦作答页保持原有模式，不增加独立认知任务创建入口。

## 数据库与恢复

兼容迁移：`server-version/backend/prisma/migrations/20261021000000_training_catalog_discovery/migration.sql`。仅新增问卷、组合测评、认知任务的标签数组及相关管理索引；作业、打卡、量表复用原有标签。增加标签 GIN 和课程/创建者 + 创建时间/ID 索引。未删除或改写既有回答。

先备份并实际恢复至独立本地数据库，再验证合成数据查询与迁移。正式本地迁移前核对，只有本次迁移待应用；使用官方 `prisma migrate deploy`。本地备份保留在工作区旁 `runtime/rollback/catalog-before-20261021.dump`（0600），摘要与恢复结果见 `runtime/evidence/training-discovery-20261021/database-recovery.json`。

应用回退优先恢复旧 API 产物并保留新增兼容字段和索引；不能为回退界面覆盖用户之后产生的数据。旧 API 产物保存在 `runtime/candidates/catalog-backend-retired-20261021`，另保留 `runtime/rollback/catalog-dist-before-20261021`。数据库恢复仅作为明确需要且另行确认的恢复操作。

## 验证与本地运行

只运行受影响类型、单元/交互检查、一次后端候选编译及一次前端构建。失败保留并针对性修复，不启动平台全量回归或性能测试。隔离数据库以禁用登录的合成教师、合成课程/任务验证三页无遗漏/重复、所有者隔离、日期/标签/标题查询、SQL 通配符字面匹配、摘要字段、标签冲突和已发布修订不变。

浏览器采用真实组件与合成 API，检查桌面/390px、五个页签、首页卡片、检索展开/收起与跨页标题查找、分析按钮可读性，无控制台错误。真实本地 URL 检查至登录入口，不代填账号或操作真实学员数据。构建、截图和检查日志在 `runtime/evidence/training-discovery-20261021/`，不是正式 CI 资格。

本地前端仍为 `http://training.localhost:5190`，API 为 `http://127.0.0.1:3190`；API 就绪确认数据库及 Redis ready，前端进程保持。仅重启原有单并发导出消费者，媒体/重型处理仍关闭。

## 后续独立事项

- 目前为有上限的 OFFSET 翻页；超出 500 页需缩小筛选范围。更深历史检索可单独改为游标，不声称已实现。
- 总数按筛选查询，未新增权限敏感缓存。包含式标题查询尚未增加 trigram 索引；生产数据量增长后，需结合真实查询计划决定，不能用本次界面验证声称吞吐或延迟提升。
- 首页首次加载速度仍属此前记录的独立优化事项，本轮不做压测或以无依据的速度数字结案。
