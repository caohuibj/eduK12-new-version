## 测量目的与答案依据

[Shallice & Evans 原始研究](https://pubmed.ncbi.nlm.nih.gov/679710/)要求用一般知识给出现实问题的合理估计，而非完成题内给齐输入的算式。这里保留既有四选一交互，仅重做现实数量/数量级题目，不复制研究原题、不移植临床误差计分或常模。多选项格式仍不同于开放回答研究，不能声称临床等效。

每题附事实锚点、来源与解释。题面不提供所有计算输入。选项为**作者设置的粗粒度数量级区间**：四区间互不重叠，事实锚点只落在一个区间，干扰项明显跨量级。它们不是从受试者分布估计的“正常范围”或临床容许误差；厂商示例不能证明所有产品的分布。只有选中冻结目标区间记1，其余选项记0，超时另列且计入分母；不设置量级误差等级、能力标签或人群阈值。

当前20题只是有事实依据的**待审候选**，尚未证明难度、文化适用或心理测量有效性。手机/猫/自行车等对象存在变异，题面限定普通类型并采用宽量级选项；高尔夫、天文、排球等题受经验和教育影响，仍需独审决定取舍。科学证据不足不通过改名掩盖，也不把这些知识题称作纯粹估算能力。暂不再为36凑题。
