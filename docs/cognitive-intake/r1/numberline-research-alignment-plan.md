# Numberline 研究版：已核原文与最小可实施变更

对象为现C1.0.1 / S1.0.0 / P1.0.1，研究档当前40点、0–100、10秒、分层随机整数、1题目标37练习（最多2次）、点击给出位置。此文件是可审阅实施方案，**没有将下述新C/S或协议安装/实施**；本分支只修新R的方法说明。文献核对完成不等于原协议对齐完成。

一手来源：Siegler & Opfer (2003), *The Development of Numerical Estimation: Evidence for Multiple Representations of Numerical Quantity*, DOI 10.1111/1467-9280.02438，[作者托管全文](https://siegler.tc.columbia.edu/wp-content/uploads/2019/12/4027Reading-SieglerOpfer-2003.pdf)，实际读Method pp.238–239。

原研究纸面线长25厘米；数字→位置NP与位置→数字PN；0–100/0–1000两个范围，每范围A或B组6个选点，特意避免仅靠熟悉中点并区分线性/对数预测；每session同一任务/点组/时限，范围分块且顺序平衡、块内随机。两session间隔1–2天，NP/PN、A/B、4/30秒反向分配。研究分析有按任务/范围的估计分布及模型比较；本项目单次误差百分比不是该研究的表征模型结论。本轮不复制题图、工作册或给个人贴线性/对数能力标签。

## 不能靠单一参数解决的差异

- 当前schema的lineMax和maxResponseMs已可表达100/1000及4000/30000；但是40个均匀分层随机点**不等于**研究的每范围6个特选点。随意只改时限无法纠正刺激分布。
- 当前runner/trial只支持NP点击，不支持PN“给定位置输入数字”，也不支持同一次任务内按范围/方向组织题目；原评分按单一config.lineMax汇总，不能直接用于混合范围后仍给一个总误差。
- 当前练习明确提示中点及目标37后反馈，是项目教学体验；不能悄悄把它带入研究档却说和原施测提示一致。原文未规定本项目15%练习通过线，不应为研究版再加这种门槛。

## 建议的最小源码片（任务内完成）

1. 保留现C1.0.1/S1.0.0及体验/正式P；新增研究C1.1.0/S1.1.0/P1.1.0和独立R。新配置冻结本次session的 `direction: NP|PN`、`targetSet: A|B`、`responseLimitMs:4000|30000`、`rangeOrder:[100,1000]|[1000,100]` 及明确的题目清单/版本。每session12题为原协议数量依据，不能拿12题声称比原40题更可靠。
2. 只扩展本任务现有 `NumberlineTrack`：NP继续点击给位置；PN使用同一条线显示固定短划、用数字输入回答。前后端同一任务生成器按冻结清单种子洗牌，每范围6题，服务端重建目标而非信任客户端声明。保持原随机整数生成器供旧C使用，不让旧题重排。
3. 新trial保留任务方向、范围、目标和原始回应/超时；新S按方向×范围分别计算响应数、PAE、方向偏差及用时，不把两个范围或NP/PN不加说明地合为一个能力指数。null和有效0不变，先不加个体模型拟合或排名。
4. 研究练习只解释对应输入方式并提供不进入正式点集的中性示例；不提示正式目标位置，不凭空加研究资格门槛。沿现有分配入口安排两次独立冻结任务，研究负责人选择互补session设置及1–2天间隔；不开发新日程/实验管理系统。
5. 公开实验的数值设置属于可核协议事实；实际题图/工作册不复制。数字界面比例不声称物理25厘米；屏幕/输入差异及缺乏实机校准保留为数字研究变式边界。

精确改动归属：本任务前端 `NumberlineTask.tsx` / `prng` / registry；本任务后端新config/trial/schema、scorer、seed、definitions、semantics及report sidecar；只更新本任务task-package后由统一集成人员生成共享表。不需要改通用runner、数据库schema、公共发布系统或CI门禁。

最小验证位置：本地做两方向×两范围的少量生成/计分反例（含超时、0、方向误差及原始单位），一条12题块切换组件流程与PN输入，旧C已通过且输入未变的证据复用。实际跨session/设备呈现仍待合成后有限真实验收；不把DOM测试叫纸笔协议复刻或信效度验证。

本轮未直接落地此新引擎的原因是：它改变原始trial、任务方向和分块评分，无法诚实称为“报告小修”或“只调研究时限”。应以这个具体、独立的新C/S片进入后续实施队列，当前版本与历史冻结继续保留；本说明不把该项标成原协议已对齐或另立阻塞门禁。
