# ERQ-CA 儿童青少年版来源核验

- 作者 Eleonora Gullone 的[量表下载页](https://eleonoragullone.wordpress.com/2018/09/20/psychological-measures-for-downloading/)链接了 [ERQ-CA 题本](https://eleonoragullone.wordpress.com/wp-content/uploads/2018/09/erq-ca.pdf)及[作者计分表](https://eleonoragullone.wordpress.com/wp-content/uploads/2018/09/erq-ca-scoring.pdf)；此两者是题号、选项与归属的主要核验来源。下载页公开提供文件，但未具体说明全文再发布或翻译条件。
- Gullone & Taffe (2012), *Psychological Assessment*, 24(2), 409–417, DOI [10.1037/a0025777](https://doi.org/10.1037/a0025777)；作者版先行发表为 2011 年。原研究样本 827 人，年龄 10–18 岁。这个年龄范围是研究样本，不能推断所有年龄均已验证。
- ERQ-CA 为儿童青少年自评版，10 题，两种策略。认知重评 1、3、5、7、8、10（6 题）；表达抑制 2、4、6、9（4 题）。作者计分表明确不反向。不要与成人 ERQ 的 1–7 选项混淆；本版为 1–5 同意度，3 表示各半。
- 原文完整定位：作者题本一页，题号 1–10。为了尊重未由用户提供的受保护全文，目录不复现整套题文或全套翻译；以下是定位线索，不是施测题干。
