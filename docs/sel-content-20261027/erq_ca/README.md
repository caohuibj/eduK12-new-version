# ERQ-CA 五点版内容准备与验收状态

这是儿童青少年自评 ERQ-CA，十题、五点同意度、两种独立策略；不是现有成人七点 ERQ。作者原始研究样本为 10–18 岁。2026-10-28 起原生定义 `server-version/backend/src/modules/scale/instruments/erq_ca_5point/1.0.0/instrument.ts` 为可执行 DRAFT：10 条英文原题逐字誊入，两维均值计分、报告与 4 组 golden cases 齐备；无 candidatePreview。

## 文件

- `source.md`：作者题本和计分表、题号映射、选项、原研究及语言/版本注意事项。主题索引保留作定位；完整英文原题自 2026-10-28 起誊入原生定义。
- `scoring.json` / `scoring.py`：计分映射及参考实现；`test_scoring.py` 测试边界和归属。
- `report_sample.html`：可审阅的完整静态模拟报告；含 SVG、两个独立分数、两维反馈、反思、行动和限制。运行时需要按真实结果动态生成，缺答时显示“未完成，暂不计分”。

## 计分及复核

作者计分表明示认知重评为 1、3、5、7、8、10，表达抑制为 2、4、6、9，无反向题。每题 1–5 分；各维分别计算和及均值。原研究使用维度和（范围重评 6–30、抑制 4–20），报告附每维均值（1–5）以方便理解。不得将两个策略加为总体得分。某维缺任何一题时，保守实现不计算该维分数；这是产品缺答规则，并不声称是原作者规则。缺答从不计为零；非法值报错。

报告例子：重评题按上述顺序 `[4,3,4,4,3,3]`，总和 21、均值 3.50；抑制题按上述顺序 `[2,3,2,3]`，总和 10、均值 2.50。条形图从 1 开始，长度分别为 `(3.5-1)/4 = 62.5%` 和 `(2.5-1)/4 = 37.5%`。运行 `python3 -m unittest -v test_scoring`，5 个测试通过，包含逐题归属、端点、缺答、非法输入和示例复算。
