# Delaware School Climate Scale — Student (Grades 3–5)

`native/instrument.ts` 根据 2021 技术手册附录 B 的 2020 版英文表生成，30道学校气候题与31真实性题；DRAFT，权利状态 unknown。技术手册第4页明确量表向公众免费，学校可自行施测；没有找到明确的再分发或翻译许可，因此不声称许可已验证。原文及题序保留，题31不参与任何维度分数。

七维映射按附录B实表核对，师生关系2/7/17/22/25，欺凌9/14/26；附录A师生关系误写26。附录A及实表题31是真实性题；完整手册筛查另依赖学生参与量表中的另一真实性题，并不能在本单独气候问卷完成。系统 STANDARD 定义目前禁止 quality purpose，本版第31题作为未进入任何维度的题目保留，未自动进行有效性判定；不把它当成内容得分或将完整调查筛查规则强行套用。该限制需由上层处理。

六个正向维度以原始回答均值呈现；欺凌维度按原始回答方向，越高表示越同意校园存在欺凌或担忧。手册总体气候分包含全部30道内容题，其中9/14/26反向后求和，范围30–120。为同时保留欺凌维度原方向，使用本工具专属自定义计分器 `native/scorer.ts`；需要将其与原生定义一起接入并注册。各维complete_required为保守约定，缺答不补零。golden cases 覆盖全1、全4、反方向、第25题缺答以及总分30和120端点。`report.html` 是对应 negative-direction 用例的单个虚构学生回答，并不代表真实班级或学校；反馈供学校通过适当群体数据及其他证据开展改进。对单次、个人回答不得推断群体结论或虚构常模。

重建顺序：先运行 `python3 generate.py`，再运行 `python3 add_total.py`；后者添加真实总分及计分插件。图中模拟个体气候总分为93：27×3 + 3×(5−1)。
