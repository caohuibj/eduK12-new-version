# CCNES 教师版：内容准备与验收

本目录不是可施测版本。作者网站限定教育及／或研究用途。`native/instrument.ts` 是 Scale catalog-only 候选条目，不含 executable；待合法提供并核对完整 12 情境与 72 回应及中文译稿后再实现。72 个独立 1–7 可能性评分均要回答，而非 12 个六选一情境判断题。正式实现的每条回应需包含所属情境，以免脱离语境。

`source.md` 提供作者来源、六维完整题键、四个反向题和版本说明；`scoring.py` / `scoring.json` 为计分参考；`test_scoring.py` 为回归核验；`report_sample.html` 为含原创 SVG 的六维教师反思样稿。

作者计分表指定每维 12 个回应的平均分，范围 1–7；DR 仅 2A、7C、8C、10A 反向，用 `8 - 原值`。六个因子共同覆盖 72 个不同题码，每情境每维各有一个独立回应，不做总分或等级。任何维度缺题则该维无分，其余完整维度可计分；这是产品规则，不宣称是作者缺答规定。无效值报错。

模拟评分后的各维 12 个值均分别设为 DR=3、PR=2、EE=5、EFR=5、PFR=6、MR=2；生成原始回答时对 4 个反向题取 `8 - 3 = 5`。报告图相对 1–7 的长度依次为 33.333333%、16.666667%、66.666667%、66.666667%、83.333333%、16.666667%。`python3 -m unittest -v test_scoring` 六项通过，包括 72 题不重不漏、每题归属与方向、端点、缺答、非法值和示例。
