先照顾自己

苦恼反应

模拟均分 3.00 / 7

这个维度关注孩子难过时您自身的不适。面对多重需要而感到压力很正常，也可能提示您需要更多支持。

想一想：在哪类情境里，您最难同时照顾孩子和自己？

小行动：在回应前做一次缓慢呼吸；事后与信任的同事讨论可以分担的支持。

留意边界方式

惩罚反应

模拟均分 2.00 / 7

这组回答涉及通过惩罚或威胁处理孩子情绪的可能性。示例分数不说明某个真实事件发生过，也不代表教师的全部做法。

想一想：当课堂秩序和孩子感受都需要照顾时，您有哪些支持？

小行动：尝试先描述边界，再提供一个可行选择，例如“我们先到安静处，等准备好了再一起想办法”。

给感受一个名字

鼓励表达

模拟均分 5.00 / 7

这个维度关注邀请孩子说出感受或让孩子知道感受可以被接纳。表达也可以是画画、动作或安静陪伴。

想一想：哪些孩子更容易说出来？谁可能需要别的表达方式？

小行动：试着说：“看起来这让你很难过，你想说说，还是先让我陪一会儿？”

先安顿感受

关注情绪的回应

模拟均分 5.00 / 7

这类回应关注让孩子感觉好一些，例如安慰或转移注意。是否有效取决于孩子当时需要的陪伴与空间。

想一想：孩子需要被安慰时，什么方式让他或她感到安全？

小行动：先询问孩子想要安静陪伴、喝水还是休息片刻，再共同选择。

一起想办法

关注问题的回应

模拟均分 6.00 / 7

这组回答涉及帮助孩子处理造成困扰的具体问题。寻找办法很有价值，也可以先确认孩子是否准备好讨论。

想一想：什么时候先陪伴一下，比立刻提出解决办法更合适？

小行动：在情绪稍平稳后问：“我们可以试哪一小步？你想先选哪一个？”

认真听见

轻视反应

模拟均分 2.00 / 7

这组回答关注是否把孩子的困难或情绪看得不重要。时间紧张时，成人可能不自觉地急于让事情过去。

想一想：当问题对成人看似很小，如何理解它对孩子的重要性？

小行动：先用一句话承认感受，例如“这件事对你来说很难受”，再决定下一步。

把一次反思带回课堂

选一个适合您的小动作，留意孩子的反应，也留意自己需要什么支持。实际选择要结合孩子安全、发展阶段、课堂资源和学校环境。

本示例基于教师版 CCNES：12 个假设情境、72 个独立回应，面向学前至小学低年级儿童的教师。中文工作表达尚未验证；自评不能代替观察或评价。
