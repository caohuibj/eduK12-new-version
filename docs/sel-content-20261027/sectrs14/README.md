## 样例与计算

参考实现将每题 1–6 原分直接计入作者会议报告列出的相应因子，无反向题；每个完整因子计算题目均值及和。因子未完成时不计算该因子，绝不把缺答当零。本均值及完整作答规则为保守产品约定，不能声称论文规定了缺答处理。单因子模型被拒，不给总分。
