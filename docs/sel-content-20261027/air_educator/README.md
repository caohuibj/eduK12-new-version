个人SEC共36题，五维按原PDF页面顺序是7/7/7/8/7项；四级同意度，正向计分，各领域题目均值1–4。`scoring.py` 为独立计算参考；`test_case.json` 可复现模拟值2、3、4、2、3；缺题该维不计算是保守产品约定。`report.html` 包含五个个人SEC的图与反思行动，另以十个主题提供非评分教学实践反思；二者没有合成总分。报告数字来自同一模拟作答。运行 `python3 scoring.py` 检验完整、缺答及非法输入。

原PDF在教学实践部分分别列出十个领域及其均值方法；Power of Language 页面列7项，但计分页写满分24，相当于6题，存在冲突，因此此项不硬算分。其它实践领域也在本样稿以非评分提示表达，并不宣称原文没有计分。原文强调2022版旨在专业反思且未经实证检验，不用于高风险决策。`native/instrument.ts`为仅供检索的CATALOG_ONLY；缺少完整受限题文，因此既无可执行SEC定义，也无可执行实践Form。正式入库需要明确题本使用、改编与公开再分发权限后完成逐题核验。
