# CASEL Schoolwide SEL Implementation Rubric（2020）

官方[工具页](https://schoolguide.casel.org/resource/downloadable-blank-rubric/)和[七页2020版PDF](https://files.casel.org/sites/2/2019/06/Blank-Rubric-Template-3.30.20.pdf)。这是学校团队对SEL实施的自我反思，不是学生个人能力量表。23个指标，每项原表有四个具体行为锚点。重点领域1A（3项）、1B（3项）、2（4项）、3（11项，跨3页）和4（2项）。切勿与旧版或另一个 districtwide 量规混用。

[学校指南许可协议](https://schoolguide.casel.org/license-agreement-for-online-access/) §2.A仅就美国境内、指定学前至高中SEL教育目的授予权利，禁止商业用途；§2.B有衍生作品权利转让，§3.B有提供衍生作品的义务。页面及PDF标示版权保留。本包不声称已经同意或代表用户接受该协议，也不向外发送。23个简短名称用于指引对应页码；完整原四级行为描述未复制或翻译。用户需对照原文及其条款作判断，记录表中的数字没有替代性行为锚点，不能冒称完整原量规。

native/form.ts 是遵循 Form V2 结构的记录草稿，每指标有1–4单选、证据、下一步三个字段；缺答可留空。水平是类别记录，不推算总分、常模或等级。实际使用还需解决原行为锚点的适用权利与文本呈现。native/instrument.ts 是 Scale 的 catalog-only发现元数据，没有 executable；Form 是独立运行类型，不自动注册或部署。

report-sample.html 使用23个指标的模拟记录（20已评、3未评），呈现各水平分布和未评数量，示意讨论要点和行动，不代表真实学校，也不绑定系统数据。计数只统计1–4，不将空缺变成1或0；示例不排名、不给个体或学校分类。生成器使用指标级原始数据算分布，未制造聚合分值。
