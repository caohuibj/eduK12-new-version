感受的六个小窗口

感受可能出现在心里、身体里，也可能在与人的相处中被发现。翻开这份小笔记，给自己一点好奇和空间。

示例报告 · 以下为模拟数据
先看全貌

六个方向，六种留意

这些数字是每一部分的回答经过计分后的平均值，范围为 1 到 3。它们只是一次回答的记录；目前没有用来解读个人分数的标准，也没有及格线。不同方向的数字含义不同，不能拿来判断好坏。

身体线索这一项的方向不同：数字越大，表示回答中较少报告身体线索。如果某一部分有题目没答，那里会显示“未完成”，不会把空题算成零分。

慢慢读，挑有共鸣的部分

试着把注意力带回生活

下面的问题和建议适用于任何分数，并不是根据数字推断你的性格或能力。你可以跳过不想回答的部分。

012.14 / 3

分辨情绪

有时候一种感觉里会混着好几种情绪，慢一点命名也没关系。

想一想 最近一次心情复杂时，你能找到哪些不同的感受？
试一试 选一个时刻，用两个情绪词描述自己，不必急着找到唯一答案。
021.67 / 3

用语言分享感受

有时说出感受并不容易，你可以选择合适的人、时间和分享程度。

想一想 谁让你感到被认真倾听？你更愿意用说、写还是画的方式表达？
试一试 如果愿意，向信任的人说一句“我现在有点……”，也可以先写下来。
031.80 / 3

不隐藏情绪

是否表达情绪会受到场合、关系与安全感影响；保留隐私也是你的选择。

想一想 什么时候你觉得表达感受比较自在？什么时候希望先保留给自己？
试一试 想分享时，先选一位信任的人，说清楚你希望被倾听还是得到建议。
042.20 / 3

身体里的线索

心情有时伴随身体变化，每个人感受到的方式和强度都不同。本项数字越大，表示回答中较少报告这些身体线索；它不是健康或能力好坏的判断。

想一想 紧张、难过或开心时，你的身体有什么变化？没有明显变化也可以。
试一试 找一个舒服的时刻，留意呼吸、肩膀或肚子；感到不舒服时可以停下。
052.40 / 3

关注别人的感受

表情和话语可能提供线索，但猜测不一定准确。

想一想 当朋友心情不好时，你通常怎样发现？你希望怎样确认自己的理解？
试一试 如果对方愿意，可以问“你现在感觉怎么样？需要我陪你吗？”
062.60 / 3

想一想自己的情绪

回头看看情绪与发生的事之间有什么联系，可以帮助你理解自己。

想一想 最近一次情绪变化前发生了什么？当时你有什么需要？
试一试 试着记下“发生了……我感觉……我需要……”，不知道的部分可以留空。

只挑一件小事就好

选一个你愿意试试的问题或行动，观察它在哪些时候有帮助。你可以和信任的人聊聊，也可以把想法留给自己。
