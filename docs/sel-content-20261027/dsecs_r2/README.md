# DSECS-R2 学生版内容准备与验收状态

本目录是独立工作材料，尚未接入系统；不是正式的中文量表，也不是可施测的完成品。目标版本为 DSECS-R2 学生版，20 题、5 维、每维 4 题，面向 3–12 年级。

## 交付材料

- `source.md`：来源页码、题号维度索引、公开使用信息和手册内部编号及年份差异。索引是主题提示，不能当作实际题干。
- `scoring.json`：结构化维度映射、1–4 选项工作表达、评分范围及标签。它是中间格式，尚未按系统 contract 适配。
- `scoring.py`：完整作答计分参考；其中缺答处置是产品规则，不声称是手册规定。
- `test_scoring.py`：端点、逐题映射与方向、缺答、非法输入、报告示例的回归测试。
- `report_sample.html`：模拟反馈样稿，含五维图、逐维反馈、反思、微行动与原创 SVG。静态样稿仅对应下列模拟数据；投入使用需按真实结果动态生成，并对缺答显示“未完成，暂不计分”。

## 计分约定及验证

题目均为同向表述，本参考实现全部直接计 1–4 分，未设置反向题。手册明确规定四级方向、五维与总分，并报告均值；按完整题组计算和与均值是本实现的运算约定。完整维度的和为 4–16，总和为 20–80，各均值为 1–4。缺失任一题时对应维度不产出分数；缺失任一题时总分不产出。其他完整维度正常计分。不可把未回答转换成 0；无效输入报错。未发现该手册对个体缺答处理的明确规则，因此完整作答策略是保守产品选择，而非手册断言。不得凭这些范围设立常模、诊断或临床阈值。

执行 `python3 -m unittest -v test_scoring`：5 个测试均通过。其中逐题映射测试对全部 20 个位置逐一验证，并验证不反向计分；模拟报告数据与图表数值一致。
