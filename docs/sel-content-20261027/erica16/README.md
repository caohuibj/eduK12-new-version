## 计分

原选项为 1–5。反向题为 5、7、8、9、10、11、12、13、14、16，计分值 = 6 − 答案，其余直接计分。分维度求和：情绪控制（7 题）7–35；情绪自我觉察（5 题）5–25；情境回应（4 题）4–20。16 题合计 16–80；各维的每题平均范围 1–5。分数越高表示作者定义的情绪调节方向越明显，不是临床判断或对人的价值评价。

此参考实现中，任一维缺题则该维无分，任一题缺答则总分无分，其他完整维仍可得分；此为保守产品规则，未声明是作者原始缺答规则。非法输入报错，缺答不会变成零。
