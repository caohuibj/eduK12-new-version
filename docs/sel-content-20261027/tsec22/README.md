## 计分

七点计分（1 = 完全不同意 至 7 = 完全同意，中间点无文字锚点）。自我情绪驾驭（SEM）6 题、专业关系建设 8 题、专业事务责任 8 题，各取均值（1–7）；无反向题，不提供总分。任一维缺题则该维无分（`complete_required`，缺答不补 0）——产品保守规则。论文正文的计分细节（信度、均值公式）待随全文核对，如不一致以论文为准。
