# EmQue 家长评定（20 题原版 + 13 题短版）：工作材料及验收（2026-10-28）

- `source.md`：论文来源、版本关系、计分方式与许可核验。
- `instrument.ts` 两个可执行 DRAFT（`emque_preschool_parent_en@1.0.0` 20 题；`emque_preschool_13_parent_en@1.0.0` 短版）：题文逐字誊自公开论文 Table 1，三维均值计分、报告与各 4 组 golden cases。
- `scoring.py` / `test_scoring.py`：两版本共用参考实现（`score20` / `score13`）与回归测试。

## 计分

家长评定孩子过去两个月的行为，三点 0 = no、1 = sometimes、2 = often。20 题版：情绪感染 7 题、对他人情绪的关注 7 题、亲社会行动 6 题；13 题短版：4 / 5 / 4 题。各维取均值；无反向题，不提供总分。任一维缺条目则该维无分（产品保守规则）。日本验证版改用五点计分，本记录维持原版三点，未采信五点分数。

## 版本关系

20 题原版与 13 题短版同属 EmQue 家族（长短版不重复计为独立构念）；两版均为独立精确版本，报告者版本一致（家长）。与 EmQue-CA（10–15 岁自评）分属不同年龄段工具，查重记录见 `../dedup.json`。
