感同身受的
三种样子

共情不止一种样子：有时是情绪跟着别人一起起伏，有时是读懂对方为什么这样，有时是想为对方做点什么。这份示例报告把一次回答放回这三个角度里看。

这是模拟报告，所有分数均为示例。它不是任何人的实际结果；共情没有好坏高低，三种样子也不必同时很强。分数只反映一次作答。

跟着别人一起感受

情感共情

模拟平均分 2.50 / 3

这组题目看的是：身边人高兴或难过时，你的情绪会不会跟着变。分数越高，表示你越常有这种跟着一起感受的体验。

想一想：最近一次被别人的情绪带动是什么时候？当时发生了什么？

小行动：把那次经历用一两句话写下来，留意情绪是如何传给你的。

想得明白

认知共情

模拟平均分 2.00 / 3

这组题目问的是：朋友生气、难过或哭的时候，你能不能大致明白发生了什么。一次分数不能定义你的理解力。

想一想：当你猜不透朋友为什么难过时，你通常会怎么做？

小行动：下次先问一句“发生什么事了”，再给自己的想法。

想帮一把

意图安慰

模拟平均分 2.67 / 3

这组题目看的是：别人难过或生气时，你会不会想安慰、帮忙，让事情变好一点。有这个念头本身已经很重要。

想一想：上次你想安慰别人时，做了什么？对方有什么反应？

小行动：本周找一个机会，从一句“你还好吗”开始。

给自己（或孩子）一个小实验

从三个角度里选一个你愿意继续练习的，给自己一个具体的小实验；做不到也没关系，共情是可以慢慢长的。
