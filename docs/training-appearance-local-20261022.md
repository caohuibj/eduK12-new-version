# Training 月夜外观（本地实现）

用户先确认了正常色／暗色／昼夜自动的方案，再确认新绘月夜山水图。
本批从实时 fetch 的官方 main `9e019c98568d9250a31346cc89d3ae272e9414dd`
建立独立分支 `work/training-appearance-20261022`，不包含尚未合并的小程序提交。
仅修改前端外观与资产；不改变后端、权限、计分、提交、数据库或部署配置。

## 使用

学员在 `/student/profile`、培训师在 `/profile` 的“外观”中选择：

- 正常色：保留原日间颜色与原山水图。
- 暗色：炭黑与墨绿表面、灰白文字、柔和草绿强调色、新绘月夜山水及暗色品牌矢量。
- 昼夜自动：按设备当地时间，07:00 正常色、19:00 暗色。到点、窗口恢复与时钟变化会重新核对。

默认昼夜自动，选择即时生效，按当前账号 ID 和浏览器 origin 保存，跨标签页同步。
未保存偏好或浏览器无法读取存储时使用昼夜自动；已明确选择正常色或暗色的账号
保留原设置，不覆盖已有偏好。
默认值调整的定向外观测试 13 项和变化文件 ESLint 均通过，日志在独立 runtime
的 `appearance-default-auto-tests.log`、`appearance-default-auto-lint.log`；
验证缺省昼夜切换、夜间正常色选择保留及存储不可用回退。不重复未变化的页面
配色、共享壳或后端检查。
不承诺跨设备同步；浏览器拒绝保存时说明刷新后需重新选择。退出或切换账号
不会沿用另一个账号的选择。只在 Training host 启用，Survey 管理页保留现有壳。

已加入课程的首页继续直接展示课程；新手引导仅在无课程时显示。
手机端月夜配图独立留出展示区域，避免月亮与文字重叠。
课程、练习／打卡、工具列表、个人设置及表单／量表／普通组合问卷编辑表面做颜色适配。
不使用整页反色，不改变图片、视频或图表标记。活动认知任务的
`data-cognitive-task-root`（包括组合中的嵌入任务）出现时，CSS 在绘制前自动
退回原始呈现；不改变任务刺激配色与尺寸。打印保留正常纸面颜色。

## 有限验证

主要位置为独立 Mac 本地，预算约 30 分钟；无平台 CI、后端重建、迁移或服务器部署。

- 当前外观 11 个用例通过：存储隔离、默认值、昼夜边界、到点切换、恢复窗口、
  跨标签同步、存储拒绝与非 Training 禁用。共享壳 67 个用例在提取 context 后通过。
- 前端 app TypeScript 检查退出 0；变化 TS/TSX 的 ESLint 退出 0，仅保留两个资料页
  原有 `fetchUserInfo` effect 依赖警告，无新增 lint 警告。
- Chromium 使用本套已有测试账号只读查看页面并选择本地外观，确认刷新保留、
  学员／教师页面、手机布局、月夜配图、加入课程弹窗、跨标签同步、自动模式与打印。
- 以临时 DOM 边界探针检查认知任务原始颜色恢复；没有新建或提交真实测评。
- 表单、量表与组合编辑器逐页修正局部亮色变量，最后无大块不透明白底残留；
  另修正半透明的组合编辑底栏和低对比提示。只读检查没有保存编辑内容。
- 初次联合测试 78 个中 77 通过、1 个失败，是“正常色”名称同时匹配自动模式
  描述造成；修正定位后单例通过，最终外观 11 和共享壳 67 分别全部通过。
  首次失败日志保留，不改称那次整条命令成功。
- 可选的 `localhost:5199/login` 非 Training 浏览器探针未在等待窗口内得到登录表单，
  保留该探针未完成身份；未修改该入口或追加平台检查。非 Training 边界由当前
  外观单测和共享壳用例验证，不声称这个浏览器探针通过。

本地日志、真实截图和逐项结果保存在独立 runtime 的 `appearance-*` 文件中，
不提交账号、凭据、个人数据或浏览器截图。未运行生产构建、CI、push、merge 或部署。
后续合并需要按完整差异选择范围检查，不能把本地结果冒称官方 CI 或发布资格。

保留页面布局、正常色、业务逻辑、打印和认知任务原色边界。

主要检查位置为独立 Mac 本地，约十分钟预算；沿用上述未变化的脚本逻辑及类型
检查，不重新构建前后端。1440/390 宽度、按钮悬停、键盘焦点、空状态、正常色
切换均完成；抽查文本对比度最低 6.67:1（暗色）和 4.64:1（正常色），无横向
溢出或页面异常。状态标签的三色核对使用临时 DOM 外观探针，不更改课程状态。
