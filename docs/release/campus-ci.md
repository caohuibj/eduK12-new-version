# 校园界面与注册码解析的最小 CI 路线（版本 1）

本路线由本次校园 PR 授权补齐。范围由 `campus-scope.mjs` 的精确文件名单及 Git 原始差异元数据限定；未知文件、删除、符号链接、执行权限变化、依赖/数据库/科学算法/培训业务变化不接纳。不是 A/B 发布资格，也不授权部署。

正式位置为 GitHub：分类与新增路由/拒绝契约、校园候选、CodeQL、稳定合并汇总。候选按 base/head 和变化组件 Git tree 绑定输入，重新计算完整计划；跳过、失败、取消和缺失均不得合并。旧全平台消费者仅接受 legacy，校园不触发媒体、科学回归、性能、附件/灾备或小程序检查。

变化组件各安装及编译一次，检查消费同一 build stage，runtime 复用缓存编译结果。后端仅 tsc 编译，沿用未变化的已登记 instrument 产物，不重复无关科学生成检查。实际 runtime 镜像保持既有 HIGH/CRITICAL、ignore-unfixed 阈值。证据保存 base/head、组件 tree、基础镜像 digest、runtime image ID、实际测试结果和候选截图。此证据用于本 PR 合并，不冒充部署产物资格。

前端检查变化 TypeScript 文件 lint、校园页面及递归导入依赖与所选测试类型、依赖审计及六个校园页面/导航/MFA 组件契约；浏览器读取从实际 runtime 镜像提取的相同编译文件，验证三端及常见 iPad 对齐、无溢出、登录/注册码/菜单/功能链接。浏览器 API 是明确的未登录合成响应，不能作为真实登录或授权证明。

后端检查注册码、CSRF、真实隔离 PostgreSQL 的注册/班级准入、亲子确认、教职工邀请码撤销、账号域隔离、MFA 和新增发现解析契约。隔离 DB 初始化仅建立测试 fixture，没有生产迁移或连接。新增发现接口只选择表单，原注册接口重新核验并原子消费；导航只显示既有权限允许的独立页面。

本地 UI 截图用于设计确认；现有文档/工具签名接纳没有扩大到应用，不将本地无签名结果伪装 CI 成功。失败只定位相关阶段；约五分钟报告具体下载/构建/检查等待项，不追加全量检查。生产部署需另获授权及正式资格。

## 同输入官方证据复用

`campus-reuse.py` 只接纳本 PR 明确选择、三小时内且未过期的 GitHub Actions 官方 artifact。校验 ZIP SHA-256、仓库/事件/workflow/run/合成 merge SHA 与 PR head 的关系、base、组件 tree、固定构建/测试程序及 workflow 命令、实际成功步骤、完整零跳过测试和同一 image ID 的既有阈值扫描。任一不符停止，不能伪造成功或静默全量重跑。复用保留旧 image/source 证据及新 head 的绑定，未通过的浏览器必须重新执行。该请求只对编号匹配的 PR 生效；其他 PR 按自身差异执行。它没有扩展本地签名接纳，也不授权部署。
