## 明确未重复执行

没有新运行平台全量 CI、业务前后端测试套件、测评/报告/账号全生命周期、数据库恢复、附件联合恢复、性能测试或应用构建。部署不重跑上述工具测试；只确认配置/版本、入口健康及回退文件。

合并受 main active rules 的唯一稳定必需状态 `merge gate / ready PR` 约束。只通过新 `release-tooling` 路线运行相关工具/路由检查及工具代码 SAST，未改动业务消费者全部跳过；不通过管理员绕过或自行填写绿色状态。当前无需全量 CI。

## 剩余限制

- 新 A/B runtime 构建/真实候选浏览器与完整 Compose 应用切换尚未实际运行。本轮不制造应用改动来演练，不声称已有合格的新 runtime artifact。
- A 15–25 分钟、B 20–40 分钟、合格产物紧急修复 10–20 分钟没有整路线实测，因此不是承诺。
- 保留 24 小时证据约束及候选 Compose 回退证明：自动审批拒绝取消有效期和删除回退证据，安全替代方案已保留它们；本轮不运行新的候选应用演练。
- 实际生产旧 entry 不支持 overlay，工具部署须保存原文件再适配；同配置/同镜像通过确认后才记录启用。原业务版本信息仍独立记录，不能把“工具已更新”冒充“应用镜像已发布”。
