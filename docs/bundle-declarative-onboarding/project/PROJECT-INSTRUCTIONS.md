# 普通组合与理论Bundle：Project指令

版本0.1.1-draft，2026-10-30。供Project使用的文件草案；未安装到Project，也未用新JD-R实例完成验收。沿现有运行时，不建立新的审批、报表或任务生命周期。

用户可以只给名称、已有工具和目标，不必先填表。先读实际材料与消费者，只询问确实缺失且影响科学含义或授权的事实，同时继续独立可做的工作。

普通COMBINATION只编排获准的精确工具，各自计分、各自报告。日常编排不逐次送专家审核，不生成跨工具总分或画像。作为可复用成品交付时记录组成、顺序与说明即可。

理论BUNDLE由专家预先确定固定必做组成与核心指标。只有核心进入Profile；其他变量只出对应工具的独立报告，不进入综合解释、建议或Modifier。接收者引用整包，不能拆改算法。当前不开发选做、补做、Modifier报告接入或在线LPA；也不为简化而删除现存未用代码。缺失/无效不补零，不硬分型。

复用实际C/P/R、参数、Bundle模型/映射/报告版本及hash。源码声明、数据库安装、发布、整包使用权和个人数据访问是不同事实；叶工具权利不自动成为整包U，职业/入口名字不成为个人数据权限。报告按已有受众投影。Bundle自有建议走现有精确内容审核，仍须允许核心解释与受众访问；不能开放源工具禁止的教育材料，普通分配权不变成内容审核权。旧任务读取冻结结果和模板，不查询最新报告重算。

EVC仍用其既定7–12年级模型。JD-R科学候选尚未由用户确定，不自动采用中心、权重、阈值或提高HSE标签权限；成人条件的最小泛化随该实例实施，不伪造年级。

按workflow.md工作；record-template.json只是可选工作笔记，不是API、运行配置、必填表或新门禁。用当前仓库AGENTS与release README确定真实检查。已有相同输入的可核验证据直接复用；新检查只针对实际变化或未执行的消费者。不要把每个新工具、入口或文档都变成全平台重复验证。

默认交付目标MAIN：按既有授权提交和正常合并可装载素材，核实当前实际装载合同。PRODUCTION须另有目标环境与授权；不因main合并自动部署、装数据库或分配给真实用户。普通工程继续自主推进；遇到明确拒绝不换渠道，具体记录，只有新的相关授权才能重试。

结果只写实际完成内容和必要未完成项。PASS只覆盖实际执行/接纳范围；目录资料不称可施测工具，局部合同不称FINAL旅程，草稿不称已安装。一个工具/模型阻塞不阻塞其它独立素材。
