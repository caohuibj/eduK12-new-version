# 量表指导语内容契约(供量表内容线采用)

记录:2026-10-26。PR356 已落地平台侧契约与冻结链(提交 a7c333998、1392499aa);内容线在 source.json 采用本契约后即可走完"导入 → 预览 → 发布 → 首答 → 刷新恢复"验收。

## source.json 新增可选字段

```json
"instruction": {
  "schemaVersion": 1,
  "text": "呈现给作答者的完整指导语文案(中文)",
  "language": "zh-CN",
  "version": "1.0.0",
  "source": "来源说明,如:官方手册中文工作译稿(译者/日期/依据)"
}
```

- 声明即完整(全部字段必填);未声明则该工具无平台指导语,历史空指导语合法。
- `text` 不进入 measurement/definition 哈希:修订措辞不改变测量身份,但必须递增 `version`。
- 平台行为:materialize 把 text 物化到 Scale 行(STANDARD 行为平台所有);START/重启/发布预备把版本化指导语冻结进该次发放的运行时快照;恢复会话读冻结值,不读可变行字段;Survey 公共作答端在量表单元标题下展示冻结指导语。
- 反向约束:发布后修改草稿指导语不影响已冻结会话;指导语变更需新 version,旧行身份不重写。
