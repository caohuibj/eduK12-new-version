## 研究问题与解释边界

描述短暂显示5–9个圆点后，报告数量是否正确、偏多还是偏少。含视觉编码、短时保持和数量报告；不是数学天赋、智力、计算障碍筛查，也不是1–4的完整subitizing跨度测验。年龄、人群、中文/英文理解、设备等值均未验证。场景标签仅为研究需求，不赋予诊断/录用预测效度。

## 需要先确认的设计分歧

1. 原文“直径5°”已由主agent本轮确认；具体采样/边界实现仍待复核，圆域采样是对此描述的项目提案；代码为7°方形采样。预览304 CSS px只是排版，不是已校准5°或7°，也不自动缩放成为施测几何。
2. 100/25正式的双profile是提案，不是短版已验证精度。既有18维key中的input_proposed仍保留not_frozen；设计扩展在design.json另列，不回写历史研究卡。
3. 默认静态预览采用与原文描述一致的**白点＋中灰极性候选**；#808080只是名义sRGB示例，不是论文规定值，也不是50%物理亮度。圆域采样仍是提案。原白底/深色点保留为可切换的“项目改版对照”，不默认采用或冒称原刺激同版。上游DrawEllipse未显式设置fill且背景涉及图像合成；不能凭孤立config值声称源码实际合成亮度已核。正式RGB/物理亮度、边界及遮罩仍需冻结，不继承MOT目标红/选择蓝给点数条件。
4. 噪声预览为原创48×48二值网格，固定seed、两灰阶、近半概率；只演示遮蔽位置。真实遮罩需定空间频谱/粒度/亮度/覆盖范围、配方与hash，并试点；不宣称等于上游noise.png。
5. 50ms并非所有刷新率都恰好整数帧；需冻结帧量化及容差、设备不能满足时的状态，不静默延长。预览无实验计时，不演示“50ms已经做到”。
6. 数量条件最小有效分母/质量门控未定，不能套MOT 50ms gap或完整分母规则。低正确率本身不是技术无效。

## 指标、数据与质量

完整机器可读提案见design.json：准确率分数量，分母为获准有效正式试次；总体聚合仅在必需条件均获准时显示。探索性指标为有符号/绝对数量误差、报告操作中位时长；负值保留，缺失为null。序列/真值/时钟与呈现证据错误须明确处理，不生成0–100能力分。

浏览器采集seed、条件/圆点位置、遮罩配方与版本/初始滑杆值、阶段时间、输入首响应与确认、失焦/旋转、帧摘要与完整帧原始记录。帧摘要标client-reported，完整帧仅科研归档；不逐帧请求服务器。DB核心/COS完整包沿已确认平台方案，当前未实现保存消费者。设备大类与实际输入分轴，未知不猜，不扩写严格V1偷渡字段。

三态：interpretable展示获准本次描述；limited隐藏受影响数量条件与总体聚合；invalid不给表现数字。具体阈值仍待定。原始数据/指标定义与冻结tuple遵从仓库实码，**尚未分配产品版本号**；没有虚构normVersion或总版本字段。换区域/遮罩/输入或练习规则均评估测量层及参照兼容，纯文案另管。
