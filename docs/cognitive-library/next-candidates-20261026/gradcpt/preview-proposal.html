先看两个操作例子

① 城市渐渐清楚时，点一下下方按钮，再松开。

② 城市变成山景时，不点按钮，继续看下一张。

不必等到照片完全清楚再反应，也不要提前猜、长按或连续乱点。

触控/鼠标用同一固定按钮，键盘可用空格。一次按下只计一次新反应；需要松开后再按。长按自动重复、多指不会叠加。

未通过先重新呈现完整说明和例子，再开始下一轮；最多3轮。

这描述了本次连续任务中“该按时回应”和“该等时停住”的记录；速度与误按需要一起看，不能只靠快慢判断表现。

一个可用的提醒

做连续单调的工作时，可以先说清哪些信号需要行动、哪些需要等待，再安排合适的短休息。

短版山景只有15张，1次误按就改变约6.7个百分点；单次短测不能给稳定能力或现实工作预测。
