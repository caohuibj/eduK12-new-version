## 公共边界

- 子agent只写各自目录，不改产品代码、共享core、数据库、AGENTS、锁文件、CI；不切分支、不自行commit/push/写Notion。
- 全部读取与渲染在云端，不使用用户Mac终端、文件或浏览器。复用既有官方锁定依赖和带sandbox Chromium。
- 标准角色色适用于界面，不强行把MOT红/蓝刺激套到别的任务；四入口相同实现仍需未来真实接入验证。
- 中文/英文、手机/平板优先，鼠标与键盘兼容方案单列差异。年龄/人群/理解验证未知，不能标全年龄。
- 沿原18维研究标签保持稳定ID；多场景和难度单列证据状态。标签文档不冒充后台检索接通。
- 文献对照版与体验版分别提案；短版次数尚未获用户批准，不假装已有可靠性或可混用常模。
- 静态稿不运行50 ms/RSVP等测量时序，不称尺寸已经校准；素材占位不算正式刺激清权。报告数字为合成示例，不产能力总分。
- 报告按需要至多一张take-home小图，标注EDUK12.TOP，正文/图片共用三态gate，null不变0、负差值不裁零。

## 主agent复核清单

1. 源码/论文与研究卡固定SHA可追溯，已核事实、提案及待确认项分开。
2. 条件次数/块数/练习/响应范围和分母可复算；论文与代码差异明确。
3. 非键盘输入未悄悄改变范式；重复比例、反应窗口、时序与报告单位保持真实。
4. 刺激/代码/字体/译文权利分轴，许可限制不当科学质量扣分。
5. 原始字段、seed/顺序、设备与质量来源提案完整；不虚构平台已有字段。
6. 手机/平板截图及200%普通阅读检查是真实云端渲染证据；不是产品四入口、硬件时序或人群效度。
7. 先向用户展示待定项与预览，再开展该项实施；本批不改产品代码或自动合并。
