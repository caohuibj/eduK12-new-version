① 说明与较易练习

先找到目标，
再指出刚才的位置

每轮先看目标字母和颜色（例如绿色O），随后在一组字母中搜索它。

先看目标

O

本轮找的是绿色O。只要找到一个匹配目标即可，不用找出所有目标。

有的轮次没有目标；有的可能有1个或5个。只有字母和颜色都匹配才是目标。

  1. 找到一个目标或确定没有后，点“搜索完成”。
  2. 所有字母立刻隐藏，换成相同位置的圆圈。
  3. 点你刚才找到的位置；没有目标就点“没有目标”。

例：你刚看见中间偏上的绿色O，就在圆圈页点那个位置。若刚才没有绿色O，应该点“没有目标”，不能随便点一个圆圈。

搜索和定位用时分开记录，不用在第一阶段逐个点字母。点完需要松开，再开始第二阶段的新点击。

先练6轮

每组仅8个字母，目标为0个或1个各3轮；给逐轮反馈。至少5/6正确即可。

没通过先重新呈现完整中英说明和例子，再开始下一轮，最多3轮。没有限时逼答，可随时结束。
