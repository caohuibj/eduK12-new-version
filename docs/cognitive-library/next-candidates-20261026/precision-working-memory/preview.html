① 说明与练习

记住颜色，找回它的位置

你会短暂看到1条或5条不同颜色的短线。短线消失后，中央会提示一种颜色。

请在圆环上指出：这种颜色刚才在哪里。判断位置，不是短线朝向。

先看一个例子

黄色短线出现在右上方。它消失后，中央提示黄色 → 在圆环右上方选点，确认。

如果同时有5条，只回应中央颜色对应的那一条。

先看时间与负担
科研版：30–50分钟，持续专注负担较高。
实用版：5–9分钟，总负担较低。
两版每题难度相同；重练另加时间。

怎样操作

  1. 先看中央，记住短线的位置和颜色。
  2. 短暂空屏后，根据中央颜色选位置。
  3. 触摸或拖动环带预览，松手后点“确认位置”；确认前可以调整。

鼠标同样操作；键盘方向键调整，Enter确认。没有正确位置的预填答案。

用6次较易练习熟悉操作

先练记1个，再练记3个。显示更久、保持更短；每题后说明落点与目标的偏差。

至少5/6次落在目标±30°内。未通过先重看完整说明和例子，最多3轮。

这是理解操作的暂定标准，不是记忆能力标准。正式阶段没有逐题对错反馈。

浅灰圈为空间预览点，不标出正确答案。手指在环带选点，确认前可调整。

一个可尝试的小建议

日常需要记住物品位置时，可以尝试固定摆放位置或增加文字提示；这只是一般方法，不是由本次测验验证的训练效果。
