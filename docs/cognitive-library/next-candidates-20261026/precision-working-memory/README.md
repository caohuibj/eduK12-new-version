## 完成的测量与教学协议

- 科研版research400正式，记1个/5个位置各200，分10个40次块、9次休息；实用版experience40正式，各20，中间不安排固定休息。两版单题相同、颜色探测/条件在每40次块内平衡；位置与目标色独立随机、全计划可重放。五项条形最少相隔18°，100位置网格保持完整位置身份。
- 正式ITI为整数950–1049ms、编码500ms、保持1000ms；3秒后文字提醒但允许继续回应，不是超时失败。实际阶段由客户端回调逐一呈现，不在延迟后补造未呈现的阶段，不为一帧误差预检/重测/修分。
- 300×300 CSS px区、#666666暗灰底、半径110px、32×6px切向条形；黑/黄#F0E442/浅蓝#00AAFF/亮绿#00FF00/红#E53935。保持与编码只留中央注视标记，响应才显示参考环和中央目标色。界面复用已批准中性色，刺激不继承入口主题。
- 触控/鼠标在半径90–130px环带选点或拖动，松开后确认；没有预填答案，环外/提前操作不算回应。键盘先激活随机初始点，再方向键1°/Shift10°调整，Enter确认；初始点与响应事件真实保留。位移轨迹不逐帧归档：保存有界选择/松开/键盘/确认事件及最终原始/投影坐标；每试次事件上限256。
- 完整中英说明和3例：按颜色找位置、五项只找目标色、调整后确认；说明两版预计时间和大致负担。练习6次，前三记1个、后三记3个；编码1000ms/保持500ms，每题反馈。至少5/6次绝对误差≤30°，最多3轮；失败必须重呈完整说明和例子。原件按practice:round:index保存，练习不混入正式。

## 计分、后台报告与保存合同

真实v2快照、configHash/protocolSignature、seed计划、记录序号/条件/阶段/坐标/时钟由后端精确验证；不接受任意客户端review或重新标记旧身份。逐试次保留[-180,180)有符号角误差，后端复核；按两种负荷分别计算最短绝对角误差均值/中位数和有效/计划次数。跨0°正确，缺失null，不补0/180°，不合成容量分。

现有MetricUnit没有角度。本内容沿既有map对象合同保存{value,unit:'deg'}或null，专属公开报告投影取自然度数显示，不伪装为level/0–100分，也不修改平台枚举。公开投影与候选报告共用interpretable/limited/invalid校验：部分记录只描述实际有效部分，零有效不输出表现结论。报告为一句本次发现、两条件数据/分母、解释、一般建议及简短限制，细节展开；不输出未验证κ/Pmem、常模、排名或诊断。

候选端口要求先耐久确认新作答身份并保存冻结计划/realm，再呈现刺激；本机逐试次保存需精确回执，失败保留同一原件，不重曝。最终声明保留真实终止原因，重试同一摘要；只有匹配身份、分母、最终摘要且finalSaved=true的报告回执才展示报告。“报告已保存”不等于完整原件已归档；没有后台上传机制就不声称关页后能自动归档。当前端口只有合同和合成自查替身，未实现/冒称真实IndexedDB或服务器耐久保存。

测评engine/scorer/config、profile/metric/quality/report、presentation均各自为真实初版0.1.0；protocol precision-working-memory/0.1.0/0.1.0，随机算法spatial-fnv1a-utf16-xorshift32-balanced-v1，练习规则spatial-easier-six-v1。它们是内容/快照身份，不是新增数据库字段。
