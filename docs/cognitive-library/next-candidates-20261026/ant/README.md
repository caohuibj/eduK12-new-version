### 两个必须确认的变式选择

1. **中性侧翼**：当前提案暂展示PEBL默认「无侧翼」，另给Fan式横杠示意供比较。选其一后冻结，不能在施测中切换或合并同名数据。
2. **固定双侧触控区**：目标在上方/下方都只判断中央箭头的左/右方向，忽略左右侧翼。建议双拇指固定回应区，鼠标点击同区，键盘显式ArrowLeft/ArrowRight；不暗称上游自动layout是固定Shift。布局尺寸、位置、早按、长按、双指与首响应规则待定。触屏RT包含动作，不能当键盘等值。

## 指标、缺失与门控

完整字段见 `design.json`。建议公开正确且技术有效的正式试次均值RT及条件正确率；源all-trials口径如需保留，只作另名研究审计。练习不入正式计分。

- 正确率：正确数 / 该条件技术可用正式试次。错误和超时仍在分母；不能因低正确率就剔除。
- 条件RT：只纳入1700ms内首次有效且答对的反应。无响应RT为null，保留实际截止耗时及超时标记，不编造0ms或1700ms反应。
- 警觉差：无提示−双位置提示；定向差：中央−空间有效；冲突差：不一致−一致。单位ms，保存正负，不裁零；两侧有效正确次数均显示。差值为0不表示正常或“无影响”。
- 块统计从raw独立重算。上游累积数组未清空的块摘要不能冒充各块独立结果。
- 分母为0或技术/质量规则不满足时为null。最小正确次数、帧容差、对中断/抢答的后果尚待冻结，不能凭本提案生成获准阈值。
- `interpretable`只给获准描述；`limited`隐藏受影响差值/聚合；`invalid`不输出表现结论。预览三态只是图文门控示例。

四类规则独立登记：技术质量规则、理论参照、文献经验、项目暂定研究者规则。24/288/48试次、1700ms和100ms是协议参数，不统称能力阈值。
