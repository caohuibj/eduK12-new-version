## 冻结设计、随机化与奖励

科研80基础单元＝2自由次数×2信息条件×5绝对均值差(4/8/12/20/30)×2高均值侧×2采样方向，4重复合320。信息不等为[1,3]，方向指较少采样侧；信息相等为[2,2]，方向指首指定采样侧。每个80局段覆盖一次全部单元，段内seed乱序。每单元4重复覆盖基准均值40/60×基准侧左/右全部4组合。

实用仅取40个单元：每个自由次数×信息条件10局，每个差值2局，高均值侧及采样方向在该差值内各左/右1次。用seed位与差值/机会/信息条件交替选择两种方向配对，减少完整80单元中的另一半交叉组合；**每差值内高均值侧×采样方向不完全交叉**，不冒称完整因子独立或320局模型参数精度。40局全局基准40/60×基准侧左/右各10次。完整计划、实际方向、强制顺序和队列冻结可复核。

信息不等指定顺序按真实[1,3]计数shuffle；信息相等首侧依单元方向，余3次shuffle、总各2次。均值局内不变，一侧40或60，另一侧按高均值侧加/减绝对差值。正式每臂预生成5/10个潜在奖励，独立Box–Muller正态SD8，最近整数后截限1–100。取该臂被选择的下一个奖励，不按全局步数偷跳队列；不展示未选奖励或隐藏生成均值。

RNG版本horizon-fnv1a-utf16-xorshift32-boxmuller-balanced-v1，UTF16 FNV1a种子＋xorshift32半开端点修正到(0,1)＋Fisher–Yates；actual raw冻结完整rewards/means/forced/seed上下文/算法版本。论文奖励边界具体算法未完全核明，截限是明确项目选择、分布不等于无限正态，不称逐项原算法复刻。

## 细致中英教学与3局练习

实际HorizonInstructions逐步说明：两台机器的整数点数波动、局内隐藏规则不变、新局重置、拿点数目标；先指定4次，再自由1/6次；5/10是两台共用总次数，不是每台分别拥有；空位是未见，不是0分；每次反馈后抬起再新按下，无选择倒计时。

例一：A只见52；B见49/55/50。A信息少但不代表好或差，B的下一次也不保证。只剩1次时新信息无本局后续用途；还可选6次时第一次所得信息还可能帮助后5次。自由选两边均允许，不规定探索为正确。例二：A见48/54，B见49/53，两边各2次且平均51，没有“较少了解侧”，均值持平也不判正确/错误。

3局带提示练习总5/10/10＝25次操作，依次不等信息短、等信息长、不等信息长。固定示例点数＋额外清楚提示，不是正式SD8奖励，不记正式报告。通过规则为3局流程真实完成，不按自由选择、累计点数、偏好或正态分布判对错。未完成局同步保存原件；先完整重呈教学与两个例子，再开始新的3局组，最多3组。练习round独立，正式round恒0；不在每个正式段前再加练习。

统一中性认知界面，深色正文、蓝色可选提示＋文字/边框，不继承入口主题；原创建模A/B几何面板，无外部图片、字体、音频或赌场素材。每台5/10行历史从开始提示前景，已见点数保留，实际全局剩余次数文字明确。触控/鼠标/笔优先，←/→保留，焦点按钮Space/Enter带真实上下文，辅助激活单列assistive。fresh按下、按住/重复不跨步，指定阶段仅指定侧；每次反馈至少300ms后才开放新选择，rAF迟到不补造物理呈现。无逐帧日志/请求、时序预检、clock probe或普通一帧误差重测。每局最多256输入/阶段事件，repeat只计数。

触控、教学、反馈、布局/奖励边界为明示项目改造，不宣称原键盘或手机/桌面等效。可重排布局、移动阅读、屏幕阅读器、键盘和缩放是内容设计目标；本次jsdom和静态图不等于完整设备/200%浏览器验收。

## 权威计分与受限报告

实际v2 tuple/schema/configHash/protocolSignature核对，按冻结seed计划核序号/条件/强制顺序/奖励队列/时钟并重放每个事件，拒绝编造完成、改奖励或state。只有完整4指定历史及真实首自由选择进入主要指标。首选已发生、后来步骤/反馈中断时保留其对应背景并标limited；不会伪称全部步骤/整场完成。4次指定后尚无首选则不入分母，真实未执行不补0。
