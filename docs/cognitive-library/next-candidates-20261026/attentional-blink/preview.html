① 说明与较易练习

记住两个带圆环的字母，
按出现顺序回答

字母会在中央一个接一个快速出现；其中只有两次同时出现白色圆环。请记住那两个字母，等整串结束后再回答。

一个慢速例子

AKFHPR

第一个带环的是K，第二个带环的是P。因此回答：第一个K，第二个P。

这只是缩短的教学示例。正式每串26个字母，只有目标出现时有圆环。

怎么看、怎么回答

  1. 看中央；字母流期间不用点按。
  2. 结束后选第一个字母，再选第二个，可以点回答框修改。
  3. 想不起来可选“没记住”，不强迫猜；确认后进入下一轮。

手机/鼠标使用字母面板；键盘可输入A–Z并确认。没有预填答案，也没有限时逼答；没记住与未完成分开保留。

先做6轮较易练习

每串12字母、速度较慢（250ms/字母），两目标间隔更大，逐轮反馈。至少5/6轮两字母及顺序均正确即可。

未过先重看完整说明和例子，再开始下一轮，最多3轮。
