## 生成与冻结

`protocol.ts`实现SHA256种子初始化的xorshift32、Fisher–Yates抽样和块内顺序；自己的候选generatorVersion明确固定。采用上游已评审默认块结构，独立实现逻辑，不执行上游脚本，不读取、复制、解码或输出OMI示例图片。它不是上游Math.random运行的逐字节重放：PRNG、种子保存、完整manifest/哈希是项目新增，shuffle省略无效果的末项交换，随机取样消耗序列不可称为上游原样。不得以本实现替代原论文逐项核对。

研究对照版是“上游示例参数”：260=60目标首次+60目标重复+124首次填充+16警觉重复；体验版100=20+20+54+6。同一750/800ms名义时序、4图/块、5块起始delay、4块最小delay、警觉间隔4块。短版目标重复占比23.08%→20%，起始/尾部开销比例改变，不能写成严格只改次数且比例不变或两版等值。两版不混常模。

两版默认ready池实际每次重复前仅1项，目标重复身份顺序等于首次目标身份顺序；`fixedOrder=false`不构成实际重复顺序随机保证。测试实际遍历20个seed核对该事实，没有扩大ready池。目标块差5、图片lag17–23；manifest保存每对索引、实际生成lag、间隔图数、块差与频数。警觉重复来自上一块首次填充并独立配对。

`synthetic-manifests.json`留存固定seed `recognition-golden`的两份完整冻结候选、刺激逻辑ID序列、目标/警觉配对、练习序列和lag频数。所有ID只是逻辑标识，不是已授权图像。两版正式独特素材需求分别184/74，资产池不足/重复ID/练习正式重叠均拒绝；最多4096个逻辑资产ID，原始事件最多5200。研究/体验各自冻结完整输入资产池及顺序，不只冻结选中图片。

练习8呈现由6个独立资产ID构成，2次重复；只是已批准预览中的项目操作练习提案，lag/比例不代表正式协议，生成器不把它混进正式分母，不自加练习通过线。

候选冻结体包括完整身份版本、profile/seed/资产池、所有参数与manifest；SHA256采用排序键的规范JSON。重放从冻结request确定重建，并对整个对象（包括参数/身份/manifest/hash、未知字段）精确比较，任何更改均拒绝。此为**隔离候选契约**，没有声称已接平台session tuple；将来原生接入还必须调用真实`parseSessionConfigSnapshot`等平台校验，验证configHash/protocolSignature、input.config与session.config及精确协议版本，不能仅复用本候选hash冒充平台冻结。

## 原始回应和计分

严格校验formal阶段、冻结hash、连续前缀索引、资产/类别真值和实际stage时间。载入失败可显式缺失全部时间，完整呈现不可缺时间；时钟逆序、窗口重叠、已知相邻窗口间隙、事件重号/逆序、非法字段/非有限数均拒绝。每呈现保留实际imageOnset/imageOffset/windowEnd及中断；名义750/800ms不冒充实际计时，当前没有擅造时序容差。

候选回应规则仍为image+紧随ISI：实际窗口`[imageOnset,nextImageOnset)`，末图到最终ISI结束。边界正好等于下一图onset归下一图；imageOffset归前图ISI。seen动作只计每图第一份有效事件；重复seen保留为extra计数，键盘长按repeat/其他键/其他动作不作为seen。原始事件保持在调用者输入中，候选不负责持久化；事件必须有唯一ID。提前/任务后seen保留审计并限制报告；无回应是正常Go/No-Go记录，不自动当技术超时。

HR/FAR使用同一个首呈+重复都技术有效的目标配对集合：HR=重复seen/有效目标pair数，FAR=对应目标首次seen/同一pair数。任一成员缺失、load-failure、timeout或中断，整对不进两个分母。CRR=HR−FAR，可负；0分母保留null。首次填充误报/警觉重复miss独立分母，不混进HR/FAR，不追加d′/总体分。实际onset间隔另保留在audit。

## 三态报告与证据等级

技术完整不自动得到获准个人解释。默认无外部研究复核即limited（无有效目标pair为invalid）；只有完整正式序列、全部有效呈现/目标pair、无提前或任务后seen，以及显式绑定snapshotHash/qualityRule/复核人的研究复核，才允许本次描述性研究投影。该复核是受信调用者责任，本模块没有用户授权/API、不能接受来自普通客户端的自我放行字段。规则等级明确为项目暂定研究者规则，没有可靠性、年龄界值、中文常模或诊断资格。

report投影除quality.state，还核查复核绑定、完整分母、合法分子、率与分子/分母相等及CRR差值；不一致隐藏。limited/invalid隐藏全部表现率、表现分子/分母和take-home图，只留完成性。内部metrics只供研究诊断，不直接交UI/导出；将来图/正文/导出必须共用该投影。获准描述时至多可选一张小图，logo EDUK12.TOP，不强制配图。上游0.7筛选规则未自动采用。
