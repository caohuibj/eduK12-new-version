## 目标与用途边界

研究连续图像流中的重复识别与误报，不是已标准化个人记忆量表。素材本身的可记忆性与个人表现不能混称。可先用于本轮描述、自我观察/趣味体验及研究；学习评估/招聘只登记待验证需求，不推断诊断、录用预测、年龄排名、智力或总体记忆能力。年龄、人群、难度等级与中文理解均待核；中英文提案。

## 双版本提案，不偷换比例

|项目|研究对照提案（上游示例参数）|体验版提案|
|---|---|---|
|T/生成块|60 / 65|20 / 25|
|图像呈现/ISI|260 / 260|100 / 100|
|首次目标/目标重复|60 / 60|20 / 20|
|首次填充/警觉重复|124 / 16|54 / 6|
|净呈现时间|403秒|155秒|
|名义图像/ISI时长|750/800ms|相同|
|其他生成参数|4图/块、起始5块、最小4块、警觉间隔4块、随机重复|相同参数值|
|拟新增练习|8次、6张独立占位/正式须独立有权图、2次重复|相同提案|

100次比260次减少160次（约61.5%），**不是严格只改次数且比例不变**：目标重复率从60/260≈23.08%变20/100=20%；尾部/起始开销比例变化；实际lag频数须manifest核验，不先宣称与长版完全相同，也不主张其范围必然变化。未偷偷改变生成算法来凑比例。短版无本项目可靠性/常模，是否接受结构差异待确认。所谓“块”是序列生成结构，不能凭此加入25/65次屏幕休息。练习为项目新增，不冒称上游已有；无伪造通过线。8次练习只教操作，短lag和重复占比不代表正式4块最小delay及正式类别比例，两profile使用相同练习提案。260次来自fixedOrder=false示例，不凭开关名声称重复顺序随机，也不凭示例称原论文同版；用户要求的文献对照目标仍需具体论文逐项核对。

### 默认重复顺序的静态发现

源码ready池初始为空。blockIdx>minRepeatDelay+1（默认>5）时每块shift一个shown target入池；同块blockIdx>firstRepeatDelay（默认>5）又pop一个repeat。故此默认路径每次repeat前ready池只有1个候选：shuffle一个元素不会使目标重呈顺序随机。配对源块差静态为5；块内位置各0–3，使图片lag=20+repeatSlot−firstSlot，范围17–23（中间图16–22）。这是源码/算术静态推导，未运行第三方生成器；若更换参数，结论需重核。不擅自扩大候选池来“优化”随机性。

## 输入与显示建议：仍是单一seen，不改成2AFC

固定的大“见过”回应区，触屏pointerdown优先，同一按钮兼容鼠标；R键为键盘替代。第一次看到时不操作；不增加“没见过”必答键。后者会把原来的重复检测/不回应任务改成二选一，不能当无差异适配。

建议将图片后紧随ISI并入上一图的回应窗口，说明同步写清。边界[该图实际onset,下一图实际onset)，每图首个有效seen才计一次，其他输入有界保留。按钮在图像和ISI位置一致，不加正确反馈/奖励，不让回应提前结束750/800ms。选择其他归属规则必须另冻结版本。

上游512×512图片/400×400注视图不适合直接塞进手机。预览提案为固定300 CSS px正方形图像区，四入口/双profile相同，容纳不足不自动缩小；这是新几何条件，CSS px不证明物理视角或设备等值。200%阅读支持只核指导/报告，不宣称刺激可自动缩放施测。素材、几何与输入等差异都进入冻结tuple/适配说明；当前提案未发行，不虚构normVersion。

## 指标、分母与质量

个人定义提案：只纳入首呈与重呈都完整技术有效的同一目标配对集合。HR=目标重复seen/有效targetRepeat；FAR=对应目标首次seen/有效targetFirst；**不把首次填充混入FAR，也不把警觉重复混入HR**。CRR=HR−FAR，可为负，绝不裁零。填充FAR、警觉miss另列研究质控，零分母为null。本轮不追加d′。

配对必须记录firstTrialIndex、repeatTrialIndex、实际lagImagePresentations=repeat−first、interveningImages=lag−1、实际onset间隔及块索引。示例0起：first3、repeat23→lag20、间隔19图、源块差5；只是字段演示，不宣称固定lag。

保守报告门控提案：全部计划目标配对完整才放行整体HR/FAR/CRR；部分受损时limited隐藏受影响整体率，显示完整性而非假表现；manifest/版本无法核验或没有有效配对时invalid不输出表现。此完整性规则不是可靠性证明，最低有效N与时序容差尚待研究。上游filler FAR≥0.7或警觉miss≥0.7是文献经验筛选，不直接采用为项目普遍无效/能力界值。

合成可解释例：目标重复16/20→HR .80；对应目标首次误认5/20→FAR .25；CRR .55（55个百分点差值，绝非55分）。54个首次填充和6个警觉重复不进入这两个分母。limited示例82/100已收、17/20完整配对，三率全null；invalid无表现数字。图文与可选单张EDUK12.TOP小图用同一投影，不直接展示隐藏metrics。
