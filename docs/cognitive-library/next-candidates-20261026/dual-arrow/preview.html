① 说明与三个例子

先看本块要求，
再回答箭头朝左还是朝右

每次都能看见上方浅蓝、下方红色两个箭头。它们可能朝同一边，也可能朝相反方向。

同一幅图，三种规则

① 只答上方蓝：蓝箭头朝左，点上方通道的“←”。红箭头不用回答。

② 只答下方红：红箭头朝右，点下方通道的“→”。蓝箭头不用回答。

③ 两个都答：上方选“←”，下方选“→”；两个通道各答一次。

上方“蓝/下方红”说的是箭头位置和身份；回答的是朝左或朝右，不是上下方向。

每通道只收第一个回应，不能改答；长按不会重复计数。双任务可两指分别按，也可先后回答，但要在5秒内完成要求的通道。

只做3轮较易练习

三种规则各练1轮；作答窗放宽至8秒，每轮解释反馈，3/3正确即可。未过先重看完整说明和例子再试，最多3组。

我已理解，进入练习

每个新块用一句话提醒本块规则，不重复加练习。颜色同时有上下位置/文字身份，不以颜色作为唯一线索。

按钮示意，每个触控目标≥44px。单任务仍显示两个箭头，但非要求通道的按钮禁用；双任务两通道独立锁首答。

不要求“同时碰到屏幕”

两箭头同时出现，各通道独立记反应时。两个都要回答，但不另设50ms同步门槛，不逼迫做物理同时按压。

键盘上方1/2，下方9/0。手机双指、鼠标先后点和键盘双手有不同动作负担，实际输入分开保留。

黑底、65px原创几何箭头、上浅蓝/下红、左右错位80px。为移动阅读调整颜色，对照原版深蓝/红的变化明示，不能称原刺激或设备等效。

每轮先短暂注视，再呈现箭头；回应完成或5秒后给反馈。未要求的通道是“不适用”，漏答是“未回应”，都不是0毫秒反应。

一个可用的提醒

两件事都需要立即回应时，可以先明确各自规则和回应方式；重要事项也可以逐项确认。这是一般建议，不是对现实多任务能力的预测。

动作方式、顺序、练习和疲劳都会影响差值。没有0–100“多任务能力分”、常模排名、临床或职业适配结论。
