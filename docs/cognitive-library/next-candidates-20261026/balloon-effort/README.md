## 已批准并实现的科研版/实用版

- research72轮：3种高按压基准50/100/200 ×3种收益3/5/7 ×2种兑现概率100%/50%，18条件各4轮。低按压恒为20次/1点。左右平衡，50%轮的兑现/不兑现预排平衡，同轮两选项的兑现结果相同，不依参与者选哪边改变。
- experience18轮：保留全部18条件各1轮，不从72轮随意截取。左右总计9/9，条件内单次不能同时左右平衡。50%条件9轮，预排兑现次数以seed等概率取4或5再排列，使抽取期望为50%；不能说每个短版个体都恰好兑现一半。高努力计点公式、单题时序、指导和输入与长版一致。这是项目短版，没有稳定个体选择参数或长版等值资格。

## 输入、刺激和计点

原创气球/目标标记：较少按压蓝色，较多按压绿色；左右位置平衡。标准中性界面，不继承产品入口主题。两版相同布局、颜色和大触控区。气球不是随机爆炸的风险游戏，不套已有BART证据。

触控/鼠标先选左右，准备后只点所选侧；一次完整按下/松开计一次，长按不连续计数、多指不叠加。键盘Q/P保留，选择键须松开再开始执行；重复keydown不计独立按压。实际输入、每次按压、起止时钟、offer、兑现预排、左右布局、选择与执行分别保留。触控计数方式和运动负担相较原键盘变化，不能混同设备速率。

高按压且本轮兑现时：点数=基准收益×实际按压数/按压基准，四舍五入2位，可低于或超过基准点数；不封顶，不在达到基准时提前结束25秒。不兑现为0。低按压完成20次提前结束，兑现时给1点，否则0；25秒内没完成则0，无部分/额外点。未选择是null，不是低按压或0速率。

默认仅记录任务点数，不承诺现金兑换；研究如采用外部奖金，必须在施测前向参与者说明、冻结实际奖励安排并实际兑现。当前不开发支付设施；缺真实激励时不得称原论文激励复现。

## 教学、报告和标签

练习为2次较易操作演示（低5次/1点，高10次/2点基准，均用100%兑现、执行窗5000ms，逐步解释）加3道理解题，3题均正确才开始：考查概率、比例收益和未选择语义；偏好选左/右没有正确答案。失败必须先重呈完整说明和例子再试，最多3轮，原件不覆盖。不能把选低按压当作练习错误，也不套用论文>85%单一偏好自动无效规则。

后台报告按努力基准×收益×概率保留实际高按压选择次数与有效选择分母；主屏可按努力基准分层，收益/概率和完整18条件展开。执行按压/时间/速率、完成情况、兑现点数另列；触控/键盘分开。率没有“越高越好”的普遍方向。图中17/18有效和8次较多为合成示例，不是预设结果。无选择/缺失不补低努力/0，报告三态与下载共用gate，不虚构动力、人格、临床或招聘预测分。首版不实现未经验证的个体logistic模型或阈值，不把报告内容留到最终测试重做。

沿18维研究稳定key，不改变旧研究标签的含义；实际输入/变式单列当前metadata。场景含科研、自我观察、工作负担交流；临床/招聘等仅未验证用途说明，年龄/难度/中文/运动和手机适用性未核。

## 时间与负担（设计估计）

科研版预计20–55分钟，实用版7–17分钟，含首次说明、较易练习与短休息；重练每轮另约1–3分钟。每轮非选择/执行固定阶段共9.2秒，假设选择1–3秒，低按压20次约4–7秒，高按压为完整25秒，约14.2–37.2秒/轮，选择比例影响总时长。另加首次说明练习约3–5分钟、科研版3次短休息。实际选择可用至6.5秒，休息自主，估算不是完成时长上限或实测。

认知负担主要为比较收益/概率/努力，预计中等；反复操作及手部累积疲劳较明显，研究版更高。短版每题同样有200次基准，25秒内允许低于基准按比例得点；不强迫按够200才算完成。输入熟悉程度和身体舒适会影响选择，不能解释为动力强弱。
