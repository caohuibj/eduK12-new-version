① 说明与较易练习

这轮，你愿意按多少次？

每轮在“较少按压”和“较多按压”之间选择，再实际完成按压。两边本轮的兑现概率相同。

先看一个例子

左边20次、1点；右边以100次为5点基准，兑现概率均为50%。

右边若兑现，按80次得4点，按120次得6点；若不兑现，则得0点。

较多按压有25秒，可少于或超过基准；较少按压完成20次后结束，未完成不给点。

操作与时间

  1. 6.5秒内选左或右，超时记“未选择”，不算选择较少。
  2. 准备倒计时后，只在所选侧反复点按；每次松开再点算1次。长按不连加，多指不叠加。
  3. 鼠标同样操作；键盘左Q、右P，长按自动重复不计数。

左右会交换，较多按压不固定在右边。连续按压容易疲劳，随时可以结束本次记录。

实际执行另看

按压次数、实际执行时间与速率、未完成次数、兑现点数分别记录；触控和键盘速率不混成一个能力分。

一个可用的提醒

安排重复操作时，可以把收益、时间和疲劳一起考虑；本记录不用于评价是否勤奋或是否胜任工作。

短版每个完整条件仅1次，不足以推断稳定偏好。实际奖励、设备、手部状态与理解都会影响选择。
