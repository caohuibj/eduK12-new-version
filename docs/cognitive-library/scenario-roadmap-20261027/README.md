## 1. 科研定位与选择方法

先问“要研究哪种真实过程”，再决定用哪个范式，不为了接近某商业平台的游戏数而重复开发。职业方向研究任务表现与工作过程/情境表现的关系；儿童方向研究发育中的抑制/规则切换/持续注意；成人方向研究注意波动、警觉和情境控制。职业岗位关联、临床效度、个体常模是未来可研究的问题，不是本轮已知结论。

Harver当前pymetrics官网列努力、风险、决策、注意、专注、学习、公平、慷慨、情绪九个方面；旧白皮书另含定量推理和数字敏捷共11类，不混为固定游戏—构念一一对应表。对标维度和交互体验，不复制品牌、美术、私有题目或匹配模型，不推定开放任务继承其岗位预测证据。[官网](https://harver.com/gamified-assessments/)、[白皮书](https://harver.com/wp-content/uploads/2023/02/pymetrics_FINAL_pymetrics_SoftSkills_Whitepaper.pdf)。

科研用途改变取用路线：NC/学术用途材料可以进入备选，不能仅因不适合商业产品排除。分别记录代码、刺激/题库/译文、分发与科研原件的条件。学术可用不等于允许把受限题库、参与者数据或NC素材直接放入当前公开GitHub；材料不公开不妨碍公开自研协议/说明。无需本轮联系授权方、注册账号、下载受限题库或参与者数据；备选登记不伪装已经获权。

## 3. 儿童ADHD相关与成人注意力：复用与新增

CDC强调ADHD诊断不是单一测验；反应波动的群体研究也显示其并非ADHD特异。这里研究注意/执行过程，不能把正常任务表现当作排除ADHD，也不能把漏答等同ADHD症状确诊。[CDC](https://www.cdc.gov/adhd/diagnosis/)、[319研究元分析](https://pubmed.ncbi.nlm.nih.gov/23872284/)。NICE对特定QbTest在6–17岁临床综合评估中的建议不适用于我们的通用CPT/浏览器版本；本轮NICE全文返回403，仅检索摘要观察，未冒称完整重读。

| 场景/研究问题 | 先复用 | 新增候选与区别 |
| --- | --- | --- |
| 幼儿/低年级能否记住规则并抑制顺手反应 | Go/No-Go、Flanker、任务转换；协议/年龄仍未核 | Hearts & Flowers：同侧/对侧/混合规则，减少文字需求；DCCS作低龄储备 |
| 学龄儿童长序列内漏答、误按与表现波动 | CPT-X、gradCPT、SST、ANT/PANT | SART：频繁按、罕见不按，研究自动化反应下的注意失误；不是把现有Go/No-Go改个名字 |
| 成人持续注意/日常注意波动 | CPT-X、gradCPT、ANT、视觉搜索 | SART；按任务分开分析时间内变化，不能混合不同protocol的RT阈值 |

儿童招募拟按低龄与学龄段分别设计，具体年龄区间等待单项方案，不将“文献用过儿童”写成本项目全龄已验证。家长/教师及成人自评信息属于量表/背景信息，可在现有表单能力中另列研究模块；ASRS/SNAP等版本和中文授权另核，不混计认知测验。Harvard当前ASRS页面抓取超时，检索提示18题版需请求许可，故本次不复制题目或宣布可直接电子化。

## 5. 实际源码与科学来源观察

- SART固定735d300…的README为18练习＋3×75正式、250ms数字/900ms mask、错误反馈3秒。亲读sart.py可见错误时core.wait(3)，不直接称原版连续225流程；每75个序列截取再shuffle也不等于全225每数字各25的严格平衡。只是静态观察，没有运行该源码或宣称缺陷复现。原研究主要成人/脑损伤，不能据此自动证明儿童ADHD诊断效度。数字大小、反馈和touch改造都须在单项图审中明示。
- PVT-B论文摘要实际样本74名健康成人22–45岁，比较10与3分钟，3分钟存在敏感性取舍；论文短版迟缓阈值355ms与标准500ms不同，是文献分析阈值而非诊断阈值。研究版与短版即使UI相同，ISI/质量解释也必须分别冻结；手机输入不继承论文验证。此处不增加物理曝光门禁或时序研究。
- 信息采样参考源码25格、固定奖励及随揭开次数递减奖励；num_trials=10不是自动证明只有10个总情境，循环/条件与计分后续单项冻结。图像路径和旧jQuery不能直接成为React资产合同。
- 感知元认知参考代码exp_len=300、10练习、4级信心；平均信心不是能力，ordinal四级不能直接当概率算Brier。meta-d′/M-ratio需对应数据/模型适用性，当前只列研究选项，不新增拟合平台/模型门禁。
- discount_titrate实际预生成36组，并含真实未来奖金承诺。若本研究用假想奖励，须诚实说明，不能承诺不存在的延迟付款或称真实激励等效；货币/时间单位儿童化也属协议变化。只有真实设计/数据支持时才估折扣参数，先保留逐题选择与条件。
- AX-CPT固定源码3×40，AX七成、AY/BX/BY各一成；文内键位描述和实际映射需未来冻结时对齐。稀有条件少、字母理解和中文年龄适用性须解释，不设置任意“注意力合格分”。
- oTree参考social任务用Python及两人等待页，不能整包导入React，也不能把一个session内的假对手伪装真人。单人标准化伙伴可先做科研变式并明示；真人配对/报酬需要后续具体业务delta，当前不改服务器或引入多人平台。fairness/generosity/reciprocity分别研究，不生成道德总分。
- ICAR当前官方限定学术用途、需按项目登记，不允许公开发布完整题库；可与学术团队用作研究/验证，不等同商业化许可。官方列中文译本，亦明确无常模且不用于推个人IQ；本轮未注册/下载受限材料，不退回旧“全部public domain”口径。
- DCCS的PhenX标准版协议可免费使用、无需许可；参考传统访谈员指导、pre/post各6张、来源年龄2.5–7岁。本项目自助触屏/双profile不是同一施测方式，需设计时明示；不照搬原发展研究通过率当本项目诊断界值。NIH Toolbox有独立版本/许可，不因范式同名自动继承。

## 7. 建议推进与系统微调清单

建议第一轮交替做儿童和职业研究缺口：H&F → 信息采样 → SART → 信心校准 → PVT/PVT-B → 延迟选择。AX-CPT、ICAR指定题型及两种社会决策进下一轮；DCCS/SJT保留，按实际样本人群与课题取舍。管理员可调整顺序，不在本轮自动开12项。

兼容性建议：这些均能沿现有候选TS/React、两真实profile、冻结清单/版本、事件/回答、三态描述报告和DB轻量核心/COS完整原件思路。通常是新内容定义及局部候选组件，不需要schema/服务器调整。具体可能新增的内容结构：①信心任务第二阶段及两次RT；②信息采样揭开顺序/成本；③延迟选择的金额/时间与真实/假想激励标记；④ICAR受限材料引用/译本版本；⑤社会博弈角色/对手类型/回合。需先读实际schema，不在此凭空新增字段。真人配对/真实延迟付款/新材料权限只有选中时给最小delta，单人科研候选可先推进，不当全计划门禁。
