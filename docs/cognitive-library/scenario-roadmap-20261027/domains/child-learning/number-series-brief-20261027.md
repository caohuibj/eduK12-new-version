# 数列规则推理｜单项设计待审

配图：`number-series-review.png`。静态原创示意；未开发、未验证、未接入，等待 DOT 实际核图和介绍后通知用户审核。

**任务与例子**：看一行数字，从四个选项中选下一项。例如 `3、7、11、15、?` 每次加 4，选 19。三种条件为等差、等比、递增差值。拟招募已学过所需加法和乘法的 8–12 岁儿童；年龄适用性尚未验证。

**次数与时间提案**：research 24 题，每条件 8 题，约 9–15 分钟；experience 12 题，每条件 4 题，约 6–9 分钟。估时含首次说明及练习，非实测、无速度期限。两版同界面、同单题规则；短版只减少重复，保留三类条件。

**练习**：先完整展示中英说明和三个例子，再做 3 题较小数字练习，每条件 1 题、逐题解释。3/3 后继续；失败、跳过或未完成先重看全部说明和例子，再练，最多 3 轮，可退出。练习不进入正式结果；重练每轮另估 2–3 分钟。

**材料与难度依据**：示例和界面为本轮原创；正式题库尚未编制，获批后拟自研条目，不复制 ICAR、韦氏或瑞文题库。方法参考 Sun、Liu、Luo（2019，DOI：10.3389/fpsyg.2019.00884）的序列关系；科研版拟保留三类条件、限定正整数及答案不超过 200，以减少无关运算负担。**这些只是项目参数，不是儿童难度标定；科研版也没有儿童实证难度、信效度或常模依据。**四选一、儿童范围及 24/12 题均为本项目改造，不能继承原纸笔研究证据。

**改造与限制**：触屏四选一、首次点选即提交，无预选答案；可跳过、组间休息或结束。正式反馈只读真实记录，完整/有限/无效三态同时约束正文、图片和下载；图中报告数字全部虚构，仅供排版。教学、运算经验及输入方式会影响表现，长短版等值性未验证。**本任务与韦氏、瑞文不等价，不是其数字等价版**；不输出 IQ、常模、同龄排名、诊断、学业或岗位预测。
