## 冻结协议与教学

- testType `information-sampling`；engine/scorer/config/protocol均实际初版0.1.0，profile、参数解释、metric、quality、reportDefinition、presentation各自独立字段0.1.0。实际配置和protocol分别哈希并按精确组合解析，不找“最新”配置重算历史报告。
- research20/experience10：两奖励块各10/5，真实多数13–17各2/1。seed选择块次序、块内条件顺序和25格身份位置；多数身份长版每条件蓝/橙各1，短版每条件仅1且两个规则互补，块内正确左/右3/2、另一块2/3。按钮固定蓝左橙右，沿已批准图；单场块顺序和细分条件不能提供独立因果识别或稳定参数。
- 两版均25格、原创蓝圆#176B9A/橙三角#A84D12、48×48px格、6px间隙；操作/普通文字沿既有标准角色色。可以0–25格后判断，首次有效多数判断锁定；完整按下松开同一控件，或明确辅助激活。取消/跨控件松开/多指/重复/长按不制造额外采样，已揭格不重复扣点。
- 固定：正确+100，错误−100；递减：正确250−10×不同揭格数，错误−100；假想点数，无现金承诺。0格直接答是合法行为，25格正确为真0；不以高收益或采样偏好作为练习或质量标准。
- 无作答deadline。判断后全盘/结果2秒；浏览器略早的定时回调只等待剩余时间，晚回调不伪造物理时刻、不重曝、不因一帧误差阻断。没有密集探测/预检/帧白名单/逐帧日志或网络。
- 2轮易练习（两规则各1，多数21/25、额外提示），完成流程后3道规则理解题（全盘目标、固定100、递减7格180），3/3理解正确才继续。不要求练习选择正确一侧或达到收益；失败/中断/未完成先完整重呈中英说明和7格例子，最多3组。各组练习/理解题独立保存，未提交理解题保留null与submitted=false，不计正式数据。
- 时长沿已批估算：research约6–10分钟，experience约4–6分钟；按采样/判断12–20秒+2秒反馈及首次教学估计，非实测/上限。重练每组另约1–2分钟。认知负担中等，长版重复更多；中文、人群、难度、设备及短版效度未知留null。

## 原始记录与权威报告

raw保留冻结plan/多数/棋盘、揭格顺序/真实输入、阶段事件、首判断/揭格数/对错/点数/实际时长、中断/溢出事实；后端按真实snapshot、seed/plan、envelope、阶段时钟与有界事件逐步重放，不信客户端state或correct/points。正式round恒0，practice/quiz按轮次隔离。中断后不继续新增正式局；判断后反馈中断保留已作判断，判断前中断不补答或−100。

分规则/真实多数格数保存planned/presented/decided/correct/completed/omissions/interruptions。正确率分母是decided，遗漏分母是presented，不与未呈现混合；中断和无判断可能重叠。揭格均值/中位数和判断时间只取已判断局，分母0为null，真0和负点数保留。递减减固定均值差保留符号；只有两边全部对应多数条件都有完整判断才给差值，其余null，不把不均衡条件差讲成成本效应。

后台metrics均research_only，通用participant presentation隐藏原始metrics，专属白名单投影负责公开报告。正文温暖具体：真实条件数值/分母、解释、一般核查建议与简短限制；完整细节展开。interpretable给获准描述，limited只给实际覆盖和可解释条件，invalid不给表现正文/图片/JSON下载。可选小图最多1张，EDUK12.TOP；JSON下载同一公开投影，不带observations/内部quality reasons。没有常模/折扣模型/最优停止模型/能力分或就业结论。

客户端候选复用既有风格的prepareLocalAttempt/persistLocalDraft/finalize端口约定：首次棋盘前需真实fresh耐久回执；每局结束先保留原件，再await保存；失败停止、同摘要重试不重曝；最终声明冻结数量/终止原因/recordDigests，只在匹配身份/摘要/报告tuple回执后显示报告。不清除待归档原件，不声称关页后台上传可靠。这里没有新IndexedDB、HTTP、DB、COS实现。实际原生envelope要求可校验软件时钟；坏时钟/身份/结构被拒绝，不补0或伪造成功，原件仍由宿主保留；未来接入不因此改共享schema。

18维稳定key来自22721e5…；无精确值的范式/素材等留空，当前状态/输入另列，不篡改历史source_research_only。多场景只是科研需求描述，年龄/中文/难度/设备留null，后台标签存储/检索未接通。素材/译文为原创，源MIT实际通知见任务NOTICE，不复制私有题库、品牌或上游PNG。
