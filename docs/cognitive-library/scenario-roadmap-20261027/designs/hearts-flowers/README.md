## 原研究及本方案

实际阅读 Camerota、Willoughby 与 Blair 的 [方法：Executive Function](https://pmc.ncbi.nlm.nih.gov/articles/PMC6675624/)：一年级儿童在笔记本键盘上先做心12、花12、混合33；图形最多呈现2500ms，回应后移除，刺激间隔1000ms；说明和练习最多重复三次。其研究分析排除了反应少于75%或整体正确低于50%的记录，且将小于200ms反应设缺失。那是研究分析选择，不作为本项目质量或能力阈值。该论文 DOI 10.1037/pas0000725；当前BioC作者稿元数据与卷期日期未作最终书目核定，删除旧稿“2019在线、2020卷期”断言。Davidson等（2006，doi:10.1016/j.neuropsychologia.2006.02.006）及 [Diamond 实验室](https://www.devcogneuro.com/eftasks.html)为范式背景；未将不同版本拼为原文方案。

本提案采用自绘几何图形、触屏/鼠标或键盘、详细双语教学、固定项目条件分配；因此称**项目研究版**，即使研究版正式总数参考该文57次也不宣称论文复现或等效。

## 教学与实践

规则在两版相同，完整中英说明含四个明确例子：心左→按左，心右→按右；花左→按右，花右→按左。先看图形，再看位置；心按同一边，花按另一边。固定左右大回应区同时支持键盘左右键，统一一次实际输入；图形与回应区分开，不能把图形本身误当回应键。说明以儿童可理解语言配图，可由照护者朗读；适用年龄和理解效度未核，实际协助信息未知保留null，不伪造已协助。

已批准每一教学轮各2次心、2次花及4次混合，共8次，较慢且逐题暂停解释；每题最多3500ms回应、空屏1000ms。采用7/8作为是否进入正式的**教学规则**，不是临床或能力阈值；最多3轮。未完成或未通过时先重新呈现完整双语指导与例子，再进入下一轮；结束练习不伪报正式完成。此教学规则已冻结；中断组不伪通过，可在完整说明后开新组并保留旧记录。

英文示例：“Heart: press the same side. Flower: press the other side. First look at the shape, then choose a side.” 实践反馈说明图形、出现位置及正确侧；不把答错解释为能力不足。
