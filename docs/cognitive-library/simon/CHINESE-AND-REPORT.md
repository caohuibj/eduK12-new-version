# 中文与描述性报告草案

独立工作译文，未经回译、理解度或心理测量验证，无此版本/人群已验证常模。

## 指令

每次屏幕左侧或右侧会出现一个红色或蓝色矩形。请根据颜色按键，不要根据它出现的位置按键。看到红色时按【红色对应的方向键】，看到蓝色时按【蓝色对应的方向键】。请在尽量准确的前提下尽快作答，每次只按一个键。先进行20次练习，练习会提示正确、错误或未及时作答。正式任务有100次，不再逐次反馈。整个任务的颜色与按键对应关系保持不变。

占位须替换实际映射，正式开始前重复映射。明确忽略位置及速度—准确文案是适配，不称逐字原译。练习反馈：“正确”“错误”“未及时作答，请尽快按键”。

## 无虚构数值的报告结构

标题：Simon 空间相容任务表现。

- 主指标：平均反应时差值（不相容减相容），毫秒。
- 并列：两条件合格正确RT数量、平均/中位RT、正确/错误/漏答及分母。
- 次指标：中位RT差、准确率代价（明确原始ratio或乘100后的百分点）。
- 质量：技术无效数量、缺失原因、协议/设备/版本限制。
- 任一条件无合格RT：“数据不足，无法计算”，原始null，绝不填0。

差值反映本次条件间表现差异，应与准确率和漏答共同阅读。速度—准确权衡、设备时序、试次数量与理解均影响结果。负值不自动表示更好；本结果不是0–100等级、年龄常模、百分位、IQ、临床诊断或风险分层。

不显示通用产品指数，不给健康排名；材料不能替代中文适配/测量验证。
