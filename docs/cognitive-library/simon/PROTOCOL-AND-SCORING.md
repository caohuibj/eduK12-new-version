# 独立冻结协议与计分规格 v0.1

设计规格，非已验证原算法；未实现。只用桌面物理方向键37/39，不用f/h、鼠标或触屏。

## 核心参数

- 程序生成红/蓝矩形、左/右位置。每场随机映射A红左蓝右或B红右蓝左，练习与正式保持一致，动态指令。
- 练习20次：四个色×侧单元各5；正式100次：各25。分别随机排列，保存种子、算法版本、实际顺序与映射。
- 响应窗口2000ms。首次允许键事件满足0 <= RT < 2000；恰2000或以后拒绝，是新明确边界，不声称复制旧竞态。
- 正式响应不提前结束试次，到2000ms窗口结束；首次有效响应后隐藏刺激。练习刺激/窗口2000ms，反馈1000ms；试后间隔整数500–999ms。
- 待决、启用前须冻结：练习反馈相对首次响应/窗口结束的确切起点、具体布局与首帧策略。源15vw×20vw和transform只是来源描述，不保证新容器等价。不把8分钟文案当精确时长。
- 单调高分辨率时钟；记录帧策略、帧间隔、焦点/可见性、视口/缩放、OS/浏览器/输入设备。时间戳精度不等于物理显示/按键时序，科学精度声明前需硬件验证。
- 忽略held/repeat，不允许键可记录但不消耗有效反应；迟到事件不覆写首键。色彩/理解检查不新增经验通过阈值，改颜色/形状/输入属于协议变化。

## 独立计分

1. congruent 当且仅当刺激侧等于颜色所需正确键的侧；否则incongruent。不得用实际按键判条件。准确性独立比对所需键。
2. 只含正式刺激；排除练习、说明、反馈。焦点丢失或映射/时序损坏为技术无效，排除行为分母并报告；完整计时无响应为漏答。
3. 每条件正确率=正确接受反应/技术有效正式试次；错误率=错误允许键/同分母；漏答率=无接受反应/同分母。分母0则比例null，不填0。
4. RT集合仅技术有效正式正确响应，finite且0<RT<2000。0ms可计正确率但不计RT；错误、漏答、非正、非有限RT排除。无默认SD/低RT阈值/post-error/winsorization。
5. 主simonEffectMeanMs=mean(incongruent)−mean(congruent)，ms、signed；中位差单独命名。任一条件无合格RT，差值null及不足标记，不填0。
6. 报告每条件n、mean/median RT、正确/错误/漏答及技术无效数。accuracyCostRatio=accuracy(congruent)−accuracy(incongruent)；若显示百分点乘100并正确标单位。
7. 非零n不保证可靠性，不制造最低n、0–100、IQ、健康分级、百分位或临床阈值；负/更小效应不自动更好，需并读速度—准确权衡。
8. 保留版本/映射/顺序/所需键/实际键/RT/技术状态。未来若迁移旧数据，保留raw condition并另存derived/scoring version；本包不迁移。

上游correct_responses随机翻转而condition固定，B四条件全部反转，但correct_response正确。credit_var混合练习/正式和错误RT，是参与启发式而非Simon评分；不移植其40%/200ms/85%门槛。
