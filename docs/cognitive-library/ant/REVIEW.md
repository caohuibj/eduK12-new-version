## 2. Original-paper protocol target versus code

Compact method facts from paper Methods, printed pp345–346: four cues (none/center/double/spatial), three flankers (neutral/congruent/incongruent), two locations (above/below), two arrow directions. Target is middle of five elements. Spatial cue is valid. Within each session: practice24; formal3×96, each block repeats48 combinations twice. Randomized order. Initial fixation400–1600ms; cue100ms; following fixation400ms; response-ended target up to1700ms; posttarget fixation3500−initial fixation−RT, nominal trial4000ms. Fixation remains central. Arrows/lines are black on gray; element width0.55°, gap0.06°, stated whole row3.08°, eccentricity±1.06°, viewing distance65cm. The original study used two sessions in one day with an intervening Stroop task (Procedure, printed p346); this package covers only one ANT session, not that complete research procedure. These facts are not normative cutoffs.

Selected MIT source differs:24 practice +3×48=144 formal, not288. first fixation uses integer400–1599ms. CSS uses viewport-relative row boxes (25vw×7vw), transformed up/down, PNG max-width16% and4% padding; cue glyph60px. These are not calibrated visual angles. Do not inherit them as paper-faithful geometry.

Source post_trial_gap computes3500−previousRT−earlierBlockDuration. If a timeout RT is−1, using it arithmetically gives3501−fixation rather than1800−fixation. With a1700ms target phase that would make a nominal5701ms trial. This is a conditional static defect derivation, not observed runtime behavior. Source dependencies are excluded, and actual legacy timeout sentinel semantics were not executed. New design uses elapsed target time, never−1.

## 3. Frozen target design v0.2

Candidate key: ant-paper-protocol-original-artwork-draft-0.2. Formal288, not144. No short variant is approved.

Canonical factor order: cue=[none,center,double,spatial], flanker=[neutral,congruent,incongruent], location=[up,down], direction=[left,right]. Each formal block contains all48 combinations with repeat index0 and1, so96 trials;3 blocks. Stable IDs include stage/block/cue/flanker/location/direction/repeat. Left/right directions map to ArrowLeft/ArrowRight, independent of cue/location/flankers. Neutral flankers are horizontal lines; congruent flankers have target direction; incongruent flankers opposite. No-cue draws nothing additional; center cue overlays central marker; double cue draws at both target locations; spatial cue only at actual target location. Correctness is defined by central target direction, not pressed-key side or trial location.

Practice24 follows paper count, but paper does not enumerate exact practice items. **Explicit engineering choice:** one direction for every cue×flanker×location combination, selected by directionIndex=(cueIndex+flankerIndex+locationIndex) mod2. Marginals: each cue6, flanker8, location12, direction12. This balanced design is not claimed to recover original practice order. The paper specifies practice feedback on both speed and accuracy (Procedure, printed p346). Show correct/wrong/no-response feedback plus actual accepted RT in milliseconds for correct or wrong responses. Display RT rounded to nearest integer millisecond for readability, retaining the unrounded value; do not label speed fast/slow or apply a normative threshold. On omission show “未及时作答；反应时：未记录”, not1700ms as an observed response. On technical invalidity show “本次计时无效；反应时：不可用” and suppress numerical feedback. Feedback duration1000ms is an explicit comparison-script choice; paper feedback layout, precision and duration were not specified. Practice timing may therefore exceed4000ms; never include practice in formal statistics. No automatic practice retries or participant exclusion threshold is inferred from the paper.

Order engineering choice: record a seed before scheduling. For each stable trial ID compute SHA256 of UTF-8 `ant-order-v1|seed|trial-id`; lexicographically sort full lowercase digest within each block, tie-break stable ID. No post-hoc run-length restriction or reshuffle. Fixation jitter uses independently domain-separated SHA256 `ant-jitter-v1|seed|trial-id`; interpret first8 hex digits as unsigned32, take400+(value mod1201) ms, hence400–1600 inclusive. This is a new reproducible generator, not the authors’ RNG; modulo reduction is minutely biased, explicitly accepted as an engineering choice rather than perfect continuous uniformity. Persist final order/jitter, seed, algorithm version and geometry revision. Practice has its own stage IDs so it cannot perturb formal scheduling. No scheduled trial list was executed.

## 4. Timing and response contract

The following are deterministic design decisions for future review, not existing platform behavior:

- Logical trial onset begins initial fixation. Cue interval occurs even in no-cue trials. Keep central marker visible across formal phases except center-cue replacement/overlay defined by rendering design. Target onset is the logged presentation-frame callback timestamp for the frame submitting target geometry; RT uses the same monotonic clock. This operational onset is not measured photon onset and must be reported as such.
- RT is keydown event time minus that target-onset timestamp. Accept first non-repeat, non-held allowed arrow event in0≤RT<1700ms; disallowed keys are logged but do not consume the response. Preserve raw event and capture timestamps; reject incompatible clock domains. Exactly1700ms is late, irrespective of callback race order. Wrong in-window arrow ends the target just like correct. Subsequent keys cannot overwrite first accepted response.
- Hide target at response or deadline; continue fixation. Let e be accepted response RT, or1700ms for timeout. Nominal posttarget fixation=max(0,3500−d−e), d=initial fixation. This yields4000ms nominal formal trials. New native records use rt_ms=null for nonresponse, with elapsed_target_ms=1700 on an intact timeout. Only a separately identified legacy import may carry legacy_rt_ms=−1; normalize it to normalized_rt_ms=null before any scoring or timing arithmetic, preserve the raw legacy value as provenance, and set elapsed_target_ms=1700 only when an intact timeout is confirmed. A negative native RT is invalid data, never a valid response or silently accepted legacy sentinel. Frame quantization and callback delay mean actual onset/offset intervals may differ; preserve them. Do not shorten later trials to conceal overrun.
- At d400/e500, post2600; d1599/e1699, post202; timeout d400, post1400; timeout d1599, post201. These are arithmetic goldens. A late accepted-by-bug callback must not move a timeout into the correct RT sample.
- Visibility loss, window focus loss during the critical interval, missing onset/response clock metadata or unknown factor/mapping makes the trial technically invalid. Keep its record and reason, exclude its behavioral denominator. Display frame drops are separately reported; no empirically unsupported millisecond quality cutoff is invented here. A valid-window nonresponse remains an omission, never technical invalidity solely for being missing.
- Desktop physical keyboard initially; touch/input substitutions require separate versioned protocol. Test key-repeat prevention, invalid-key handling, focus transitions, deadline boundary, resource readiness, and actual timing on supported OS/browser/display configurations. Use hardware timing validation before accuracy claims; high-resolution timestamps alone do not measure hardware latency.

Timing evidence: [Bridges et al2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7512138/), DOI10.7717/peerj.9414, demonstrates configuration dependence and recommends local timing validation. It does not certify this future renderer.

## 5. Original geometry design, explicitly NOT original visual equivalence

No original PNG was loaded, modified or traced. This is a mathematical proposal, not a rendered deliverable. Coordinates are angular-design units pending physical calibration. Use stroke segments and mirror transforms, not font arrows. Define target unit width w=0.55° and clear end-to-end gap g=0.06° from reported paper numbers. Five centers at x=j(w+g), j=−2,−1,0,1,2; target row y=±1.06°. This yields2.99° total, **not the paper’s stated3.08°**. Do not silently resolve the conflict by changing a gap or width. The manuscript values require verification; chosen w/g route is only an explicit draft branch.

**Engineering-only choices, absent from currently confirmed paper details:** rightward arrow shaft from(−w/2,0) to(w/2,0); head branches from(w/2,0) to(w/2−0.18°,±0.12°). Left arrow is horizontal mirror. Line flanker is the shaft only. Stroke0.03°, butt caps/miter joins. Central fixation uses two0.18° orthogonal segments, stroke0.02°. Cue uses three0.20° segments centered at0°,60°,120°, stroke0.025°, not a font glyph. Black#000000 on gray#BFBFBF. These are not measured original head shape, stroke width, luminance or cue size. ## 6. Denominators and network metrics, scoring proposal v0.2

Only formal target trials. Exclude practice, instructions, cues, fixation and feedback rows. Count every formal scheduled trial in audit totals; technical invalidity is reported separately. For each full48-factor cell and each marginal group, let N=technically valid formal target trials. Exactly one behavioral category per trial: correct accepted response, wrong accepted response, or omission. Accuracy=correct/N; error rate=wrong/N; omission rate=omissions/N, so their sum is1. N=0 produces null, not0. A first key atRT0 can count for accuracy but is flagged and excluded from RT. Correct-RT inclusion additionally requires finite0<RT<1700. Do not impute omissions1700 into RT means. No automatic low-RT cutoff, SD trim, post-error deletion, winsorization or credit_var borrowing. Any later exclusion policy requires explicit versioning and justification.

**Independent scoring choice:** collapse three blocks and two repetitions into each full-factor cell, calculate its mean correct RT. Compute marginal RTs by equal weighting required cells to prevent unequal errors/omissions silently changing factor weights. Cue mean weights12 cells; flanker mean weights16 cells. This equal-cell method is transparent but not asserted to be the original paper's precise aggregation code. Report cell sample counts and pooled descriptive RT separately. If a required cell has no eligible correct RT, the dependent primary contrast is null with missing-cell flags; do not zero-fill, silently drop the cell or switch aggregation. No participant minimum-n validity threshold is claimed empirically established. Dependency sets are contrast-specific: alerting needs the24 none/double cells, orienting needs the24 center/spatial cells, conflict needs the32 congruent/incongruent cells across all cues. A missing neutral cell can suppress its dependent cue contrast but cannot by itself suppress conflict. Report missing cells for each effect independently.

Network directions:
- Alerting = RT(none) − RT(double).
- Orienting = RT(center) − RT(spatial).
- Executive conflict = RT(incongruent) − RT(congruent); neutral is not pooled into congruent.

Positive alerting/orienting values describe cue-associated speed differences; positive conflict describes interference cost. Do not label all positive numbers “better,” rank three networks on one scale, assume their independence, or infer brain-region function in an individual. Report errors/omissions beside RT effects and identify speed–accuracy tradeoff. Output milliseconds, counts and uncertainty limitations; no population percentiles, diagnostic cutoffs, IQ estimates or normative traffic-light bands.
