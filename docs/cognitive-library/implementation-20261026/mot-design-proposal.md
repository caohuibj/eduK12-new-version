## 版本比较（提案）

| 项目 | 文献对照版 research | 体验版 experience |
| --- | --- | --- |
| 正式试次 | 45：3组×15 | 9：1组×9 |
| 3种速度各自重复 | 每组5次，共15次/速度 | 3次/速度 |
| 练习 | 2次，可重复教程练习 | 相同 |
| 每次对象/目标 | 10/5 | 相同 |
| 注视/目标提示/移动/停止保持 | 500/1000/8000/500ms | 相同 |
| 选择 | 停止后选5个不同对象，不可撤销，第5次后结束试次 | 相同 |
| 组间休息 | 两个组间休息点 | 单组，无组间休息 |
| 正式固定呈现时间 | 450秒 | 90秒 |
| 报告 | 正确目标数/比例、有效分母、质量状态 | 同一定义；每速度仅3次，明确分母和较少记录限制 |

时间不含指导、校准、练习、选择和休息，不承诺固定完成时长。参考未核固定响应超时；本项目中断策略另冻结。9次是项目暂定设计，不是论文验证短版，不能预先保证任何场景测量精度。
