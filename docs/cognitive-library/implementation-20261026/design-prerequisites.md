## 1. 标签是设计和入库前置项

每张卡保留稳定ID，至少登记认知领域、多个应用场景、年龄适用状态、任务难度；补充目标过程、范式、刺激、输入、指标、语言、设备、负担、版本用途、证据和许可。

- 沿用内容分支固定提交22721e5c63dd78819e8c58921adf20157cdaa08c的18维受控词表与稳定key，不改写历史研究目录。场景、年龄、难度等不足项单列扩展提案，核对实际消费者后接入。
- 领域标签说明任务拟测主题，不自动赋予个人能力解释或domain合成资格。实际catalog的权威domain/facet仍来自evidence-mapping registry，不创建平行真值。
- 每个场景分别记录拟用需求、证据支持程度、来源、适用协议和限制。学习困难评估辅助、企业招聘辅助可登记为待验证需求，标签本身不构成诊断或录用预测效度。
- 年龄未核保留null/待核，不标全年龄；难度描述刺激/操作负担，不从分数反向生成个人能力标签。
- 标签随内容包交付；实际入库还须核存储/回读、组合过滤、搜索、详情与导出。只有文档/JSON可检索不算后台接通。
- 用途、人群、难度标签在任务库/发布选择中展示，不在正式施测中显示，避免期待和策略暗示。

## 2. 四入口使用同一中性认知界面

范围：Survey、Training、HuiSchool、HuiTeacher。同一协议、版本、语言、设备条件使用同一呈现实现。

- 中性不是全灰阶：采用color-collection/README.md及colors.json所登记的标准界面色与任务特定刺激色，不继承入口品牌配色、渐变、装饰插画、主题动画或特定字体。统一背景、对比度、边框、按钮、焦点、间距和固定区域，不自动切换昼夜配色。
- 正式刺激阶段不显示入口导航、用途标签、奖励、跳动进度或非协议提示；退出和异常处理按协议规定。
- 颜色/形状/亮度若承担实验条件，就属于测量协议，不能以换肤为由静默修改，例如Stroop的颜色。必要刺激在四入口精确一致，改动须记录协议差异并核版本/参照。
- 真实四入口使用相同合成seed和冻结身份，比较像素/计算样式、几何、字体、背景、触控范围、状态和语言；不能用四张独立设计稿冒充共享消费者已通过。
- 视觉一致是汇总的必要条件之一；常模汇总还须核协议/profile、设备输入、校准、语言、人群和质量，不能因界面一样就自动混合数据。
- 不追溯修改历史发布刺激或冻结报告。新任务先遵守；旧任务统一改造另列范围。

## 3. 每项任务交付两个版本

优先复用实际已有research、experience profile及冻结机制，不凭空新增normVersion或总版本字段。已有standard的兼容按真实消费者核查，不自动发布第三版。

- 文献对照版采用所选论文/协议的正式重复次数与条件构成，列清本项目输入、几何、语言、设备、时序差异。“对标文献”不等于本项目效度已验证。
- 体验版主要减少正式重复次数；保留条件覆盖/随机化、刺激难度、单次时序、指导语、练习、输入、计分定义、质量门控。若还改变这些因素，单列差异并重新确认。
- 两版分别冻结profile、解析配置/hash、协议、报告、参照绑定，分开记录练习/正式分母。缩短带来的组数/休息变化也显式记录。
- 体验版提供实际记录、条件分母和获准的描述性反馈，服务自我探索和后续分析；不预先承诺测量精度、招聘预测或诊断资格。记录不足仍按limited/invalid隐藏受影响结论。
- 不默认合并两版数据或套用长版常模、误差和可靠性；等值/合并须另有证据。两版不是两个任务家族。
