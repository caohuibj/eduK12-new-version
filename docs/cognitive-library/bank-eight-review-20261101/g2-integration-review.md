## 集成发现并修正的实际缺口

- 新版本原保存false后回到可改选状态，重新计算RT；throw则无恢复入口。现在保留首次完整payload，仅显式重试同一选择、用时和中断事实，等待期间不接新选项，不自动超时重发。
- 末题保存后的最终完成改用CognitiveRunner已有manual动作，失败返回仍由宿主按钮重试，不重新提交最后一题。组件局部完成重试已删除；保存尚未确认时显示“正在保存”，不声称已记录。
- 原选项仅pointerdown，键盘聚焦按钮后的原生激活无效；新版本补接detail=0的键盘click，避免真实pointerclick重复提交。旧身份保留原路径。
- 新版本说明不再承诺含自行阅读/练习的固定结束上限，改为正式题用满时限的估计，另计说明练习时间。
- 新前端报告显式关闭产品指数；只修新报告里复制来的“读前对”“套关系”和“错误关系次数”，逻辑题明确区分必然结论与仅不矛盾的可能情况。旧报告不改；不新增阈值、常模或能力等级。

以上只改新版分支，不改题面、答案、36题协议、评分公式或原新版本号。2.0.0仍处于未发布审阅状态。
