# G1：词语类比与词义判断审计修订

来源：PR441 `16d9bbaa5fffb424ce463220d6f9f7d3a7280db5`。集成基础：PR477 `605a3a5f5a03e23da442f0e17a6fb9486870e8dd`。本记录只覆盖两项，不代表另外六项已经完成或整批已经安装、发布。

## 题量、版本与来源

两项原有正式题库均36题，原体验/标准/科研配置为18/30/36题。本轮不降题量、不新增正式题。各新增1道独立原创练习题，正确完成后才进入正式题；错误则重新呈现说明再练习。练习ID、题面和正式题分离，不能被正式评分接纳。原预计分钟数沿用且明确不是本轮完整时长实测；浏览器仅跑两题短流程。

旧1.0.0题目记录、评分函数和报告文字保留；旧身份不推荐新建。修订用engine/config/scoring/profile/report/presentation/reading 1.1.0，题库`wordanalogy-zh-v1.1.0`和`wordmeaning-zh-v1.1.0`。新评分绑定新题面与答案位置；准确率与有效正确RT的公式、0.5低准确率提示和至少2个有效RT阈值不变。新seed为DRAFT，报告referenceMode:none，不提供产品能力指数、常模、诊断或跨版本等值结论。

题目源声明为项目原创；修订文字与练习亦为本项目新撰，未复制第三方题本、词典正文或受限素材。此次内容核对不构成独立法律鉴定或信效度验证。

## 逐题审核

全部72题逐项核对题面、四个选项、正答与解释，并经第二位只读审阅者独立复核。两库新版本的每道解释留在后端`bank-v1.1.ts`，前端只持有刺激题面。原版键位分布为类比5/24/7/0、词义10/20/6/0；仅随机题序无法消除该线索。新版本固定重排选项，两个题库正确位置均为A/B/C/D各9题，评分索引同步冻结，不运行时任意重排。这仅是整库36题的键位分布；18/30题随机子集不保证四个位置等数或难度等同，也没有跨档等值证据。

词义任务的目录目的、能力提示和新报告修复了复制来的“类比关系”描述。新报告正确率按全部正式题作分母，选错与超时分别计数；RT仅纳入答对且满足冻结下限的反应。真实第一个选项0和用时0保留，与null/null超时不同；过快反应只从RT集合排除，不冒称超时。旧报告内容不改。

## 工程行为

新运行器支持数字键与原生按钮，忽略持续按键repeat；第二题真正重新进入注视/刺激阶段。保存失败保留首次题目、选择、用时和中断事实，只重试该原件，不能在失败后改选或重置用时。练习错误不进入正式，重练前完整呈现说明。题量超容量或题库版本不符会在开始前给出明确提示；不再静默截题后停在“正在生成结果”。
