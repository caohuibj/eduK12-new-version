## 2. 整体与当前单元作答说明

整体说明与当前单元标题、说明分别投影并展示。问卷子量表使用 `currentScale.name / instruction`；问卷表单区段使用 `currentFormSection.title / description`；综合量表使用当前 `scale.name / instruction`，综合表单区段使用正式 `title / description`，兼容现有当前单元形状。原文按文本保留换行，切换单元时更新；新单元没有说明时清除上一单元说明。后台、退出及卸载清理，恢复后重新读取服务器原文和加密草稿。

新增3项原生用例：两份不同回顾范围的子量表及恢复页面；问卷/综合表单区段与综合量表契约；恢复表单及无说明下一单元。实际 HTTP 的问卷与综合两区段推进用例同时验证整体说明、标题、区段说明、恢复答案及后续单元更新。

## 3. 学生逐份撤回报告

学生授权预览新增服务器确认的 `consentStatus / canConsent / canRevoke`。当前同意状态绑定精确来源、当前发布记录、版本、关联及双方账号；已同意时不重复展示同意按钮。撤回动作针对该关联下这份报告已有的同意与披露授权，沿用既有 `POST /parent-links/:relationshipId/reports/:artifactId/revoke`，不新增披露权限。

学生入口：**我的 → 家长关联 → 管理每份报告的授权 → 选中报告 → 撤回本份报告授权 → 确认**。同意或撤回成功后重新读取授权状态，失败保留可重试的命令；后台、卸载、退出及迟到响应不恢复报告或确认框。撤回本份报告保留家长关联和其他报告授权；再次同意仍需要新的负责人披露授权。

新增4项原生用例覆盖授权前/后撤回、同意后立即刷新可撤回状态、缺少动作与错绑定拒绝、后台/退出/卸载迟到响应。真实 publication HTTP 链同时验证：同意但未获披露时可撤回，旧同意不能再授权；已可读时撤回后家长新读取404；同一孩子另一份独立报告仍可读、关联仍 ACTIVE；其他家长不能撤回；重新同意并新授权后可读。沿用当前工具上限、来源授权、重新发布不继承同意等检查。
