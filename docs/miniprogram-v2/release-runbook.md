# 小程序 v2 发布执行清单

适用目录：`server-version/miniprogram-v2`。本轮代码和隔离回归结论见 [prelaunch-review-20261004.md](./prelaunch-review-20261004.md)。客户端无需单独上传到网站服务器；服务端/API 兼容版本先就绪，小程序代码经微信开发者工具上传，在微信公众平台体验、审核并发布。

## 1. 完成真实身份与隔离服务配置

负责人提供已有注册小程序的 AppID 和开发/体验环境 HTTPS 地址。在 `project.config.json` 设置真实 `appid`，保留 `setting.urlCheck=true`；本轮没有真实 AppID，因此仍为 `touristappid`。AppSecret、测试密码、数据库和 COS 密钥不得进入小程序包；现有账号密码登录流程没有要求客户端持有 AppSecret。

在 `core/config/environment.js` 填写：

```js
module.exports = {
  origins: {
    develop: '', // 填实际隔离验收服务的 HTTPS origin
    trial: '',   // 可与 develop 共用同一个隔离验收服务
    release: 'https://eduk12.top',
  },
}
```

develop/trial 不能连接 release 地址。代码根据 `wx.getAccountInfoSync().miniProgram.envVersion` 选择 origin；同一上传代码在体验版和正式版使用不同服务地址。origin 不带路径；客户端 API 为 `origin + '/api'`，因此该 origin 的 HTTPS 反向代理必须实际提供 Web 和 /api。不能仅填写一个尚未部署的域名。

隔离服务需要匹配当前后端契约、完成既有迁移，并使用独立数据库/存储。只生成合成学校、教师、学生、家长和报告；为确需验收的功能在该隔离实例开启对应 flag。仅在生产建立测试学校不能隔离全站功能开关。

本轮没有改变生产开关。此前生产查询为家长入口已开、小程序测评/课堂未开；这不是本轮对生产最新状态的再次核实。后续发布应保存当前配置快照；不得因小程序可上传而重置已开放的 Web 家长入口。

## 2. 微信后台与域名核对

在真实小程序管理后台核对主体、实际业务类目、认证/备案及发布资格，以该账号控制台当前要求为准。本轮没有访问或确认这些后台状态。

按实际配置的 origin 分别设置：
- request 合法域名：当前统一 JSON API。
- uploadFile、downloadFile 合法域名：封面/打卡等上传和受保护资源下载。
- web-view 业务域名：当前同源网页测评及其实际导航链路；验证当前主体是否支持 web-view。不能通过关闭域名校验代替验收。
- 课堂客户端当前没有原生 connectSocket；若后续增加该传输，再增加对应 Socket 域名和真实连接测试。

后台隐私保护指引必须准确声明实际收集和处理的图片/相册/相机等信息及用途。代码使用原生同意按钮，拒绝后保持其他功能可用；操作系统相册/相机权限也可能单独拒绝。确认首次同意、再次进入、拒绝及撤回后的表现。

微信官方说明中 `getPrivacySetting.needAuthorization=false` 既可能表示已同意，也可能表示后台没有声明隐私接口；因此代码测试通过不能证明后台声明完成。图片授权与孩子报告授权是独立流程。API 依据：[微信官方 API 类型及文档说明](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)（getPrivacySetting / requirePrivacyAuthorize / onNeedPrivacyAuthorization / chooseMedia）。

## 3. 本地检查与微信编译

使用 Node 24.21.0：

```sh
cd server-version/miniprogram-v2
npm run verify
node scripts/feature-inventory.cjs --check
npm run release:check
```

release:check 先核对真实 AppID、三个 HTTPS 地址、URL 校验、基础库和包排除；配置通过后执行静态检查、功能清单和全部 Node 测试。当前默认配置应报出三个阻塞；需要填写真实配置后再运行。测试用例使用独立配置样例，填写真实配置不会因默认占位符断言而失败。

用微信开发者工具导入该目录并选择真实 AppID；项目基础库为 3.7.12，新增隐私接口至少要求 2.32.3，仍需验证目标微信版本支持实际使用的 API。检查实际 WXML/WXSS/JS 编译、组件注册、警告、实际上传包大小。源码资源统计不能替代编译包体积。

保持项目域名校验开启，同时检查私有开发工具配置没有覆盖该设置。上传包排除 tests、scripts、README、package.json 和 project.private.config.json。正式上传版本号、说明和验收记录必须对应同一个 Git 提交。

## 4. 体验版及 iOS/Android 验收

上传后设为体验版并加入授权体验成员，确认体验版请求实际隔离域名。至少用两台设备完成教师—学生课堂交互；用独立账号核对每步角色，进入 Web 适配后再次核对网页账号。

| 流程 | 必测条件 |
|---|---|
| 登录与身份 | 四角色登录/退出/冷启动；强制改密；登录过期；切换账号后旧表单、图片、报告消失；离开登录页后迟到请求不跳转；存储不支持或配额不足有明确提示 |
| 深链与扫码 | 获准/无权/删除内容；非法或外域链接；登录后返回目标；新深链覆盖旧入口；错误页能返回 |
| 课程/作业/打卡 | 从课程创建预选正确课程；无权教师和学生不能操作；单/多选及主观答案标签；带时区日期和非法日期；上传 0/1/多张、超过上限、拒绝隐私或系统权限 |
| 选图生命周期 | 相册和相机各一次；取消；原生界面返回保留正文；离页/换身份后迟到回调被丢弃；公开打卡参与凭据不因选图返回被清除 |
| 弱网与提交 | 断网、超时、429 Retry-After、双击、进入后台/返回、进程重启；已支持的 FINAL 草稿恢复；封存原内容重试，不换载荷；确认成功后不重复写 |
| 资源 | 签名过期可以刷新且仍保持有效登录；真正会话过期回登录；撤销访问不可读；公开资源失败不退出已登录用户 |
| 课堂 | 两设备加入/等待/发题/结束/重启；旧轮次拒绝；后台与弱网重试；关闭后停止交互；实际 Web 与小程序状态一致 |
| 测评 | 已支持的原生类型逐项提交/恢复/次数用尽；未支持类型按固定同源路径进入 Web；iOS/Android 实际 timing 和呈现单独验证 |
| 家长 | 学生确认关联；正式 PARENT 报告发布、学生精确同意、有权负责人逐份授权后可读；逐份撤回、解绑、披露上限降低、报告撤销后不可读；家长/非成员/平台管理员不能据身份名称越权 |
| 无障碍与布局 | 键盘/读屏命名、长文本、手机窄屏、横竖屏及字体放大；确认实际选图授权层不会被其他浮层遮挡 |

记录设备、微信版本、基础库、Git 提交、体验版号、后端版本、flag 和测试结果。未运行的项目保留待验状态，不写“全部通过”。原生 Node 回归不替代这些设备结果；本轮也没有容量/性能测量。

## 5. 正式发布与回退

1. 确认后台部署与该客户端契约兼容、已有迁移完整；本轮修复本身没有新增迁移。
2. 根据验收结果明确首发范围。小程序测评/课堂 flag 是全站开关，先记录影响与开关前后状态；未验收的能力保持不可用提示。家长既有学生同意和报告授权条件保持不变。
3. 体验版和设备验收完成后，在公众平台选择同一版本提交审核；如需审核账号，单独提供最小权限的合成学校账号，不写入 Git 或日志。
4. 审核通过后发布，确认正式 `envVersion=release` 请求 `https://eduk12.top/api`；核对登录、一个授权读取和核心流程。上传、审核通过和正式发布是不同状态，分别记录。
5. 上线后观察错误、登录失效、429、提交冲突及课堂状态，不采集原始答案、密码、Cookie 或报告内容。
6. 需要回退时使用微信后台已验证旧版本；对故障的小程序功能按已记录范围关闭对应能力。不得为回退小程序而关闭已授权开放的 Web 家长入口；保留已完成提交和报告授权数据。

本轮已完成代码优化及自动化证据，尚未完成第 1 步的真实 AppID/验收地址配置，也未执行微信编译、体验版、审核或正式发布。
