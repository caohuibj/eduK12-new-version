## 保留的功能边界

- 家长读取继续逐请求检查关联、学生对精确发布内容的同意、负责人逐份授权和当前工具披露上限；微信图片隐私同意不会赋予报告权限。平台管理员不自动获得个体报告权限。
- 当前原生 Runtime 覆盖已实现的量表、表单、问卷/综合单元及文本 SJT；复杂认知、媒体/随机化/分支、组织分析等仍使用受限的同源 Web 适配。Web 登录独立，进入后必须核对网页身份；没有实现 SSO。
- 课堂仍采用 HTTP 轮询；完整实时传输、弱网及容量验证待执行。文件导出、独立视频/文档库、科学工具完整创作和完整组织治理尚未原生对等。
- 作业答案标签使用当前题目元数据，与现有 Web 语义一致；本轮未新增历史题目冻结快照。
- release 配置检查只能核对显式地址和代码设置，不能证明服务器/DNS、微信主体、业务域名、后台隐私声明或审核资格已就绪；编译包体积以开发者工具为准。
