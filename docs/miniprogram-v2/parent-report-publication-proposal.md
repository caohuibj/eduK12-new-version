# 正式家长报告生产与发布设计（用户已批准本地实施）

本提案只保存在本地；未新增生产发布、未赋予任何组织能力。

“正式家长版报告未发布”是指现有代码没有通用的 PARENT 内容生产和发布适配器，不是已核实线上发布状态。家长报告讲的是已关联孩子获准披露的测评情况；不因关联自动开放学生报告、教师报告或原始作答。

## 建议实现

1. 建立独立的不可变家长发布记录，绑定已有报告 artifactId、原 sourceHash、学生、组织、精确工具 family/key/version、独立 PARENT 模板版本及模板 hash。保留原始报告内容和 hash，禁止向旧报告追加正文来伪装家长内容。
2. 首期生产器只支持已验证的 PROTECTED_FEEDBACK 和 INDIVIDUAL_LONGITUDINAL 来源。完成情况使用服务器完成事实；教育摘要只能使用正式 PARENT 模板声明的指标和服务器已经允许显示的值、解释及限制。受抑制、缺失、不具可比性的指标不得转换成正常数值或变化结论。不自动改写教师、研究、学生报告全文，不生成新的风险判断或建议。
3. 发布操作由组织内已持有 PARENT_REPORT_DISCLOSURE 且满足来源读取权限的负责人完成，要求明确预览并提交稳定 commandKey；SYSTEM_ADMIN 仅设置工具层披露上限，不因此获得报告读取或发布权。发布时在同一事务内复核组织成员有效性、组织策略、来源权限、deny rule 和工具上限，留下不可变审计。
4. PARENT 模板必须单独审定。第一阶段允许的模板仅包括完成事实和明确指标的教育摘要；不开放 rawAnswers、逐题内容、研究导出。模板变更产生新版本和新发布身份。
5. 学生逐份同意与负责人逐份授权绑定本次不可变发布内容 hash。内容或模板变化必须重新预览、同意和授权，旧许可不能自动转移。读取时继续复核关联、学生同意、负责人授权、有效成员、deny rule 和当前工具上限；解绑、撤回、能力取消或收紧上限立即阻断新读取。
6. 现有 parentAudience 合成测试保留为旧适配兼容测试；正式来源读取改为验证独立发布记录。没有合法发布记录时返回未发布，不用测试 fixture 充当正式业务闭环。

## 风险与验证

这是新增孩子信息的正式披露来源及持久化发布路径，需要明确批准。代码、数据库迁移和合成验收可本地实施；不会发布任何真实孩子报告，不会迁移生产数据库，不推送。

必要验收：篡改 source/template/publication hash 被拒绝；subject/组织/工具版本不匹配被拒绝；跨组织及 SYSTEM_ADMIN 无来源权限时被拒绝；抑制和不可比信息不泄露；同意绑定精确内容；发布重试只产生一份；内容更新不能继承授权；关联/同意/授权/成员资格/deny/上限撤销后不可读取。

需确认的产品决定：采用上述独立发布记录与单独 PARENT 模板方案，并允许本地新增该发布路径。首期模板内容仍须按每个正式工具审定；通用生产器完成不代表每个工具的正式内容已经上线。
