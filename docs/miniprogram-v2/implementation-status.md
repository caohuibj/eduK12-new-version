## 家长披露语义

“正式家长版报告内容尚未发布”先前描述的是代码缺少 PARENT 生产路径，不能推断生产数据库状态。该代码缺口本轮已经实现并验证。当前通用模板只告诉家长报告已生成；具体分数/教育解释等必须有对应工具版本的独立已审阅 PARENT 模板，且落在 SYSTEM_ADMIN 披露上限内，再取得学生对精确内容的同意和负责人逐份授权。上限提高不会自动发布内容，也不会绕过同意。原始作答、单题内容、研究导出不开放。本轮未发布真实孩子报告或安装真实教育内容。
