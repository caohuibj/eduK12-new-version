## 验证与边界

当前完整工作区原生测试 122/122，包含上述新增 9 项；operations 真实 HTTP/PostgreSQL/Redis 测试 17/17，包含新增 2 项。最新 PR3 与相关后端、Web 验证结果和复验方式见 `pr3-local-acceptance-20261002.md`。测试均使用专属隔离服务、合成账号/图片/测评。

打卡的既有私有图片 URL 是 10 分钟签名 capability。收紧“查看同学”会阻止再次获取列表；已签发且尚未过期的 URL 仍遵循原后端签名契约。此修订没有声称立即撤销已复制的 URL，也没有修改通用媒体交付授权规则。小程序记录页重新读取权限、清除旧展示及临时文件，且不自行查找其他资源。

这三项功能修订不构成完整安全审计或发布批准，也不表示全部 Web 业务对等已经完成。
