# Survey 管理员授权与同链接问卷子版本

## 范围与使用

复用既有 SYSTEM_ADMIN 管理员邀请/研究者授权入口。管理员可复制邀请链接，并在研究者管理页查询系统来源的精确已发布版本、授权或撤销工具复用。邀请功能不自动发送邮件。未增加独立管理员角色、学校成员链或真实账户。

研究者的“授权来源”目录只显示自己的有效授权。导入创建只读草稿，复制后仍受相同授权约束，不能通过编辑接口改写来源内容或评分。草稿冻结时批量复核授权及来源版本；冻结快照保存精确来源、原始评分定义和答案键映射。列表只投影元数据，不返回完整题包。

来源能力按实际兼容范围开放，不把“可授权”解释为科学资质认证：
- SCALE：已发布且许可允许再分发的兼容量表；保留原生评分和字符串/数值选项值。
- SJT：可无损适配的固定流程 V2 单选版本；保留原生评分。不支持的分支、研究捕获、受限许可明确拒绝；不升级旧 V1 科学语义。
- COGNITIVE：已发布 OPEN 的受控 Go/No-Go 配置；精确核对协议、引擎及评分版本。
- FORM：本管理员创建并已发布的普通 Questionnaire 独立表单节，目前支持必答单选；保留节说明、父问卷及题目/选项来源映射。不支持媒体选项、未知选项属性等有损投影。此入口不声称提供跨机构 HuiteacherForm 复用。

撤销阻止未来导入、复制及草稿冻结，不改动已有冻结研究或在途答案。已有研究仍按冻结评分执行；紧急停止使用原有波次 hard-stop，不把授权撤销隐式变成停测。

## A/B 问卷子版本

在研究 Flow 编辑器中选择“问卷子版本”，设置各组名称、正整数权重；各版本选择工具，按已设流程顺序执行。共用工具可属于多组，组专属工具对未分配被试不可见。全部工具须属于至少一组；组内条件依赖、反馈和访问条件必须兼容。单个公开波次链接在首次参与时使用服务器密码学随机抽样，按预置权重分配冻结子版本；配置、选中定义摘要和分配记录随后不可改变。

同一参与身份刷新、重试、并发标签页保持同组。默认每个波次独立随机，分组不跨波次继承；已有研究编号的纵向关联机制不变。匿名参与者清除身份后无法保证仍是同一个自然人。权重表示概率，不承诺精确人数配额。零、负、非有限数及非法权重拒绝，不回退到最新或未激活版本。

任务、媒体、认知子会话、检查点及 FINAL 均校验已分配组。未分配工具不评分。导出保留子版本、配置、概率、权重、分配算法/时间及精确来源。通用合并描述统计拒绝混合 A/B 子版本，使用分层导出或组别 Flow 分析。

## 验证与证据边界

验证主位置为隔离云端 Node 24.21 / PostgreSQL 17.11 / Redis 8.0.2；仅合成账户和数据。未运行浏览器验收、CI、部署或合并。

- 单元、组件、真实 PostgreSQL 测试按完整测试名去重，当前 195 项通过。覆盖旧四类工具、原生评分等价、越权/撤销、只读草稿、随机边界、并发稳定分组、链接波次及导出。
- 真实 revoke/freeze 行锁竞争验证两种先后次序；已冻结来源不会静默变更。
- 新路径 HTTP：最终 51 项检查（包含 API 清理）、121 次请求、63 个带观测标签请求；四类来源均实际授权、导入、冻结、作答、导出。存在的本组媒体返回 200 且字节摘要一致，存在的异组媒体返回 404。
- 增量迁移在既有四类研究数据副本上验证，旧记录摘要不变；dump/restore 后数据、触发器、runtime 权限及只读拒绝一致。临时副本及转储已清理。
- 前端类型检查、组件检查及单次候选构建通过；后端候选按不可变输入构建。第一次候选因分析读取合并优化被后续候选替代，保留原始证据，未冒称同一产物。

新路径规模检查是不同输入的有界查询检查，不是前后性能提速比较：来源目录与管理员授权列表 1→25 项均为 3 SQL；冻结为 18→17 SQL，差异来自首个项目激活更新，不代表 25 项更快。公开冻结任务/提交路径没有新增来源或工具授权查询。

## 后续审查修复（2026-10-17）

- LINKED_WAVES 中已分配子版本的 STARTED、SCREENED_OUT 和质量排除记录，参与状态导出现在保留冻结子版本及完整分配审计；不读取未完成答案。逐题/得分 Long、Wide 与单波次分页状态表使用相同的研究编号 × 波次关联，真实 NO_WAVE 仍为空，已撤回记录仍不导出。SINGLE_UNLINKED 的无参与状态表契约和认知试次的 FINAL-only 契约不变。
