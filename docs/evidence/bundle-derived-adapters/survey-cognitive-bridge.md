# Frozen native cognitive sources in Survey Bundle reports

The Survey host reuses `SurveyCognitiveUnit`, its injected `CognitiveRunner` API, the existing FINAL transaction, child receipts, scorer and frozen profile artifact. New native execution support is bounded to the existing Corsi and digit-backward kernels without media or reference bindings. Their protocol trial ceilings are not exact completion lengths: original authoritative scorers continue to reject nonterminal or truncated paths. Legacy Go/No-Go retains its exact 120-trial contract.

At a new exact-profile FINAL, the original report projector creates the report from the same frozen definitions and authoritative score. Its serializable snapshot is retained inside the existing encrypted result and copied with the verified child receipt into the compact immutable parent. Historical results without that snapshot are not reconstructed.

Whole-package intake binds the original cognitive assignment's config/profile/report to the exact approved Survey profile source, including its original owner/grant/publication checks. Only SELF schema 3 packages with a source-configured participant report may declare this bridge. An explicitly researcher-only R, absent source report, changed profile, changed receipt or missing saved snapshot does not provide participant disclosure. Original source publication/approval checks remain required; this code does not promote a draft task or issue a grant.

`projectFrozenCognitiveDisclosure` from independent PR #504 intersects the saved report's visible dictionary, frozen metric ceiling and package selectors. The existing participant feedback endpoint returns only permitted saved metric values/labels. The same release intersection restricts saved combined reports and removes a ratio when its denominator is withheld. The frontend continues to display the existing frozen numerical DTO; it does not execute a new scorer or reconstruct a report.

This change does not copy the helper owned by #504. Its commit must be composed alongside this C adapter in the integration candidate. Production source, schema 3 core, admission and helper dependencies must be present before an installed end-to-end check can be claimed.

## Targeted evidence

- Four unique public cases cover the two native scorers/report projections, positive stopped paths, negative nonterminal paths, receipt/profile/report/metric/source/audience restrictions, and legacy GENERAL/exact-budget behavior.
- The original Corsi check found optional `undefined` presentation fields rejected by canonical persistence. Serializing optional report fields before saving fixed this; only affected cases were rerun.
- One additional isolated check uses the actual B15 content: both task spans project, saved participant reopening preserves permitted task rows, and withdrawing the backward denominator removes its ratio. The default legacy ADEXI fixture has no explicit audience contract; it remained redacted. No leaf R or permission was changed to make that fixture pass.
- Type evidence and retained original failures are recorded in `survey-cognitive-validation.json`. These are local targeted results, not formal CI, browser administration or production installation.
