# 教师成长反馈编辑草案

以下是项目原创中文编辑计划，不是已启用报告、原量表译文或经验证阈值。填答者为教师，报告接收者为该教师；是否可见沿用既有接收者授权与发布条件。无学生对应题本，不制作学生分数报告。群体信息仅按已有授权、匿名和最小人数规则呈现，不披露个体敏感回答。

使用频率描述教师报告的使用经历；主观有用性描述教师的判断。二者分开呈现，不能用“觉得有用”推断“经常实施”，也不能据频率评价教学质量。没有原计分范围、方向或常模时不设高低阈值、不生成图表分数或合成母工具总分。

- 正常／有可用经验（未来依据真实回答呈现，不是分段）：你提供的经历可以帮助你回顾评价信息怎样支持教学。可以选最近一节课的一条学习证据，记录它让你调整了什么，再观察学生接下来的学习表现。频率与主观有用性需要分别理解，这份自述不能证明某种做法已经有效。
- 遇到困难／支持不足（未来依据真实回答与情境呈现，不是低分诊断）：如果某类信息不常使用或暂时帮助有限，可能与取得时机、解释支持及课程任务有关。这不等于你缺乏教学能力。可先选一个容易获取的信息，与同事共同讨论一个具体教学决定，并试着记录一次小调整及后续证据；不要求为了提高分数增加无意义的测验。
- 证据不足（当前唯一适用状态）：本工具的完整题本、原版选项和计分说明尚未核实，目前不能据此产生你的测量结果。材料齐备并经授权后，可重新选择是否填写；不推算缺失答案，不给能力或绩效结论。

若未来只有合法原文而无评分依据，Form仅呈现描述性回答及自愿反思，不套分数报告。实际Scale内容、参数、报告分别版本管理；上述草案无执行C/P/R版本，未运行报告渲染兼容测试。
