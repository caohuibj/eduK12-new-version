# IQES 教师发展反馈编辑样例（未安装）

以下为项目原创编辑参考，不是IQES原报告、原常模或任何已计算结果。完整题本及使用范围未齐，本批无量表分数、无分表单或R发布版本。后续仅通过现有报告版本和接收者授权应用；教师自评默认面向本人，向同伴或管理者披露仍按原权限/同意处理。下列三种是情境，不是自造分段。

**已有具体实践证据的情境**

> 这份记录可以帮助你找到值得继续尝试的课堂做法。选一个你能举出实际例子的环节，例如给学生留出思考和解释的时间；下次保留这个做法，再观察不同学生是否都有参与机会。自评反映你的视角，不能单独证明学生都获得了相同体验。

**遇到困难或希望调整的情境**

> 某些课堂安排暂时没有达到你的期待，并不等于你缺乏教学能力。先选一个可调整的小环节，例如把一个较长指令拆成两步，并请学生用自己的话复述；记录这次尝试的情境和结果。需要时，可邀请你信任的同伴围绕一个具体问题观察，先约定哪些记录可以分享。班额、时间和支持条件也值得纳入讨论。

**信息不足的情境**

> 目前可用的记录不足以形成稳定判断。我们不会将未回答或无法观察的内容当作低分，也不会据此评价你的教学。可以先留下一段具体课堂经历，之后在合适的时机补充观察或反馈。

应用边界：

- 从实际回答/证据选择可支持的文字，不给所有人套同一个结论；不将意图、信心或价值观改名为实际教学效果。
- L02“无回答”、L03“不可观察”与实际低类别不能混成0分；精确缺失规则待所选版本的解释说明核实。
- 若实际采用无分FORM，仅展示获授权的描述与反思支持，不生成均分、等级、教师排名或“教学质量总分”。
- 学生版必须使用其独立合法原文、年龄适宜的呈现和既有披露规则；未取得S01原题本，本批不伪装成已经制作了学生版工具或报告。
