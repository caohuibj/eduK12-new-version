# 教师成长反馈示例（无计分）

适用对象是教师本人自愿填写的项目自编札记。当前原生 Form 保存事实和缺失信息，只提供完成/事实回显，没有量表得分或能力分析报告。下列文字是可审阅的支持性说明，不是通过勾选项目自动判断教师状态的模型，也没有已发布R版本。

可见条件：教师本人或既有明确授权的接收者可见相应记录。提交本批不会自动对学校管理员、学生或同事开放个人札记及敏感开放回答；普通组合也不新增披露权限。需要分享时仍走既有授权。若没有可见权限，既不显示记录，也不以状态提示透露其内容。

## 有具体片段的普通记录

你已经留下一次可以回看的课堂经历。先看看这段记录里哪些是实际观察，哪些还只是你的理解；两者都可以保留，不必急着给自己下结论。

如果想继续，可以选一个已有帮助的小安排，下次再试一次，并留下一个简短片段。一个片段不能代表全部教学，也不能单独说明学生的真实感受；愿意时，可结合适合当前场景且获授权的其他证据一起理解。

## 遇到困难或需要支持的记录

这次尝试可能受到时间、任务、班级情境或资源条件影响。记录这些困难是在看清下一步需要什么，不是在证明你不够专业；也不需要把所有问题都归到自己或学生身上。

可以先缩小到一个可尝试的步骤，例如为下一次讨论预留一点思考时间，或和同事商量一项合适的支持。若暂时没有条件实施，可以把需要的资源先写下来。你可以选择调整或暂缓，不必为了完成表单而勉强追加任务。

## 信息不足、没有合适情境或留空

目前的记录还不足以整理出具体经验，空白会保持为空白，不计0分，也不会显示“能力不足”。如果最近没有合适的课堂情境，可以先结束记录。

之后愿意时，只补充一个具体片段或一个希望得到的支持就够了。不要靠推测学生感受、编造事例或填写并不愿意保留的私人经历来补齐表单。

## 行动计划的事实回顾

可向有权查看者回显其填写的“准备尝试什么、观察什么、需要什么支持、何时回看”。回顾时只核实实际发生了什么和下一步想怎样调整，不自动评价“执行成功/失败”或推断SEL能力提高。教师自信、意图、价值和行为自报均不能改名为实际教学质量。

本批没有学生填答版本，也没有学生个人报告。若未来合法取得独立的学生对应版，应使用适龄语言、独立身份和原有接收者授权；不将上述教师反思文案直接套给学生。
