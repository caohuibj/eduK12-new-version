## 无分语义与项目适配

原题本第2页允许按原则统计 O、S、N 三类勾选数量，帮助选一两个优先改进领域；**没有 O=3/S=2/N=1 的计分规则、反向题、总分、阈值、常模或教师排名**。候选将三类保持为无分 `SINGLE`，机器键 `o/s/n`，显示仍为原 O/S/N 分类；手填分类计数用 `NUMBER` 事实字段，限定整数0到该原则勾选行数。计数不是潜变量得分，不自动加总，不跨原则比较“能力”。原生 Form 引擎不自动核对手填计数与逐行选择，管理员和使用者需据原始作答核对；不能把人工总格当自动派生分。

全部字段允许缺答，以保留信息不足；缺答不是 N、不是0，不补值、不生成方向性结论。例子保留在对应提示内供理解，均不是额外作答行。项目适配包括原则导航拆分、可缺答、行动文本2000字符上限及清晰的项目说明；候选不是逐像素复刻题本，也没有声称改编等值。参数和评分报告始终为空，完成后只能呈现事实与缺项。

共同母标签及角色/学段/语言/用途/PILOT/权利状态标签复用现有 `reference.tags`，回读后位于 `reference.metadata.annotations.tags`。现有受控分类使用 `population:teacher`、`response:self`、`domain:teacher_workplace`、`language_validation:content_en`、`license:redistribution_restricted`、`use:not_diagnostic`，未新建字典、权限或标签引擎。家族标签已在隔离库元数据查询中分组出5项，**尚未注册为目录 UI 筛选项**，不得声称筛选 UI 已验证。
