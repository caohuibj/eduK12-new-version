# 教师反馈编辑草稿

这些文字供后续内容审阅，非运行时R版本、非按答案触发的等级解释。当前无完整题本或实际答卷，不生成分数报告。填答者与接收者在教师研究版均为教师本人；其他Staff角色需固定原版后另审。

**较积极的自陈情境**

你的回应表达了对融合教育某些目标或做法的认同。认同、准备实施和已经实施是不同的信息，可以分别留意。选一节近期课，看看任务、材料或表达方式是否让有不同学习需要的学生都有参与机会；记录一次具体调整和学生的回应，作为下一步改进的依据。

**遇到困难或较少认同的情境**

回应可能反映疑问、培训不足或资源障碍，不能据此断定你不关心学生。先选一个具体困难，与可信同事或支持人员讨论一种小调整，例如提供一种额外的任务说明方式，并约定需要什么支持。时间、人员和制度造成的困难应共同解决，不由教师个人承担；也不能根据这些回答限制学生获得支持的机会。

**信息不足情境**

有些问题尚未回答，或你暂时缺少足够的教学经历作判断。目前只保留已表达的看法，不为未答题推定立场或给出完整概括。可先记录一个自己希望了解的具体情境，待观察或获得相关信息后再补充。

解释边界：知识回答不自动证明实际技能；感知他人期待不是外部事实；感知培训充分性不是教师能力考试；意向不是行为；实践自陈也不是独立观察的教学质量。原始态度题可能按不同需要/程度提问，后续须忠实保留来源并审阅呈现语境，不能用结果给学生贴缺陷标签或决定其教育资格。

只有现有授权、匿名、最小人数、发布和接收者条件均满足时，教研人员才可查看允许的群体汇总；不直接披露个人意见或敏感开放回答。本文不修改任何访问规则。没有原生学生对应版，本任务不创造学生报告。
