## 录入及使用原则

- 图书馆与管理员页面可搜索 `use:research`、`use:individual_reflection`、`license:noncommercial`、`license:author_contact_required` 等**原有** tag，已补部分中文显示字典；没有为这些标签新增新的权限表、拒绝行为或授权状态。
- `verified/allowed` 代表当前源码登记了某个来源的声明，不自动对第三方中文译稿、单独发表的人群研究、全部商业场景或公开分发作出扩张许可。
- 项目内容可先冻结并静态注册；实际法律/作者联络由管理员管理，科研成熟度与质量证据独立。不可把“需联系作者”解释成平台科学门禁，也不能在展示时假装取得完整许可。
- 每项source、题本、scoring、报告须保留既有C/P/R版本。对报告文字与图表做编辑必须单独提升R版本并保留旧快照，切勿改写结果哈希或补造常模。
