# U4 原生 Form 独立候选与描述报告

状态：工程候选，待人工内容审阅；不是经验证量表、常模或生产发布。基于实施时最新 main `fe4ddcb88e9f4f50de08149f5bfa4929312576f0`。四源联合报告不在本次实现范围。

## 可以独立使用的内容

Teacher 私有编制界面的“统一教学评价 · 独立候选工具”按需加载目录，明确选择后只创建一个本组织、本人所有的可编辑草稿。九份基础 Form，加上教师十二专题、学生十二专题、观察十二专题和八个独特体验单题，共 53 个独立候选。每个候选保留原施测窗口、响应类别和指导语，无其他模块的运行依赖。专题是内容范围，不声明独立测量效度。

| 选择 | 字段 / 内容 | 现有投放入口与反馈 |
|---|---|---|
| 教师实践自报 | 36 题，或每专题 3 题 | TEACHER / SELF；冻结为一叶普通问卷后单独投放，本人描述报告 |
| 教师反思 | 5 个开放反思 | SELF；无分记录，原有完成反馈 |
| 学生课堂经历 | 6–12 年级 24 题，或每专题 2 题 | TEACHER / STUDENT_REPORT 学生评教活动；学生本人完成反馈，授权教师群体报告 |
| 学生独特体验 | 8 项或任选独立单题 | STUDENT_REPORT；不合成体验总分 |
| 小学课堂经历 | 3–5 年级 12 题 | STUDENT_REPORT；保留四级类别，与高年级不假定等值 |
| K–2 访谈 | 6 个主持人记录提示 | 可独立创建和试填；实际主持角色、同意与访谈记录协议仍需确定，不冒充低龄学生自填测验 |
| 课堂观察 | 24 条线索、6 个扩展提示，共 84 字段，或每专题独立记录 | TEACHER / EXPERT_REPORT；机会、线索、解释与证据分开记录，沿用专业权限，不生成均分 |
| 观察事件证据 | 7 字段 | EXPERT_REPORT 独立记录；事件引用是内容约定，不是新数据库关联 |
| SJT 后反思 | 3 个开放问题 | SELF 独立无分 Form；可选择与 SJT 同次使用，SJT 本身不依赖此表单 |

操作：加载候选 → 创建所选草稿 → 审阅、保存、检查 → 固定私有版本 → 在普通问卷中只选该版本并声明实际施测角色 → 固定问卷 → 按现有教师活动、学生评教或专业观察流程投放。普通问卷只是现有运行容器；选一项即独立使用，不要求四源同人、同次投放。

目录接口为现有私有工具路由内 `GET /organizations/:organizationId/private-tools/u4-candidates` 和 `POST .../u4-candidates {key}`，受 Teacher 作者与组织权限约束。School 入口拒绝此候选目录。没有发布、授权共享或代发任务副作用；创建结果不确定时界面停止重试并要求先核对已有草稿。

## 描述规则

Form V2 可选 `descriptive`，其 `version=ordinal-description-v1` 随既有私有内容版本冻结。旧表单不填该字段，解析与历史 hash 不变。规则只覆盖明确映射的单选有序类别；每个选项必须归入有效类别或 NA/U 等非回答，禁止同时带计分值。它不是表达式引擎，不产生 Scale 分数。

- 教师本人只看到该固定版本明确允许的类别描述。0 是有效类别；NA、U、拒答、跳过和未呈现均不补 0。开放文本不通过新描述报告返回。
- 学生每题类别频率比例 = 该类别人数 / 本题有效有序回答人数。NA、U、拒答、跳过、未呈现以及完整类别分布的比例 = 该类别人数 / 已提交人数。两种分母明确显示；已提交人数不是每题有效人数。
- 教师三题、学生两题的专题均值默认关闭。作者可在草稿中预先启用；固定后生效。每位答题人只有专题所有题均为有效有序类别时才计算。学生先逐人完整题均值，再用现有受保护群体 reducer 汇总；无跨专题或跨模式总分。
- 小学、独特体验不预设专题均值。均值仅为有序类别的探索描述，不是等距能力、教学质量或常模分。
- 沿用冻结的最低人数、小单元、补集、精度和跨次披露策略。每题有效人数也须达披露下限；受限精度不返回精确人数；不可披露结果不返回数值。不同已选隐私方案的附加抑制强度不同，不宣称每个方案都启用小单元抑制。
- 仅报告配置改变时，Form 内容比较身份保持不变，不能借开关均值绕开既有跨批次差分保护。

本人报告只在当前 Teacher SELF 授权、冻结的 INDIVIDUAL_SUMMARY ceiling、原始固定内容版本、完整原生 FINAL 及其 section / submission / hash 一致时返回。学生、观察者和旧无此 ceiling 的版本继续原有可见性。没有迁移旧数据，也不回写历史结果。

## 来源与版本

`source-versions.json` 保留六份用户原始 Google Docs 的精确 URL、修订版本和取证摘要；`text-revisions.json` 为先前逐项审计的 14 处候选最小修订。本 PR 的九份 Form 使用该修订题文；CJX01 内容与显式无分运行模式分属另一个 PR。

内容题文修订 0.2.0、包装目录 0.3.0、报告规则 ordinal-description-v1 分开记录，未设数值计分版本。实际私有版本 ID / 内容摘要由既有服务生成；每次固定产生新版本。源文档、旧私有版本和既有 CPJ 版本均不覆盖。本地 provenance 不冒充生产 release、人工审核或科学验证。
