## 必须保留的异常与边界

- Safari FORM：第一次点击正式提交后，后续刷新/恢复仍显示“本次答案已封存。结果未确认时请重试原提交，暂不能修改答案。”，控件禁用、原提交按钮可重试。明确重试后得到成功回执，DB 对该 attempt `0298c64f-6316-460a-9063-9b3d9875bad5` 只有一份 FINAL `9965bcb7-e76a-418e-ae9a-160ee99fd855`。没有首次数请求的 HAR/响应，无法区分操作时序、网络或产品原因，不能写成首次无异常通过，也不据此猜测代码修复。
- 早期 Chrome SJT 标签已跨两小时恢复期限；其后不出现恢复入口的观察与新鲜作答的即时恢复分开。`chrome-sjt-answer-initial.png` 属于旧标签的作答外观，不能证明该旧会话之后的恢复。
- CUA 有延迟、焦点与一次 30 秒超时导致会话内核重置。未把快捷键或点击尝试当作成功；超时后的截图实际已保存，另从磁盘和页面确认。重置前内存中的步骤数组未完整落盘；原步骤在本任务工具记录中，文档表格是人工整理。`native-ax-filtered.json` 是重置后真实 AX 文本的过滤快照，不是全程日志或反填的历史原值。
- Safari 打开检查器前后曾读到不同缩放，故各功能操作按当时页面菜单确认；不从导出 PNG 像素尺寸反推 CSS 视口。`safari-scale-restored-capture.png` 的检查器当时 body 宽 1423 CSS px，只作为恢复后的量表外观；不称其为 200% 原图。Safari FORM 截图前 body 约 711.5 CSS px，原生页面已确认 200%。
