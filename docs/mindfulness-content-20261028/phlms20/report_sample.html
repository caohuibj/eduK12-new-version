看见，和允许它在那里

这份问卷回顾的是你最近一周的日常体验：你有多常觉察到自己的想法、身体和情绪？又有多常允许它们存在、不去急着推开？

这是模拟数据，不是你的测评结果。 数字只为展示报告的样子。觉察多一分或少一分都不说明一个人是否清醒、是否成熟；两个维度各自独立，没有总分。

看见正在发生的事

觉察

模拟 37 / 50

这组题问的是你最近一周有多常"注意到"：念头掠过时你看见了、洗澡时感觉到水温、走路时闻到空气的味道、情绪变化的那一刻你意识到了。觉察不等于分析——它更像是"知道现在正在发生什么"。

想一想：最近一周，哪一个瞬间你清楚地"看见"了自己心里的活动？那时你在做什么？

小行动：挑一个每天都有的场景（洗澡、走路、喝第一口水），试一次只留意感觉本身，不给它起名字、也不评价。

允许它在那里

接纳

模拟 31 / 50

这组题的表述多是"不接纳"的样子：想把某些念头赶出脑子、告诉自己不该这样想、用忙碌把感受挡开。官方计分把这些题反向后求和——分数更高，表示你更少跟自己的体验较劲。接纳不是喜欢，也不是放弃改变，而是先允许"它在这里"。

想一想：有没有一种情绪，你越想把它推走，它反而越明显？

小行动：下次不想要的念头冒出来时，先不赶它，心里说一句"我注意到它了"，然后做手头的事，看它自己停留多久。

两个维度，各自独立

你可以在觉察上很敏锐，同时还在练习接纳；也可以很接纳，却常常心不在焉。它们是两种能力，不是一张成绩单的两个科目——没有总分，也就没有"及格线"。

题本为 PHLMS 英文原版（20 题，5 点频次选项，过去一周；官方计分注：奇数题直加、偶数题反向后求和，两维不合成总分）。论文正文另一处写作 0–4 计分，与表注 1–5 不一致，本条目按表注官方计分方向实现并已记录差异。自评受情境、心情与理解方式影响，只能作为回顾参考，不能用于人格评价、诊断或排名。
