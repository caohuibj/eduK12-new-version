# C-MIPQ（正念教养问卷中文版，28 题）

## 工具识别

- 全称：Mindfulness in Parenting Questionnaire 中文版（C-MIPQ），28 题两维（正念管教 15 题 / 与孩子同在当下 13 题）
- 拟用 key：`cmipq28_zh_cn@1.0.0`（**catalog-only，未建可执行记录**）
- 评价对象：家长自报过去两周的正念养育（与孩子同在当下、正念管教）
- 来源论文：Wu et al. (2019), *Frontiers in Psychology*, 10:1847（OA CC BY）；原版 MIPQ：McCaffrey et al. (2017)，经原作者授权翻译
