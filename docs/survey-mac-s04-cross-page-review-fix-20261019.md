Builder 为每次具体试答错误定位生成独立请求，交给已经挂载的 ResearchPreview。预览按当前可见分页找到题目，提交页状态，待该页控件渲染后再聚焦、滚动并显示原焦点边框。一次请求只聚焦一次；连续点击同一错误也可重新聚焦。保持同一预览实例及其答案状态，不通过重挂载、重提交或取数来切页。服务器首个错误也使用同一流程；其他没有此可选请求的预览消费者保留原行为。

组件集成用例同时返回两页的两个错误：第一页文本过长、第二页数值低于下限。首次回执聚焦第一页，此时第二页控件未挂载；Tab／Enter 激活第二页错误后验证切页、目标挂载并聚焦。鼠标激活第一页错误后验证原文本仍在，第二页数值亦保留；再次激活同页错误仍聚焦。两次错误定位前后 fetch 调用数完全相同，试提交仅一次，不调用 PATCH 或模拟评分。
