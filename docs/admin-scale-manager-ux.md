# 系统管理员量表管理页交互优化

本增量基于核心 Draft PR #457 的交付源 `320e88a15c425d1335383004d0016790a562f4f7`，仅改善已接入功能的使用效率。核心三阶段提交、Excel 解析、草稿存储、来源、发布试运行、兼容判断和四入口授权均未在本 UI 增量修改。原 UI 证据保留原基线；此前无冲突跟随含 #448/#461 的核心分支时，管理员 UI 源码和测试未改，主线其他页面的既有验证未重跑。之后新增的待审目录接线及定向验证独立列在文末，不冒充原 UI 输入未变。

## 现有入口与本次变化

入口仍为系统管理员“工具库治理 → 批量导入与草稿”。其他管理员入口及服务端 SYSTEM_ADMIN 检查保持原状。

- 原页将上传、结果、列表、完整 JSON 和发布串成单一长表单；现在分为“批量导入”和“草稿与版本”两个任务区，支持键盘方向键切换。任务切换保留编辑内容，未保存修改有状态提示。
- 导入按下载填写、预览修正、保存有效草稿展示进度；结果显示中文状态及有效/需处理数量，可只看错误。成功条目可直接打开对应草稿，无需在列表重新寻找。
- 草稿按名称/编码、可编辑/已批准状态筛选当前页；明确标注“本页”，不伪装成全库搜索，不为输入筛选词增加请求。原分页和手动刷新保留。
- 配置名称、量表名称、指导语及其语言/版本/来源用常规字段编辑。组分卡明确区分本次提供、继承和显式不配置；缺少的 P/R 可明确选择不配置，沿既有文档接口保存。
- 已有量表/报告编辑器继续使用原能力边界。高级 JSON 默认收起，完整结构保留；高级修改保存通过校验后恢复常规编辑。复杂计分、参数和自定义图表没有新增另一套编辑器或归一化器。
- 已批准配置的定义可展开只读核对并复制新版本，不能保存原地修改。未保存切换仍沿原有确认保护。
- 发布预览先显示各组分版本和新增/继承状态，再展示所选普通准则分档与配置报告文字。高级参考结构、自定义报告结构明确转到完整定义核对，不把其他参考版本或旧解释冒充当前所选内容。
- 发布入口范围、原因、管理员二次验证及自动试运行保留。操作中说明当前步骤；服务已返回的发布状态先显示，再回读草稿，避免回读失败掩盖已收到的结果。

## 协议与显示边界

继续使用原 JSON/multipart session 客户端、导入摘要/请求号、草稿 revision、精确 base 和发布 preview hash。没有新的服务端接口、权限、队列、存储或兼容计算。

参数/报告核对组件仅投影既有精确预览。它不计算被试分档、不改报告引擎，也不判断专业语义；报告展示的是配置文字，实际反馈仍由冻结分数、参考结果及既有披露规则决定。共享编辑器的描述性量表类型不会用于归一化标准量表内容。

## 定向验证

- 相关前端组件用例去重 10 项：原导入确认/修订保存/不完整草稿与 JSON 保护，直接打开导入结果、键盘任务切换及页内筛选、指导语编辑保留完整定义、显式 no-P、冻结只读查看、精确参数/自定义报告展示。最后辅助标签修改仅复验受影响的 4 项，其余未变结果复用。
- 前端应用 TypeScript 检查通过。定向 lint 无错误，管理组件沿用核心 PR 已有的 4 个 hooks 警告；未放宽规则。
- 实际 Chromium 组件预览使用拦截的合成 API：1440×1000 桌面、390×844 深色窄屏，无整页横向溢出；上传预览/错误过滤/保存/直接打开、revision 保存内容保留、发布条件、键盘切换及冻结只读通过。此检查不连接真实账户或数据库，不等于生产浏览器或正式鉴权资格。
- 新只读预览初轮的语法/类型错误，以及临时浏览器夹具的路由范围、响应 envelope 问题均保留本地原记录；修复后只复验相关检查。浏览器随后发现文本域辅助标签不稳定，已补明确标签并定向验证。

未重跑后端、数据库、恢复或未变页面用例；未启动完整 CI。临时页面夹具和浏览器截图不作为产品路由或源码提交；只保存必要 UI 源码、测试及合成工程说明。该增量保持 Draft，依赖核心 PR #457；正式资格、Ready、合并和部署由后续独立审查确定。

## 后续独立增量：待审目录承接

在已交付 UI 候选之后单独提交最小接线，读取内容 Draft #462 的现有 `onboarding-status` 字段，不修改该内容 PR 的任何文件。中文缺口在“接入状态”的主要区域直接显示；已有许可范围、计分缺失规则和专用计分器缺口使用中文说明，原标识保留供核对。

系统管理员可从条目选择“补齐内容并导入”或“查找已有草稿”，携带名称、工具标识和版本进入原管理区。草稿筛选明确只针对当前页；目录记录不冒充数据库草稿，不自动填造题本、计分、批准或安装。CTAS/TAS 的缺项、Psy-Flex 的既有 HOLD、SPANE 的计分器缺口仍须沿原来源处理；Skaalvik 的 DRAFT、评分及审核声明不变。

新增 4 项定向组件检查证明中文缺口可见、精确导航、当前页筛选及无写请求。另执行当前前端应用类型及变更源码 lint；不重跑原解析、DB/UI 全套或浏览器流程。后端、权限、接口、迁移、状态机和 #462 内容均未变。原 UI 证据保留原输入身份，新增验证仅覆盖此次独立增量。
