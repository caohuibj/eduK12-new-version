# 弹窗与学生待办收尾

## 实现范围

旧弹窗接入共享原生模态：问卷／量表导出、两类旧问卷的表单题目编辑，文档／图片／视频素材库的上传和预览、图片重命名、视频标题编辑、共享媒体及 PDF 预览、学生打卡图片预览。组织测评发布采用真正的模态确认。

作业、打卡、课程及上述编辑弹窗共享草稿保护：内容变化后退出需确认；提交时同步锁定，禁止重复请求、关闭和继续修改；失败在弹窗内显示并保留草稿，成功沿用原保存流程。课程封面上传与课程保存共用锁。关闭浏览器时使用标准未保存提示。

共享模态显式隔离下层弹窗，关闭最上层后恢复入口焦点及滚动状态。Tab 循环不依赖浏览器是否默认允许按钮获得键盘焦点；单选组保留单个 Tab 入口。Safari 点击按钮不自动聚焦时，仍记录其打开入口。内嵌文档拥有独立键盘作用域；文档库提供“单独打开文档”用于完整浏览器预览操作，外层 Tab 循环不进入 iframe，关闭按钮始终保留。Escape 在外层控件上验证，不能据此宣称跨域内嵌文档内的 Escape 也会冒泡到外层。

## 学生待办接口

`GET /api/courses/my/tasks?page=1&pageSize=20&state=IN_PROGRESS`

- 仅认证学生访问；用户身份取服务端当前 principal，忽略客户端传入的用户 ID。
- 课程任务仅限 ACTIVE／APPROVED 成员的非库课程。作业仅返回已发布内容；问卷及综合测评复用现有可用性规则。公开课程问卷按现有公开规则返回，未关联有效课程时标记为公共问卷。
- 四类任务：作业、打卡、旧课程问卷、综合测评（含新问卷和测评包）。不把课堂、独立认知任务或泛化问卷自动定义成课程待办。
- `PENDING` 待完成；`IN_PROGRESS` 有草稿／当前作答；`UPCOMING` 未到开始时间；`EXPIRED` 已过截止时间且未完成；`COMPLETED` 已完成；`UNAVAILABLE` 可用次数已耗尽。
- `canContinue` 为进行中且当前允许继续的动作标记，不是独立状态。历史完成记录后有新作答时优先显示新进度。已截止的进行中测评无继续入口。完成的旧问卷链接到最新完成报告，不自动开始重测。
- 开始时间相等视为已开始，截止时间相等仍可提交，与现有写接口一致；整个聚合使用同一服务端时间。客户端显示本地时间，实际操作仍由写接口重新验证权限和时间。
- 一项问卷投放多个课程只返回一次，并列出当前学生可见课程。无其他学生身份、答案或分数。
- 默认每页 20，最大 100；页码为正整数，最大 100000。非法状态和分页返回 400。读请求任一失败返回 500，不回退成空列表。
- 先按进行中、待完成、未开始、已截止、次数耗尽、已完成排序，再按截止时间、类型及 ID 稳定排序。`total` 是筛选后的数量，`counts` 是全局各状态数量，`generatedAt` 是本次计算时间。

前端每次加载／筛选／翻页发一次聚合请求，课程卡片仍独立使用课程列表接口；不逐门课程查任务。加入课程后刷新待办，旧响应不会覆盖新筛选结果。读取失败显示重试，不呈现旧结果或假空状态。

聚合使用固定数量的批量查询，与课程数量无关；不是每课程查询。当前复用综合测评可用性服务，在服务端对当前可见候选项排序、计数后分页，内存开销随可见任务数增长。数据库没有新增结构或迁移。聚合不是事务快照，任务变化后需刷新，所有动作继续受现有服务端校验约束。

## 验收

- 前端完整回归、前后端类型检查、构建和静态检查。
- 后端定向测试：学生角色、非法查询、成员及可见性筛选、100 门课程固定批量查询、截止边界、已完成与新进度优先级、完成报告入口、分页和部分读取失败。
- Chromium／Firefox／WebKit：授权读取失败和重试、嵌套弹窗、焦点循环／恢复、滚动锁、报告限制、素材上传键盘入口、素材预览、两种导出、两种题目编辑、真实表单提交保护／失败重试、首页待办读取失败和重试。CI 重跑三引擎矩阵并上传证据。
- WebKit 自动化不等同于实际 Safari／VoiceOver 认证。
- 按用户 2026-09-30 的指示，本 PR 暂缓真实 VoiceOver 验收及其系统设置操作；NVDA 因无 Windows 环境暂缓。不能将此项标记为通过。

后续真实读屏验收应使用正式产物和隔离测试数据，逐项确认授权错误被读出、背景不可导航、嵌套关闭只影响最上层、焦点返回父入口、上传控件可发现、失败后错误与草稿可读、报告限制及导出权限清晰。记录系统／浏览器／读屏版本、具体步骤和结果；不能用自动化替代。
