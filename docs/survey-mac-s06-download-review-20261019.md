# S06 第二小批：独立下载与准确反馈

SurveyAnalyticsWorkspace 保持原生成 POST、票据／签名游标与 Artifact 协议，改为 CSV、Codebook、Manifest 三个独立按钮。每个明确用户动作 GET 原票据，只发起所选文件，不自动触发另外两个，也不自动创建／重试 POST。每次读取都保留后端实时 owner／资格、五分钟 MFA、票据有效期、内容摘要及研究修订检查；不新增文件 API 或持久敏感缓存。后端、权限、计分和认知运行器没有变化。

代价明确：完整一批从原来 1 GET 增至 3 GET，每次仍返回完整 Artifact，并产生原读取审计；单文件重试增加 1 GET。现有每研究者 40 次／15 分钟读取限流与所有拒绝保持，不以原生验收为由放宽。后续资源／查询比较须记录此差异，不称为效率改善。

生成成功继续单独提示；取得票据不自动下载。各按钮显示“尚未发起”或“已发起，请核对保存”，发起后可显式重试同一文件。反馈明确“网页无法确认文件已落盘”，取消／拦截须查看浏览器下载列表。三个动作均发起后可以生成下一批，按钮及说明要求先自行核对保存，不再使用“当前批次已下载”。参与状态表同样如实列出三个文件。读取失败不发起 Blob，不丢弃原票据；发起边界异常提示结果未确认，不宣称已保存；临时 anchor 总是清理。

已有文件名、CSV 单 UTF-8 BOM、原服务端 CSV 字节、JSON 缩进、自由文本选择、格式／波次／时间过滤与参与状态关联合同保留。只校验读取回执匹配当前票据／格式及基本结构，拒绝错批次内容。

精确验证：第一次受影响下载文件 14 项全部通过；追加“换格式后清除文件发起状态且不自动取件”后仅定向该新项，1 项通过、14 未选择。因此共 15 个不同下载用例，不将复验重复累计。覆盖紧凑参与状态两个版本、CSV/JSON 精确字节、单动作单文件、完整一批 3 GET、网络／非 JSON／403／404／409／429 后原文件重试、错票据拒绝与浏览器发起异常清理。原生许可／取消不由这些 mock 断言替代。

最终应用类型检查通过。五个相关 Survey 产品／新增名称测试／下载测试 lint 无错误或警告；最后测试追加后单独 lint 通过。矩阵旧 Builder 用例另在第一小批记录。原始报告、日志与源码 SHA-256 见 download-evidence 目录。没有重跑无关后端／完整历史套件、没有 CI／PR／合并。

本提交冻结产品，下一步在真实 Mac Chrome、Safari 及 Numbers 验收并单独保存证据。S05 原生非空列表／授权状态、Safari 历史登录／首次提交和首轮四项失败继续保留到 S07，不在本批猜测关闭。
