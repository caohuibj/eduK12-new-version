## R5b 匿名闭环

- A：停用、过期或未开放入口明确说明原因并禁用新作答；同页切换入口清除旧状态和凭证，已有凭证仍可显式恢复原记录。
- B：后台一个“建立波次并生成链接”动作。有效期、名称及次数上限有可见校验；同一请求 UUID 可跨重试复用；链接与波次同一事务，失败全部回滚。旧链接绑定功能保留在高级选项中。
- C：原有研究身份页在 `/public/studies/waves/:waveId/:token`；普通波次链接现提供“选择单次访客或保存研究内身份码”入口，保持知情选择。
- 匿名 FINAL 作答页提供主动展开的保存/复制恢复凭证入口；换设备恢复测试直接从 UI 取得完整凭证，再在隔离环境输入，避免只靠读取内部存储验证。
- 结束研究在同一事务关闭研究及其波次公开链接，单次访客同样不能新作答；已有恢复凭证、历史统计及无关研究/普通链接保留，后台同步刷新链接状态。此边界已先在真实 PostgreSQL 复现失败，再验证修复。
- 隔离验证覆盖两个访客独立会话、两个 FINAL、刷新、粘贴作答凭证恢复、换浏览器环境输入研究身份，以及后台跨波次历史、仅当前波次导出、结束研究后恢复和撤回权限。
- 浏览器 UI 使用明确标注的合成 API/本地上传服务；真实数据库、计分、权限与冻结报告由独立 PostgreSQL 套件验证。此证据不能替代部署后同版本完整验收。

## PR #243 review 修订

Review 对照的是 `f454a6c9`。第一项在较新的 `0df74389` 已修复；本次保留并重跑真实数据库验证。其余五项意见成立，已按以下方式处理：

1. 结束研究原子停用所属波次 token，拒绝直接匿名新作答；原答卷恢复、历史统计、无关普通链接和其他研究保持可用。
2. 固定包认知 wrapper 同所有者时继承来源 root，同时继承 `maxAttempts`；跨所有者不冒用他人的 root。真实 PostgreSQL 覆盖独立、组合测评、旧综合测评、固定包四入口先后与并发争抢一次额度，以及原会话无额外计次恢复。通用多答卷生命周期 fixture 显式设置 100 次，限额回归仍严格设置 1 次。
3. 保留七天运行时审核有效期，已发布版本增加独立续审入口及到期状态；登记者仍不能自审，每次审批成功清空四项审核确认。时间推进验证到期拒绝新准入、独立续审同一 hash 恢复准入、内容和历史冻结报告不改写。
4. 登记阶段比对代码目录同 key/version 的声明式包 hash；不同内容立即拒绝，完全一致可幂等登记，避免发布后目录刷新才失败。
5. `installedBy` 记录登记者，签名 `reviewerId` 记录独立审核者，`publishedBy` 记录实际调用发布的管理员。独立审核约束以登记者为基准；底层签名接口也不能借另一发布者接受登记者自审。
6. 波次创建响应成功即显示成功并清理请求意图；统计/链接刷新失败另报刷新提示，不误报创建失败。两种刷新失败及原网络重试复用 UUID 均有 UI 回归；结束研究后的链接刷新采用同样的已提交状态提示。

上述实现及小程序清单仅本地验证，未启动任何新 CI。正式合并与发布条件保持未完成。
