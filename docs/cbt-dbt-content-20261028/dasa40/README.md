# DAS-A（dasa40）英文原文草稿与验收

`native/instrument.ts` 为 DAS-A 40题英文 DRAFT：40题自 Beck Institute 资料包中的 DAS-A 表单页逐字誊入（注意：包内第1–9页是100题原版，勿混淆）；七点选项（完全同意=7 … 完全不同意=1）；官方计分表10个功能信念题（2/6/12/17/24/29/30/35/37/40）按 8−作答 反向，总分求和 40–280，分数越高代表失调态度越强。反向键另与 de Graaf et al. (2009) 交叉一致。100题版与 Form B 未实现。来源、冲突与提取纠错过程见 `source.md`。

计分测试6项通过（反向键数量、极值、方向锚定、逐题翻转、缺答/非法值、样例：总分200）。`report_sample.html` 为模拟报告（示例总分214/280），含态度强度图示、非学术反馈、反思与行动、原创SVG；分数匹配 `sample-responses.json`。人群标注为成人原始样本；反向题方法因子已写入局限。缺答不补0；无常模、百分位或临床界值；授权未确认。
