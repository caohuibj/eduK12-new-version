# DTS-15 英文原文草稿与验收

`native/instrument.ts` 为 DTS 15题英文 DRAFT：全部15题及五点选项自公开副本逐字誊入；全部题目按 6−作答 统一反向后求均值（1–5，分数越高代表对负性情绪的耐受评价越好）。**四因子分量表未实现**——原论文题项归属未能核实，已标记 `subscale_structure_pending_verification`，入库前须与原文逐题核对。来源与冲突见 `source.md`。

计分测试4项通过（极值、逐题、缺答/非法值、样例：均值3.00）。`report_sample.html` 为模拟报告，含均值条形图、非学术反馈、反思与行动、原创SVG；分数匹配 `sample-responses.json`。人群标注为大学生原始样本；K12施测前须评估年龄适配。缺答不补0；无常模、百分位或临床界值；授权未确认。
