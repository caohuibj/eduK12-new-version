# CATS-40 英文原文草稿与验收

`native/instrument.ts` 为 CATS 儿童自评40题英文 DRAFT：40题自版权方（麦考瑞大学情绪健康中心）官网题本逐字誊入；0–4频率（过去一周）；官方四分量表求和（身体威胁/社交威胁/个人失败/敌意意向各10题、各0–40）＋总分0–160；无反向题。官方计分表印有临床界值，仅登记不使用（无 bands/标签）。来源与冲突见 `source.md`（旧官方链接已失效，新链接经浏览器会话验证；中文路径未交付）。

计分测试5项通过（分组、极值、逐题、缺答/非法值、样例：社交20/身体10/总分50）。`report_sample.html` 为学生视角模拟报告，含四维条形图、非学术反馈、反思与行动、原创SVG及安全提示；分数匹配 `sample-responses.json`。人群 7–16 岁（ESTABLISHED），是该平台 K12 场景的适龄 ATQ 对应版；与成人 ATQ-30 分属不同人群工具，不混用。缺答不补0；无本地常模；授权未确认。
