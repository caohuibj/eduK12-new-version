十张信念地图，
没有一张是判决书

这份记录描绘的是十类“关于自己与他人的信念”的相对强度。信念是长期形成的透镜，不是诊断，更不是对你的定义——看见透镜，才谈得上擦拭它。

这是模拟数据，不是你的测评结果。 十个量表描绘的是“信念维度”的强度，不是人格障碍诊断，不能用于给人贴标签。本工具为成人临床研究工具，对非临床人群的效度证据有限。

最突出的维度之一

自恋型信念

模拟总和 20 / 28

这组信念关注特殊性与应得感。自信是资产；当它需要通过压过别人来确认时，关系容易紧张。

想一想：最近一次感到“没被特别对待”的愤怒，背后期待的是什么？

小行动：做一件不署名的好事，练习让价值感不依赖观众。

同样值得留意

表演型信念

模拟总和 19 / 28

这组信念关注是否必须被关注、逗乐他人才有存在感。渴望联结是天性；把注意力当作唯一货币会让关系变得疲惫。

想一想：安静独处的时刻，你通常感觉如何？

小行动：尝试一次“不表演”的相聚：只倾听、不接梗，观察关系是否依然稳固。

信念与行为之间

偏执型信念

模拟总和 17 / 28

这组信念关注他人是否暗藏动机、需要时时设防。警觉曾是有效的保护；但持续开启会很耗能，也容易误读善意。

想一想：最近一次“觉得对方有别的意思”，事后看证据支持吗？

小行动：写下三个最近被你解读为“有意图”的举动，各自列一个替代解释。

情绪与关系

边缘型信念

模拟总和 17 / 28

这组信念关注被抛弃的恐惧、情绪的失控感与自我的不稳定感。高分说明这些体验频繁——不等于诊断，也不代表无法改变，DBT 技能训练正是为此发展。

想一想：情绪最猛烈的时刻，通常由什么事件触发？

小行动：为强烈的情绪准备一个“降温清单”（冷水、快走、给信任的人发消息），存在手机里备用。

透镜可以被擦拭

信念图谱的意义不在于“我是哪一类”，而在于发现哪些透镜在放大痛苦。选一个维度的小行动试一次，把图变成练习。

PBQ-SF 为成人（精神科门诊）研究工具；量表名指信念维度，不构成人格障碍诊断。官方 Z 分数常模仅登记不使用；本报告为原始分。
