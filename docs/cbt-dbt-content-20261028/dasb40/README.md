# DAS-B（dasb40）英文原文草稿与验收

`native/instrument.ts` 为 DAS-B 40题英文 DRAFT：40题自 Beck Institute 资料包中的 DAS-B 表单页（第16–20页）逐字誊入；七点选项（完全同意=7 … 完全不同意=1）；官方计分表10个功能信念题（1/5/12/14/19/20/26/30/33/36）按 8−作答 反向，总分求和 40–280；题文内容逐题核对为功能信念方向。#12/#30 在 A/B 两表均列为功能题（平行表非完全不相交），原文疑似印刷错误（you weaknesses / advise / unloveable）按原样保留并标注。100题版与 A 表（dasa40@1.0.0）分别登记，两表分数不互换。来源与冲突见 `source.md`。

计分测试6项通过（反向键数量、极值40/280、方向锚定220/100、逐题翻转、缺答/非法值、样例：总分200）。`report_sample.html` 为模拟报告（示例总分200/280，与 golden sample 一致），含态度强度图示、非学术反馈、反思与行动、原创SVG。人群标注为成人原始样本。缺答不补0；无常模、百分位或临床界值；授权未确认。
