# ATQ-30 英文原文草稿与验收

`native/instrument.ts` 为 ATQ 30题频率版英文 DRAFT：全部30题自第三方公开题本逐字誊入，无反向题，总分求和（30–150），另含来源说明页列出的四个因子求和（PMDC 5–25、NSNE 7–35、LSE 2–10、无助 2–10；因子只覆盖其16题）。来源与冲突见 `source.md`：ATQ-B 可信度列未实现；第三方转录须在发布前与原版核对；授权未确认。

计分测试5项通过（分组、极值、逐题、缺答/非法值、样例）。`report_sample.html` 为模拟报告（示例总分74/150、NSNE 28/35），含频率图示、非学术反馈、反思与行动、原创SVG；分数匹配 `sample-responses.json`。人群标注为成人/大学生原始样本；儿童青少年施测前须做年龄适配评估。缺答不补0；无常模、百分位或临床界值。
