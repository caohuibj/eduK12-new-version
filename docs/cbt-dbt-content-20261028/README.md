## 计分与核验

- 7 个可执行版本共 28 组原生 golden cases 全部通过；每家族 `scoring.py` 独立实现与 `build_native.py` 内嵌模型交叉一致，详见 [native-validation.json](./native-validation.json)。
- 缺答不补 0：统一采用 complete_required 产品保守约定，并在各工具记录中声明这不是原作者缺答规则（BSL-23 官方允许缺 2 题算均值，本实现未采用）。
- 未发明常模、百分位、临床界值或能力等级；CATS 官方界值仅登记不使用；BSL-23、RFL-48 明确禁止用于普通学生筛查与个体分级（forbiddenUses 含 INDIVIDUAL_REFLECTION）。
- DTS、RFL 的分量表与 KIMS 的总分等未经核实或官方未定义的分数一律未实现，并标记 pending。

## 报告验收

7 份 HTML 样稿均有分数范围条形图、非学术反馈、反思问题、可尝试行动与原创 SVG；数值为明确标注的模拟数据。系统现有 ReportRangeTrack 用真实分数绘图；未引入新的报告渲染框架或外部图片依赖。BSL-23、RFL-48 样稿为安全口径：不逐题解读、不分级，含危机求助提示。浏览器视觉/交互验收未完成，不得把本记录用作 UI 上线证据。
