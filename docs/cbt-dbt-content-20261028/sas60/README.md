# SAS-60（sas60）英文原文草稿与验收

`native/instrument.ts` 为 SAS 60题1983表单英文 DRAFT：60题以扫描页渲染图逐题转录（第10题 “I like to left alone” 为原表排印，按原样保留并记录论文版差异）；百分比时间选项（0%/25%/50%/75%/100%）以0–4线性等价计分；社会依赖（在意不赞成10＋依恋分离13＋取悦7）与自主（个人成就12＋行动自由12＋独处偏好6）两个总分（各0–120）＋六个分量表；量表构成以资料包内 Clark 等论文 Tables 2–3 为准，六分量表恰覆盖60题、每题一次。来源与冲突见 `source.md`。

计分测试6项通过（分组覆盖60题、各表题数10/13/7/12/12/6、极值0/120、逐题翻转、缺答/非法值、样例：依赖60/自主90）。`report_sample.html` 为模拟报告：两大维度＋分量表条形图、“两个独立维度而非对立两端”的框架、非学术反馈/反思/行动、原创SVG；分数匹配 `sample-responses.json`。人群为成人原始样本。缺答不补0；无常模、百分位或临床界值；授权未确认。
