# 延后需求：管理员库与教师复用

**状态：** 只记录，本轮不实现。  
**提出：** 手动体验综合测评时（教师只能看到自己创建的量表 / 认知任务）。  
**当前停点：** `checkpoint-2026-08-22-followups`

---

## 现在的行为（不要改）

教师只能使用**自己创建**的材料：

- 量表：`GET /api/scales` 对教师按 `creatorId` 过滤。
- 认知任务：`GET /api/cognitive/assignments` 对教师按 `createdBy` 过滤。已发布的任务类型配置（反应时 / 记忆 / Stroop / Fake）全教师可见，但必须各自建任务才能放进综合测评。
- 表单：**没有独立库存**。题目写在聚合问卷或综合测评模板里，不能像量表那样单独授权。
- 综合测评模板：教师只能看到自己创建的草稿/已发布模板。

管理员列表目前可以看到全站课程和用户，但**还没有**「把某份量表/任务授权给某教师」或「发一份综合测评模板给教师复用」的产品。

这是隔离，不是 bug。谁来打破隔离，由管理员做。

---

## 需求 1：权限分配（稍后，不急）

管理员可以把**特定**材料授权给**特定**教师，而不是默认全员可见。

范围（按现有对象）：

| 材料 | 说明 |
|---|---|
| 量表 | 授权后教师可在问卷 / 综合测评里选用，不必自己重编。 |
| 认知任务 | 授权的是教师可选用的已发布任务，或可基于某套 config 建任务。实现时再定是「任务实例」还是「任务类型」。 |
| 表单 | 若仍无独立表单库，不要单独做授权；放到需求 2 的模板复用里。 |

未授权的教师继续只看到自己创建的。

**不做：** 本轮不建授权表、不改列表过滤、不改综合测评添加模块的校验。

---

## 需求 2：问卷编制与复用（管理员预编综合测评）

管理员可以预先编好一份**综合测评模板**（量表 + 表单 + 认知，按顺序），让教师看见并可复用，而不必从零拼模块。

产品上要再定的两点（实现前确认）：

1. **复制还是引用：** 教师拿一份自己的草稿拷贝（改了不影响管理员原件），还是大家共用同一份已发布模板。课堂场景更稳妥的是**复制成教师草稿**。
2. **课程绑定：** 复用时再选该教师自己的课，不要沿用管理员预编时绑的课。

「问卷」在这里指综合测评容器（可含认知），不是现在的聚合问卷（只有量表 + 表单）。若以后也要让教师复用聚合问卷，另开一条，不要和综合测评混成一个按钮。
