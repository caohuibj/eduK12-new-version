# R5 补齐功能的发布与验证边界

本轮实现只在隔离环境验证。用户要求推送不触发任何 CI；保持 Draft PR，不合并、不部署，不自动开启固定包或家长报告开关。

## 兼容迁移

`20261007020000_assessment_workbench` 仅新增私有组合模板、管理事件和课堂结束小结三张表及索引，不修改既有作答或报告。发布时仍使用正式 `npm run db:migrate:guarded`，先应用迁移再启动新后端。旧应用版本可以忽略这些表；回退应用时保留新表和记录，不能直接删除已经产生的小结或审计。

组合模板保存为无投放能力的草稿：不复制课程绑定、公开 token、学生答案或报告授权。教师使用固定包仍经过精确版本、审批有效期和依赖校验。批量家长报告仅复用已有准入、预览、幂等发布、学生同意及逐份授权接口，不自动发送消息。

## 历史认知配额盘点

运行 `npx tsx src/scripts/r5-quota-audit.ts` 可以输出未绑定来源的历史 wrapper、精确 item 引用及同所有者/同配置的候选源。脚本只有读取操作，不输出答案、密文、姓名或计分结果。

候选源不是来源证明。缺失的历史来源不能根据配置哈希或唯一候选自动回填；须结合原始编制记录确定映射后另做受控迁移。无确切证据时保留待核查状态，不改写冻结记录。当前新增和复制路径已经使用显式来源关系并共享配额。

## 报告和统计

- 课程概览是已登录投放的作答次数，不将次数当作人数，不计算群体心理指标。组织群体与纵向结果仍使用正式投影和 `allowedOperations`。
- 部分报告只读取普通组合中已正式提交的单项，使用当前 epoch 的冻结 FINAL 记录；不触发作答创建、完成或重新分析。组织关系型记录、固定包和分析方案不使用此通用入口。
- 认知历史同时标记独立与普通组合来源，不暴露原始 trial 或研究专用指标。
- 课堂小结绑定题目内容哈希和结束时点，按结束前加入/提交统计。缺失历史结束时点明确标记，不能伪造。GET 不生成小结；显式生成后重复读取同一冻结记录。
- 合成对象筛选在服务端已授权全集执行；批量归档逐项使用最新 revision，保留历史，审计与归档同一事务。归档不是附件清理。

## 尚需正式环境验证

真实合法固定包/SJT 内容、参考方案和家长披露内容仍需要独立审批；隔离合成 fixture 不构成科学或版权认可。恢复 CI、部署、生产复验和小程序真机等价验收需要后续明确安排。本次本地通过不替代这些门禁。
