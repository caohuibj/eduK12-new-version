# R5 补齐功能的发布与验证边界

本轮实现只在隔离环境验证。用户要求推送不触发任何 CI；保持 Draft PR，不合并、不部署，不自动开启固定包或家长报告开关。

## 兼容迁移

`20261007020000_assessment_workbench` 仅新增私有组合模板、管理事件和课堂结束小结三张表及索引，不修改既有作答或报告。发布时仍使用正式 `npm run db:migrate:guarded`，先应用迁移再启动新后端。旧应用版本可以忽略这些表；回退应用时保留新表和记录，不能直接删除已经产生的小结或审计。

跨 PR 修订后，正式生产的 guarded migration 末尾和 release preflight 还需 `DATABASE_URL_RUNTIME`；Compose 已传递。检查器使用独立运行角色只读验证受限身份、按 release 清单分类的表/序列/schema 权限和精确迁移指纹，缺权、未分类表或运维表越权阻止发布，不自动授予权限。前序授权已精确撤销生产迁移账本多余写权；本轮进一步只读确认两个 legacy 导入运维表及 future-table 默认授权仍较宽，未在生产运行新 reconcile。首次配置、新增表和灾备恢复按 [数据库运行角色配置流程](runtime-database-provisioning.md)，在 migrate 后显式 reconcile，再以真实 runtime 重验。生产仍在原 100 条迁移 release，不代表 PR 的 102 条迁移就绪。旧家长兼容 JSON 不再具有新发布权限；已有旧同意/授权仅提供逐份撤回，重新授权需合法发布、同意和逐份授权。完整边界见 [跨 PR 修订说明](qa-cross-pr-review-repair.md)。

组合模板保存为无投放能力的草稿：不复制课程绑定、公开 token、学生答案或报告授权。教师使用固定包仍经过精确版本、审批有效期和依赖校验。批量家长报告仅复用已有准入、预览、幂等发布、学生同意及逐份授权接口，不自动发送消息。

## 历史认知配额盘点

运行 `npx tsx src/scripts/r5-quota-audit.ts` 可以输出未绑定来源的历史 wrapper、精确 item 引用及同所有者/同配置的候选源。脚本只有读取操作，不输出答案、密文、姓名或计分结果。

候选源不是来源证明。缺失的历史来源不能根据配置哈希或唯一候选自动回填；须结合原始编制记录确定映射后另做受控迁移。无确切证据时保留待核查状态，不改写冻结记录。当前新增和复制路径已经使用显式来源关系并共享配额。

## 报告和统计

- 课程概览是已登录投放的作答次数，不将次数当作人数，不计算群体心理指标。组织群体与纵向结果仍使用正式投影和 `allowedOperations`。
- 教师部分报告只读取普通组合中实际已正式提交的测量单项，使用当前 epoch 的有效冻结 FINAL 记录；零结果和仅背景表单不开放。组织关系型记录、固定包和分析方案不使用此通用入口。
- 参与者（含匿名）默认完成整份组合测评后才开放受众允许的反馈。旧部分报告链接、FINAL 返回、量表/SJT 读取及认知会话/历史遵循同一边界；单项已提交时明确显示反馈延后。未新增逐项反馈模式，不触发作答创建、完成或重新分析。独立测评原规则保留，关系型仅完成确认的规则仍然优先。
- 认知历史同时标记独立与已完成普通组合来源，不暴露原始 trial 或研究专用指标。
- 课堂小结绑定题目内容哈希和结束时点，按结束前加入/提交统计。缺失历史结束时点明确标记，不能伪造。GET 不生成小结；显式生成后重复读取同一冻结记录。
- 合成对象筛选在服务端已授权全集执行；批量归档逐项使用最新 revision，保留历史，审计与归档同一事务。已归档重试直接返回当前记录，版本和审计不重复增长；越权请求仍拒绝。归档不是附件清理。

## 固定包暂停恢复

HOLD 暂停新准入，恢复仅使用“重新审核并恢复发布”：另一位管理员重新确认科学、版权、语言和报告四项，再进行管理确认。服务端校验新签名的 `reviewedAt` 严格晚于暂停记录的 `updatedAt`，不得重放暂停前签名；审核有效期为该时间起七天。内容 hash、历史冻结报告和精确依赖保持原治理规则，RETIRED 不可恢复。

`reviewedAt` 是现有 review JSON 中的可选签名字段，本轮不新增迁移。已发布旧签名可继续按原有效期准入；无该字段的旧审核不能用于解除 HOLD，必须重新独立审核。应用回退前须明确旧版本不具备新的恢复限制；不要用旧应用执行暂停恢复。

## 尚需正式环境验证

真实合法固定包/SJT 内容、参考方案和家长披露内容仍需要独立审批；隔离合成 fixture 不构成科学或版权认可。恢复 CI、部署、生产复验和小程序真机等价验收需要后续明确安排。本次本地通过不替代这些门禁。
