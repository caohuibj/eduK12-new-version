# Reporting V2.2 收尾验收

基线：`main@527be744`（PR #169、#170、#171 已合并）。本 PR 补齐指定成员界面、普通报告用语、大样本查询预算及真实浏览器验收。

## 功能与边界

- 群体筛选支持全部、班级、标签和指定成员，条件之间取交集；单次与纵向报告共用选择器。
- 新增 `GET /organizations/:organizationId/reporting/cohort-members`，支持搜索与分页，每页最多 100 人。只有具备现有个人访问范围的管理者、教师或咨询师可发现姓名。返回历史测量已冻结的 Membership IDs，不返回结果或人数统计，并在查询后复核权限。
- 同一学生的历史成员记录作为一组勾选，避免重新入校造成遗漏。BASELINE_FIXED 仍按稳定 userId 跟踪；历史班级和标签仍按每次发布时刻解析。
- 搜索失败清除已显示姓名，但不自动把已选子群扩大成全体。切换组织和卸载后的旧搜索响应被丢弃。
- 普通生成区使用中文分析方式、测量类型和报告状态，不要求填写 ID。原有手动 Series/Wave、受保护反馈及编号读取保留在折叠的高级区。报告方案仍使用平台发布时命名的方案名称；不自动发明或发布科学方案。

## 原文档七个最终场景

| 场景 | 自动化验收 |
|---|---|
| 1. 已完成测量按性别标签生成子群报告 | 新增真实浏览器场景勾选女生、生成报告并验证所选人数；数据库测试验证来源子集与隐私阈值 |
| 2. 三个时间点的群体趋势 | 浏览器选择三个时间点，生成 REPEATED_COHORT 并检查三波结果 |
| 3. 同一批学生的三波匹配 | 浏览器选择 BASELINE_FIXED/FULL_CASE，验证匹配人数；数据库测试覆盖未完成记录和跨成员身份时期 |
| 4. 转班不改变历史班级 | 夹具在 T1 后转班；浏览器选择旧班级与 T1，仍得到历史四人子群；数据库验证半开时间区间 |
| 5. 个人纵向自动发现与生成 | 浏览器选择学生、项目及三个时间点，直接生成三波个人结果，无需建 Series |
| 6. 跨版本无证据时不计算差值 | 夹具含 1.0.0 和 1.1.0，无 comparability evidence；浏览器验证 NOT_COMPARABLE 且无 delta |
| 7. 匿名完成后查看本人报告 | 四类问卷浏览器完整作答并读取报告，随后从已用尽的一人链接恢复同一报告；既有 PostgreSQL/权限测试验证跨凭证拒绝和匿名隔离 |

浏览器使用隔离数据库中的合成数据，不使用真实学生数据，也不声称重新验证某一具体量表的科学效度。报告场景使用 canonical Bundle 结果覆盖同一报告管线；Scale/Cognitive/SJT 结果解析和版本契约仍由既有回归验证。

## 性能验收

- Cohort：100 / 1000 / 5000 人，筛选查询数相同且不超过 6。
- Longitudinal：3 波 × 100 人与 3 波 × 1000 人，完整自动编排分别为 **147 / 147 次查询**；验证全体匹配人数，没有逐个学生查询。
- 测试计数不包含夹具构建，包含实际冻结、权威结果读取、Series/Wave 绑定及 artifact 生成。不是生产环境延迟或吞吐量承诺。

## 合并后复查与修正（2026-09-26）

PR #172 已合并，完整 CI 通过。随后复查发现，主流程验收未覆盖以下界面边界，原“全部关闭”口径应以这些修正的完整门禁通过为前提：

1. 成员搜索失败清除姓名缓存后，再取消一个已选成员会丢失其他成员条件。现在始终以父级 selector 中的 membershipIds 为准进行增删，搜索失败仍清除姓名；新增失败、恢复、取消和重新选择的回归。
2. 修改分析人群或测量条件后旧报告仍显示。现在相关条件变化清除旧报告与成功提示，生成过程中禁用条件编辑；组织或权限上下文变化重建工作区，迟到响应不能显示到新上下文。新增切换条件及生成期间权限变化的回归。
3. 群体纵向结果直接显示 Wave UUID。现在改为第几次测量及日期，用中文显示可比性、允许操作、匹配人数和变化量；个人报告共用可比性文案。不修改服务端统计值、比较规则或 artifact。

本次还复核了历史标签/班级解析、基线固定策略、跨 membership episode 的稳定 userId 匹配、单人权限与导出复核、匿名恢复和组织报告来源隔离。结合前一轮已通过的 PostgreSQL、浏览器和完整门禁，未发现需要在本修正中追加的后端阻断问题。这是本次检查范围内的结论，不代表生产部署或真实数据验收已完成。

现有边界保持：PAIRWISE 仅选择两个时间点；更多时间点使用 FULL_CASE；无可比性证据不产生数值差值；匿名报告恢复受原 capability 有效期约束；正式报告方案须经审核发布。
