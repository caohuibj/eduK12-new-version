# Survey 独立工具集（本地验收）

本轮入口为 `/workspace/tools`，不创建隐藏研究，也不把工具归属到某个研究。研究页面保留研究设置、私有报告、发布与采集、研究数据四个分区。旧的 `section=tools` 地址兼容到发布与采集的问卷内容区。

## 当前开放范围

| 类型 | 自建 | 当前能力及边界 |
| --- | --- | --- |
| Form | 开放 | 复用原有分页、题型、条件、导入、图片与正式答案验证器。 |
| Scale | 开放 | 复用维度、反向题、总分、原始分区间反馈及结构与模拟计分；研究中的测量发布、报告与反馈策略仍单独管理。 |
| 普通组合问卷 | 开放 | 顺序选用自编表单、量表和获授权工具，不嵌套组合包；加入当前问卷时保留顺序，各测评分别处理结果，不生成打包综合报告。 |
| Cognitive | 暂不开放自建 | 当前 `ResearchCognitiveEditor` 是固定 Go/No-Go PILOT 协议，试次数、比例、时序等不能独立设计；反馈只有受控描述性指标，不是完整的参数、阈值与报告编制体系。授权原版仍可选用。 |
| SJT | 暂不开放自建 | 现有情境、题目、构念贡献、校验与运行链不等于完整的独立科学参数、阈值和报告产品；`builder.compiler.ts` 的作者预览仍标明 `GENERAL_ONLY`。授权原版仍可选用。 |

## 存储与选用

- 新增 `survey_tool_templates`，所有读取和写入都限定当前合格 SURVEY 研究者所有权。普通组合问卷记录明确工具引用及自编工具修订，不接受其他研究者的内容，也不嵌套组合问卷。
- 选用时校验保存修订、结构和当前授权，再在一个事务中建立项目快照；`survey_tool_selections` 记录请求摘要及有序工具 ID，重复请求返回原结果。
- 工具集后续修改不覆盖已选用内容。过时组合引用需要重新选用当前修订；正式发布、冻结和参与者访问仍走原有服务。
- 静态图片沿用所有权、摘要、大小、类型及说明校验；只为经过验证的同一所有者目标附加引用，不增加跨用户媒体权限。
- 旧研究工具保留只读查看、发布版本和存入独立工具集的兼容入口。新编制统一在首页工具集；SJT/Cognitive 的原自建创建、编辑、复制接口同步拒绝，历史冻结内容读取保留。

## 本地检查与未覆盖项

本地增量迁移已应用于本对话独立合成库；未改已有业务行、账号权限、Training 服务或数据库。新增数据库用例仅选用既有合格研究者，创建并清理本次测试工具、项目和合成图片元数据，不创建登录账号。

检查覆盖所有权、修订冲突、普通组合顺序、选用快照、重复提交、图片引用、旧入口兼容、四个 Tab、折叠说明、保存与上下文保护。数据库和前端检查分别留存报告；失败初始化、旧文案断言及修正后的定向重验保留原记录，不把失败调用改写为全套成功。

截图使用明确标注的合成前端响应，全部写入被拒绝；不作为真实 MFA 登录、完整人工验收或生产发布证据。前端代理中的新接口已核对为未登录 401，独立 API 及依赖就绪。未执行全量 CI、生产访问、部署、推送或合并。历史 FINAL 集成文件只调整受新自建关闭策略影响的合成 fixture，本轮没有运行该完整文件。
