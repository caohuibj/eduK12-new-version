# 教师成长反馈草稿（项目编辑，非分数报告）

版本：编辑草稿1.0.0。填答者和接收者均为教师本人；仅在既有结果访问授权下呈现。以下情境是阅读示例，不是自动阈值分档、诊断或教师评级。FORM 没有个人维度得分、等级、常模或“优秀率”。当前未安装运行时报告版本。

**较多认同的回应情境**

你对部分课堂做法、理解与支持来源表达了较多认同。这提供了一个值得继续观察的起点，还不能证明这些做法对每位学生都有同样效果。可以选最近一节课，记录一次具体做法及学生怎样回应；再找一个容易被忽略的学习需要，尝试调整一个环节。用小量课堂证据帮助自己判断哪些做法值得保持。

**遇到困难或较少认同的回应情境**

你的回答提示，有些做法可能难以持续，或所需的资源与支持还不容易获得。这不等于你不关心学生，也不能据此断定你的教学能力。先选一个可改变的小环节：公平课堂实践可观察一次发言或反馈机会的分布；文化与情境考量可检视一个教学例子是否预设了所有家庭有相同经历；信息与支持获取可向可信同事提出一个具体资源请求。资源、时间或制度造成的限制需要共同解决，不由教师独自承担。

**信息不足情境**

部分题目尚未回答，或你还没有足够经历作判断。目前只能保留你已表达的看法，不为未答项推定立场，也不作完整的个人概括。可以先记录一个近期课堂情境；若你愿意，待观察或获得相关信息后再补充。这里不计算或推算缺失题分数。

对美国制度或文化术语不熟悉时，保留“不确定”的实际情况，不把文化差异误判成缺陷。当前题本无“不适用”选项；本项目也没有自行增加此类别或把空白编码成反对。反馈不要求教师收集可识别的族群、家庭或学生敏感资料作为个人反思作业。

**给已获授权教研人员的群体说明示例**

在既有匿名、最小人数、发布和接收者要求均满足后，可以讨论哪些题目的群体回应显示相对一致的认同，哪些实践或资源值得继续了解。较少认同也可能反映资源和制度障碍，不能直接归因于教师态度。先共同选一个可支持的改进点并约定观察证据；不要公布个人答卷、给教师排名，或根据小群体/可识别组合推断某位教师的回答。样本不足、未发布或未授权时不提供这份群体反馈。本文没有改变现有披露权限。
