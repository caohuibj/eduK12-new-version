# K–12 教师反馈素养｜简体中文工作译文反思版

![教师和学生并排看一份作品的两个版本。](../art/cover.webp)

一条评语是不是真的帮上忙，常常要等学生动手修改才看得出来。这份反思从一个你还记得的课堂片段出发，帮你挑出下次想调整的一件事。

## 开始前

选几题写下实例、没想清楚的问题，或想进一步学习的做法，几句话就够。也可以留空或拒答。引用作业时请去掉姓名、照片和其他能辨认学生的信息。

## 反馈知识

看一看，学生从评语里能读到什么

从你写过的一条评语想起。它是在提醒学习目标、说明这次表现，还是提示下一步？具体例子能帮你看清自己想再了解哪种反馈方法。

找一条自己写过的评语，划出告诉学生怎么改的部分。如果这一部分很难找到，就补一句行动建议。

## 反馈技能

留出用反馈的时间

回想你是在什么时候、用什么方式给出反馈的，再看看学生有没有时间尝试。反馈的用词固然重要，学生能不能马上试一试也会影响结果。

给一个可以马上做的小建议，再留出一次修改机会。对照前后两版，看看学生实际用了你说的哪一点。

## 反馈价值

听听学生是怎样理解的

想一想某次反馈过后，课堂气氛有没有变化。学生可能更敢提问，也可能认为内容已经定下来了。听听学生自己的解释，有助于理解变化从哪里来。

请一位学生说出听懂的一点和还想追问的一点，再回看自己当时是怎样提供反馈的。

## 反馈行动性

让学生知道第一步从哪里做起

老师觉得明确的评语，到了学生手里，可能还是不知道先改哪里。可以从评语之后发生的事情，看哪一步还需要交代。

把一句笼统评语换成一个学生现在就能做的小动作。请学生用自己的话复述，再看修改时到底发生了什么。

## 写完之后

下一次先试着改一条评语或一个课堂环节。提前想好要观察什么。等看过学生的下一次尝试，再决定有没有必要继续调整。

留空只表示这次没有留下文字，不能据此判断教师掌握了什么、做过什么。记录按原文字保存，反馈指南不会计算分数或自动给出等级。
