# 教师反馈素养｜反馈价值

听听学生是怎样理解的

![老师认真听学生说自己为什么做了一处修改。](../art/values.webp)

想一想某次反馈过后，课堂气氛有没有变化。学生可能更敢提问，也可能认为内容已经定下来了。听听学生自己的解释，有助于理解变化从哪里来。

## 下次可以试一件事

请一位学生说出听懂的一点和还想追问的一点，再回看自己当时是怎样提供反馈的。

## 怎样看自己的记录

留空只表示这次没有留下文字，不能据此判断教师掌握了什么、做过什么。记录按原文字保存，反馈指南不会计算分数或自动给出等级。
