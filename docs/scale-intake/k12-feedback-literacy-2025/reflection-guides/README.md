# 中国 K–12 教师反馈素养｜英中独立图文反思

本目录把原有 [英文与中文普通问卷配方](../ordinary-composite-recipe.json) 与十份图文导读绑定。每个语种单独保留反馈知识 7 项、技能 8 项、价值 8 项、行动性 7 项。各版通过现有普通问卷导入对应 Form 模板。原反思题本、原题码、模板定义和应用报告模式均保持原状。

- [English reflection guide](en/overview.md)
- [简体中文工作译文反思导读](zh-cn/overview.md)

练习导读供教师本人结合自己的文字记录使用。空白和拒答保留原行为。图文建议不会被系统按字数、关键词或题数自动触发，沿用原有 COLLECTION_ONLY 模式；没有分数、名次或能力标签。

目录中的 [版本索引](index.json) 将图文、语种、题序和各现行 Form 定义摘要对应起来。所有八份摘要与 [原表单验证](../native-validation.json) 一致，相关普通组卷使用 [隔离导入回执](../isolated-import-receipt.json) 作为既有模板装配证据。

Kang、Huang、Liu、Yin 2025 年研究发表的题文获得 CC BY 4.0 许可。中文为项目工作译文。原施测教师选项、正式中文题本及个体计分依据仍需要另行取得。
