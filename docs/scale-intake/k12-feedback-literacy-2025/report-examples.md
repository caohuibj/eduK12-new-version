# 教师成长反馈：无分版本与未来计分候选分开

目前实际导入的是无分文字反思表单，报告模式为既有 `COLLECTION_ONLY`。以下均为原创合成文稿，没有计算、装载独立R版本或推断教师能力等级。正常、困难、信息不足是示例情境名称，不是算法分类，也不从空白、否认或拒答中猜测原因。

## 当前无分版本的完成提示与可选反思

**正常情境：教师主动记录了具体实例。**

合成回答：“我在这次作业后给出了一个具体修改建议，下一课看了学生修改的作品。”

可用文稿：“你留下了一个具体的反馈实践实例。若想继续复盘，可以选一份修改前后的作品，看看学生改动了什么、还有哪一步需要说明。自我记录提供的是你的视角，还不能证明所有学生都理解并使用了反馈。”

此文稿仅在教师主动提供上述经历并明确查看反思建议时采用，不能由题目打勾或字数自动触发。当前系统实际只收集原文；没有新增文本分析或自动建议能力。

**困难情境：教师主动说明实施限制。**

合成回答：“讲评后时间不够，我还没有检查学生是否按建议修改。”

可用文稿：“你提到了反馈之后缺少跟进时间。可以先从下一次作业中的一类常见问题开始，给出一个可执行的修改要求，再抽看少量修改作品。也可以和教研同伴商量如何把检查融入下一课。这个困难不等于你不重视学生；先做一个资源允许的小尝试即可。”

只回应教师已明确说出的限制，不把未实施推断为意愿、能力或责任缺失，不要求教师独自解决超出其资源的条件。

**信息不足：教师留空、拒答或只写“暂不确定”。**

可用完成提示：“这部分暂没有足够信息做具体讨论。你可以以后再补充，也可以只留下一个想了解的问题；不会据此生成分数、等级或能力判断。”

留空和拒答在既有事实状态中分别保存，不补0，不显示“反馈素养低”。不把可选文字题全部空白当作失败测量。

## 四个子项可供教师自行选择的微行动

| 子项 | 讨论边界 | 可选的一步 |
| --- | --- | --- |
| 反馈知识 K1–K7 | “我理解/知道”是自我判断，不是客观知识测验成绩。 | 选一句常用反馈，说明它与哪个学习目标有关，再与教研同伴核对理解。 |
| 反馈技能 S1–S8 | “我能/我曾能”是自评能力或经验，不保证已稳定实施。 | 把一条笼统评价改成一个具体建议，请学生用自己的话说说下一步准备做什么。 |
| 反馈价值 V1–V8 | 价值认同不是行为频率，不能据认同推断已经落实。 | 记录一次反馈后学生的提问或情绪反应，思考措辞与语气是否需要调整。 |
| 反馈行动性 A1–A7 | 教师认为反馈可执行，不等于学生已理解并使用。 | 选一份任务，给出一个修改步骤，并查看修改后的作品是否体现该步骤。 |

反思建议不与数值区间绑定，也不评教师优秀/不合格；这些都是教师可选择的工作方法，不是问卷确认其已经做过的行为。

## 未来原计分版的报告准备边界

需先取得原教师响应锚点、编码、反向/聚合/缺失规则和实际原始中文题本，才能确定对应C/计分/R。现有论文的IRT信息曲线不能替代完整项目参数并计算个体潜在能力。没有原生学生平行版；不将教师陈述改人称造学生问卷。

未来若有合法、完整的计分版，教师报告应分别解释知识自我认识、技能自我判断、价值认同和行动性自报，并提示核对作品/课堂等证据；不作绩效、诊断或学生实际体验结论。尚不能给出真实高/低分示例或分档阈值，当前无分表单也不会生成这样的报告。

报告接收者是教师本人，须沿现有个人结果/文字答卷权限。管理者或教研组没有因本次标签和报告文稿获得读取个人文字回答的权限。任何群体材料或公开案例仍应符合已有授权、匿名和最小人数规则；这次没有发布、投放、共享或改变规则。
