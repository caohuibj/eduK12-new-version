# 教师成长反馈编辑草稿

没有R版本、结果、阈值或渲染通过证明。仅在未来题本/使用范围和可解释结果具备、既有接收者/发布权限允许时才按原生报告流程接入。教师自评不自动向校方披露个人结果；群体汇总沿原授权、匿名、最小人数规则，无分Form只给描述性反馈。没有原生学生对应题表，不造学生版。

**正常回顾**：你这次的回答反映了自己对校本评价的感受、用途判断和实施把握，不能单独证明教学效果。可以选一项你认为有用的安排，回看一份实际评价记录，看看它帮助了哪一步，并保留一个想进一步了解的问题。

**遇到困难**：认同某项改革的价值，同时对工作量、准备或实施感到压力是可能的。这不表示你不努力或不适合教学。可以先把一个具体问题与可信任的同事或培训支持者讨论，区分需要补充的知识和需要共同协调的条件，不必独自承担制度层面的困难。

**信息不足**：当前没有足够资料形成个人解释，不显示0分、能力标签或改革配合度结论。你可以自愿保留一个希望澄清的要求，待取得适当信息后再回顾；不要求为了获得反馈而强行补答。现阶段实际只能显示来源准备状态，不能假装已收集答案。

各构念分别解释：情感态度是感受，工具性态度是用途判断，规范是感知他人期待，自我效能是自觉可行性，知识是自述熟悉程度，意图是打算。它们不能代替真实实施行为、客观知识正确率或教师绩效，也不因论文回归关系就给个人作因果预测。反馈不为了积极措辞而反转原计分意义。
