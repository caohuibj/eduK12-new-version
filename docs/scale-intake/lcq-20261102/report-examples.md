# LCQ 报告文字示例：按接收者区分

编辑草稿，未建立R版本、未绑定计分、未生成真实结果。当前只有目录，无个人报告可看。以下“正常体验／较低体验／证据不足”是供审阅的情境名称，**没有数值阈值，不是运行时分支或常模等级**。原计分及方向保持不变，不为鼓励改分。

## 可见条件与真实路径

学生是填答者；报告接收者须独立选择并满足现有授权。未来学生版只能在精确题本、可解释结果、既有结果发布与接收者政策均允许时，展示给该学生本人；不由“完成了问卷”推定有完整结果查看权。教师版只用于其已有权限允许的群体汇总，继续遵守原匿名、发布、最小人数规则。不得展示可识别的学生个体得分、原答卷、敏感开放回答或可反推身份的小组。

原生实现路径为 `server-version/backend/src/modules/scale/onboarding/report-variants.ts`（已有报告版本材料）及 `server-version/backend/src/modules/scale/policy/disclosure.ts`（已有接收者投影）；本轮未修改它们、未给LCQ接入运行时R。四项LCQ `source.json` 只有 `candidatePreview.reportPlan`，不含 `executable` 或 disclosure授权。后续有合法C/P后再按现有报告版本流程落实，不能直接把本文注册为个人结果。

示例按原始已核的**高校学生**认知水平撰写。未来若要用于小学/初高中，需先补适龄题本及理解证据，再分别调整文字；本页不宣称这些例子已适用于K12。全体教师版本必须写“这些课程中与老师相处的整体经历”，不能把整体结果改成某位教师的评价。

## 学生版：特定课程／教师

**正常体验情境示例**

你这次的回答描述了自己在这门课中感受到的支持，例如有没有机会表达想法、学习上的需要是否被理解。这些经历值得被看见；它们不能说明每一次课堂都会相同，也不是对你能力的评分。

你可以选一件小事尝试：课后记下一个仍不清楚的地方，用“我在这一步遇到了困难，能再举一个例子吗”提出具体问题；也可以留意哪一种学习安排最帮助自己，合适时表达这个需要。选择你觉得自在的方式就好。

**较低体验情境示例**

你的回答提示，这段时间你可能较少感到自己的想法被听见，或较难找到适合表达学习需要的机会。这不代表你能力差，也不需要你独自负责改变课堂。问卷只记录这次经历，不能据此判断老师的好坏。

如果你愿意，可以先写下一件具体发生的事和希望获得的帮助；觉得直接表达有压力时，可以请一位可信任的导师、辅导员或其他支持人员陪你讨论。你不必对抗老师；如果遇到不公平或不当对待，寻求帮助是可以的，责任不在你身上。

**证据不足状态示例**

这次资料还不足以形成可靠的个人解释，因此这里没有得分或高低结论。它不能说明你是否获得了足够支持，更不能说明你的学习能力。你可以保留自己希望被听见的学习需要；是否继续提供问卷信息由你按活动安排自愿决定。

以上证据不足文字只供既有流程允许的状态提示，不给出个体测量解释或强制补答建议。对本轮仅目录缺题本情形，实际状态文案应为“目前仅有来源资料，尚不能作答或生成个人报告”，不能假装学生曾作答。

## 教师版：已授权群体汇总

**正常体验情境示例**

这次可解释的群体反馈描述了学生在指定课程和时段感受到的自主支持。它为回顾教学安排提供一个角度，不是教师能力评级，也不能代表每位学生的经历一致。只在原有授权及群体披露条件满足时展示汇总；不呈现个人意见。

可以回顾一项让学生容易表达问题或选择学习方式的安排，保留有效的做法；下次课尝试用一个简短、可选择的提问入口，了解还有哪些学习需要未被回应。不与其他教师、长短版或不同指称版本直接排名。

**较低体验情境示例**

这次群体回答提示，部分学习经历中的表达空间或被理解的感受值得进一步关注。它不能确定原因，也不是对学生配合程度或教师人格的判断。课程要求、接触时间、学生所处情境都需要一起考虑。

可以先选择一个具体环节改进，例如说明一项任务为何这样安排，并提供一种低压力的提问方式。通过现有匿名反馈渠道了解需要，不追问是谁给出较低体验的回答，不展示可识别的原话，也不让学生为教学条件或不当对待承担责任。

**证据不足／披露条件不满足状态示例**

当前没有可供此接收者查看的可靠群体解释，因此不显示得分、分布、分组或个体内容。缺资料不能被解释为“没有问题”或“支持不足”。可按原活动安排继续提供通用的提问和学习支持；不要求学生补答以换取反馈，不降低既有匿名和最小人数要求。

## 无计分情形及必要检查

若未来另附项目自编背景表单，只回显现有权限允许的事实或描述，不生成LCQ分数、分级和评分报告。本轮没有这类表单，也没有学生作答。

当前检查只需确认四项源是 `CATALOG_ONLY`、无可执行定义/计分/报告和新披露授权、原生报告选项为空；不能把本页文字检查说成真实报告渲染已通过。合法题本及C/P/R建立后，才针对实际学生接收者路径、教师汇总权限、正常/低体验/证据不足和无分表单做必要验证；不得因新文字重开保密结果或扩展全量测试。
