# RTTQ教师成长反馈草稿

没有R版本、实际结果、分数阈值或渲染通过证明。以下为原创项目中文编辑文字，不是问卷翻译或已验证中文版。未来只在内容使用范围、可解释结果及既有接收者/发布权限允许时接入原生报告。个人自评不自动对校方开放，群体汇总保持原匿名、授权和最小人数规则；无分Form不生成反思能力分或等级。

**正常回顾**：这次自述可以帮助你回看自己如何学习、评估做法和使用反馈，不能单独说明教学效果。你可以选一次具体课堂经历，写下一件观察到的事和一个可能的解释，再找一份学生作品或同事反馈核对。选择一个小调整，下次回看它是否有帮助。

**感到困难**：反思时有困惑或不舒服的感受并不罕见，也不代表你不适合教学。可以先选一条清楚、具体的反馈，与可信任的同事一起区分事实、解释和可改变的条件；不必一次处理所有意见，也不需要把每条批评都当作对个人的判断。缺时间或支持时，可以共同协调一个可行步骤。

**资料不足／无分情形**：目前没有足够依据形成个体分数或高低结论。中立回答和空缺分别保留，空缺不当成0。你可以自愿留下一件想进一步了解的教学经历，待有条件时再回顾；不要求为了得到反馈而强行补答。当前尚无可作答内容，实际只展示来源准备状态。

四组解释分别聚焦学习与调整、自我评估、信念与自觉可行性、对教学方式的觉察；不互相替代。负向题含义和反向键未核时不根据组名给“积极程度”或教师优劣结论，也不把对反馈不安的回答诊断为焦虑、低自尊或不胜任。
