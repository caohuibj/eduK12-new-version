# DigCompEdu 高教版｜三份独立简体中文附件

此处配对 Ersoy 等的 2023-06-02 高教英文附件。原英文留在[上一级目录](../forms.json)。[独立中文版](forms.json)覆盖问题 2、25–38、39，保留题码、选项、矩阵、允许选择其他、字段限制及作答布局。电子邮箱仍沿用原项目版本的省略。译本用于审稿和非计分反馈阅读，可沿现有表单流程选用。中文群体效度及独立译审尚无完成记录。

组合计划见 JSON。顺序是填写前自我定位、六个已有中文领域、背景与数字教学条件、填写后自我定位。前后选项是自选 A1–C2 类别，背景表记录可选语境。三份附件均无计算等级或计分，组合也不自动合成总分。计划只引用已登记内容。
