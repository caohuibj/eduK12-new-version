# 教师成长反馈示例（项目中文草稿）

这是英文原生R的中文解释草稿，不是已验证中文版量表，也不另建报告引擎。填答者及报告接收者均为同一位已授权教师；`teacher`受众是已有报告投影名称，不自动开放其他教师或管理员对个体结果的访问。正常、困难、信息不足以原始回应及证据为依据，不使用新绩效等级。实际英文运行输出见 teacher-report-runtime-examples.json。

## 正常自我定位：评价领域4.1–4.3均选择B1

本次三项都选择了B1描述，各项原始位置为3／6。这表示你认为当前做法符合各项B1文字；它并不能证明实际教学质量或学生的学习结果。可以选一项最近的教学任务，记录采用了什么数字评价方式、看到了哪些学习证据，以及下一次如何调整。一次只选一个小改进：例如在一节课末收集一个关键问题的回答，再依据结果决定下一节课需要补充什么。学校设备、时间和学生可及性都会影响实践，请把这些条件一并考虑。

## 困难或尚不熟悉：选择“不知晓此项能力”

0分代表你明确选择了“不知晓此项能力”，不是漏答，也不是对你的教师价值作判断。它指出一个可以开始了解的具体方向。先阅读该项的原始描述，找一位可信同事讨论一个可操作的例子；如果工具或培训不足，可以向学校说明所需支持。选择一次范围很小、符合学校数据保护要求的尝试即可。反思的目的是帮助你决定下一步，而不是要求用更多技术证明成熟。

如果选择A1或A2，应按各题具体原文理解为相应自我定位；不能把所有较早位置统一叫作能力差。是否有更充分证据、是否适合该情境，仍需实际教学材料及自主反思。

## 信息不足：有一项未回答／全空

这份领域反馈尚不完整，本次不作领域解释；已有回答保留，漏答为null，不换成0分。你可以在愿意且能够判断时补充回答，或保留未答并与可信支持者讨论哪些信息尚不清楚。单次漏答不能说明能力、态度或专业投入不足。其他完整领域可按各自限制单独查看。

## 可见条件和限制

只在既有系统授权允许时显示教师自己的个人反馈。任何用于教研的群体汇总继续遵守现有匿名、最小人数与发布规则，本包不增加授权。研究者个体输出默认关闭。本包没有学生填答版或适用的学生报告；不将教师自评改写为学生实际课堂体验。没有常模、优秀教师排名、教师等级或跨工具总分。数字代码只对应该题原始成熟度描述。
