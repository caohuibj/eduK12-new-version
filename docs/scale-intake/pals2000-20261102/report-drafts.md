# PALS2000 报告草稿：按接收者区分

本文件是编辑性候选，没有实际被试结果、阈值或已发布R版本。当前29个来源均无executable，因此没有可从真实作答生成的报告。下面“一般体验”“支持不足体验”是假设案例语境，不是量尺分段或自动触发条件。单个均值不能概括全部体验；正式实施时须按已冻结、可解释的数据和原有报告合同选用文字，不能用本文件反推评分规则。

填答者与报告接收者分别记录：学生填答不等于教师能看到学生个人结果，教师自评也不改为给学生展示。无既有授权则不展示，保留既有匿名、发布、群体最小人数和结果开放规则，绝不因新增文案扩权。手册原研究作答说明中的保密承诺，不应被直接复制到具有不同可见政策的项目。实际知情说明要准确描述当前授权与保密范围。

## 学生个人版：小学四至六年级，掌握目标/课堂学习支持

可见条件：当前学生有权看到自己的反馈，所选版本与语言适用，且该子量表达到已冻结的可解释条件。只写学生自己感受到的课堂或学习经历，不展示他人回答、教师档案或班级排名。

**一般体验的假设示例**

这次回答里，你觉得课堂有一些帮助你理解和进步的地方。想一想，最近哪次解释或练习对你有帮助？你可以保留这个办法。下次遇到不懂的内容，也可以试着说：“我弄懂了前面这一步，后面还需要一点帮助。”

这些回答说的是你这次的感受，不能用来判断老师好不好，也不是你的能力分数。

**支持不足体验的假设示例**

从这次回答看，你可能不太容易感到课堂在支持你弄懂内容。学习时需要更多解释、时间或帮助，是可以表达的需要；这不表示你不聪明，也不是你一个人要解决的问题。

你可以先记下一个具体难点。在你觉得安全、合适的时候，请老师、家长或另一位可信任的大人帮你想办法。如果某种做法让你不舒服或担心，不需要勉强自己当面争辩，可以先寻求可信任的大人的支持。

这只是一次感受记录，我们还不知道事情的全部经过。

**证据不足的假设示例**

这次还有一些信息没有填完整，暂时不能整理出这个方面的结果。你没有因此得低分。不想回答的内容可以先留空；愿意时，也可以只说说你希望得到哪一种学习帮助。我们不会把没有回答当成0分。

## 学生个人版：初高中，成绩比较/回避体验

可见条件同上，还须使用适合该学科与学段的独立版本；本批目录英文一般措辞不能冒充已验证的中学分学科中文版。

**一般体验的假设示例**

你的回答反映了你这次感受到的课堂期待。关注成绩可能与你希望做好有关，也可能带来不同的感受；单凭这份问卷，不能判断这些期待对你一定有利或不利。你可以留意：哪种反馈让你更清楚下一步怎样学？选一个与别人名次无关的小目标，可能更容易看见自己的进步。

**支持不足体验的假设示例**

这次回答里，避免出错或被比较可能占了较多注意。这描述的是你感受到的学习环境，不是说你“胆小”或能力不足，也不能据此给老师贴标签。你应当得到尊重和合适的学习支持。

如果直接提问让你担心，可以先写下问题，或找可信任的成人讨论更安全的表达方式。遇到不公平或不当对待时，责任不在你；你可以寻求支持，无需独自处理或与老师对抗。

**证据不足的假设示例**

这次结果还不足以作出解释，例如该维度有未答项目，或当前版本不适合用来说明你的这类课堂经历。暂不展示该维度分数或趋势，也不补成“普通水平”。如你希望得到帮助，可以直接描述需要，不必等到有问卷结果。

成绩回避维度高分仍代表相应回避取向/体验更强，不会为了使用鼓励语而反转成积极支持分。成绩趋近维度没有统一优劣方向。个人目标、教师目标感知、课堂目标结构是不同对象，不能把上述文字互相套用来推断学生动机或教师意图。

## 教师接收的学生评教群体汇总版

可见条件：既有权限允许该教师/人员看到该精确群体与所选维度的汇总；当前发布与群体最小人数规则满足；仅显示允许的统计字段。不附学生逐人结果、单个学生意见、原始题项回答、敏感开放回答或可重新识别的切片。没有汇总授权或人数不足时，不生成这份汇总。

**一般体验的假设示例**

这次获授权的群体反馈反映了部分学生对课堂学习目标的感受。若掌握导向的可解释结果显示学生较能感受到理解与进步受到重视，可把已有做法作为改进讨论的起点，例如保留解释思路的时间，并用日常学习反馈观察它对不同学生是否有帮助。

这是学生感知的汇总，不是教师质量评定，也不证明某种教学方式已造成学习效果。不与教师目标组、课堂结构组混合生成总分，不进行优秀教师排名。

**支持不足体验的假设示例**

如果获授权的汇总提示学生较少感到理解过程受到支持，或较多感到需要避免公开出错，可优先检查课堂安排是否让学生容易提出问题、获得进一步解释。一次只尝试一种调整，例如增加允许先思考再回答的机会，再结合不具识别性的日常反馈观察。

不据此查找或追问“是哪位学生给低分”，不向学生转嫁改进责任。群体感知可能受任务、课程阶段和其他条件影响，不能据此认定教师有不当行为或学生缺乏努力。

**证据不足的假设示例**

当前可解释信息不足，或群体结果不满足既有可见条件，因此暂不提供该维度的分数与推断。未答不当作低分；不以开放回答补足评分，不用零值、缺省百分位或猜测值画雷达图。权限或人数不足时，仅按原系统允许的状态提示处理，不泄露哪位学生参与或未参与。

## 教师自评个人版

可见条件：教师本人或既有明确授权的接收者可见其自评，所用教师子量表可解释。它不是学生评教，也不能与学生结果拼成教学能力总分。

**一般体验的假设示例**

这次自评呈现了你对教学安排或教学把握感的当前看法。可以选一个较有把握的教学片段，看看其中有哪些资源或支持值得继续保留。自我感受提供了反思起点，不能单独证明实际教学效果。

**需要支持的假设示例**

这次你可能对某些教学情境缺少把握，或希望获得更多支持。这不等于你不适合当教师。可以选一个具体情境，与熟悉课程的同事讨论可行的任务调整或支持资源；不要求独自解决班级中所有困难。成绩导向教学方式、学校成绩结构等分数也不直接判断“优秀/差劲”。

**证据不足的假设示例**

这次所需信息还不完整，暂不提供该子量表得分或个体推断。不把未答补成0，也不借用学生版、其他教师效能工具或其他学段的常模来补解释。

## 无分表单

可向有权查看者提示：“已保存你提供的背景信息。未填写的项目保持空白。这份表单没有分数或能力评价。”可按现有授权回显事实字段；不对开放补充生成情绪、满意度、教学质量或风险评分。教师个人、群体汇总和事实回显之间不存在自动披露通道。
