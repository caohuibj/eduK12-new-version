## 版本与学段

全部 native source 的 `instrumentVersion=1.0.0` 是首次目录来源身份，`catalogManifestVersion=1`；没有 executable，尚无已冻结的 C 内容、P 计分参数或 R 报告。英文 localization 元数据 v1.0.0 仅定位源语言，不表示中文题本已翻译或验证。`subscales.json` 的 C/P/R 均为 null；不能把中文目录名称或中文报告草稿当成中文版科学版本。

学生最低范围按手册“四年级起”的建议；年级不换算年龄。原手册在小学一般课堂、中学分学科措辞之间作了区分，本批仅定位定义页英文一般措辞，未新增数学/其他学科版本。中学、高中部署前要分别核定改写、适用性、许可和三轴版本，不能直接沿用一般措辞身份。表中的具体样本为该手册描述统计所用群体，不是所有学段均已独立验证。教师样本同样区分小学教师、六年级数学教师和九年级数学教师。

现有教育适用性合同的评价对象只支持学生/教师。教师目标感知及理解促进要求按既有 `TEACHER:STUDENT_REPORT` 声明；个人目标/教师自评按现有SELF声明。课堂、学校、家长与社区等对象仅用目录标签和说明定位，未硬映射成教师个人，也未新增枚举或权限。填答者以逐项记录为准。
