# 教师自评填写说明与成长反思示例

本工具只收集你对融合实践的描述和证据。A、B 都是无分 Form；以下是项目原创阅读说明，不是自动计分解释、官方评估结论或已发布报告版本。正常、困难、证据不足是示例情境，没有分数阈值，也不依据 Yes／No／Partial 自动给教师分类。

填答者及首要接收者是教师本人。任何同事、团队、评价者或学校查看个体内容，仍须现有授权和发布流程允许。原表纸面签名的接收含义不等于本系统审核批准。这里不要求披露学生身份、IEP细节或家庭敏感信息；用去标识的课堂例子即可。本工具没有学生填答或学生接收者版本，不自动开放任何既有保密结果。

## 已有一些可以保留的做法

你已经记录了部分有帮助的安排，可以从一节课的具体例子开始，看看哪些学生获得了参与和表达理解的机会。“已实施”描述的是你的自我观察，不能单独证明效果，也不需要为了看起来完整而每项都选 Yes。

可以尝试：保留一种已有帮助的支持；在下一次相似任务中收集一份去标识的学生作品或简短课堂记录，回看它是否帮助学生开始任务、表达理解或获得反馈。选择一项具体证据就够了。

## 遇到困难、尚未实施或只实施了一部分

No 或 Partial 可以帮助你找到下一步值得尝试的环节，不表示你是一位差教师。先区分可调整的课堂安排和需要资源、时间或同事协作的条件。学生需要的支持也可能随任务变化，不必把某个学生固定归为一种类型。

可以尝试：选一个优先需要，把任务要求拆成清楚的步骤，或给学生增加一种展示理解的方式；约定一个可回看的小证据。如果需要材料、翻译或专业协作，向适当同事说明具体需求，不把系统支持不足全归到个人身上。

## 目前证据不足或不愿回答

少量回答、空白或拒答都不足以判断实践是否有效。本表不会把空白变成 No、补出分数或推断你的能力。暂时不确定时可以留空；也可以先记下一个需要进一步观察的问题。

可以尝试：在下一节相关课中只观察一个可见行为，例如学生能否理解任务的第一步；之后再决定是否补充记录、是否分享。是否分享仍按你的实际授权和既有流程处理。

## 说明和行动边界

原文历史措辞 “learning styles” 不构成按固定学习风格划分学生或匹配教学的科学依据。这里的建议关注可观察的需要、无障碍支持、学生实际反应与可调整做法。Yes／No／Partial 不转换为心理分数、百分位、优秀教师排名或跨表总分。

本批没有新增官方行动计划题或拼入 Guidebook 3a/3b。A 表有关“拟采用何种实践”和“优先发展哪些方面”的原题可支持教师自主规划；上述微行动只是填写后的可选思路，不是后台已执行的分析、消息通知或人工阅卷承诺。现行完成提示只能确认实际提交事实。
