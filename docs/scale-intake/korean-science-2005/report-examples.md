# 教师成长反馈草稿：未绑定运行时

接收者和填答者均为教师。以下为项目原创中文反馈示例，不是原量表报告、不是已验证中文版；在取得完整题本和明确计分方向前，不依据数字选择“正常/困难”等分类。适用条件是教师主动描述相应情况，且有既有结果访问授权。它们不开放学生结果或敏感开放回答，不改变匿名、发布、最小人数及接收者规则。未创建学生版，因为本工具未核到原生学生版本。

## 教师描述已有稳定做法时

你已经能说出一些稳定使用的教学做法，这是继续反思的起点。自评能帮助你整理经历，但还需要课堂材料来了解这些做法如何支持学生学习。下次科学课可选一个目标，课后保留一份匿名化学生作品，再写下一处有效做法和一个待调整的问题；先持续观察这一小点。

## 教师描述遇到困难时

你提到实验组织或课堂反馈还有困难，这不等于你是一位差的教师。设备、时间和支持条件都可能影响实践。先选一个能改变的小环节，例如与同事核对下次实验的安全安排，或准备一道能了解学生想法的课末问题。需要资源或培训时，可以提出具体支持请求；个人自评不能说明困难都由个人造成。

## 证据不足或只有部分作答时

目前的信息不足以判断某个领域的情况，也不能据此排出你的强弱项。你可以补充一节近期科学课的具体经历，记录自己做了什么、学生怎样回应，再决定下一步想了解什么。暂时不想补充也可以，报告不填补答案、不生成分数或能力判断。

## 无计分表单及团队用途

若将来依法建立无计分 Form，反馈只能整理教师本人选择分享的事实、反思与行动，不生成量表分、优秀等级或诊断。团队接收者只能在既有授权允许的范围看到汇总材料，不能默认看到教师个人回答。若以后建立原生计分版本，应保留原量表方向，明确自评和外部实践证据的区别；不因鼓励语气修改分值。
