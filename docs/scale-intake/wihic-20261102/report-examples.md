# WIHIC 报告示例：填答者与接收者分开

以下均为合成示例，正常/低体验是演示情境名称，不是运行时分档或新阈值。原生R1.0.0目前提供英文学生报告；这里中文文本供审阅，未声称已作为可选中文R装载。真实生成结果在 [report-runtime-examples.json](report-runtime-examples.json)。

## 学生本人：初中，教师支持维度

可见条件：学生本人是合法结果接收者，且既有发布和反馈设置允许个人反馈。填过问卷不自动开放保密结果。报告说的是你感受到的课堂经历，不评价教师能力或学生品质。

**正常完整示例：8题均选Often，均分4/5。**

你在这份问卷中表示，自己常常感受到老师的关心和帮助。可以回想一下，哪一种帮助最能让你看清学习任务？下次需要时，可以提出一个具体问题，例如“这一步我还不明白，可以换一种方式说明吗？”这份结果只记录你对这门课的体验，不代表每一次学习都很顺利，也不能用来给老师排优劣。

**低体验完整示例：8题均选Almost Never，均分1/5。**

你在这次回答中表示，很少感受到这些关心和帮助。你的感受值得被认真听见；这不说明你能力差，也不意味着要由你独自改变课堂。如果你愿意，可以先想清楚一件具体需要，比如“我需要更明确地知道哪里做对了、下一步怎么改”。选择让你感到安全的方式，向可信的家长、班主任或其他成人说明，请他们一起想办法。无需为了问卷分数与老师对抗，遇到不公平也不是你的责任。

**证据不足示例：漏1题，仅7/8，分数null、解释为空。**

这部分还没有足够完整的回答，所以暂不计算分数，也不猜测你的经历。你可以按原活动允许的方式补充回答；即使不补答，也可以向可信成人表达学习需要。没有结果不表示你的体验不重要。

实际英文R采用相同的温和解释和条件性行动建议，不用“优秀教师”“问题学生”“你不够努力”等标签。真实缺题输出不含个体解释/分档/常模；这里缺题文字是安全的完成提示示例，未伪造测量结论。

## 教师：已有授权的群体汇总，仅教学改进

可见条件：既有系统已允许这组数据用于匿名群体汇总，满足原有发布、受众权限及最小人数等规则，且消费者确实支持该统计。以下20人仅是合成演示规模，**不是新设最小人数**。本包teacher披露策略不开放学生个人结果。无个体题分、学生身份或可识别开放回答；不从学生个体报告直接复制。教师模板为文稿准备，未装载新R或运行时汇总引擎。

**正常完整汇总示例：20份完整答卷，10份均分4、10份均分5；本维度群体均分4.50/5。**

这组学生总体较常感受到教师支持。可以保留学生认为有帮助的做法，再在合适的课堂反馈渠道确认：哪些说明、提问机会或帮助最有用？均分不能代表每名学生都获得同样体验，也不能据此认定教师优秀。可尝试在下一单元明确一个求助渠道，并给不同表达方式留出空间。

**低体验完整汇总示例：20份完整答卷，10份均分1、10份均分2；本维度群体均分1.50/5。**

这组反馈提示，学生报告的教师关心与帮助相对少。这是了解课堂支持条件的线索，不是教师能力或意图的判定。可先检查学生是否知道何时、以何种方式求助，以及困难是否能得到具体回应。选择一项小调整，例如固定一个安全的提问渠道，再通过相同、合规的群体反馈了解变化；不要追问“是谁给了低分”或要求学生为课堂问题负责。

**证据不足示例：汇总披露条件不满足，或该维度没有可用完整答卷。**

本次不展示该维度的群体数值或个体意见。当前资料不足以形成可靠且符合披露规则的结论，不解释为学生满意或不满意，也不用0代替缺失。可说明本轮未形成可用汇总，并依原有流程安排自愿、安全的课堂反馈；不因缺数据放宽匿名或最小人数规则。

## 无分情形
