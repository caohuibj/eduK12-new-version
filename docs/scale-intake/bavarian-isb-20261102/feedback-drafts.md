# 教师和学生反馈语言准备稿

本批没有完整题本或可运行内容，以下均为项目原创示例，不是原工具的题项、计分解释、自动报告或已安装报告版本。“已有支持／困难／信息不足”是情境，不是计算阈值。取得完整题本、权利范围并确定真实受众后，才考虑纳入既有发布流程；不从自查结果诊断能力或评价教师好坏。

## 教师自评：教师本人可见条件

仅在既有授权及发布规则允许时，向自评教师本人展示其自己的描述。学校、评价者或同事不因同一母工具或本稿获得个人结果权限。后续学生视角只在原有匿名、最小人数、授权汇总条件满足时提供；不能直接披露学生个体意见或敏感开放答案。观察者记录仍是另一来源，不自动合并为“真实教学质量”。

已有一些可保留做法：你记录了自己对课堂支持的看法。可从一次具体任务回看：哪些学生能够开始行动、说明自己的想法，哪些地方仍需支持？保留一种已有帮助的安排，并用一份去标识的任务作品或课堂记录检查它是否适合这次需要。自评与另一视角一致，也不能单独证明教学效果。

遇到困难：某些安排暂未形成，可能与任务、时间和可用资源有关。选一个可调整的小环节，例如在任务开始前说清第一步，或在练习后留一次使用反馈修改的机会。需要专业协作、材料或时间支持时，把具体需求提出来；不把支持条件的不足全归到个人身上。

信息不足：目前没有足够、匹配版本的证据进行解释。可以先记下一个近期课堂例子，不用为了完整而猜测。师生题目并非全部一一对应，不能把两个来源的不同回答直接当成谁不真实或教师的缺陷；也不据漏答补出均分、排名或总差分。

## 学生接收者：适龄文案示例

原学生附件尚未取得，具体适用年龄未核定。下面分学段语言只是项目编辑示例，**不表示该工具已被验证适用于这些学段，不可直接启用学生报告**。未来只有既有权限和发布规则允许时才给学生自己的适龄反馈；不会因本稿公开教师个人自评，也不把匿名原始意见转发给教师。

3–5年级表达示例：

- 已感到一些支持：“你说有些课堂安排能帮助你学习。下次可以试着说清楚，哪一步对你最有帮助。”
- 感到困难：“有些时候，你可能还不清楚该怎么做。这不说明你学不好。你可以问‘能给我看一个例子吗？’如果遇到让你不舒服或不公平的事，可以找信任的大人帮忙。”
- 信息不足：“现在的回答还不够了解你的经历。不确定时可以先不选；想说的时候，可以讲一件最近发生的小事。”

6–12年级表达示例：

- 已感到一些支持：“你描述的是自己感受到的课堂学习经历。选一种有帮助的安排，在下一次任务中观察它怎样帮助你理解、练习或表达想法。”
- 感到困难：“支持不够或任务不清楚不等于你的能力差。你可以提出一个具体需要，例如‘我卡在这一步，能再示范一下吗？’若涉及不公平或不当对待，可以向可信成人寻求支持，不需要独自处理或与教师对抗。”
- 信息不足：“少量或缺失的回答不足以判断你的体验。可以先保留不确定；如果愿意，再用一个具体任务说明什么帮助了你、什么仍然困难。”

这些建议不改变原题方向、不鼓励学生承担不公平对待的责任，也不把低体验标成学生能力不足。没有完整题表就没有分数，更没有由无分 Form 强造的心理报告。不同语言、角色和版本的比较必须保留各自证据限制，没有跨专题总分。
