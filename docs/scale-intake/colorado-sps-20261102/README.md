## 计分与报告边界

官方学生响应从 Never、Some of the time、Most of the time 到 Always 按 1–4 同向编码，最终题组不含已删除的负向行为题，不得把它加回或做反向。教师层可描述均值 1–4 或顶端两档比例 0–100%；比例表示观察到的响应占比，不是“教师能力百分制”。原技术报告的 IRT 研究分析不等于平台已实现 IRT；本批不新增 scorer。

完整观测下，每维题目值相加的数学范围是 n–4n（15题为15–60，10题为10–40，7题为7–28，5题为5–20，8题为8–32，4题为4–16）。这些只作边界核对，不默认安装维度总和或跨维总分。官方研究中的整体分数也不要求本平台新增总分；普通组合不生成跨工具总分。

原施测允许跳题；技术报告未在本次核到足够明确的最终维度级最低完成项数、插补与不同作答人数的加权细则。未来须确认分母、缺失显示与计分契约；**缺失不补零，不把未答当 Never，不自行宣称“半数有效”是官方规则**。无完整可用证据时只给证据不足说明。历史教师研究分析用至少 8 名学生，向教师出具报告采用至少 10 名；这是研究/历史施测背景，不是本 PR 新增的平台权限或人数规则。实际汇总继续沿现有授权、匿名、发布与最小人数机制；不满足既有条件不展示。

项目原创、按接收者分开的报告文字及正常/低体验/证据不足示例见 [report-examples.md](report-examples.md)。它们是文案草案，不是已装载的 R 版本或实际用户报告。保持原分向；不得为积极鼓励改分、给教师优劣排名、把低体验解释成学生能力低，或把原始学生意见、敏感开放文本随汇总披露。表单只回显获准查看的选择/文字及不计分说明。

学生问卷与教师反思由不同填答者完成，不拼成一个人必须完成的单次问卷。学生版前置教师/课堂核对和自愿参与说明属于原施测事实，不计入34题，不从目录记录猜造；实际内容须在授权范围内导入。未建立 Bundle 或组合执行实例。
