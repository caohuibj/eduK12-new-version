# Colorado SPS 接收者文案草案

文案草案版本 1.0.0，仅供审阅。没有正式 C/P/R，没有分段阈值、自动分类、实际报告或新权限；“正常”“低体验”“证据不足”是三种编辑情境，不是本批实现的评分等级。这些中文文字解释英文来源所测的体验，不是题目翻译或已验证中文版。最终 R 应复用 scale-result.ts、已有 report / educationalFeedback 与 projection 的受众契约；无计分内容走现有 reporting/typed-form-presentation.ts。不得为了文案新增 scorer、公开授权或结果入口。

## 可见条件

- 学生填写评教，评价对象是教师/课堂。学生个人体验反馈仅在既有接收者授权允许、发布时点满足、且该反馈可在现有匿名设计中合法投影时显示给该学生。匿名设计无法向本人安全返回结果时，不创建身份映射，只可显示获授权的非个性化完成提示。不能为本草案收集身份或扩大成绩/结果可见性。
- 教师群体反馈仅接收其获授权、符合当前最小人数/发布/匿名保护的汇总结果；不给学生个体分数、逐人答案、身份或未经另行授权处理的敏感开放回答。人数不足时先执行既有隐藏策略，不能拿“证据不足”模板绕过隐藏。历史材料中的10人报告条件不自动更改平台配置。
- 教师自评和反思表单仅对现有权限允许的本人/明确授权接收者显示事实性内容；不从学生参与许可推导教师或家长可以读学生报告。

当前11个 CATALOG_ONLY 候选都没有可执行报告；下面是未来权限及完整测量条件成立后可采用的原创示例。较低频率不意味着学生能力差，也不直接证明教师好坏。四维不同题目难度使最低项不一定等于“最差教学”；未经核定的比较组不可写为常模。

## 3–5 年级学生

正常体验示例：“从你这次分享的感受看，课堂里有一些帮助你学习的做法。谢谢你认真说出自己的想法。你可以选一件最有帮助的事，记住它为什么有用。下次遇到难题时，如果你愿意，也可以问一句：‘能再举一个例子吗？’这次反馈说的是你的课堂经历，不是给你的能力打分。”

低体验示例：“你提到，有些时候课堂里的帮助没有满足你的需要。这样的感受值得被认真听见，也不表示你学不好。你可以把最不明白的一步圈出来，请可信的大人帮你想办法；如果你觉得安全，也可以说：‘我卡在这一步，能换一种方法讲吗？’如果你感到被不公平对待或不安全，可以找你信任的家长、学校支持人员或其他可信的大人。解决不当对待是大人的责任，你不需要一个人处理。”

证据不足示例：“谢谢你分享愿意说的部分。现在的信息还不足以说明你整体的课堂感受，所以这里不作高低判断。你可以保留不想回答的问题。如果你有需要，也可以直接向可信的大人说一件希望得到帮助的事。”

## 6–12 年级学生

正常体验示例：“你这次描述了若干有助于理解、参与或安心学习的课堂经历。这反映的是你在指定课堂中的感受，不能代表每位同学。可以选一种有效的支持，在接下来的学习中继续使用；也可以在安全、自愿的情况下具体说明：哪一种讲解或反馈最能帮助你。”

低体验示例：“你描述的部分课堂体验，似乎还没有充分回应你的学习需要。反馈值得认真对待，不能据此判断你的能力或给教师贴好坏标签。你可以选一个具体困难，写成‘情境—我需要的帮助’，在觉得安全时向合适的支持者表达；也可以请求另一种讲解或反馈方式。若涉及羞辱、不公平对待或安全问题，可向可信成人或学校已有支持渠道求助，不需要与教师对抗，也不应由你承担改变不当对待的责任。”

证据不足示例：“现有回答不足以支持完整的体验分析，暂不生成维度高低结论。缺失回答不会当作负面回答。你可以保留跳过问题的选择，也可以通过你觉得安全的渠道表达具体学习需要。一次反馈不能替代对课堂情境的持续了解。”

## 教师接收的学生群体汇总

正常体验示例：“在本次获准展示的汇总中，部分课堂支持获得了较多积极体验反馈。请结合已发布的作答人数、响应分布和教学情境理解；这些比例描述响应，并非教师能力百分制或优秀教师排名。可选择一个已有做法，在后续教学中保持，并用其他获授权的教学证据观察变化。”

低体验示例：“汇总中的部分回应提示，一些学生的学习或课堂支持需要尚未被充分满足。这是进一步了解情境的线索，不能直接归因于教师能力、学生动机或某位学生。可先从一个具体做法着手，例如提供另一种解释、明确求助方式或检查反馈是否可理解，再在适当时点观察群体体验是否变化。不要寻找作出负面回应的学生或要求其自证；涉及不公平或不当对待的信息，应按已有支持和处理程序负责回应。”

证据不足示例：“当前可用证据不足以形成稳妥的群体解释。本报告不输出维度高低、常模位置或教学优劣结论。请先核对允许展示的作答覆盖、缺失情况及施测情境；不通过辨认学生或查看受保护的原始回答来补足证据。若现有发布/人数规则要求隐藏，系统应隐藏结果，本句也不能成为披露受保护汇总的理由。”

## 教师自评与反思：无分情形

教师自评：“这份表单保存你对课堂实践的自我描述，没有计算总分、等级或与学生的标准化差值。你可以挑一个具体做法，结合你有权查看的群体汇总或观察记录，想一想：自己的预期与学生体验有哪些相合或不同。差异是反思线索，不是证明哪一方正确。”

反思指南：“你记录的想法将作为下一步教学反思的材料。本表单不计分，也不会根据文字自动评价教师或学生。你可以保留暂时没有答案的部分，在已有授权和支持条件下继续讨论。”

表单未答：“你可以留空不愿填写的内容；空白不会被计为低分。这里没有需要补齐才能获得的评分类别。”

## 文案核对范围

正常体验不夸大为教师优秀或学生高能力；低体验不反向计分、不责备学生、不要求对抗；证据不足不编分、不补零、不推导常模；Form 没有数值报告。上述各情境均区分学生/教师受众和查看条件。候选状态、目录不可启动与原生 materialize 拒绝在 evidence.json 单列；本批没有可运行的报告内容，故不声称完成真实用户报告/权限端到端验证。取得授权并建立原生 C/P/R 后再对实际 scorer、report projector、无分表单路径作所需最小验证。
