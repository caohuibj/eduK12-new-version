## 原论文与已核边界

김지선、김혁동、이원재、이동배（2014），《교사전문성을 위한 자기평가 준거 개발 연구》，한국교원교육연구31(4)，167–196，DOI [10.24211/tjkte.2014.31.4.167](https://doi.org/10.24211/tjkte.2014.31.4.167)。[KCI原始记录](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART001939079)的韩英摘要确认小学版50题/5领域、中学版51题/6领域，分别研究1438、1727名教师；题表和心理测量结果正文尚未读到，不将摘要的验证结论当作已独立复核。

本研究是专业发展自评准则开发，未核实为韩国政府颁布的全国统一标准。项目简称“韩国TPD2014”仅方便识别，不是作者正式量表简称。覆盖教师较宽的职业活动，不能当作单课教学质量或教师品格等级。

[扩展研究报告B06/R19](https://docs.google.com/document/d/18JsjVIUbKNmNYOljL6FHzgzmFvP7keRPMLmMzeIK5y0/edit)也明确原题未取得；它只作为研究线索，不替代原论文。
