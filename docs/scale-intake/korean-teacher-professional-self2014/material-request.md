# 具体缺件清单

目标原文：김지선、김혁동、이원재、이동배（2014），《교사전문성을 위한 자기평가 준거 개발 연구》，한국교원교육연구31(4):167–196；DOI10.24211/tjkte.2014.31.4.167，KCI ART001939079。

需要合法取得论文正文及问卷附表，或作者/学会提供的同一最终版题本。必须能区分探索/预试删题前版本与最终版，不能仅凭文章摘要或别处改编版补题。

1. 小学最终50题和中学最终51题逐字韩文，含原题号、题序、指导语及任何共同题干；各领域逐题归属与题数。
2. 两版原响应选项和锚点、数值映射、是否反向、维度聚合和任何作者明确支持的总体结果。不要预设五级或直接求和。
3. 漏答/拒答/不适用的原处理；若作者未规定，需明确记录原文未规定，再提出可审阅的保守项目政策，不伪称原规则。
4. 精确韩文版本和数字拆分的使用条件；是否可独立施测子量表、是否有施测时段限制。缺独立短表验证不自动否决有依据的计分，但应保留原组卷与解释限制。
5. 适用的题表电子化、展示、翻译/改编、自动计分、平台使用、再分发和商业/非商业范围证明。购买论文或机构阅读权限不自动包含这些权利；作者/学会署名及第三方材料另行保留。

收到合法原题及响应、无官方评分：推进原生无分Form，不加numeric option score或伪造数值报告。收到原计分：推进原生Scale。仍缺原题：保持本档案“缺题本”，不生成可施测占位工具。

本轮没有联系作者/学会、付费、登录机构、开订阅、接受许可或绕过拦截。管理员可通过已有合法获取渠道补充材料；后续审核本身不是使用授权。
