# 教师成长反馈示例（项目原创草稿）

接收者为完成自评的教师本人，且既有资源授权和该报告版本允许查看；当前仅合成投影契约检查，没有开放任何真实用户结果。组织接收者仅在已有授权、匿名及最小人数规则允许时看群体汇总，不披露教师个体或敏感回答。未建立学生版、学生填答或跨角色等值主张。下面三种情形是说明样例，没有数值阈值或绩效分档，不能由1–7分机械诊断。

一般体验：你的回答呈现了一些重视学生差异、尝试灵活组织学习或利用反馈的想法与做法。它们是你对当前经验的描述，不能单凭自评证明教学效果。可以选择下一节课的一个学习目标，收集两三份学生作品，比较学生需要，再尝试一项小调整，并记录实际变化。

困难体验：如果你感觉统一进度、教材或评价要求限制了调整，这反映了你感受到的工作条件，不能解释为缺乏师德或教学能力。先选一项可控的小行动：在同一目标下提供两种支持方式，或请同事一起看一份学生作品。需要制度支持时，可以向教研组说明具体情境和所需资源；不把结构性约束全归责给教师。

信息不足：本次回答缺失或暂时难以对应某个实际课堂，因此不生成该维度的均值，也不把空白当作否定。可以选择最近一个清楚记得的教学片段补充反思；不确定时保留“不确定”也有价值。该工具没有据此诊断教师或学生的能力。

维度解释：成长思维描述信念，不是学生潜能的定论；课程自主感描述感受到的课程约束，不是师德评级；灵活分组是同意程度，不直接证明实际频率；评价反馈循环是自述频率，不能替代作品和课堂观察。EC/FG/OI当前项目描述性均值并非已核作者标准算法，实际报告发布前需确认。

无分适应性教学表单：本次只保存你选择的描述，不计算“适应性教学分”。你可以挑选一项做法，结合学生作品思考何时有帮助、何时需要调整。若没有填写，只提示已完成/有缺项，不推断表现；不依据固定学习风格给学生分组或贴标签。

这些建议不改变题项方向，不创造常模、不排名；不因报告新增而扩大既有查看权限。投影示例的授权输入是合成契约，不是HTTP权限或匿名汇总端到端验证。
