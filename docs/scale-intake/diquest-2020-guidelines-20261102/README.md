本批取得并完整阅读作者上传的七页研究指南；Table 1 共31题，p6题表图像也已核对。公开文件为四个 **CATALOG_ONLY** 目录条目、第五项表单元数据及脱敏验证说明，不能直接施测。未向公共库、生产库安装工具。完整研究配置仅保留在私有工作区。

来源：[2020作者指南](https://www.researchgate.net/profile/Katrien_Struyven/publication/342355130_DI-QUEST_guidelines_for_researchers/links/5ef08f5d299bf1faac6ca5c5/DI-QUEST-guidelines-for-researchers.pdf)，Struyven、Gheyssens、Griful-Freixenet、Coubergs，DOI 10.13140/RG.2.2.16110.43848；其补充的[2017原论文](https://doi.org/10.1016/j.stueduc.2017.02.004)作者为 Coubergs、Struyven、Vanthournout、Engels。原论文出版社返回403，VUB只有书目元数据；未绕过访问限制。2020指南英文不能冒充2017英文验证版。2023中国大陆五点、删至27题的版本另有身份，未混入。

Scale统一ID为 `diquest2020_{gm,ec,fg,oi}_teacher_self_en`；Form为 `diquest2020_at_teacher_self_en_form`。名称为“DI-Quest｜子项｜教师自评｜2020作者指南英文”。GM/EC/FG用原七点同意选项；OI/AT用原七点频率选项，两者不得混称。

反向转换为8减原答值。四个私有Scale均以1–7描述性均值表示；**仅GM的均值公式在已读指南中明确，EC/FG/OI等权均值是项目研究摘要，并非已核2017原算法、因子分或结构方程模型**。不得将该研究摘要作为原标准分发布。完整作答才计算是项目保守缺失规则，非作者缺失阈值；不把缺失当零，无常模、分档或总分。AT没有得分、反向转换或分数报告。背景题只有主题列表，缺确切题干和选项，未凭空创建表单。

共同tag `family:diquest`，另含角色、语言、2020指南版本、2017来源研究、用途和PILOT/权利待确认标签。复用现有tags和目录constructOverlapTags。隔离库Scale通过现有tags列写入；Form模板没有自由tags列，共同tag由其普通组合问卷的现有Questionnaire.tags承载，未虚构Form标签能力。共同tag用于筛选并列分析，不证明等值或跨量表求和。

已实际做原生Scale materializer导入、四份axis snapshot、原生Form定义/答案规范化和草稿持久化，以及普通Questionnaire的四量表链接和八个无分字段。全部DRAFT/HIDDEN，未建发布策略或材料授权。详见receipt和verification。问卷只是可选既有普通组合；独立拆用有效性没有因数据库拆分而自动确立，研究应保留原组卷背景并说明子项解释范围。
