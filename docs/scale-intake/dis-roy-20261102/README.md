## 反应和计分边界

手稿125名Québec小学1–6年级教师，参照法语和数学课；5级频率端点为1从不、5非常频繁，中间标签未核。Table 2/3两表题序不同，未来唯一ID必须带来源表和行号并经题文比对，不能直接以同号联结。初始20项加焦点小组5项为开发池，不是最终25题，也不能抽两题拼成14题。

较高反应仅表示更频繁自报该类实践，不能等同质量、能力、实施适切性或学生效果。未确认个体均值/总和、反向键、最小有效题数与缺失规则，故没有计分实现、反向处理或理论分数范围。论文的研究级FIML估计不是个人缺失补分规则；论文样本相对均值划分常用/少用实践不是教师分档常模。两个相关因素不能任意压成总体质量分。
