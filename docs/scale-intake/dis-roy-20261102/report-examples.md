# DIS 教师成长反馈草稿

状态：原创中文文案草稿，不是验证中文版，不是运行报告模板，无实际得分或自动阈值。填答者和接收者均为教师本人。仅在既有结果授权下呈现；给教研负责人只能沿既有群体汇总、匿名和最小人数规则，不披露个体意见或敏感材料。未改变权限或发布规则。

以下三种状态由实际证据决定，不用捏造分数界线或常模；IA与APM分别叙述，不合成质量总分。

**一般实践证据较充分。** 你的记录显示，你在部分课堂中尝试调整任务，并关注学生后续进展。这是关于你所报告经历的线索，不能单独证明哪种调整最有效。可选最近的一次作业调整，保留一份调整前后的匿名学习样本；下周检查学生是否更接近同一个明确学习目标，再决定保留还是修改。

**实施有困难。** 你在一些实践上记录的使用机会较少，可能与课程要求、时间、资源或学生需要有关。这不等于你缺乏教学能力，也不要求你在每节课使用所有方法。先选一个近期确有学习需要的任务，只改一个可操作环节；用一次简短的形成性检查了解变化，并与可信同事讨论需要的资源。学生不应被固定能力标签限制机会。

**证据不足或未答。** 这次材料不足以说明你的实践频率和效果，留空也不按零分处理。你可以补充一个具体课堂情境和一条可观察证据；若没有实施机会，直接说明条件。此时不输出优劣结论、能力标签或与他人的排名。

无分Form将来只回顾原始回应、教学情境和自选行动，不产生分数报告。原版的频率方向不会为了鼓励而反转；频繁也不是一律更好。学习风格匹配、多元智能分类不作为科学指导添加到报告中。

本工具教师自评没有取得原生学生对应版，不制造学生问卷或把上述教师文字套给学生。若将来取得学生版，须另定角色、语言、版本和适龄接收者文案。
