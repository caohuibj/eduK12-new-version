# SEP-Klassik：接收者区分与无分成长反馈草稿

本批16份都是教师填答的无分 Form，运行时没有计分参数或报告。以下是项目原创阅读说明和未来呈现样例，不是自动分析、官方报告、分数阈值或已安装R版本。“已有支持／困难／信息不足”是情境，不是给教师或学生划档。不能把来源中的动机名称当作人群标签，也不为鼓励而更改原题或选项方向。

## 教师本人：自报与感知的解释边界

教师只在既有授权和发布规则允许时查看自己的自报内容。数学题有课堂机会也有期待性表达；媒介题是对具体实践的看法；SINUS是教师对学生当节课动机的感知。三者都不能直接等同真实教学质量、教师能力或学生稳定特质。其他教师、评价者、学校或学生不会因同母工具tag自动获得这些个体内容。

已有一些可保留做法：从一个具体的数学任务或媒介学习活动中，挑出你认为已有帮助的安排。下次保留这一安排，并回看一份去标识的学生作品：学生能否解释思路、检索来源或修改作品？自报认同并不单独证明效果，回答“应该”也不等于实践已经发生。

遇到困难：某些实践暂时较少或难以判断，不表示你是一位差教师。可以选一个小环节：让学生解释一次“为什么这样算”，或在媒介任务中示范怎样核对一条信息来源。若需要时间、设备或专业协作，说明具体支持需求；媒介使用的多少本身没有质量高低含义。

信息不足：空答、拒答、不能判断各自保留原始含义，没有补成零分或推断能力。你可以先记录一个清楚的课堂例子，后续再决定是否补充。SINUS教师判断可能看不到学生内在原因，且PDF方向说明与正向题文需澄清，因此不能据此推断谁“缺乏动机”、作教师排名或计算师生差距总分。

若以后取得学生对应内容，只能在原有匿名、最小人数和授权群体汇总规则满足时给教师相应反馈；学生个体意见与敏感开放回答不得直接披露。本稿没有更改任何此类权限，也不承诺后台人工阅卷、提醒通知或未实际执行的分析。

## 学生语言样例：尚未启用的独立接收者文案

本轮没有导入或发布学生版，下面只为后续原生学生来源的适龄呈现准备，不把教师对学生的动机判断发给学生。未来是否可见仍由各自内容版本、实际受众和既有接收者授权决定；教师自评保密结果不会因此开放。

数学3–5年级表达：

- 已感到支持：“你说有些数学活动能帮你明白怎么做。下次可以试着说出一步思路，或画一张小图，看看哪种办法帮到了你。”
- 感到困难：“没听明白或还不会解释，不说明你学不好。可以问‘能再给我看一个例子吗？’如果遇到让你不舒服或不公平的事，可以找信任的大人帮忙。”
- 信息不足：“现在还没有足够的回答了解你的经历。不确定时可以先不选；想说的时候，讲一件最近数学课上的小事就好。”

数学6年级／相应中学语言表达：

- 已感到支持：“你记录的是自己感受到的学习经历。可以留意哪种任务安排帮助你说明理由、比较方法或修改答案，并保留一个具体例子。”
- 感到困难：“支持不足或任务不清楚不等于能力差。你可以提出一个具体需要，例如‘我不清楚这一步为什么成立，能再示范一次吗？’若涉及不公平或不当对待，向可信成人寻求支持，不需要独自解决或与教师对抗。”
- 信息不足：“少量、不能判断或缺失的回答不足以说明你的整体体验。可以先保留不确定，再用一个具体任务说明什么帮助了你、什么仍然困难。”

媒介教育 Sek I／D 后续若启用学生版，可让学生选择一次真实的信息检索或作品呈现经历，尝试核对一条来源或说明一次修改需要。不能把设备数量、屏幕时间或教师对动机的归因当成学生能力标签。任何未满足受众与权限条件的结果都不因这些文案变为可见。
