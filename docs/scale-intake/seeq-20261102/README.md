## 报告接收者及待审文案

下列是未来取得合法题本、确认计分及适用性后供审阅的**中文文案示例**，不是已部署报告模板或真实结果，也不代表中文版量表。实际题本仍为英语；英文报告另需审校。正常/低体验示例以可解释结果确实支持该描述为前提，无常模分界。填答者是高校学生，不能仅凭填答关系推导其可看所有结果。既有报告版本、接收者授权、匿名、发布、最小人数、缺失与保密规则不变。

学生版可见条件：现有权限允许学生查看自己的反馈且结果可解释；不显示其他同学回答、教师私有群体报告或未发布信息。语气按高校学生写，不评定教师好坏，不以体验分解释学生能力。下面以“群体互动”示例：

| 状态 | 学生版示例 |
|---|---|
| 正常体验、有足够证据 | 你这次的回答显示，你在这门课中感受到了表达想法和提问的机会。可以留意哪种参与方式最有帮助。下次试着准备一个具体问题，或课后记下一点讨论带来的新理解。 |
| 较低体验、有足够证据 | 你的回答显示，你目前感受到的提问或表达机会可能不够。这种经历不说明你的能力不足。可以先写下一个具体困惑，通过你觉得安全的渠道表达需要；如果担心被不公平对待，可向可信任的导师、学业支持人员或学校支持渠道求助。你不需要独自承担改善课堂的责任。 |
| 证据不足/大量不适用 | 目前的有效信息不足，暂时不能形成可靠的体验解释。课程未安排某类活动时，选择不适用是有意义的。你无需为了得到结果勉强作答；如愿意，可以为自己记录一个希望获得支持的具体学习情境。 |

教师版可见条件：现有授权允许的、已发布且达到既有最小人数和匿名规则的群体汇总；不得直接把学生个人结果或敏感开放回答披露给教师。群体不足时不输出可识别的个人例证，不借此重新查询或放宽门槛。

| 状态 | 教师版示例 |
|---|---|
| 正常体验、有足够群体证据 | 本次可用汇总显示，学生整体感受到了一定的讨论与提问空间。可结合课程形式保留有效的提问安排，并在后续课程中检查不同参与方式是否都便于学生使用。这反映当前学生体验，不是教学能力认证。 |
| 较低体验、有足够群体证据 | 本次可用汇总提示，部分学生感到表达与提问的机会不足。可尝试提供课前问题收集、短时同伴讨论或课后答疑渠道，并在后续已授权反馈中观察变化。不能据此归因于学生积极性，也不能将结果用于教师排名。 |
| 证据不足/未满足披露条件 | 当前证据或授权条件不足，暂不呈现群体解释及个体示例。可检查本维度与课程活动是否相关；按已有规则安排后续反馈，不通过追踪个人回答补齐结果。 |

其他维度的学生微行动计划：学习价值→选择一个概念试着应用并记录困惑；教学热情→记录有助于自己投入的讲解方式；组织→对照课程目标整理一个待澄清问题；师生融洽→使用自己感到安全的答疑渠道；内容广度→选一个观点找补充背景；考试评分→请求说明一条评分标准或反馈；阅读作业→联系一个作业与课程目标。每份实际反馈最多选1–3条，避免把不公平或不当对待的责任交给学生，不要求对抗教师。维度方向和分数不为文案改变。

无分表单可在现有权限下显示“已记录你的回答；本部分不生成分数或能力评价”。工作量各题分别保留单位和语境，确有完整授权选项后才启用；总体评价三题分别保存，不产出总分报告。当前候选没有表单内容，连逐题反馈也未启用。
