## 计分准备与真实缺项

[scoring-preparation.json](scoring-preparation.json) 是静态审阅材料，运行器不消费它。

- 八维各描述该类行为出现的程度，方向为 higher_is_more；高分不是更好、更优秀。不把不满、对抗等反向变成“优质教师分”，不制造40题总分。原文未规定项目反向题，当前转录不加反向键。
- p4只说5点Likert，Never—Always。论文没有完整原中文指导语、五个精确中文选项、中间标签与数值编码。不能把自行拟定的“从不/偶尔/有时/经常/总是”称为原版锚点。也不能仅凭表2均值猜编码为0–1、0–4或1–5；当前范围为null、没有可执行分值。
- 八维均分可作为待审计分提案，但必须由完整计分协议确认。缺失算法原文未载：本项目仅提议每维完整才计分（complete_required），少一题即该维不可计分；不补0、不插补、不按比例折算。派生指标提议八维均完整才计算。此规则尚未激活，不伪称作者规则。
- Agency/Communion是同一40题八维的圆环线性组合，不是两套题库、额外独立短表或40题总分。a=0.923880、b=0.382683；Agency权重 `[a,b,-b,-a,-a,-b,b,a]`，Communion权重 `[b,a,a,b,-b,-a,-a,-b]`。作用于八个尺度分，不能直接让7题维度比4题维度权重大。
- 表2脚注称维度均分缩放至−1…1，并列上述权重，却未展开数值编码和缩放步骤。若假设八维0…1，未缩放组合数学范围是±2(a+b)=±2.613126；这与所称−1…1不同。按表2展示的八维均值重建约0.80864349/1.31240658，除4恰近表中0.20/0.33，但四舍五入数据的吻合不是正式缩放规则。也不擅自选择除2(a+b)的替代实现。待核官方计分材料后再冻结P与派生范围。
- 原样本均值、SD和相关不是常模或阈值；不造百分位、优秀等级、学校/教师排名、跨来源总分。顺从维度原文特别提示较低信度与表述问题，不静默修题后沿用原效度。
