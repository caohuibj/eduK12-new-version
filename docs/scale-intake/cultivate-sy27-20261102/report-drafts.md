# Cultivate SY27：按接收者编写的待审文案

这些是未来文案设计示例，不是施测结果、评分解释或已发布的R版本。当前9个目录候选和14个表单资料候选均不产生分数报告。许可、计分和独立施测证据不足时不生成量化结果，不把示例里的情境写成学生真的回答过。

## 可见条件与语言

学生填答者与报告接收者分别判断。原版承诺保密，并将学生响应合并；学生不能因填答自动查看个人评分，教师不能因此读取学生个体意见。未来若经明确授权提供学生反馈，沿现有报告接收者授权和发布能力，只展示该授权允许的内容。不能把以下草稿变成公开个体反馈的默认依据。

教师版仅用于已经授权的群体汇总与课堂改进，遵守既有匿名、最小人数、发布与保密规则。原版学校层面50%响应率和10响应不自动赋予任意子组披露资格。学生个体条目和敏感开放回答不混入教师报告。报告接收者、数据范围、C/P/R版本必须由现流程确定，不新增权限或报告引擎。

5–6年级用短句和具体场景；7–9年级可加入表达学习需要的示例；10–12年级尊重自主选择，解释样本和比较限制。所有学段不诊断学生、不把教师贴成优秀/差劲，不将低体验解释为能力差，不让学生为不公平或不当对待负责。鼓励只改变表达，不修改原分、反转方向或隐藏不好的经历。

## 学生接收者：三个状态示例

以下“正常/低体验”是未来**合法可见描述数据足够**时的情境，不是虚构阈值。

### 正常体验（5–6年级用语）

你这次说起的这门课里，有一些安排让你学习起来比较安心。这些感受能帮助大家了解课堂，也可能随着不同的课和不同的时间而变化。这不是能力测验，不会评出你是不是“好学生”。

如果你愿意，下次可以选一个帮到你的地方，告诉老师哪里有用，例如哪一种解释让你更容易明白。还有不清楚的地方，也可以问：“这一步可以再举个例子吗？”你可以自己选择是否分享。

### 低体验（5–6年级用语）

你提到有些课堂经历让你不太舒服，或让学习变得吃力。这样的感受值得被认真听见。这不说明你不聪明，也不需要你一个人把课堂里的问题解决好。

你可以选一个小办法：把想问的问题先写下来；在觉得安全、合适的时候，请老师再说明一步。如果你担心开口，或遇到不公平、不当对待，可以找一位你信任的家长、老师或学校支持人员一起想办法。你不需要独自面对，也不用为了改善结果去对抗任何人。

### 证据不足（5–6年级用语）

这次的信息还不足以说明你的课堂体验。没有回答、暂时不想回答，都不等于你的感受不重要。现在不会给你打分，也不会猜测你的能力或老师的好坏。

如果你想说，可以先记下一件学起来顺利的事，或一件希望得到帮助的事。是否分享、向谁分享，可以请你信任的大人和你一起决定。

### 同一低体验情境的学段调整

- **7–9年级**：你反馈的一些课堂安排可能没有很好地支持你的学习。这个结果描述经历，不衡量你的能力。若你愿意且觉得安全，可以把一个具体需要写成问题，例如“我需要先看到一个完整例子，能安排一下吗？”担心直接表达时，可以请可信成人协助；不公平或不当对待不应由你负责修复。
- **10–12年级**：你描述了这门课中一些需要更多支持的经历。感受会受具体任务、时段和参与情况影响，不能据此给你或教师定性。可以选择记录一个具体学习障碍，在合适渠道表达需要；也可以寻求可信成人或校内支持人员协助。是否表达及表达方式由你在安全、知情的条件下决定。

若只是无计分表单，反馈只确认记录/跳题，不套用“正常/低”分类。例如：“已记录你选择填写的课堂经历。这份表单不计算分数，也不能据此判断任何人的能力或教师表现。”这一句也只在平台实际记录成功且接收者有权见到时显示。

## 教师接收者：三个状态示例

### 正常体验（获授权的群体汇总）

本轮获准展示的学生回应中，有一部分课堂安排被体验为有帮助。它们可作为与学生讨论“哪些做法值得保留”的线索，不是教师绩效评级。请同时查看实际响应覆盖和未回答情况；不同课程、群体和波次的差别需要结合语境理解。

可以先选一个已有安排，邀请学生以合适的匿名方式说明它在哪类任务中更有帮助，再决定是否保留。这里不披露任何学生的个体意见或敏感原话。

### 低体验（获授权的群体汇总）

本轮汇总提示，一些学生在课堂支持或表达需要方面仍有不够好的体验。回应是改进线索，不足以判定教师“差”或学生“不配合”，也不能推断单个学生的动机。

可以从一个具体环节开始，例如检查任务说明是否清楚，或提供安全的提问渠道；再用合适的匿名方式了解调整是否有帮助。不要追查负面回答者或要求学生证明自己的感受。涉及不公平或不当对待时，沿学校已有支持渠道处理。

### 证据不足或未达披露条件

目前不能提供可解释的群体结果：可能是响应覆盖不足、未满足现有披露条件，或尚缺适用的计分依据。这里不展示分数、排名、子组细分或学生个体回答。不能把未展示理解成“没有问题”。

可以先检查本轮施测机会是否覆盖到应参与学生，并说明反馈的用途和保密安排。后续是否补充收集或展示，由原有流程和授权决定，不通过放宽最小人数或披露范围凑出报告。
