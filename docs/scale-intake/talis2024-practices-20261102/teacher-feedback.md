# TALIS2024教学实践：教师成长反馈文案

接收者为**填写自评且获准访问这份记录的教师本人**。Form没有分数，当前不会按答案自动把教师划分为正常/困难等级，也不生成能力报告。下列三种情境是原创待审说明，适用于后续既有接收者权限允许的事实回顾或教研讨论；没有新报告引擎、没有已发布R版本，不自动给管理者开放教师个体答案。未取得学生对应版，不虚构学生报告。

## 记录较完整、实践有实施机会时

你记录了自己在一个指定班级中的教学做法。它能帮助你回想“我在什么任务中做过这些安排”，但不能单靠频率判断学生是否理解或学习更好。

可以先选一个想保留的做法，再找一份具体证据，例如学生的解题过程或一段课堂提问。看看哪些学生受益，还有谁可能需要另一种支持。下一次先调整一个小环节即可，不必同时增加很多活动。

三个已核官方题集的具体反思方向：

- 清晰教学：选一个近期目标，请学生用自己的话说说这节课要弄清什么；观察目标说明是否被理解。
- 认知激活：选一道有思考空间的题，保留学生说明理由的机会；复杂或小组活动次数多不自动代表深度学习。
- 课堂管理：回看一次转换环节，先说明下一步任务与所需支持；把关注点放在帮助学生回到学习，不用“更安静”代替学习证据。

## 实施受限或感到困难时

如果有些做法在这个班级中不常出现，先看看是否有适合的任务和实施机会。课时、班级规模、学生需要、材料和协作支持都可能影响选择。这不等于你的教学能力不足，也不能据此评价你是否适任。

可以先做一项可行调整：选择一个近期任务，写清想支持的学习过程，并与同事讨论一种现有资源能支持的做法。若长项目暂时没有合适的课程窗口，不需要为了“填得更高”额外布置项目。下一次只查看这次调整是否帮助了学生。

Q50时间记录只描述分配，不代表“教学时间越高越好”或“用于秩序的时间越少越好”。可以选一次过渡，试着让材料和下一步提示更清楚，再观察是否减少了不必要等待；也要保留学生需要的支持时间。

## 信息不足、遗漏或目标班级不明确时

这次记录还不足以支持稳定的实践判断。没有填写的条目仍是缺失，不会当作“从未实施”或0分，也不会据此给你或学生贴标签。

如你愿意，可以先确认这份记录对应的班级和时间，再补充一件你记得清楚的教学片段。不确定时保留空白即可；不需要为了得到结论勉强补答。后续讨论也应把这份自评与学生体验、作品或观察分别看待，不强行求一致。

## 当前原生无分反馈应有的表述

仅在原生保存/提交成功、且接收者有权查看时显示相应成功提示，例如：“已记录你选择填写的教学实践。本表单不计算教学质量分数，也不进行教师排名。未填写的内容保留为空。”本片隔离验证没有创建实际参与者提交，不声称已验证该提示的生产UI或真实提交旅程。

不得显示“高分教师”“能力不足”“低认知激活教师”等标签，不用二次评分、隐藏均分或人为阈值把Form变成量表。管理者只有在原有授权、用途和群体披露条件均满足时查看允许的汇总；同母tag不是披露授权。若未来接入官方因子分，需沿原版本及报告接收者机制另行验证，不能把这份无分文字直接套成绩效报告。
