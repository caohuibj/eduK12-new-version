# 教师成长反馈编辑草稿

编辑草稿1.0.0，非运行时R版本。填答者及个人反馈接收者为教师本人，仅沿既有授权访问。以下是三种阅读情境，不是按数字阈值触发的等级；无分FORM不产生个人分数、常模、百分制达成率或教师排名。

**较频繁的自陈情境**

你报告在课堂中较常使用一些支持学习的做法，可以把它们作为继续观察的起点。先选近期一节课，记录一次具体做法和学生如何回应；再留意是否有学生尚未得到同样的参与机会。回答反映你的看法，还不能证明每次实施的效果一致。

**较少使用或实施困难情境**

有些做法可能不容易持续，也可能需要更多时间、资源或同事支持。这不能直接归结为你的态度或能力。可先选一个小环节尝试：把任务目标说清楚并请学生用自己的方式复述；给讨论留一点思考时间；或与支持人员讨论一种适合具体学生的说明方式。一次只改一个环节，用课堂证据判断是否有帮助。资源和制度障碍应共同解决。

**信息不足情境**

部分问题未回答，或题目所指的文化与语言情境与你的课堂不完全相符。目前只保留已表达的情况，不把空白当成很少使用，不推算缺失分数，也不做完整概括。可以先记录自己需要了解的情境，再与可信同事或社区资源讨论；不根据想象补答。

七个分区分别讨论文化与家庭联系、目标和反馈的明确性、自我调节支持、关怀、读写、行为支持及教学方法，不把它们汇成“好教师”标签。涉及当地原住民语言、家庭与社区的项目应保持文化谦逊，不能从一个群体的材料推断另一个群体的固定特点。V69不用于给学生分类学习风格，也不要求教师按固定偏好类型配教学。中文文字是项目编辑说明，没有冒称原量表验证版。

群体反馈只有在现有匿名、最小人数、发布及接收者授权均满足后，才可向获准教研人员提供允许的汇总；不足或未授权时不展示。不给无权者查看个人答卷或敏感开放回答，不因本次文案改变保密规则。未发现原生学生对应版，本任务不新造学生报告。
