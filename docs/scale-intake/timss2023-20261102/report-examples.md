# 接收者分别适用的报告编辑示例

**所有文案均为原创中文编辑草稿，没有数值、自动分档、R冻结版本或运行时绑定。** 美国英语题本没有因此变成中文版。正常／低体验是条件场景，不是诊断或本地常模区域；正式显示前要有合法题本、与实际计分相符的解释、对应语言和既有接收者授权。两个指数分别反馈，不能合成“课堂质量总分”。

填答者都是学生；这不自动决定谁有权看报告。学生个人版只在现有配置允许本人接收时显示。若调查只允许群体反馈或不向学生发结果，沿原规则完成提示即可，不开放隐藏结果。教师版只在现有发布、匿名、最小人数及接收者权限均允许时呈现群体汇总；不得显示可识别的学生个体回答或敏感开放内容。目录候选当前两个接收者都没有实际得分报告。

## 四年级学生

**清晰度：较顺利体验。** 你这次的回答表示，课堂上的说明常常能帮助你知道要学什么、接下来怎么做。这是你的学习感受，不是给老师打一个好坏标签。下次遇到不明白的地方，可以说：“我听懂了前面这一步，后面能再举个例子吗？”也可以记下一个对你有帮助的例子。

**清晰度：低体验。** 你这次提到，有些说明还不够容易明白。这不说明你不聪明，也不是你的错。如果你愿意，可以圈出最不明白的一步，找合适的时间请老师再讲一个例子。觉得不好开口时，可以请一位你信任的大人帮你表达需要；你不用自己解决所有困难。

**课堂秩序：较顺利体验。** 你这次感觉，课堂里的打扰比较少，比较容易把注意力放在学习上。可以留意哪种安静学习的安排最有帮助；需要帮助时，也可以按课堂里约好的方式提出。一次回答不能代表每天都一样。

**课堂秩序：低体验。** 你提到，课堂里的打扰有时会让学习变难。让课堂更安全、更容易学习是大人们需要一起做的事，不需要你去管其他同学。你可以把一次影响你学习的情况告诉可信的大人，请他们帮你找到能安心学习的办法；不必独自与任何人争执。

**证据不足。** 这次的信息还不够，我们先不判断你的课堂体验。没填的地方不会算成差，也不会补成零。如果你愿意，可以在合适的时候向可信的大人说说：最近哪一部分学习需要帮助。是否补答按原有安排决定，不要求为了拿到报告反复填写。

**无分表单。** 这里记录了你选过的课堂活动，空着的地方显示“未填”。活动出现得多或少没有统一好坏答案，也不表示你学得好或不好。如果某种活动让你不明白，可以说说你希望得到怎样的帮助。这里没有分数或等级。

## 八年级学生

**清晰度：较顺利体验。** 你的回答反映，这次你通常能理解课堂目标、说明或反馈。它描述你的经历，不能单凭这个结果判断某位教师的整体水平。你可以保留一个有效做法：把反馈中最有用的一点写进下一次解题或实验记录，遇到新疑问时提出具体问题。

**清晰度：低体验。** 你的回答提示，部分课堂说明或反馈还没有满足你的学习需要。这不等于你的能力不足。可以选一个具体卡点，用“我理解到……，还不清楚……”说明需要，或请可信的成人协助沟通。改善解释和支持是教学与学校共同的责任，不要求你独自承担。

**课堂秩序：较顺利体验。** 你感受到的课堂打扰相对较少，学习空间对保持专注有一定帮助。可以观察哪个既有安排最有效，并在适当时机表达这个需要；无需把这次体验推广为所有同学的感受。

**课堂秩序：低体验。** 你报告的打扰可能让专注或参与变得更难。这反映你经历的课堂环境，不是给你或其他同学贴行为标签。若你愿意，可向可信的成人描述具体场景和对学习的影响，请对方协助处理。遇到让你不安或不公平的对待，你不必先改变自己来证明值得得到支持，也不需要直接对抗教师。

**证据不足。** 现有回答不足以支持可靠解释，我们不会据此判断你的能力、动机或教师表现。未答不等于没有经历。你可按自己的意愿向可信的成人说明一个学习需要；是否补充信息按现有安排，不将反复填写作为获得支持的条件。

**无分表单。** 这部分只保留你选择的活动及频率类别；未填处不补零。不同活动的作用依赖课程目标，不能据此算“认知激活能力”或课堂好坏分。若需要反思，可以选一个你希望得到更多支持的活动，并具体说明需要什么帮助。

## 教师接收者：仅获授权的群体汇总

以下“本群体”必须绑定同一国家语言、年级、学科、调查波次及冻结版本，并按既有规则处理缺失和披露。不得从一个学生、很小群体或可识别回答直接生成这些句子，不虚构人数或比例。

**清晰度：较顺利体验。** 本群体的有效反馈总体反映，学生较容易理解课堂说明和反馈。可保留学生认为有帮助的一种解释或示例方式，同时检查群体内是否仍有未被充分支持的需要。结果是学生感知，不能据此认定教师优秀，也不能用成绩关联宣称教学导致了提高。

**清晰度：低体验。** 本群体的反馈提示，部分学生尚未从课堂说明或反馈中获得足够帮助。建议先选一个概念，尝试更具体的示例或检查理解的方式，再听取非强制、符合既有保密规则的反馈。不要追问“谁打了低分”，也不把差异归咎于学生能力、态度或家庭。

**课堂秩序：较顺利体验。** 群体反馈显示，较少干扰的学习环境是可保留的条件。可检查目前哪些活动转换或支持安排有帮助；这一感受不代表每位学生都没有遇到困难。官方失序指数高分对应较少干扰，不能把高分误写成失序更多。

**课堂秩序：低体验。** 群体反馈提示，课堂干扰可能影响部分学生的学习。优先检查活动转换、任务清晰度和可获得的协助，并与学校支持人员讨论一种可行调整。不能将结果直接用于教师问责、学生惩戒或优秀教师排名；不把改善秩序的责任交给报告低体验的学生。

**证据不足或披露条件未满足。** 当前没有可报告的群体结论。不要用缺失补零、降低现有最小人数要求、合并不同年级／科目凑人数，或向教师披露个体回答来弥补。保持已有规则允许的状态提示；如果连参与人数也受限制，则不显示人数。可使用独立、合适的教学反思，不宣称它来自本次结果。

**无分表单。** 获授权且满足匿名规则时，仅描述活动类别的分布及已填／未填状态；不同频率没有统一价值顺序，不求均分或加进清晰度／失序指数。没有获准汇总则不显示个体选项、敏感回答或推断性建议。

## 本轮验证边界

人工核对上述每个场景：学生措辞符合四／八年级理解水平；不诊断、不把低体验归责学生、不要求对抗教师；每段给不超过两项可选微行动；清晰度与失序方向保留；教师只谈授权群体；信息不足和无分均没有虚构数字。目录实际路径只提供候选状态及限制，不运行这些场景。真实学生／教师报告分发、匿名阈值、语言呈现和普通表单交卷路径均未执行；合法内容可用后只补相应代表路径，不跑全平台回归。
