## 计分与原生导入准备

原件说明两套五点选项（频率、感受），以1–5计算问题及域平均，数值越高代表较好的体验。
这仅是作者的概括性描述，当前不足以实现本年可复核计分：

| 合同 | 已核信息 | 未核信息及当前处理 |
| --- | --- | --- |
| 选项映射 | 两套五点选项均完整读取 | 每道题究竟用哪套未标注；不得按措辞猜测 |
| 反向 | 本年PDF未给反向键；方向统一描述为高值较好 | 没有安装反向或正向计分；不从未见反向键断言正式无反向 |
| 缺失 | FAQ明确所有题目可跳答 | 域平均的最小作答数、学生/题目权重、学校聚合方法未说明；不把漏答当0，不强制全答，不自造折算 |
| 范围 | 对合法1–5值，普通算术均值理论范围1–5 | 不是已核官方本年计分实现；无总分、分界值、常模、百分位 |
| 内部题组 | PDF提供13个分组 | 未核独立分量表计分、可靠性或拆开施测证据；不创建13个量表 |
| 人口学 | 原件提供性别单选的不同地区配置与族裔多选 | 只记录事实/描述，无数值映射；选项配置未确定，不默认采集敏感背景 |

人口学不依赖域计分，但仍缺平台使用许可及地区选择，已单列而不是阻塞其元数据准备。
