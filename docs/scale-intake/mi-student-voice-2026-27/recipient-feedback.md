# 接收者反馈候选：学生与教师

这些是平台原创文案示例，不是已安装的R版本、量表解释或官方报告。
本次只有目录和无计分表单计划，没有真实答卷，也没有授权可发布结果。
三种情形依赖今后真实回答；不设高低分阈值，不从答案自动诊断、标记或推断教师好坏。

填答者固定为5–12年级学生。学生作为接收者，只能在现有产品支持且管理员已依既有授权开放时，
看到属于自己的适龄填写完成提示或允许的回答回顾；原生产品不支持该可见性就保留为准备文案。
官方匿名说明不等于本平台已经实现匿名，不能声称本平台采集匿名或向教师开放身份关联数据。
个体回顾和群体摘要均沿原接收者授权、匿名、发布及最小人数规则，不因本文件新增披露能力。

## 学生接收者示例

| 情形（仅示例，无数字分数） | 5–6年级文案 | 7–12年级文案 |
| --- | --- | --- |
| 较积极的学校体验 | 谢谢你说出在学校的感受。如果你觉得有人愿意帮助你，可以想想哪一次帮助最有用。下次不明白时，试着说：“我卡在这一步，可以再给我一个例子吗？” | 如果你在课堂上较容易得到帮助，可以回想哪种讲解或反馈最适合你。下次遇到难题时，指出具体卡住的一步，向老师提出一个明确问题。你分享的经历可以帮助学校了解哪些支持有效。 |
| 较低体验、感到支持不足或不公平 | 如果你觉得在学校不容易得到帮助，这不说明你不够好。你可以把一次让你不舒服的经历告诉信任的大人，也可以请他陪你说明需要什么帮助。如果有人欺负你或让你不安全，你不用一个人解决。 | 较少感到被理解、被支持或被公平对待，描述的是你经历的学校环境，不能说明你的学习能力或价值。可以记下一次具体经历和你需要的支持，找可信的老师、家长或学校支持人员一起商量；不需要独自面对不公平对待。若涉及欺凌或安全问题，优先寻求可信成人帮助。 |
| 未回答或信息不足 | 你可以跳过不想回答的问题。没有回答的地方，我们不知道你的感受，不会当成不好或不努力。如果你愿意，可以以后找信任的大人谈一件你希望改变的事。 | 这次没有足够的回答来了解某些经历；未回答保留为未回答。你不需要为了完成问卷透露不想分享的事。愿意时，可以选择一个最重要的学习需要，向可信成人表达。 |

若学生报告受限，不显示对其未授权的回答或群体结果，只用既有完成提示。
无计分表单不能把“正常/较低体验”包装成自动评定标签；上述文案仅在真实描述支持且可见性允许时适用。
体验可能随课堂、时间和环境变化，单次回答不能评判教师好坏，也不能保证已全面反映你的学校生活。
学生不承担纠正不公平、危险或不当对待的责任；建议不要求学生直接对抗教师。

## 教师接收者示例

教师只有在现有角色、任务、发布及群体最小人数/匿名规则允许时，才能看到已授权的学校或班级群体摘要。
填答者是学生不代表教师能查看其个体回答；不披露身份、敏感背景或未经授权的原始意见。
这不是教师自评，不能套用教师自我反思量表报告，也不能把本工具“多数教师/学校成人”的回答归给某位教师。

| 情形（仅使用真实且授权的群体描述） | 教师文案候选 |
| --- | --- |
| 较积极体验 | 若授权摘要中有学生描述较容易获得帮助，可以在教学讨论中整理有效做法，例如清楚的作业要求、具体反馈和多种讲解方式。邀请学生自愿补充哪些做法有帮助；不追问谁填写了什么，也不据此评定优秀教师。 |
| 较低体验 | 若授权摘要呈现部分学生较少感到被支持或被公平对待，先把它作为改善环境的线索。可试行一次更明确的求助方式或反馈机会，并在后续自愿反馈中了解变化。不要把不满意归因于学生能力或态度，不把群体体验当成某位教师的能力分。安全、公平与欺凌相关问题按学校现有支持流程处理，不能要求学生自行解决。 |
| 信息不足或不可披露 | 当前没有足够且可公开的群体信息作判断。漏答不计零，也不补成平均体验；未达到现有群体披露条件时只显示既有不可用状态。不追索单个学生补齐，不披露小群体或敏感人口学明细。 |

本候选不提供教师排名、跨域分数或因果结论。后续报告需分别核实际数据、接收者与版本，
未来可计分版本保留原计分方向，不为鼓励而改分。数值R未创建，表单也不借评分报告呈现事实回答。
