# CID-DUA3｜课堂实践证据与行动导读

![同一项课堂任务里，老师让学生用图片、口头说明或动手操作来理解。](hero.webp)

先想起一节你记得清楚的课。学生是怎样接触新内容、参与活动并说出自己懂了什么的？写下一个具体场景，再决定下一次可以改什么。

## 从一件课堂小事开始

挑一个经常使用的任务，保持学习目标，试着给学生两种参与或呈现所学的方式。观察在哪一步学生能独立开始，在哪一步还需要帮助。

## 证据还少的时候

手上没有足够证据，也可以只记下下次想观察的细节。留空不会得到分数。结合班级、时间和资源理解记录，避免填写可以辨认学生的信息。
