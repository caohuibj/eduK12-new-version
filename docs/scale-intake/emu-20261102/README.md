## 响应、缺失与分析边界

教师和同伴核心27项采用四档同意响应；学生Q1–25同为四档，Q26为五档难易适配分类。未来合法原生Form应使用原文选择标签和稳定类别键，**不设置option.score、总分、维度均分、反向转换、阈值或评分反馈**。学生Q26的中间类别表示合适，不能把末档当最高质量，也不能反向后并入前25项。未回答保留缺失，不当作不同意，不填0，不为了完整率强制补答。

原作者的逐题、学生群体响应讨论不等同于量表维度得分；软件中逐题描述指标也不授权本平台新造域分或跨角色差值诊断。正式改编许可未建立，本轮没有复制或执行官方软件、Excel宏、R代码，也不声称审计了其中全部缺失/加权公式。

Q1–22按主题可供多视角讨论，不声称跨角色测量等值。Bilanz不能按同号硬配：Q23学习、Q24感受主题相近；学生Q25的多样性/激发体验与教师/同伴Q25的媒体和组织形式适切性不同；学生Q26难易适配不等同教师/同伴Q26标准导向或Q27差异适配。长期的教师Q40班级表现与学生Q40本人表现也不能当成同一个变量。共同tag不产生统一“真实教学质量”或跨工具总分。

教师自评是自己的课堂判断；同伴是一次观察；学生是学习经历和感受。任何一方都不自动证明实际教学效果。反馈应落到具体情境、可得证据和下一次尝试。不同接收者的普通/困难/信息不足示例见 [feedback-examples.md](feedback-examples.md)，不是原作者文字或运行中的评分报告。
