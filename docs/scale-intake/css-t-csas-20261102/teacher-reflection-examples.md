# CSS-T／CSAS：教师成长语言与无分反馈边界

当前可导入的15份完整内容都是无计分原生Form；英文纠正反馈整组已因原35缺件撤下，完整英文49题组合不可施测。其余说明仍适用于保留的法文8份及英文7份，运行时`parameters`和`report`均为null。下面是原创填写说明和可由教师自主使用的反思示例，**不是由分数自动生成的测评报告，不是已发布R版本**。接收者首先是自评教师；任何同事、管理者、观察者看到个体内容，仍需原有授权与发布规则允许，不自动把教师自评交给学校或与观察者配对。

正常、困难、信息不足是情境示例，不是分层阈值或教师标签。原题频率方向和选项保持不变；不为了积极鼓励改变事实，也不把f1/f7变成好坏、优秀或差劲。现行Form完成提示仅确认提交事实，不承诺系统未执行的人工阅卷、求助通知或建议分析。

## 已有一些稳定做法时

你记录的是自己近期对这些教学做法使用频率的看法。可以从中选一个已有把握的具体行为，回看一次课堂片段：学生是否更清楚接下来做什么，或更能说明自己的想法？不需要同时提高所有策略的频率；把一种适合当前学生的做法用得更合适，往往比追求每题都选最高频率更有帮助。

可尝试：下一次课保留一个已有帮助的安排，并收集一两份学生任务或课堂反应作为线索。这些材料也不能单独证明因果成效。

## 发现困难或暂时较少使用某类做法时

较少使用可能与任务类型、学生需要、时间和可用支持有关，不能据此认定你教学能力不足。选一个具体场景，分清可以调整的做法与需要协作解决的条件。纠正反馈、表扬等也不是越多越好：更需要关心它是否具体、适时并帮助学生回到学习。

可尝试：从一个小变化开始，例如在给反馈后留一点修改时间，或把过渡要求说成一两步。必要时请可信同事共同看一个片段，讨论支持，而不是接受一份个人质量排名。

## 信息不足或不愿回答时

当前内容只收集原始描述，没有用漏答、拒答或少量回答估算你的分数。你可以略过暂时无法判断的问题，不需要为了“完整”猜测。若愿意继续反思，可以先记录一个明确的课堂例子；是否与他人分享，由既有流程和你的实际授权安排决定。

## 八组可选微行动（非原量表计分解释）

| 题组 | 一个可尝试的行为 | 可回看的线索 |
| --- | --- | --- |
| 学习投入与参与 | 为一次小组任务说清各人的角色 | 是否有学生一直没有参与机会 |
| 教学呈现 | 展示一个关键步骤后请学生复述下一步 | 学生能否开始行动，而非只看是否安静 |
| 促进学生思考 | 追问一次答案是怎样得到的，并留思考时间 | 回答中是否出现具体理由 |
| 学业表现反馈 | 给一个可操作的反馈，并留修改机会 | 学生是否理解并尝试修改 |
| 表扬与鼓励 | 把一次鼓励指向具体努力或策略 | 学生是否知道什么做法值得保留 |
| 纠正性反馈 | 先确认理解，再用清楚、尊重的方式说明下一步 | 学生是否获得回到任务的帮助 |
| 预防性管理 | 在一次转换前明确一个约定 | 只讨论具体行为；不据本维度作高低结论 |
| 指令与过渡 | 一次给出一两步要求并确认理解 | 学生是否知道先做什么、卡在哪里 |

预防管理因子在卢森堡研究中证据弱，CR=.148；不是“预防能力差”的个体诊断。其他组的研究系数也不能自动转化为这些拆分数字Form的可靠性。原英文第35题有缺印，已撤下英文纠正反馈整组；下表纠正反馈建议当前仅对应完整法文内容。法文选项是项目翻译，来源和编辑限制一同保留。
