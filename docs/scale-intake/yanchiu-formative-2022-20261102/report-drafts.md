# 教師發展性回饋草稿：接收者與無分邊界

未建立R版本，沒有真實結果、閾值或已渲染報告。以下為原創中文編輯文字，不是量表翻譯、已驗證簡體版或作者報告。個人結果只給原有授權允許的接收者；教師自評不自動對校方開放，群體匯總沿原匿名、發布及最小人數規則。無原生學生版，不造學生平行結果。

**正常回顧**：這次回答描述了你對形成性評價的看法與實施條件，不能單獨證明課堂效果。可以選一個你認為有幫助的做法，回看一份備課、反饋或修訂記錄，看看理念如何落到具體行動，再決定下一次保留哪一步。

**遇到困難**：有實施意願但缺時間、資源或協作是可能同時出現的情況，不代表你不努力。可以先選一個可協調的條件，例如與同事共用一份任務範例，或為學生安排一次根據反饋修改的機會；不要求你獨自改變考試制度或同時解決全部問題。

**資料不足／無分**：目前只記錄了你自願提供的描述，沒有可靠依據形成個體分數或能力結論。空缺不當成0，沒有分數也不表示能力不足。你可以保留一個想了解的實施問題，待有合適的教學機會再回顧；不為產生報告強迫補答。

各子構念解釋焦點：考試與問責看外部壓力、教學環境看時間與負荷、學校支持看可協調資源、學生條件看教師所感知的參與條件；工具性態度看對用途的信念、自我效能看自覺可行性、意願看未來打算、主觀規範看感知的他人期待。以上不能互相替代或轉成綜合教學品質。
