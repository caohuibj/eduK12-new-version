## 已核计分事实与真实风险

详细算术观察见scoring-audit.json。读取2,691个公式，逐一比较第41行公式平移到42–72行，未发现复制偏移。独立有限算术核对32个示例行的逐项公式缓存，无不一致；不是完整Excel应用重算或生产scorer。

- 原题多为“是否发生”的复选、连续次数/百分比、区间选择及文字。权重不相同，部分采用分段阈值；不能简单均分、按频率越高越好或将0–100图形当能力分。
- 课堂提问次数严格大于3才贡献1；小组讨论次数=1贡献1、>1贡献2，0.5按本文件公式不贡献。预测—观察比较次数严格大于0.5；学习价值讨论每学期3–5贡献1、>5贡献2。单位“每次课”和“每学期”不能混。
- ISR同伴讨论次数严格>1贡献2；要求解释推理的考试分数占比严格>15%贡献1；期末考试占比≤60%贡献1。边界共核17个输入。
- **Excel空白不是安全缺失政策**：期末考试占比空白可按0比较而贡献1。因此不能用缺答跑出“已实施”反馈。来源未给本站完整缺失/不适用规则，本次不补造阈值或均值插补。若未来做无分Form，未答与明确未实施分别保存，不必等待计分规范。
- “无TA”可贡献3，但其公式还依赖其他TA计分贡献；与英语要求同时选时其自身3分被抑制，而与本科TA身份这种零权重标记同选时不抑制。保留来源事实，不能擅自改权重；先核矛盾回答，不用“无TA”推断教学更好或更差。
- 讲授比例是区间token；0–60%各档贡献2，60–80%贡献1，80–100%贡献0。原显示区间边界相接，不替用户把百分比重分箱。讲授比例或实践种数都不能单独判断实施质量。
- 无传统反向题键；上述阈值/权重是规则映射，不能统称反向题。保留零权重事实及文字说明，不从得分删掉它们。

## 面向教师成长的反馈计划

以下为原创中文待审示例，不是已部署报告或真实测量结果。未来报告只向现有接收者授权允许的教师本人呈现；汇总研究按现有授权/发布/最小人数与匿名规则，不自动对学校或他人披露个人选择和开放文本。未提供学生报告，因为这份来源是课程实践清单，不是学生题本。

| 状态 | 示例 |
|---|---|
| 实践信息充分，有已实施做法 | 你这次记录了本课程正在使用的几种反馈做法。这能帮助你看清教学安排，但还不能说明每项做法实施得怎样。可以选一份近期作业，看看学生是否读懂反馈，并在下一次任务中用上它；只选一处需要调整的细节即可。 |
| 存在实践困难或较少记录 | 你目前记录的某些反馈机会较少，可能与课时、班额、资源或课程目标有关。这不是对你教学能力的判定。可以从一次低负担尝试开始，例如让学生根据一条具体反馈修改一个答案，再用简短检查了解是否有所帮助；资源不足时也可以与同事或教学支持人员讨论。 |
| 信息不足/不适用 | 当前有些信息尚未填写或不适用于这门课，暂不形成可靠的计分解释。空白不等于未实施。可以先补看课程材料或教案；确实没有助教或对应活动时按实际情况记录，不为得到分数勉强填选。 |

各组件微行动可分别选择1–3条：I将一个目标改写为学生能完成的具体任务；II检查一份材料是否给出推理过程；III记录一次活动中谁在思考/交流；IV将一次作业与目标对照；V观察反馈是否进入修改；VI选一个与目标一致的证据查看变化；VII与TA讨论一个常见学习困难并核对支持；VIII与同事交流一项做法及其条件。不能把这些行动文字变成原作者新题目。

两项无分表单未来只按现有权限显示“已记录，本部分不生成分数或能力评价”，可提示教师自主选择是否反思。不得把完成时长当能力或认真程度分。正常/困难示例无新常模或人工分界，须以实际已允许结果支持；不能为鼓励而改分或弱化限制。
