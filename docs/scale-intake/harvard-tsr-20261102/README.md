## 计分边界

原文支持五点有序响应，积极、消极分开解释。积极更高表示更多积极关系感知，消极更高表示更多消极关系感知；不为鼓励学生而改方向。附录无标明反向计分题，星号不得用作反向索引。

原论文pp.17–18报告了两个维度的描述统计和研究中的观察范围，但未给本候选可复用的逐题选项映射、原始分聚合公式和可容许缺失阈值。不能仅凭描述统计断言官方算法就是均分，也不拿观察范围当理论范围。若以后确认每题按1–5编码，9题和5题求和的数学区间分别是9–45、5–25、均分均为1–5；这些是**条件算术，不是现行计分参数**，未装载。当前原始分、理论分数范围、缺失处理均未实现；缺失不按0、不插补、不按自造80%阈值折算。无常模、百分位或好/差分档。

## 报告接收者

`report-candidates.json`是编辑审阅材料，不是后端payload或已冻结R。学生与教师自评分别有正常体验、较低体验、证据不足三个示例；这些只是叙述场景，绝不等于分数阈值。积极与消极可能同时存在，正常体验文稿不能抹去具体不公平经历。

学生报告只在现有发布、接收者授权和原匿名/保密策略允许时给本人，围绕本人感知、适龄解释及1–3个微行动。教师自评给该教师，只解释自己针对指定学生的关系感知。教师接收学生反馈时，只能用已授权且满足原最小人数/匿名约束的群体汇总，不能把个体回答或敏感开放文本直接贴入教师报告；本次无新的汇总报告实现，也不改现有可见性。学生和教师两方结果不互相自动开放。无分表单/目录条目没有分数报告。
