## 计分准备与边界

官方效度报告p.7给出研究分析方法：将各题转为正向1–5，7级题先算术转换，再按主题平均；某主题漏答超过半数时排除。这里登记家族层的方法与逐表待核事实，**没有可执行计分参数**。

- 5级题原序号可记r=1…5；学校安全模块全部原题反映风险，若绑定“更高=更安全”，`6-r`是根据原选项与报告正向规则推导的候选反向映射，仍待题本版本逐项核定。3–5年级5题、6–12年级6题，不能漏掉年龄差异。
- 课堂气氛4题、学校气氛5题中，第3题为7级，其余为5级。端点保持的线性映射 `1+4*(r-1)/6` 得到1、5/3、7/3、3、11/3、13/3、5。这个具体公式是对报告“算术转换”的明确推导，不冒称原报告逐项列出；不可先舍入或直接平均5/7级原序号。
- 其他模块在当前指南中为5级、原始选项随积极感知增加；仍保留逐题语义锚点，不统一改成同意/不同意。观察方向不等于冻结可用参数。
- 研究分析边界可推为有效回答数至少`ceil(n/2)`；n=4/5/6/7/9对应至少2/3/3/4/5题。等于半数未被“超过一半”规则排除；全缺失不可计算。有效题均值、跳答、技术无效及这份历史指南的实际应用方式仍需精确版本确认，不把研究样本排除法自动升为产品个体反馈合同。
- 将来若确认上述映射，主题均值理论范围为1–5，正向越高反映更积极的本次感知。当前没有发布得分、分层阈值、百分位、教师优劣排名、能力推断或跨模块总分；也没有把均值换成0–100能力分。

无计分表单只作事实/描述性反馈：课堂开放题26个建议、学校开放题13个建议、背景7个问题。开放题与背景页未分年级；按年级分别管理是项目组卷计划，不能叫官方分龄平行版。背景题没有完整选项，不能自行补造分类后仍称原版。详见清单和batch中的6个计划；不建伪Scale、不向量表报告塞分数。

## 接收者与普通组合

各模块在batch中分别有学生版行动和教师版行动。完整适龄、正常体验/低体验/证据不足及无分反馈示例见 [report-examples.md](report-examples.md)。**填答者不自动等于结果接收者**。学生版须既有接收者授权允许查看本次个人反馈；教师版须既有授权的群体汇总并满足实际匿名、发布、最小人数与敏感信息规则。目录/文案不扩大这些权限。

4个普通组合计划为两个年级段各一套课堂4模块、学校4模块，可选对应开放表单及最少必要背景信息。遵守各模块精确C/P/R，避免重复问同一背景问题。指南允许混合层级，但本候选只提供分层清单；不创建特殊组合引擎或跨子项总分。实际组卷前才通过现有普通组合编辑流程绑定合法且已核的子项。
