# Panorama：按接收者与学段区分的报告编辑示例

本文件为原创编辑草稿，**没有发布R版本、真实分数或真实学生数据**。三种状态是叙述情景，不是常模分层；当前未据它们建立阈值或自动分类。每个模块独立的学生/教师行动草稿见 [batch.json](batch.json)。不为鼓励而改分、反向或粉饰体验。

## 可见条件

学生是问卷填答者，只有现有身份和报告接收者授权允许、且本次结果的保密/匿名/发布规则允许个人反馈时，才显示其本次适龄说明。匿名设计中不追踪或重识别学生，不能只为生成学生报告增加身份绑定。没有权限时不生成可见个体报告；这不妨碍依法授权的其他结果流程。

教师版只供既有权限允许的群体汇总，且满足该流程实际最小人数、匿名、发布和敏感数据规则；不自行设一个新人数阈值。不把学生单份低体验、开放原答、可识别细节或个人支持记录自动发送给教师。学生求助内容不经目录文案自动披露。教师自评工具的报告仍给教师，本母工具没有教师自评子项。

## 3–5年级学生接收版：课堂师生关系示例

**可解释、体验较积极的情景。** 你这次的回答里，有一些和老师相处时感到被关心、被尊重的经历。你可以想想：哪一次帮助最有用？下次需要帮助时，可以说清楚一个小问题，比如“这一步我还没明白，可以再讲一个例子吗？”这份回答只说这次的感受，不能评定你或老师的能力。

**可解释、体验不太好的情景。** 你这次的一些回答，让我们看见你有时可能不太容易感到被理解。这样的感受值得被认真听见，也不表示你不够好。你可以找一位让你安心的成人，说一件具体发生过的事，再说说希望得到什么帮助。如果受到不公平或不好的对待，这不是你该独自解决的问题；一次没有得到帮助，还可以找另一位可信的成人。不需要为了报告去和老师争执。

**证据不足。** 这次的回答还不够，我们暂时不能作出可靠分析。我们不会把没有回答的题当成你的看法。你不需要为了让报告完整而勉强回答；如果你想谈谈课堂里的感受，可以找让你安心的成人。

## 6–12年级学生接收版：课堂师生关系示例

**可解释、体验较积极的情景。** 你的本次回答反映了一些获得尊重与支持的课堂经历。可以回想一次让你更愿意提问的交流，把其中对自己有帮助的方式保留下来。下次遇到困难时，试着说明一个具体步骤和你希望获得的帮助。这里呈现的是你的体验，不是教师能力或教学成效的客观评定。

**可解释、体验不太好的情景。** 你在某些回答中表达了较少被理解或获得支持的感受。它们值得被重视，也不表示你的能力差或需要由你修复这段关系。你可以选择安全、合适的方式，把一个具体学习需要告诉老师；也可以请可信的成人帮助表达。如果涉及威胁、不公平或不当对待，优先通过学校已有的支持渠道寻求帮助，无需直接对抗教师。报告不能替你判断事件原因或所有人的意图。

**证据不足。** 目前的有效回答不足以可靠解释本模块，因此不显示得分结论或高低标签。未回答不等于没有体验，也不会被当成零分。如果你愿意，可以通过已有支持渠道表达一个需要帮助的问题；是否重新填写遵循原有自愿与施测安排。

## 教师接收版：同模块的已授权群体汇总示例

可见前提是上一节所述群体汇总条件全部满足；以下不引用或反推某位学生。它不与上面的个人示例构成同一批真实数据。

**可解释、群体体验较积极的情景。** 本次汇总反映了学生群体在尊重、回应和支持方面的一些积极感知。可与班级共同回顾哪些交流安排帮助学生表达需要，并选择一项保持。结果描述的是参与学生的感受，仍需结合响应覆盖和教学情境理解，不能据此评定优秀教师或推断所有学生都有相同体验。

**可解释、群体体验不太好的情景。** 本次汇总提示，一部分课堂交流与支持安排可能需要进一步倾听和改进。可先提供不要求学生公开个人经历的反馈机会，说明教师会如何回应具体学习需要，并选择一项可观察的调整。不要要求学生解释自己的低评价、寻找个体批评者或将差异归因为学生“不配合”。它不能单独证明教师有无能力、事件责任或教学因果效果。

**证据不足或不能披露。** 当前回答覆盖、有效性或既有汇总条件不足，暂不呈现本模块的得分结论、可识别小组信息或个人原答。可检查施测沟通和参与机会是否充分，再按原安排决定后续；不补零、不推算缺失者态度，不通过缩小筛选范围绕过匿名与最小人数规则。

## 无分表单

学生完成开放反馈或背景信息后，可在既有流程允许时看到“你的回答已提交”之类的事实性确认。不能承诺保密之外的内容或声称已有人收到求助；未实现的通知不写成已完成。无计分、无高低分析、无能力建议或评分图。若要展示支持入口，应使用学校现有可用渠道，并向学生准确说明谁能看见反馈。

教师只有原有授权与发布规则允许时查看事实性汇总或经过相应处理的开放反馈；不把性别、族群、家庭背景、个人情感或负面措辞转成学生/教师质量分数。原背景页缺选项，本轮尚无可运行表单或结果展示路径，因而不宣称上述示例已经实测。
