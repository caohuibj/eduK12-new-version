# QTI教师实际／理想版待补材料

优先从乌得勒支官方服务页所列的 Educational Development & Training 联系渠道索取；当前公开联系人为 `educationaltools@uu.nl`。本次没有发送邮件、开户、购买或接受任何需要用户同意的条款。

请提供或协助取得下列准确材料，任选一个明确版本先闭环，不必把所有语言都凑齐：

1. 教师实际自评与教师理想两份原生题本，各自的确切版本/发布日期、语言、学校阶段、全部题文和原顺序。需要区分教师理想与“学生眼中的理想教师”；不以改写学生表代替。
2. 两角色的完整指导语、参照班级/时间窗、所有作答选项及数值编码。官方网页对学生端的说明不足以填齐教师协议。
3. 对应原版本的题项—八维归属、反向（若有）、缺失处理、聚合/派生计算及范围。没有常模也可做描述性原量表；没有官方计分但允许内容处理时转原生无分表单，不编造公式。
4. 来自实际权利人的可核验授权范围：电子呈现、存储、计分、公开Git再分发，以及确需时的商业使用/翻译/改编范围。仓储作者、QTI第三方作者与平台权利人可能不同，论文中的研究许可不自动覆盖这些动作。受限材料按实际授权处理，不公开全文。
5. 如选历史Lee2010英文版：需要附录E/F清晰原件、逐题校对、完整计分依据和覆盖该使用的书面许可。仓储条目明示需书面许可，不把可阅读等同于可移植；此版与现行中学版单独管理。
6. 如选Xin/Lin2000中文教师版：需要原研究全文、准确中文版教师题本/计分和权利说明，不能借Sun2018学生40题回译补齐。

取得材料后按既有流程继续：目标库按作者/来源/题项/版本再排重 → 重合引用既有ID → 同母标签与角色/语言分别固定身份 → 仅修改该内容与三版本 → 原计分边界或无分归一化、教师报告及隔离库preview/apply/回读 → 管理员审核。不会因完成目录、提交PR或得到管理员同意就宣称第三方授权已具备。
