## 直接核过的材料

[乌得勒支官方服务页](https://professionals.uu.nl/en/programme/questionnaire-on-teacher-interaction-qti)明确区分学生感知、教师实际自我感知、教师理想。公开说明页没有完整题目、教师专用指导语或题项键；它链接订阅和付费单次施测，本次未开户、订阅、购买或接受条款。页面给学生端的1–5端点和10–15分钟，不能冒充已核教师端全部作答协议。

[官方January2023操作手册](https://vil.fss.uu.nl/files/Manual_en_online_2023.pdf)两页已读，说明英文／荷兰文中学及高教服务，以及教师完成实际／理想两视角；它没有题库和计分键。手册日期不是题本版本号，服务中的班级规模设置也不替代EduK12现有隐私与最小人数规则。本轮优先中学，未另注册高教或中文教师版。

Lee, Yoke Cheng（2010）的[Curtin博士论文](https://curate.curtin.edu.au/articles/thesis/Teacher_interpersonal_behaviour_in_gifted_students_Primary_Science_classrooms_and_effects_on_achievement/31462462/1/files/62347123.pdf)是**不同历史版本**：新加坡小学科学资优教育情境。正文说明教师填写实际与理想两份；附录F印刷139–140页可读到48题教师自评文本及端点，但OCR有瑕疵，未逐项看图校正。附录E的137–138页为理想表，扫描内容尚未逐项核清。PDF本地下载返回403、图像读取也失败，均未绕过。

该论文的[官方仓储元数据](https://api.figshare.com/v2/articles/31462462)成功读取：条目许可为 **“All rights reserved, written permission required”**。虽同时标记open access，不能据此复制成平台原生题库。[仓储版权说明](https://researchtoolkit.library.curtin.edu.au/publishing/curate/meeting-copyright-obligations/)进一步说明保留复制、改编、出版与在线传播等权利。没有把研究伦理许可、学校同意或仓储公开阅读误作题库再发布授权。公开提交不含题文、截图、原PDF或题项改编。

Fisher/Fraser/Cresswell1995与Nugent2009机构论文落地页可读，PDF端点403，不能称全文已核。Xin与Lin2000中文教师版本次仅核到书目及Sun2018所述版本来历，未得原题；它不是#545中文学生40题。[source-status.json](source-status.json)逐源保留取得范围与访问失败，仓储2026年迁移时间不当作2010题本新版本。

## 标签与报告准备

[tag-and-split-plan.json](tag-and-split-plan.json)使用现有 `tags: string[]`，共同标签计划为 `family:qti`；另分 `role:teacher_self`、`view:actual/ideal`、语言、学段、来源与用途。现有筛选合同最多10个标签、每个最多20字符；方案按此约束，不新增表或标签引擎。标签仅计划、未写DB；共同标签只用于筛选与并列分析，不表示等值或合成总分。#545原元数据不在本分支改动，后续统一标签由主线协调。

[teacher-report-copy-plan.json](teacher-report-copy-plan.json)提供教师实际／理想视角各“通常、困难、信息不足”三类原创文案。它们是未发布草稿，不是运行期R。实际版聚焦自我感知与可观察课堂片段，理想版聚焦可行目标；均给小行动、承认资源和情境限制，不诊断、不排名，不把自信或愿望改叫实际质量。当前只适用信息不足说明，不能生成画像或分数。

将来仅在既有教师本人接收者授权允许时显示自评报告；学生材料仍走对应独立报告与匿名、最小人数、发布规则，不把个体学生答案带入教师报告。师生并列还需同对象/时间窗及相应版本适用证据；不另造理想—实际差距指数或规范阈值。
