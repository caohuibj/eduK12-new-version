# IATPDI 2024｜独立简体中文工作译本

[原始英文表单](../native-forms.json)与[本次简体中文表单](native-forms.json)一一对应。六份中文表各有独立 ID，沿用原行码、选项键、顺序及可留空的数字表单行为。四档为从不、很少、有时、经常，分别保存为 r1–r4 类别。开放题保留原问法及长度上限。原参与者填答时未跳过题目。本项目沿用现有 Form 的可留空设计。

可选两种普通组卷：

- M2 34 题，配对英文 M2 组卷，顺序为评价、内容、过程、产出。保留原拟合模型划分及其删除的第 8 题边界。
- 表 1 的 35 项及开放题，作为可选组合保留 B08 与原文开放题。以六份现有题单组成，无需重复作答 M2。完整研究问卷还包含背景、策略、影响因素与资源部分。

组合采用现有无计分 Form，选项记录频次，开放回答记录原文，均供教师反思和后续获授权的定性或描述性分析。表中学习风格及多元智能相关术语照原著翻译，读者可结合学习任务和实际观察判断教学安排。
