# IATPDI：教师本人可理解的成长反馈草稿

接收者为填写本表单且获准访问自身记录的教师。其他接收者只能沿现有授权查看允许内容，family标签不授予管理者读取个体回答的权利。原研究没有学生平行版，不制造学生报告。

本片Form无计分，不会按回答自动生成正常/困难等级、能力雷达或教师排名。以下是原创情境文案，供后续已授权的事实回顾或教研使用；没有运行时报告版本，也没有真实答卷推断。

## 实践较顺利、记录较完整的情境

你记录了自己在评价、内容、学习过程或学习成果方面做过的一些安排。这份自评提供的是你对实践的描述，不能单独说明学生已经获得了同样的学习体验。某种做法更频繁，也不自动代表效果更好。

可以先保留一个对学生有帮助的具体安排，再找一份学生作品或一次简短交流来核对效果。一次只调整一个环节，看看还有哪些学生需要更多说明、练习或其他支持。

## 实施受限或感到困难的情境

有些做法暂时不常出现，可能与课程机会、材料、班级规模、时间或协作支持有关。这不等于你缺乏差异化教学能力，也不意味着学生需要被分成固定类型。

可以先选一个近期任务，明确共同学习目标，再根据学生已经理解和仍需支持的具体证据调整一步。若资源有限，可与同事讨论已有材料如何复用，不必一次准备很多套任务。不要为了让记录显得“更好”使用更多活动或学习风格测验。

## 信息不足、部分遗漏的情境

这次记录不足以支持稳定的实践判断。空白会保留为空，不会当作“从未实施”或0分；也不会据此判断教师能力、学生潜力或教学效果。

如你愿意，可以先补充一件记得清楚的教学片段，说明当时的任务和可用支持。仍不确定的内容可以不答。后续如有学生反馈或观察证据，应分别理解其对象和时间范围，不强求自评与他人看法一致。

## 四组可选微行动

| 题集 | 教师可选择尝试的一步 | 解释边界 |
| --- | --- | --- |
| 评价 | 用一道短题或一份作品了解学生已经掌握什么，再决定下一步支持 | 不建议以VARK、Kolb或多元智能分类推断固定学习类型；原文出现这些词不代表方法已获证实 |
| 内容 | 围绕同一学习目标，提供一个更清楚的例子或可访问的材料，并检查学生理解 | 多媒体可以帮助说明具体内容，不需要假设学生具有必须匹配的视觉/听觉类型 |
| 过程 | 在一个任务中提供可撤除的支架，再观察何时可以减少支持 | 分组和活动形式本身不等于深度学习；四因素高相关，也不足以识别互相独立的能力强弱 |
| 产出 | 允许一种合适的表达方式，同时用清楚的共同标准检查学习目标 | 作品更丰富或形式更多不必然说明学习更好；不按学生类型指定唯一表达通道 |
