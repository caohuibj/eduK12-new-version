# TALIS 2018 上海初中｜支持学生参与的自我把握

![学生围桌分享自己的想法，教师倾听。](hero.webp)

## 让学生有一个能参与的开始

有些学生愿意当众回答，有些人需要先和同伴说一遍。四题反映教师对支持学生投入活动的把握感。遇到参与少的情况，也值得了解任务有没有清楚的入口，以及学生能否得到所需支持。

## 怎样读这份反馈

对应上海 ISCED 2 原卷 Q34 的 A、B、E、G 四项。每题保留原四档 1–4，分别以该题的有效回答人数为比例分母。空白单列，报告只描述所收回答，便于教研讨论。

## 下次试一件事

选一次小组任务，给学生口头、书面或先与同伴讨论的选择。活动结束后看看哪种入口帮助更多人加入，再决定下一次怎么安排。

## 版本与适用范围

本项是面向成年初中教师的群体反馈导读，沿用同一份官方上海问卷。官方 T3SEENG 另有模型及转换，详见技术报告表 11.67；本报告止于原类别分布。表单题文由现有授权管理，分类汇总使用匿名计数。
