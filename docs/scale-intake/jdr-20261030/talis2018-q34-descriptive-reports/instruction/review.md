# TALIS 2018 上海初中｜调整教学方式的自我把握

![教师与学生一起对照不同的课堂材料。](hero.webp)

## 同一个难点，可以换个入口

一节课上出现不同理解时，有时换一种例子，有时问一个更具体的问题，就能看出学生卡在哪里。四题分布反映教师感到有多大把握去尝试和调整。

## 怎样读这份反馈

对应上海 ISCED 2 原卷 Q34 的 C、J、K、L 四项。每题保留原四档 1–4，分别以该题的有效回答人数为比例分母。空白单列，报告只描述所收回答，便于教研讨论。

## 下次试一件事

从一个学生容易卡住的知识点出发，准备两种解释。课上请学生指出哪一步容易理解，下次先改一处。可以请同事从学生角度看一眼材料。

## 版本与适用范围

本项是面向成年初中教师的群体反馈导读，沿用同一份官方上海问卷。官方 T3SEINS 另有模型及转换，详见技术报告表 11.66；本报告止于原类别分布。表单题文由现有授权管理，分类汇总使用匿名计数。
