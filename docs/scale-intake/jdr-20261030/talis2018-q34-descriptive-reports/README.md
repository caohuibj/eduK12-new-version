# TALIS 2018 上海初中教师问卷 Q34 分类反馈

三个题组分别绑定上海 ISCED 2 中文原卷 Q34 的原题码。原卷和各国译本由 OECD 分发，本目录提供独立图文导读、题码与选项数字字典、汇总表，不附题干或线上问卷。署明 OECD 来源并把项目原创内容与原题分开。

使用者可从获准使用的同一份问卷中提取各题四档人数和缺答人数，按目录样例填写 JSON，再运行 `node report-summary.mjs GROUP item-counts.json`。结果按各题有效人数显示比例，缺答单列，无有效答案时比例留空。仅输入同组同版的匿名计数，不提供姓名、答卷、开放评论或少量可辨认群体。

这套报告适用于了解教师自报感受的分布。完整四答时，研究项目若另作描述，可用 1–4 原分均值。发布的分类汇总不会还原任何个体均分，也不会输出 OECD 官方 CFA 指数、常模、跨校比较或给教师定级。正式指数的适用参数及完整题文的公开电子分发权限继续记录在目录清单。
