# JD-R 教师语境首批独立工具

目标是 main 中可重复装载的内容素材，不是生产安装或公共分配。10 个工具：CBI 个人、工作、服务对象耗竭；HSE 工作要求、自主性、管理者支持、同事支持、工作关系、角色清晰、变革沟通。各自稳定 key、独立版本和单一教师语境报告。原整份 CBI/HSE 源文件不覆盖。

## 内容与解释
CBI 的独立分量表沿原平均分、反向题和最低有效作答规则；服务对象不暗改为学生。HSE 保留选定分量表题项、原序、时间窗和方向，并明确为选用分量表的中文工作稿，不宣称独立短版效度。来源、改动及许可附注保留在各 source 中。无额外个人常模或阈值；不将群体工作环境基准伪作个人诊断。

每工具仅一个教师语境报告，文字提供结果解释、反思及可行建议；不生成标准/趣味双版本。现有报告结构不支持新的插图字段，故不混入共享运行时或假称已展示插图。真实得分与缺失沿原消费者表达。

## 已执行与范围
使用当前 main 真实 source parser、checkSelectedSource、计分及报告消费者，每项四个有针对性的样例；CBI 首次三项通过，HSE 首次因 reviewedAt 的 UTC 格式被结构拒绝，未执行计分。将 +00:00 改为同瞬间 Z 后只复验 HSE 七项，全部通过。原失败保留。CBI 后续仅将 executable.releaseStatus 设为可装载要求的 PUBLISHED，题本、计分和报告无变化。此字段不等于数据库 PUBLIC 或已经发布施测。

索引按既有生成器生成一次。初次从错误工作目录调用未找到 sources，改为 backend 工作目录成功；未手改索引。Node 24.22.1；本地原件由 DOT 保存。没有运行 PostgreSQL、浏览器、Docker、全平台测试或生产操作。本地结果不代替正式内容 CI。
