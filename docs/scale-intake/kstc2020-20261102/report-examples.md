# KSTC 教师成长反馈示例

这是原创反馈说明，实际运行时英文建议已写入各因素 R1.0.1。以下中文为项目说明，不是已验证中文题本或新量表。展示仍由现有接收者授权决定；不是自动向主管披露的个体评价。

## 正常完成例：科学探究

合成作答全部选择5时，探究因素均分为5，实际消费者输出一份因素解释、零份常模参考。这表示教师把相应行为报告得较频繁，不能证明每次都有效、学生都得到机会或学习成绩因此提高。

可以回看一个科学探究任务：学生是自己形成主张并寻找证据，还是主要照步骤完成？下一次请学生说出一个主张及能支持或挑战它的证据，保留一份学生解释，再决定需要怎样追问。次数更多并不自动表示探究质量更高。

## 困难／较少实施例：专业发展新方式

合成作答全部选择1时，均分为1，实际消费者仍输出非诊断的成长解释，不输出“能力差”或低等级标签。这是自报较少参与相应活动；时间、资源及机会都可能影响回答，原文“新方式”也不等于更高等级。

可选一个很小的课堂问题，邀请一位愿意参与的同事查看一个具体案例，利用已有备课时间讨论。不要求开展正式课题或额外增加工作量。记录这次讨论带来了什么实际调整，不把能否参与活动归为个人缺陷。

## 信息不足例：备课学习环境

合成作答少一题时，现有计分/报告消费者给出invalid、value=null，**不生成个人因素解释或参考**；不会给缺失题补0，也不把缺答叫作低能力。界面可沿现有完整性提示说明信息不足，本次没有测试或修改界面文案。

若教师希望继续反思，可自愿选一个实际备课决定，记录所需材料或安排及尚缺的信息。没有实施机会、不适用和不愿回答都不能被猜成较差教学表现。

## 各因素已绑定的微行动

备课环境：检查一项实验材料或座位安排与学习目标的关系；内容理解：用可信学科资料核对一个概念并讨论可能的误解；学生认知：先收集一份预测/解释，调整一个教学环节；科学探究：核对主张与证据；科学与生活：辨析一条公共科学信息的证据和不确定性；有效参与：先独立思考再讨论，并提供不同表达方式；评价实施：用一次简短评价调整下一步并再核理解；新方式发展：利用既有时间与同事探讨具体问题；传统方式发展：将反馈或培训中的一个想法作小范围尝试并记录结果。

这些行动不改变原计分方向，不作为优秀教师标准、诊断或绩效要求。没有跨因素总分，也没有把自认为理解或有效直接解释成客观知识和实际教学质量。
