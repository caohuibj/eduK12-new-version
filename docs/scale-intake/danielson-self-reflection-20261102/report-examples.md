# 教师成长反馈写法：原创草稿，未绑定 Danielson 执行报告

这些是项目原创的无分反馈示例，没有改写官方量规、提示或等级。它们展示证据限制和下一步行动的写法，不能据此推出官方工具或软件集成许可。缺原件时不能按这些文字反向造题，也不能生成某位教师的报告。

接收者为填答教师本人；仅在既有接收者权限允许时显示。导师、管理者或研究者不因这份草稿自动获得个体原话/附件访问权。未修改已有披露、匿名或群体最小人数规则。没有核到学生平行版，故不制作伪学生报告。

## 正常：已记录一段可回看的实践

你为一次教学尝试留下了具体记录，这能帮助你在下次备课时找到可调整的地方。先把“我做了什么”和“学生随后怎样回应”分开看：有了课堂记录，还不能直接断定某种做法造成了学习进步。

下一次可以保留同一个小尝试，再收集一份与你关心的问题有关的学习材料，看看原先的判断是否仍适用。无需给自己排等级，也不必一次改变整节课。

## 困难：预期与看到的情况不一致

这次尝试与你的预期有差距，值得继续了解，但不能凭一次经历判断你的能力或整体教学质量。先区分你已经看到的事实、目前的推测，以及还缺少的信息。课程安排、学生已有知识和当时条件都可能影响结果。

可以从一个可行行动开始：把下一次要调整的环节缩小，记录变化后出现了什么；如果需要支持，选择一位你信任且获准参与的同事一起讨论。学生没有充分参与时，不将原因直接归为学生不努力，也不把困难变成对自己的诊断。

## 信息不足：暂不能形成解释

目前可用记录还不足以支持关于这次教学尝试的判断。没有记录、尚未实施或本次不适用，都不能记作表现差，也不应补成零分。

如果你愿意，下次先留下一个具体事件或一份学习材料即可；可先记录“还不知道”，不需要为填满表单猜测。当前草稿不显示得分、常模、表现等级、排名或推断出来的学生体验。

## 实际验证范围

本轮仅核对文字面向教师成长、没有能力诊断/行政评级/数字分数，且每种情境包含可行行动与证据限制。未绑定 R 版本，未运行真实报告消费者；源题和授权齐备后才将反馈接到现有实际表单或量表路径，按正常/困难/信息不足与无分情形做必要定向检查。
