## 量表、表单与计分准备

原生量表候选：目前为零项已核定。需先核题码、完整题组、响应锚点、原作者或适用研究的计分依据，以及抽离后是否仍适用。论文自建指数不能自动升级为 CEPS 官方量表；原组卷中可算分也不证明独立施测有效。有疑义保留原组卷上下文、题序、时间窗和分支说明。

无计分表单候选：上述九个检索目标中的事实、频次、经历、单项描述题块，取得原文和合法使用范围后优先按原题制作无计分表单。缺官方计分、正式常模或独立施测效度证据本身不阻止无分表单导入，不将这些条件新增为表单门禁。真正阻碍是尚未取得可逐题核对的原题/选项，且实际使用与再分发范围未确认。频次或有序响应码不自动成为分数；不把表单塞进评分报告。完整问卷的家庭、健康、个人识别等非本任务内容不随主题表单一并导入。

## 发展性反馈草稿（非运行时报告）

[学生版与教师版六种情境示例](report-examples.md)分别说明接收者可见条件和一般体验、较低体验、证据不足的无分反馈。学生版按初中认知给出具体微行动；教师版限已授权群体汇总，不披露个体敏感回答。未绑定运行时报告，不改变既有权限、匿名、发布或最小人数规则。

无分表单仅反馈作答事实，例如：“你记录了本次学校生活中的经历。这些记录可用于整理你希望获得的支持，不代表教师能力或学校质量的分数。你可以选择一个希望改善的具体情境，与信任的成人讨论。”此文案不显示数字得分、优秀教师标签、红黄绿等级或排名。

若后续有依据建立原生量表，报告只解释该精确版本所支持的维度及方向，列明回顾期、缺失限制和独立施测证据，不能把分数变化归因于教师表现。未取得计分依据前不设计伪示例分数；当前未验证代表性报告消费者。
