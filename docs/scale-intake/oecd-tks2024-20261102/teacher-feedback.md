# OECD TKS2024｜教师自评无分反馈文案

填答者与接收者均为ISCED2教师本人。以下为项目原创发展性说明，不是OECD原报告，不是学生报告或已经上线的评分报告。原生Form保持`COLLECTION_ONLY`：可以显示教师自己实际选择的原选项、对应目标班级和Q27“上周”时间范围，不产生分数、百分位、优良等级或高低阈值。文案中的案例是明确标示的合成例子，不是实际填写者结果；只有其原始回答支持时才选用相应叙述。

既有授权团队如查看群体汇总，只能沿当前发布、匿名和最小人数规则处理，不自动取得教师个体回答或敏感开放文本。共同tag只用于找同源题块，不授权跨调查合并个体或计算总分。

## 通用开场

“这份记录帮助您回看一个具体班级中的教学经历。它呈现您对实践频率或上周目标达成的自我观察，不能单独证明学生学得怎样，也不能判断您的教学能力。不同任务、学生需要和可用时间会影响选择。可以先找一个值得保留的做法，再选一个小调整，用下一次课堂证据看看是否有帮助。”

## 常见情况示例（假设回答信息足够）

合成回答：Q24C口头/书面反馈选择Frequently，Q24D学生自评选择Occasionally；Q25C换一种解释选择Frequently；Q26B任务逐渐增加难度选择Frequently；Q27A清楚呈现内容选择Quite a bit。

“您记录了经常给学生改进反馈，并会在理解遇到困难时换一种解释。学生自评是偶尔使用的做法。这是您对这个班的观察，还需要学生作品或理解检查来判断效果。下一次可在反馈后留一分钟，请学生写出‘我改了哪一步，还需要什么帮助’；再留两份匿名作品，看看反馈是否转化成了具体修改。您对上周内容呈现的达成感较多，可同时找一题让学生用自己的话解释，补充另一类证据。”

这里不能据较频繁选项推导“所有学生已掌握”，也不能用Q27的Quite a bit改写成“教学质量优秀”。共享Q23的频率也不等于知识测验得分。

## 困难示例（假设教师确实选择较少/未达成）

合成回答：Q25B按需要提供不同材料选择Never or almost never，Q26C提前提醒练习难点选择Occasionally，Q27E适应不同需要选择Not at all。

“您感到上周在回应不同学习需要方面还有困难。这并不说明您不够努力或能力差；备课时间、资源、班级情况和课程要求都可能影响实施。可以先选一个近期最常见的难点，准备两种解释或一个额外例子，让需要的学生自愿使用；课后只记下‘谁仍需要支持、哪一步卡住’，帮助下次调整。如果资源或支持不足，可向同伴或教研支持者提出一个具体需要，共同解决。”

“无需把所有实践都提高到Always。先根据当前学习目标判断哪种做法适合，再观察学生是否得到支持。”

不责备教师，不把情绪/行为支持困难诊断成教师或学生问题。Q27F/G逐项保留原义，不能塞入T4FULFIL五项的因子解释。

## 信息不足示例

合成回答：Q25只有C一行有回答，其余缺失；Q27未答，或无法确认所指目标班级/上周授课经历。

“目前记录还不足以描述这一组实践，更不能推断您上周的目标是否达成。已填写的‘换一种解释’会保留，未填项表示缺少信息，不当作‘从未’或‘完全没有达成’。如果您愿意，可以在下一次该班上课后补记一两件具体发生的事情；也可以暂时保留空白。本表不会据此生成分数或评价等级。”

这里不把官方因子计分的“至少两项”变成无分Form强制补答门槛，单行原始记录仍可展示，不能从一项概括整个维度。

## 各题块可用的一步行动

| 原题块 | 合适的解释重点与一个行动 |
| --- | --- |
| Q22共享时间分配 | 仅描述教师估计的行政、秩序和学习时间；合计100%不是“教学效率分”。若需调整，可记录一次过渡环节实际用时，比较自己的估计；不设统一优秀比例 |
| Q23A–D共享清晰教学 | 选择一次课，在结束时请学生用一句话写出学到什么，查看与开课目标是否对应 |
| Q23E–H共享认知激活 | 选一道有多种解法的合适任务，追问一次“为什么这样做”，观察解释而非只看是否完成 |
| Q23I–L共享课堂管理 | 区分提醒规则的次数和学生学习状态；和同伴讨论一个具体过渡环节，不把安静程度当学习证据 |
| Q23M–O共享其他实践 | 生活联系、长项目、同伴论证需要适合的内容与机会，不要求每节课都有。选一个适合的时机尝试并观察学生参与 |
| Q24评价方法 | 各项单独描述，不把相对同伴排名频率当成正向质量。挑一次反馈，请学生据反馈修改一个步骤并回看修改 |
| Q25适应性教学 | 先收集一个常见误解，为同一目标准备另一种解释或材料，不给学生贴固定学习风格标签 |
| Q26循序练习 | 选择两个难度递进的任务，在中间加一次理解检查；根据错误调整支持，不要求机械重复直到所有人同速 |
| Q27上周目标达成 | 保留上周、目标班级与教师感知语境。选一个目标，寻找一件学生作品或简短理解检查补证，不外推全年、实际能力或学生总体成效 |

教师有授权的群体改进讨论可使用：“这次参与者对上周适应不同需要的感受存在差异；先核响应覆盖、班级和授课机会，再共同选一个可提供的支持。缺失不计为低体验，个体选择不向团队直接披露。”这段不隐含平台已经具备新的汇总器或已经满足发布条件。
