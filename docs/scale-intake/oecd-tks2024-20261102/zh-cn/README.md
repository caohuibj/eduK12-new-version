# TKS 2024 教学实践情境中文题单

公开 TKS 2024 未列中文参加方题本。四个主题按英文原件形成简中工作译本，并与上海 TALIS 2024 对应中文题项逐一比对。九题块组合复用五份同题项的中文版。

题本及合卷为原生无计分交付，配套图文用于教师回顾。各语种有独立键。项目材料保留原题序、公共变量、作答值、跳答规则及百分比合计约束。英文手册中的官方 CFA 分数及 TKS 公开本删节的教学知识试题保留既有材料状态。

OECD 官方问卷页指定书面使用条款。本批为非商业选择性摘编和工作翻译，保留署名、改编与英语原件为准说明及所需出处。原国际问卷留有 Restricted Use 页脚，发布范围为已核对的公开教育实践题块。上海教师题本 PDF SHA-256 为 25133b9a702687feb770bfe161255b097814b69911899bd031eb5743ae270b3b。上海版初中 Q50 与 Q51 的公开变量依据英文及代码本，上海页面分别标作 TQ_50、TQ_52。
