# RPQ教师成长报告：项目中文场景稿

这些是英文运行时报告的原创中文编辑场景，未作为中文题本或已验证中文版发布。场景不设自动阈值；实际数字取各组件的真实均分1–6，不产生母工具总分。接收者只限已有授权允许的本人或相应报告角色。

## 专业反思

较顺利时：你描述自己会在互动中及之后留意想法、感受和做法。可以保留一项有帮助的习惯，再用一个真实片段检验：哪些是观察，哪些只是推测？反思较频繁并不自动证明教学更有效。

遇到困难时：难以抽出时间反思不等于不负责。可以只选一次互动，记下一件已观察到的事和一个想核对的问题；时间与支持条件也值得被讨论，不必新增一整套任务。

## 专业自信

较顺利时：你较常感到准备充分，仍可以用学生回应或具体任务证据检查自己的理解；自信不是已经掌握一切的证明。

遇到困难时：较少自信不直接说明能力不足。挑一个实际卡点，请合适同事提供一个例子或一次具体反馈；不需要先提高分数才值得获得协助。

## 不确定与压力

较顺利时：你较少报告这些压力或不确定体验。可以保留一项有帮助的安排；较低均分也不否定你仍可能有需要支持的事情。

遇到困难时：较大均分表示这些体验出现得更频繁，不是反思能力差或心理诊断。先说清一个可澄清、可分担或需要资源支持的要求；不要把所有负担变成自我检讨。

## 工作满意感

较顺利时：工作中的意义感和愉快体验是值得保护的线索，不能据此推断教学绩效。可留意一项现实条件，看看如何保留它。

遇到困难时：满意感降低可能与工作要求、资源和生活责任有关，不能用单份问卷查明原因或催促职业选择。先选一个可行的支持或调整，不给自己下整体结论。

## 所有组件的信息不足情形

该组件有未答题时不计算均分，不补零，不显示虚假能力图或分档。其他已经独立完整回答的组件保留自己的结果。可以说明目前的信息不足，而不诊断动机、不要求反复测量以换取支持；原作者未规定缺失处理，本项目complete_required是实现选择。

本轮没有学生评教平行版，也不让学校管理者因这些文案读取教师私有自评。英文运行时报告和真实缺失结果的验证以execution回执为准，场景文案审阅不冒充真实HTTP授权或浏览器验收。
