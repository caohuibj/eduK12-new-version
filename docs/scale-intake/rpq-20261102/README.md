## 原始材料与许可

已实际读取[作者工具页](https://www.shanerogersresearch.com/rpq)、2024及2018作者Word题本／计分手册；扩展研究报告C06仅作线索，私有原文和链接不提交。作者页允许自由使用，无需正式申请许可。2024原论文 [Rogers等，PeerJ12:e16879](https://doi.org/10.7717/peerj.16879) 的官方EuropePMC XML明确采用CC BY4.0，允许署名条件下复制、分发、改编。全文题项的公开依据采用该论文Table6，作者Word用于逐项核对。

30项正文与作者Word在仅统一空白后逐字一致；短版Table5的10项等于扩展版前10项。因此短版直接引用同一反思10题组件，不另造同题副本。原作者、标题、出版来源、DOI及CC署名保留在每个定义中；组件拆分和项目报告不是原作者原版报告。取得方式、哈希与来源访问失败见 [source-evidence.json](source-evidence.json)。PeerJ网页403、PMC网页验证页未被绕过；使用EuropePMC公开全文API读取公开论文，不登录、不付费、不接受新条款。

本轮保留英文原题和原频率选项；原指导语明确教育工作中的client应理解为student，已完整绑定指导语，而非擅自改题。没有已验证中文版；中文名称与[中文报告场景稿](report-scenarios.md)是项目编辑材料。

## 拆分及普通组合

| 原生子项 | RPQ-E原题号 | 原计分 | 方向 |
|---|---|---|---|
| 专业反思 | 1–10 | 等权均分1–6 | 较常自报反思，不是更好的教学 |
| 专业自信 | 11–18 | 等权均分1–6 | 较常感到准备充分，不是客观技能 |
| 不确定与压力 | 19–26 | 等权均分1–6 | 较常不确定／压力；不反向改成健康分 |
| 工作满意感 | 27–30 | 等权均分1–6 | 较常感到工作有意义／愉快，不是绩效 |

六级频率锚点为作者2024版，全部题项同向，无反向题。作者未给缺失规则；项目采用明确的complete_required：该组件有漏答则均分null、不补零、不插补；不影响另一独立完成组件。项目时长估计和该缺失策略不冒称作者规定。

可选普通组合按上述顺序引用4个子项，保留原30题内容与顺序；没有RPQ-E总分或跨工具总分。原量表没有额外背景／开放题，本轮不为凑齐表单创造“RPQ原题”。组合清单不等于实际发布。拆开施测属于项目包装，不能自动继承完整30题协议的效度；研究原扩展版时应保留原组卷语境。

手册还允许将自信分成一般／沟通自信，将不确定／压力分成压力／不确定，各4项。本轮不重复登记这些重叠题项的另一套施测包；原题号和可选细分事实保留在inventory中，当前输出仍是4个作者主分数。

## 2018版独立处理

2018原版为40题、10个四题子量表，另有6题督导体验评价；完整作者手册已读到，不称缺题本。它采用程度／符合度响应，2024采用频率；旧工作满意度题37反向，2024满意感四题均不反向。原40题、督导评价及2024的30题不能共用题号或参数。详见 [legacy-2018.md](legacy-2018.md)。

本次选定当前2024版进入原生候选，不将2018旧协议额外安装进当前组合，也不将旧四个反思分量表拼回2024短版。没有把两个年代的分数当成等值纵向数据。

## 报告与边界

运行时为教师成长取向的英文报告：解释本人自述与真实实践证据的区别，提供一个可行微行动，承认工作负担和支持条件；不通过反转压力来“鼓励”，不将低自信诊断为能力差。无常模、无自动高低档、无同龄／同行排名。正常／困难／信息不足场景见report-scenarios，属于条件示例，不是虚构个体结果。

报告格式面向教师SELF；接收者仍由现有身份和行级授权决定，不给其他教师、学校或研究者自动读取个人数据的权利。没有原生学生评教对应版，不从教师题改人称造学生量表。
