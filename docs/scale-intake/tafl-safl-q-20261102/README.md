## 计分：原文事实与项目规则分开

原文方法p.10明确五点Likert，1=strongly disagree，5=strongly agree；附录未印2/3/4完整文字、原指导语和原始排版响应表。私有研究原型仅呈现数字1–5，并以明确标为项目说明的指导语注明已知端点，不杜撰中间选项文字。它尚不是忠实复现的正式施测表。

原文报告分量表均分并讨论配套版本均分；本原型采用两分量表各自等权原始均分，理论范围1–5，越高为对该维度实践陈述的更多认同。原项未标反向，使用identity，不造反向题、权重、CFA因子分或0–100。没有找到作者缺失/无效作答手册，因此完整作答才计算、任一缺失不补0或插补是**项目保守规则**，不是冒充原作者规则。无常模、好坏阈值或跨维度/角色总分。

原样本为荷兰职业中等教育，学生11–18岁、中位14，教师22–65岁；年龄为描述样本范围，不是原作者允许施测的硬年龄标准。论文的跨角色结构证据局限于该研究及其荷兰语版本，不移植为英语/中文或所有中国K12等值。作者还提醒学生嵌套班级，整体简单均值差可能有偏；共同标签不自动生成师生差分解释。

## 教师与学生报告

报告解释的是当前班级的形成性评价实践**感知**，不能把自信、意图、价值或自述改叫实际教学质量。私有原型实际调用现有buildScaleResult，按角色得到teacher/student报告受众。正常/困难时保留原始均分与描述，无分档；信息不足没有分数和解释。无referenceSet或常模。当前只检验后端报告对象，没跑浏览器排版、下载或外部参与者流程。

`report-examples.json`另给教师/学生各三种情形的中文编辑文稿，便于审阅语气；不是中文版量表、冻结R、已开放报告或分数阈值。教师选择一个具体任务、观察学生如何使用反馈、尝试一个小调整；学生可请求示例、说明下一步或寻找可信成人支持，不为不公平/不当对待负责。教师自评给本人；学生报告给本人及已授权接收者，教师接收学生资料仍遵循原匿名、最小人数及群体汇总规则，不因family标签互相开放。
