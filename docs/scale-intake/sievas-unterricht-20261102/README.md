[source-index.json](source-index.json)记录全部17条官方链接、读取结果、题量、快照hash和PDF链接。公开学生预览的105块仅登记标题/题数/角色/反应类别类型，见[component-plan.json](component-plan.json)。这个数量是页面组织块，不是105个已验证潜变量量表。

## 教师版与拆分计划

[官方使用说明](https://sievas-unterricht.de/de_DE/unterricht/anwendung.html)明确“从教师视角回答”为可选步骤；[概览](https://sievas-unterricht.de/de_DE/unterricht/befragungen.html)说明可与学生反馈比较。公开17份预览没有给出教师角色的完整题文，不能把学生主语替成“我”，不能照搬学生题数或把教师对学生体验的推测当教师实际行为。

现登记17个教师问卷候选身份，分别绑定原索引/学段/学科，教师题数为null。拆分要等合法取得该角色原块和原措辞后进行，不把学生105块假充为已取得教师版。若完整题文、原选项已允许处理但仍无计分合同，按用户要求走原生无分Form，不需要等待常模。若计分原件随后齐备，再按原维度使用现有Scale与C/P/R。

各项名称统一“SIEVAS-Unterricht｜子项｜教师自评/学生填答｜学段与来源版本”。共同`family:sievas_unterricht`只准备在现有tags字段使用，另含角色、学段、学科、德语、未署期快照、成长反思与书面许可待补。当前是计划元数据，**没有写入DB标签或新增标签引擎**。17个教师候选和105个学生来源块也没有变成平台注册工具。

可选普通组合只在同一角色、语言、学段和来源版本内保留原块组织；源平台允许Baukasten选块，不能据此宣称心理测量独立施测等效。不同角色/学科并列不算跨工具总分，不自动计算自他差距或强制配套。

## 计分与反应格式

公开学生预览混合四类频率、四类认同，各另有“不能判断”。这不是五级有效分数，不能判断须独立保留，不编码成最高、最低或填补零；未答与不能判断也应分开。教师版完整反应协议尚未核，不能复制学生协议为已确认教师协议。

官网列QuAIT四领域，并显示通用17个实际页面块；不把四领域强拆为四个验证分数。一般模块包括沟通清晰、知识联系、形式结构、兴趣/生活联系、错误文化、无恐惧氛围、方法、师生关系、投入、期望、差异化、了解学习需要、个体进步参照、反馈、时间、课堂管理及课内外任务。

[反馈说明](https://sievas-unterricht.de/de_DE/unterricht/r%C3%BCckmeldung.html)描述图表与表格、自他比较和突出差异，未提供完整题号键、反向、聚合、缺失或阈值协议。原平台有报告不等于项目已掌握算法。方法使用频繁或任务检查多不自动更好；无恐惧氛围也不是学生心理诊断。当前不编范围、反向、常模、优秀教师排名或教学质量总分。

[比较说明](https://sievas-unterricht.de/de_DE/unterricht/vergleichsm%C3%B6glichkeiten.html)要求至少50份外部同类调查才显示其平台参考比较，并可放宽相似情境。这个50不是本项目班级最小人数规则，也不是现成可移植常模；没有取得参考数据，不生成本地百分位。

## 许可与精确缺件

[官方使用条款](https://sievas-unterricht.de/de_DE/start/nutzungsbedingungen.html)§3(6)写明：

> Diese dürfen nicht ohne schriftliche Genehmigung des LaSuB weitergegeben werden.

§2允许注册用户用于自身职业实践反思，不能自动解释为对第三方平台、翻译、商业嵌入或公开GitHub再分发的许可。仅阅读公开条款，未注册、签署、登录、发邮件或请求验证码。Impressum中图标CC4.0声明仅针对Font Awesome图标，不移植为问卷许可。

继续实际导入需要：

1. LaSuB针对本项目数字施测、存储、翻译/适配、公开分发的书面范围；若仅私有授权，原题走授权内容路径，不放公开PR。
2. 三个学段各通用与学科教师角色的完整原题、选项、说明、角色切换规则、原始版本/日期。学生预览不代替。
3. [5–6年级生物预览127](https://sievas-unterricht.de/de_DE/fragebogen/voransicht/127.html)的可用官方原件；原链接在普通下载和网页读取均HTTP400，未猜其他题本ID。
4. 如需计分：原题号/块对应、反向/不适用/缺失、聚合与自他比较协议及报告方法说明。仅此项缺失时，内容和许可齐备即可先原生无分Form，不把常模当门槛。

教师与适龄学生原创反馈草稿见[report-examples.md](report-examples.md)，均未注册为实际报告版本。既有接收者授权、匿名和最小人数规则不变；原平台教师专属结果不因提供文案自动向学生开放。
