# 成长反馈草稿及接收者条件

原创中文草稿，未经过德文题本翻译验证，不是SIEVAS官方报告或运行R版本。没有分数、数值阈值、自动分档或渲染结果。以下状态需依据合法取得的真实回应及情境，不能靠无分表单强造分数。

**角色与可见条件。** 教师自评只给已有权限允许的教师本人；学生填答不等于学生获准查看原平台报告。原平台说明结果教师专属、学生匿名。本项目不自动开放任何结果。教师仅在现有授权、匿名、发布与最小人数规则满足时看学生群体汇总；个体意见、恐惧感与敏感开放回答不直接披露。学生草稿只供已有规则允许的适龄反馈或教师选择分享的匿名课堂对话；当前未生成个人测评分数报告。没有授权时仍不可见，不新建授权规则。

## 教师本人或已授权的群体反馈

- 一般支持证据：你记录了一些帮助学生理解任务和获得反馈的做法。学生的群体反馈若可用，提供的是另一种课堂体验线索；两者一致也不单独证明学习效果。选一个近期任务，保留匿名作业样本，并检查学生能否说清下一步。
- 实施困难或较低体验：某些回应提示任务理解、提问机会或学习支持还不稳定。先了解具体情境、机会和资源，不能据此给教师或学生贴好坏标签。下节课可只试一项改变：把任务目标和例子写清，并安排一次可选择、不公开个人困难的反馈机会。
- 信息不足：目前回应不足、不能判断较多或情境不匹配，无法作可靠解释。留空与不能判断均不按零分。先确认参照哪一节课、是否有实施机会，再决定需要什么证据；不补造平均分、比较或能力结论。

无分Form只回顾原始回答、情境和可行行动，不生成心理测量分数报告。方法更多、使用更频繁不等于每次更适合。师生感受不同不自动说明谁判断错误，也不要求学生证明教师不当行为。

## 学生3–4年级

- 一般课堂体验：这些回应说的是你感受到的课堂，不是给你评能力。如果有一种讲法帮助了你，可以告诉老师：“这个例子让我更明白了。”
- 较低体验：有时听不懂或不敢问，会让学习更费力。这不表示你不聪明。你愿意时，可以请老师再举一个例子；如果你常感到害怕或受到不公平对待，可以找信任的大人帮忙，你不用自己解决。
- 信息不足：有些事情你还不能判断，没有关系。可以想一想最近的一节课；如果还是不清楚，就保留“不能判断”，不用猜。

## 学生5–6年级

- 一般课堂体验：你能留意哪些课堂支持对自己有帮助。可选一次任务，记下让你理解要求的提示，并在合适时表达需要。
- 较低体验：有些课堂安排可能没有满足你的学习需要，这不等于能力不足。可以具体问：“这一步能否给一个例子？”不公平或让你害怕的情况不是你的责任，需要时请可信任的成年人支持，不要求你与教师对抗。
- 信息不足：这次信息还不够，不能据此评判你或教师。可先确定讨论的是哪门课、哪段经历，不确定的回应保留为不确定。

## 学生7–10年级

- 一般课堂体验：你提供的是对课堂经历的看法。可以选一种有效支持，例如清楚的任务标准，描述它具体帮助了哪一步；这比给教师笼统打好坏标签更有用。
- 较低体验：若任务节奏、解释或反馈让你难以参与，可以在安全、合适的场合表达一个具体学习需要，也可通过已有反馈渠道提出。若涉及不当对待，寻求可信成人支持；你无需为修复不公平承担责任。
- 信息不足：当前证据不足，不生成优劣或能力结论。只补充你愿意且确实记得的具体经历，不要求提供同学隐私或敏感个人材料。

上述文字不改变原题方向，不把强权、恐惧或不满变成学生标签。没有跨来源总分、学习风格分类或多元智能匹配建议。
