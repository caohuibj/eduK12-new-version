- 当前框架按C引擎/评分身份解析一个推荐呈现，随后将完整呈现与R阅读规则写入冻结快照。没有新增独立R选择器；第四组最终生成清单后，新冻结使用R2，已有冻结仍使用嵌入旧文案。缺旧快照的legacy适配继续读未变通用定义，不把新文字回填旧记录。

## 时长与短版可靠性边界

所有估时均是源码推导，未作被试墙钟测量。人工练习反馈、重练、打字、持久化/渲染重试会增加时间。原estimatedMinutes仍为未校准预算，不移用论文施测时长。

一个可复算的规划情景：每项说明+一次练习+反馈共90秒；倒背/运行广度每题回忆8秒；图片/配对/词表每回忆轮30秒；句图每题2秒；序列反应0.5秒；字母数字回忆15秒；视觉判断1.5秒；音反应0.3秒且平均等待2.5秒。假设倒背走满、不重练、不含网络保存；不是人群平均或产品承诺。

## 不能被文案掩盖的待修项

1. **sentencecheck 条件混淆（核心设计，未修）：** 前端 `tasks/sentencecheck/prng.ts:58–65` 同步交换真假/否定数组，当前各档两者完全重合。应由C负责人给新刺激身份并平衡交叉条件、同步服务端验证；不可原地改旧冻结。R2已隐藏差值、明示限制，但正确率仍受线索影响，不能宣布该工具科学验收完成。
2. **visualwm 首题练习泄漏（核心流程，未修）：** `VisualwmTask.tsx` 练习/正式均用同seed+index0。应隔离练习随机命名空间并明确新C版本，R2先如实披露。原dual-contracts虚列K/d′、质量定义“正确RT”与scorer含错误不一致，也交C负责人，不原地改旧定义。
3. **auditorynback 体验目标不足：** 没有最小目标保证。仅改题量或降低门槛都不能冒称可靠；本轮使用原质量门槛、保留计数、限制d′解释，不改随机过程。研究协议仍是变式。
4. **文献旧书目：** runningspan治理材料的“Bunting(2003) JEP:LMC”未核实；本报告采用实际可读的Bunting/Cowan/Saults(2006) QJEP，不把旧书目当已验证。
