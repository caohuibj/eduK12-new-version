Unknown source, dependencies, homepage, deletion and mode changes fail closed. The two default CPU caps now total 3.5 cores across the default five services; live experimental multiprocess limits are unchanged. One isolated new-schema backup/restore contains a legacy pending unit, a compact pending whole receipt and shared control binding, a completed compact result and templates, and a shared Cognitive runtime.
