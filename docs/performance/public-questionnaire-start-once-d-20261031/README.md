## 确认的问题及最小补修

原入口在 POW 返回后立即 setPowLoading(false)，START POST 还未返回时，开始按钮
就重新出现。合成例再次点击可得到2次 POW和2次 START；首个 loading 渲染前的连续
点击也会启动两次 POW。这是同一页面中可操作的重复请求，不声称服务器实际创建了
两条答卷、重复扣额度或生产请求的频率。

本补修以本页 ref 阻止在途重复开始，pending UI 持续覆盖 POW 和 START，当前请求失败
后解除，可明确重试。成功后维持 pending 等原浏览器跳转，不再中途开放第二次开始。
没有新弹窗、认证、POW算法、API、幂等框架或后台修改，原请求字段完全保留。

为避免在途标记影响另一公开入口，同时核了 token 切换：旧 POW 不能在离页后再发
START，旧 START 错误不能解除新入口的 pending 或显示为新错误。入口代次在切换/卸载
时失效。已经发出的合法 START 不取消；若收到旧入口成功响应，仍按其原 token 保存
恢复凭据，再停止旧导航，不丢掉已取得的合法会话。恢复存储和服务端规则不改。
