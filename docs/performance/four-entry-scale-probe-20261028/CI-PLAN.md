only for PR374, installs the locked frontend/release-tool dependencies from the
official npm registry and the Ubuntu CJK font package. It uses the runner's
installed Chrome, `chromiumSandbox:true`, and the existing active sandbox reader.

host, backend replay, new database service, image build or deployment.

5 minutes. Source and current SAST keep their existing limits. Five minutes is
an alert/diagnosis point, not a fabricated promise that all CI ends then. All

failure fails the required admission job; screenshots and partial observations
are uploaded even on failure. The stable gate still requires source, admission
and SAST success. Main post-merge uses the existing bounded source continuation.
