# Whole V2 交卷复测

main 后端与先前 e0f4b5e29 的 Git tree 一致，原候选对照为 #816 的 f2ff8ebfa。通过复测的批量核验补丁已纳入 #816，后端生产差异与实验副本一致。

每端分别按每秒 30 次运行 30 秒，每秒均发出 30 次。每轮 4 次预热和 900 份新的 303 题、9 量表作答，真实 Training / Teacher 授权、V2 HTTP 和 PostgreSQL。Teacher 在交卷后直接请求反馈。两个实验及重复对照恢复自同一份 Training START 后快照。

实际环境为 4 核 CPU 配额、16 GiB 内存硬限额。应用限额为单进程 Node heap 384 MiB，连接池 12，整卷准入 9。结果仅覆盖后端压测路径。
