# TOSA 0.4.2 完整工具｜计分算法、分析与解释手册

本候选使用 WD 指导语：在给定时间、权限与资源下，现实中最可能先做哪一步。它测得模拟选择和自述，不能当作课堂观察、真实履职或 SHOULD（应当怎样做）的适切性判断。15个母情境独立；完整工具顺序连接15个母情境，保留各故事的独立指标。版本0.4.1保留v0.4题面与51项审阅修订，新增原生兼容、明确算法与训练反馈；不把两版分数混用。

## 三层证据及不计分项目

第一层是可复核的描述编码：选项明确出现某行为记1，未出现记0。它不是优劣、能力或人格分。第二层是适切性判断：需要教师和任务专家独立判断情境约束、可行性、收益代价与不可接受风险，目前为UNSCORED，不由“主动、公开、加班”机械确定好坏。第三层是心理潜变量：SEL、建言、主动变革、OCB与窄人格假设只保留机会矩阵和竞争解释；未估计因子得分、载荷或测量误差。

每轮四选一的A/B/C/D是名义类别。选项经过固定轮换，原字母保存在source_option_key中；字母无顺序、无1至4权重。两个额外选项UNABLE_TO_JUDGE与DECLINED是非回答，不能编码成0。固定轮换不是已经验证的社会赞许控制。

## 可执行计分规则

对母情境s、实际到达节点r、行为原子a，定义 c(s,r,o,a)=1 当且仅当被冻结选项o的文本明确包含该行为；否则为0。完整的192×20作者键见[动作编码键](action-key.md)，每个1均可定位到对应选项全文。所有行为原子权重为1，无反向计分，无负分。一个选项可以同时包含多个原子；因此原子不可相加成总分。

机会集合 O(s,a) 包含实际路径上至少一个实质选项被编码为a的节点。未到达分支不进入机会集合；到达但四项均不含a的节点也不进入。A(s,a)是O中已给出实质行动的节点。

原生算法 AUTHOR_KEY_SUM@1：当 |O|>0 且 |A|=|O|，指标值为 Σ c(s,r,所选o,a)。否则value=null，status=not_calculable。相应期望/已答机会数保存在coverage及expectedResponses/answeredResponses，已答节点贡献单独保存在contributions。不能把null转为0，也不能仅看整数而忽略机会数。可展示“在本故事可观察到的m次机会中，有k次所选文本包含该行为”，不能称“k/m能力达标率”。

若同一原子在某节点所有四项都是1，此节点只能记录行为存在，没有区分度；当前键须在人工审定中检查这类节点，不因该原子常见就增加权重。原生range由每个机会中实际选项的最小/最大贡献相加，未强制假设范围总是0到m。

主指标tosa.action_count仅检查本故事是否完整记录实质行动：每个实际到达节点贡献1；任一已到达行动非回答则value=null。它不是心理结局。该指标为主指标是为了使用原生完整性判断；quality=invalid只表示不能完整计数，不能解释为教师回答无效、能力差或不诚实。报告仍描述已经回答的部分。

严格完整规则按每项指标分别判断：如果后面拒答的节点不提供某原子的机会，之前该原子的完整值可保留；若提供机会则该原子value=null，之前贡献仍可见。因此“整份有非回答”不意味着抹掉所有已知描述，也不意味着给未答机会补0。

## 独立场景、跨轮与路径可比性

服务端FINAL把sceneKey映射回motherSceneKey，因此同一母情境2至3轮的独立场景数最多为1。48个节点不是48个独立测量题，42个被呈现轮次不是42个独立情境。分支由前序行动决定，是内生选择；不同分支的整数计数及比率不默认可比，不能把某路径当作随机实验条件。

同一个人不同节点的变化只能描述“新增信息后选择怎样变化”；不能说明训练、调节或事件造成改善。共同汇流节点仍保留前序路径身份。正式组间分析须先按冻结版本、WD/SHOULD条件、角色和路径报告机会分布；需要潜变量模型时，应在足够独立母情境与样本后预注册，并检验局部依赖、测量不变性和条件选择偏差。

## 可选追问

96个追问均为RAW_ONLY，不进入AUTHOR_KEY_SUM、不改变分支。它们仅在行动确认后出现；现有界面需要确认追问阶段后继续，追问可以全部跳过。若行动选择非回答，后续故事结束，但仍需确认本轮追问页。当前包没有假装支持自动跳过追问的界面能力。

有序1至5仅表示题干所问程度：情绪强度高不等于调节差；效能高不等于实际有效；责任感高不等于必须接任务；角色正当性不等于个人意愿。锚点相同也不自动等距。报告用类别与原始文字，研究首选频数/比例、有序模型，必要时使用中位数与四分位范围；均值与线性模型只能作为明确假设下的敏感性分析。

担忧类别、归因、价值优先等名义题无高低。OTHER为有效名义类别；不强迫归入现有类别。显式“无法判断”“选择不回答”、未到达、计划未呈现、呈现后跳过分别保留。系统原生导出保留missingness与原始响应，分析时再按题目字典处理；不得把不同原因统称0或缺乏特质。

仅T02/T05/T07/T08在题干与锚点完全相同时启用同故事两时点的类别变化。报告写“类别相同／上移／下移几档”，不写情绪调节成功率；缺任一时点则不计算变化。不同情绪、成本、价值、效能之间不求和，不作真实性或人格测谎。

## 分析计划与校准条件

先做教师认知访谈：是否能在题面给定时间与权限下实施、前序行为是否一致、哪项被识别为“显然正确”、追问是否被误读成评价。让两位独立编码者盲读选项进行20原子的多标签编码，先报告原始一致率、分歧表、标签基率及机会识别一致性，再选择适用的一致性统计；未测得前不填系数。

试点先报告每轮选项比例、非回答与跳过比例、路径流失、完成时长分布与探针类别分布。完成时长不设“认真作答”切点；超短或超长只能作为待核实流程现象。对低选择率或明显优势选项优先访谈，不能仅凭低频删除内容必要的合理退出。

心理构念关系应分别验证：建言与主动变革的区分、本职任务与额外角色行为的区分、主张性与公开渠道的区分、责任与无边界投入的区分。收敛/区分/效标证据需获得合适且获授权的外部测量，避免共用自报方法造成虚高。预测或因果结论、常模、切点和个体可靠性均未建立。多指标探索应注明探索性并控制多重比较；样本量需根据预定模型、分支暴露与精度需求设计，不在没有参数时给出虚假精确人数。
