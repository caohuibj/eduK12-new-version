# 教师参与指导语

这些都是虚构且独立的故事。请按当前时间、权限和资源，选择现实中最可能先做的一步。四项不是好坏排序。行动确认后才出现可选追问；追问不会改变后续情节。信息不足或不愿作答，可结束当前故事的后续轮次（线上仍需确认本轮可跳过的追问页，再进入下一独立故事）；未答不补零。本任务用于研究和形成性反思，不用于招聘、绩效排名或诊断。

完整工具含15个独立故事；每个故事2–3轮。新的信息可能使你调整行动。行动一经确认，才显示该轮可选追问；追问可留空，确认继续即可。选择“无法判断”或“选择不回答”会结束当前故事其余轮次，再进入下一故事。

请根据题面设定判断，不必把这些虚构故事理解为学校要求或对自己的履职考核。报告帮助你观察取舍、练习沟通和资源协调；某种行动出现更多不意味着更优秀。
