# 教师反馈与练习

状态：作者提出的形成性练习，尚未验证为有效干预。实际报告由 instrument.json 中的冻结 report 配置按实际路径、已答证据及机会生成；不作人格贴标、排名、诊断或跨工具总分。

反馈顺序：回顾你实际选择的文字及可能收益和代价 → 说明本故事中该行为出现的次数与机会 → 区分行动、追问和缺失 → 选择一个可执行练习 → 安排一次迁移复盘。无回答的部分写“目前没有足够信息”，不补零。

## 动作练习

### BOUND

用3分钟把这次边界改写为一句可沟通的话：“我能在___前做___；目前不能承担___；如仍需要，请一起确认___。”请同伴复述他听到的承诺，检查是否仍有隐性加班或责任悬空。

### COORD

在纸上写三列：谁确认事实、谁决定、谁在何时反馈。用一次5分钟沟通确认对方愿意承担的部分；未得到同意的任务保持待定，不把发送消息当作交接完成。

### VERIFY

用5分钟分开写“已知事实／我的解释／还缺的信息”，只选一项会改变决定的信息去核实。预先写下两种可能结果及各自下一步；本次不要求把所有事实查清。

### ASK

和同伴做两轮各2分钟的倾听练习：先用一个不预设原因的问题，再复述对方的需要并请其纠正。记录一次自己改动的解释，不以让对方同意作为成功标准。

### RISK_VOICE

先私下演练一段30秒表达：“目前看到___；如果继续，可能影响___；我还不确定___；建议先确认___。”让同伴指出哪句是事实、哪句是推测，再选择安全且有权限的沟通渠道。

### IMPROVE

把建议缩成一页：要解决的具体困难、保留的做法、一次最小尝试、需要谁同意、何时停止。找一位使用者问“哪一步增加了你的负担”，据此删去一项要求。

### PILOT

为一次自愿试行写出范围（一个班或一个任务）、时间上限、一个观察信号和停止条件。事先征得参与者同意，复盘时同时记录收益与新增负担，不用单次成功证明方法有效。

### REVIEW

在日历中约一个10分钟复查点，写清届时只查看哪份证据、谁愿意参加、哪种结果会使你调整或停止。没有时间或资料时可取消复查并说明原因。

### SHARE

把可分享材料压缩到一页，标明适用条件、仍有疑问的地方和使用者可自由改动的部分。请一位同事试读，记录他真正用上和未用上的各一点，避免只追问“有没有帮助”。

### DEFER

给延后补上一个可辨认的触发点：“当___出现或到___时再处理；此前由___维持基本安排。”模拟触发点没有出现的情况，检查是否需要主动告知相关人。

### GENERAL

选出这一步最想保留的收益和最担心的代价，各写一句。与同伴交换角色演练2分钟，再写一个在时间不足时仍可完成的最小行动。

## 情境迁移

### T01

下次遇到重复表格时，只记录一次填写耗时与重复栏目；先确认法规或校内用途，再决定保留个人复用还是共同试行。1周后检查是否减少重复，也检查是否把工作转给了同事。

### T02

用匿名案例分别练习回应家长、询问孩子和与班主任分工。每次先说明已知与待核实处；次日查看孩子是否愿意采用安排。孩子的同意与课堂参与都是反馈，群里安静下来不是唯一目标。

### T03

在一次作品展示前提供可退出的参与方式，私下询问学生愿意怎样被看见。检查“匿名”是否仍可能被认出；学生拒绝展示时，以尊重其选择且保留参与机会为练习结果。

### T04

下一次公布表扬前，用两个虚构记录练习区分阅读表现、记录条件和评奖规则。请有决定权的人确认表述；复查是否有人因记录机会不同而受到不恰当比较。

### T05

选一节课的一次讨论，只观察谁得到准备和发言机会。若调整安排，保留内容难度和可用时间的记录；课后询问两名表达方式不同的学生，不把发言人数增加直接当成学习提高。

### T06

在下次协作任务开始前约定缺页/延迟时的交接清单：最小可交付内容、求助截止点和可拒绝范围。完成后比较谁实际承担了额外工作，而不只看最终材料是否齐全。

### T07

请可信同伴就一个课堂片段分别说出观察与解释，自己先复述再回应。选择一条反馈尝试一次，保留未支持它的证据；不需要当众表达“接受所有意见”。

### T08

用同一个课堂打断片段演练“先恢复任务、稍后核实”与“短时当场询问”两条路径。请同伴扮演被误解的学生，检查措辞是否给其纠正事实的机会。

### T09

选择一周，与相关人约定晚间信息的紧急标准和次日回复时段。只记录实际例外与第二天是否补上必要支持，不记录家长姓名；边界有效也包括休息得到保留。

### T10

用两份匿名迟交例子区分学习掌握、时间规划与记录规则。练习向学生解释可以申请的安排及不变部分；1周后看计划是否可执行，不把一次按时提交推断为责任心提升。

### T11

在一次自愿集体活动前写明自己愿意贡献的资料、时间上限和不承担的协调事项。活动后问使用者哪项资源可继续复用，允许选择下一次不参加。

### T12

对一个小组分歧做3分钟角色互换：先说出对方担心失去什么，再提出能由谁决定的小试验。记录未达成一致的事项及后续处理，不把表面一致当作合作成功。

### T13

选一项可能让部分学生失去参与机会的流程，以不含姓名的证据写一段风险说明。先核对替代方案所需资源，约定一轮试行的退出条件，并看资源较少的班级是否也可实施。

### T14

与可信同伴演练在权威意见下表达专业保留：一个具体风险、一处不确定、一个低负担替代方案。事先决定何种渠道与时机可承受；如果风险过高，可先记录证据并寻找支持。

### T15

给自愿反馈卡试行设一个“继续／简化／暂停”复查点，收集一位使用者和一位未使用者的意见。只保留有人愿意维护的部分；暂停试行也可以是资源判断后的合理结果。
