## 只选一个专题即可

48 个工具＝12 个专题（T01—T12）×每专题两个母情境（CJ01—CJ24）×SD/WD 两种独立条件。一次按当前问题选一个专题，再选一个贴近实际的情境和一种条件；完成三轮即可。不是48项必做问卷。`inventory.json` 给出专题、条件与准确登记路径；相邻两个 CJ 属于同一专题。

SD问“你认为下一步较适切的是”，WD问“现实中更可能先做的是”。两种条件不能混为一项总分，不能作差推断诚实度。O课堂观察、J情境选择、R反思分别解释。课前、课中、课后短表可以分别选用，不强迫全填。

## 如何理解结果

24个指标是**选项文字是否明确提出某教学动作的描述性内容编码**，不是已验证心理因素、适切性分或能力分。包括对未来行动的明确安排；不证明已执行或执行得好。每次实际出现机会权重1；选项未明示记0不代表教师缺陷；不存在机会、不适用、退出或证据不足不能补零。实际到达的适用机会有U/N时，本指标返回null，保留此前叙事证据。不同路径机会不同，不排名、不跨工具加总。

报告按真实选择展示代价、现实限制和具体的小练习。当前浏览器走原生叙事报告，不显示动作次数图表或能力等级；API/导出保留次数与机会。动作更多不代表更好，不按次数推荐训练。算法、操作定义、映射、权重、缺失和逐步计算见 `docs/` 与 `mappings/`。

## R1原研究探针与交卷后反思

原研究版R1探针保存在六册修订研究题本中，未无声替换。运行SJT不施测该探针；可选表在交卷且看过反馈后另行填写，可能受到反馈、事后解释和记忆重构影响，不能推断未经反馈时的真实动机，也不能与原R1探针合并分析。CJ01-SD 0.4.3报告和独立反思表指导语均明确这一点。

可不打开反思表或随时退出，SJT交卷和报告不受影响。三个字段全部留空时，实际持久化为COMPLETED/SATISFIED，恢复报告显示三项“已显示未填写”，没有数值分。现有独立匿名入口不会自动绑定SJT身份；需本人保管恢复链接，不能按相似答案拼接身份。浏览器中间页曾短暂显示“任务未达成”，最终状态及恢复报告正确；此呈现问题未在本内容候选中修改。
