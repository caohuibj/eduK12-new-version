计分算法与测量分析说明_v0.4

用途和结构

这是原创课堂情境工具的作者候选内容编码版，供低风险反思。12专题、24行为目录是内容框架，尚非验证因素模型；24个母情境可独立选择，每个仅3轮。建议一次选1个贴近实际的问题，再选一个训练；不要求做完。SD判断下一步较适切，WD报告现实更可能先做什么，两者独立，不能作差当作诚实度。O课堂观察、J情境判断、R课后反思分别解释。

计分是什么

每专题两个狭义动作族，共24个内容指标。选项明确写出某动作或安排记1；提供该类入口但所选项未写出记0；本组选项完全无入口记NA。1只说明文字有该动作，不代表执行得好、现实已做或比0适切。0不代表缺陷。规则逐项见672行编码表，全文是判读证据；这是AI作者候选，不是独立专家评判。

公式、方向和权重

对实际到达且有入口的节点集合V_m，C_m = Σ x_nm；每次权重1，不给第三轮或特定字母更高权重。不除以3；不跨专题相加。方向descriptive。全部已呈现机会均实质回答且|V_m|>0才给C_m，否则null。报告同时提供numberOfOpportunities、numberOfAnsweredOpportunities和numberOfIndependentScenes。该单个母情境独立情境数最多1，三轮不算三个独立样本。理论上0到机会数，但当前路径四项恒定时原生range可能下限大于0；这是选项集合范围，不是常模。

缺失与中止

未到达分支为结构性未呈现，不进入集合、不补0。U信息不足与N不愿答均终止；若终止节点是本指标机会，该指标整体null，已答贡献和文字仍保留；若其为NA且此前机会答全，可继续显示此前次数。这遵循现有引擎，不用插补掩盖缺失。无机会为null，不设强制补答。O证据不足/不适用不等于相反证据，观察首版不评分。

跨轮、跨路径与条件

同一题中轮次反馈含选项历史；实际选择原文作为桥接，避免合并节点误称做过另一动作。不同路径机会、信息、难度不同；只能解释本路径，禁止把频次或比例跨人排高低。SD/WD、不同场景/学段/版本/探针时点不直接可比。路径选择内生，统计建模不能把分支当随机分组。

探针和训练时点变更

v0.4原生SJT仅baseline，保持选择后的单次FINAL。原第一轮顾虑探针完整保留在题本；其原时点组合在现有前端对U/N即时退出有待验证，因此不放入可用候选。改用24张独立可选交卷后反思FORM，明确提示已看反馈。回答只描述回顾理由，可能受反馈影响；不与原R1未经反馈的顾虑比较，不评分、不改分支、不覆盖首次选择。

心理构念与适切性边界

SD对应情境中的专业判断内容，WD对应行为意向的自报；动作计数不是这两种心理构念的量表分。适切性需独立多学科专家逐项评定策略、必要条件与现实代价，并讨论可接受多个策略；尚无足够依据，故本版不强行打分。潜变量模型、难度、区分度、测量不变性、信效度、常模、切点均未估计。12类内容是来源框架的改编组织，不继承原工具因子、权重或效度。

分析计划

先按版本、条件、题面学段和探针时点分层，报告开始/到达/有效回答/U/N分子分母，选项比例分母为该节点实质回答。列动作次数与机会数联合分布，不报跨路径平均能力分。检查选项长度/负面词与选择关系、位置平衡、天花板/底板、分支暴露不均；不把少选项自动删掉。认知访谈询问真实约束、理解、是否存在明显道德答案及修改条件。独立两人编码报告原始一致率和逐类混淆，并在适用时估计κ和置信区间；因稀疏或恒定导致不可估计必须说明。后续试点才预注册并检验结构/不变性，按情境聚类，不把168节点当独立题样本。O与J关系需另收真实观察证据，相关不能当因果或同一构念。

训练效果分析

本版提供可执行练习，不保证有效。若评估训练，保留初次选择，另用未见的平行情境与独立课堂证据；记录完成/退出/负担和随访，避免同题记忆、反馈提示与自我报告共同方法偏差。无对照研究只能描述变化，不能说培训导致改善。

T01 操作定义与练习

A：明确把任务产出对准学习理由或比较条件

B：安排获取学生理解证据以检查或调整任务

课前用一句话写出学生需要解释的理由，再删去一个与它无关的活动。课中抽取三份不同学生的独立产出；课后比较是否真的出现该理由，下一课仅调整一处任务要求。不要把答对、安静或完成量直接当作达成证据。

T02 操作定义与练习

A：明确解释或修订概念的条件、联系或表征

B：要求学生解释、检验或迁移概念关系

选一个易混概念，设计一组只改变关键条件的对比例。让学生先独立解释，再同伴比较；收集反例或新表征的解释。若只是背出规则，补充条件判断再试一道新题；不因表达流畅就推断理解。

T03 操作定义与练习

A：将基于证据的解释或论证交给学生

B：要求处理相反证据、限制或修订判断

把一条主张和两条可能冲突的证据交给学生，留一分钟独立写“依据—限制—修订”。教师展示一种证据权衡过程，再换证据让学生重试。检查是否说明为什么改判；只增加发言人数并不等于推理改善。

T04 操作定义与练习

A：按具体困难调整或让学生选择支架

B：安排独立尝试、支架撤除或迁移检查

先记录学生具体卡在哪一步，准备一张最小提示卡并允许选择。下一题逐步撤掉提示，比较独立产出。若撤架后不能完成，缩小任务或补一项先备知识；不要把使用支架解释为能力差。

T05 操作定义与练习

A：提供或调整不同学生的实质表达入口

B：明确收集或核对可辨认的个人理解，或据此调整参与

选择一个平时难获得表达机会的学习环节，提供先写、两人说或匿名提交等入口。抽查不同参与方式学生的一份独立解释，区分未发言与未理解。下一课按证据调入口，不强迫所有人公开发言。

T06 操作定义与练习

A：保留学生对实质学习事项的选择

B：让学生根据证据自检、说明或修订下一步

给出共同学习目标和两条可行路径，让学生说明选择依据并设一次检查点。中途用产出判断是否调整路径，课后记录一次改变依据。只选展示形式未必是实质自主；自由选择也不能替代必要支持。

T07 操作定义与练习

A：收集能区分理解原因的学生证据

B：根据证据区分需要或收窄诊断结论

为同一错误写出两种可能原因，各设计一个能区分原因的追问。先对三名学生试问，记录原话和作答，暂缓给全班贴标签。若证据仍不能区分原因，下一次只补收一项关键证据。

T08 操作定义与练习

A：让学生把具体反馈用于修订或重试

B：检查反馈使用后的理解或新任务迁移

反馈一次只指出一个可改的具体地方，留两分钟让学生当场修订并解释改动。隔一课用稍变条件的任务检查迁移。区分看过反馈、按提示改对和能独立应用，不能用满意或认真代替反馈效果。

T09 操作定义与练习

A：明确保护尊严、非公开表达或合理质疑

B：检查后续参与、修复需要或落实后续支持

预先练习一句不评价人格的回应，并给学生私下说明或暂缓回应的选择。课后经学生愿意再确认参与是否恢复、还需要何种支持；记录回应与后续表现分开。涉及持续伤害时按学校保护程序求助，不强求公开和解。

T10 操作定义与练习

A：安排成员相互解释、整合信息或作实质贡献

B：安排个人理解检查、角色互换或互助负担限制

把合作任务设计成成员信息需要整合，先各自准备再互相解释。结束时每人独立回答一个核心问题，同时询问互助负担。下次只调整一个角色或轮换规则；作品完成不等于人人理解，帮助者也需要支持。

T11 操作定义与练习

A：在组织流程中明确保留解释、理解证据或独立回应

B：根据进度、等待或媒介差异调整组织

列出本课必须保留的一项学习产出和可压缩的一项流程。备一条低技术替代路线，在等待或进度失衡时切换。课后同时看用时和学生解释证据；速度快不自动代表教学有效。

T12 操作定义与练习

A：说明可执行的行为期待、提问渠道或替代方式

B：明确安排返回或继续任务的具体动作，或检查参与是否恢复

把“守纪律”改写成学生能执行的一句期待，并教会提问、暂停或求助的具体方式。先用最小足够回应，再检查学生能否安全回到任务。下一次比较重复中断的情境线索，避免用服从度替代学习参与。

0.4.2复核后的判读补充

所有计划中的以后动作也计为明示行动；不要求它已执行。仅笼统承诺“以后再处理”而未说明本指标动作时不推断。具体动作是否适切仍单列未评分。同一类动作可能有合理或不合理实现方式，计1不作价值奖励。T05须明确收集/核对个人理解，单纯安排说话不自动计个人理解检查；T10角色互换可计出现，不代表随机互换适切；T11聚焦解释/理解证据/独立回应；T12B不含“相称”这个尚待评价的价值判断，只计返回任务或参与检查。

逐步加总及U/N实例见《实际运行报告样例与逐步计算_v0.4.2》；原共同指标与更窄编码对象对应见24指标CSV。机会判定以本组选项至少一个明示入口为操作规则；它是内容可选性，不等于现实情境一定应采取该动作。四项恒定的指标虽然可描述次数，却不能区分本节点选择，已在机会表标注。

原生接口把A标为primary、B标为secondary只为呈现与完整性判定，不代表A更重要，两个动作均权重1。quality=interpretable仅指引擎规定的主要计数可计算，不代表心理测量有效、所有次指标完整或教师表现合格；必须逐指标检查null与机会数。measurement字段中的unit=score是接口通用单位，本候选实际单位为次。
