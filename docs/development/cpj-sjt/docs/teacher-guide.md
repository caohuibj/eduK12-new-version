教师使用与反思训练手册_v0.4

开始前

选择一个与你教学最接近的情境即可，约5—10分钟仅为计划预算，尚未实测。没有要求所有情境、观察表和反思表全做。SD想一想下一步哪项较适切；WD按现实最可能先做的回答。每轮只选一步，新信息出现后再决定。可以选信息不足或不愿回答并结束。

看报告

报告复述实际选择、显示其中明示的动作，并给一个小练习。次数只描述所选文字，不能说明教师好坏。先看自己保护的目标和现实代价，再决定练习是否适合。没有出现或没有回答的机会不会算作0。

一次10分钟复盘

2分钟：回看一个实际选择及条件。3分钟：写它帮助了什么、可能牺牲什么。3分钟：选一处可实行的小调整及一份学生证据。2分钟：约定下一课后检查是否值得保留。反思可以跳过；发现不合实际可直接记下修改建议。

T01

课前用一句话写出学生需要解释的理由，再删去一个与它无关的活动。课中抽取三份不同学生的独立产出；课后比较是否真的出现该理由，下一课仅调整一处任务要求。不要把答对、安静或完成量直接当作达成证据。

T02

选一个易混概念，设计一组只改变关键条件的对比例。让学生先独立解释，再同伴比较；收集反例或新表征的解释。若只是背出规则，补充条件判断再试一道新题；不因表达流畅就推断理解。

T03

把一条主张和两条可能冲突的证据交给学生，留一分钟独立写“依据—限制—修订”。教师展示一种证据权衡过程，再换证据让学生重试。检查是否说明为什么改判；只增加发言人数并不等于推理改善。

T04

先记录学生具体卡在哪一步，准备一张最小提示卡并允许选择。下一题逐步撤掉提示，比较独立产出。若撤架后不能完成，缩小任务或补一项先备知识；不要把使用支架解释为能力差。

T05

选择一个平时难获得表达机会的学习环节，提供先写、两人说或匿名提交等入口。抽查不同参与方式学生的一份独立解释，区分未发言与未理解。下一课按证据调入口，不强迫所有人公开发言。

T06

给出共同学习目标和两条可行路径，让学生说明选择依据并设一次检查点。中途用产出判断是否调整路径，课后记录一次改变依据。只选展示形式未必是实质自主；自由选择也不能替代必要支持。

T07

为同一错误写出两种可能原因，各设计一个能区分原因的追问。先对三名学生试问，记录原话和作答，暂缓给全班贴标签。若证据仍不能区分原因，下一次只补收一项关键证据。

T08

反馈一次只指出一个可改的具体地方，留两分钟让学生当场修订并解释改动。隔一课用稍变条件的任务检查迁移。区分看过反馈、按提示改对和能独立应用，不能用满意或认真代替反馈效果。

T09

预先练习一句不评价人格的回应，并给学生私下说明或暂缓回应的选择。课后经学生愿意再确认参与是否恢复、还需要何种支持；记录回应与后续表现分开。涉及持续伤害时按学校保护程序求助，不强求公开和解。

T10

把合作任务设计成成员信息需要整合，先各自准备再互相解释。结束时每人独立回答一个核心问题，同时询问互助负担。下次只调整一个角色或轮换规则；作品完成不等于人人理解，帮助者也需要支持。

T11

列出本课必须保留的一项学习产出和可压缩的一项流程。备一条低技术替代路线，在等待或进度失衡时切换。课后同时看用时和学生解释证据；速度快不自动代表教学有效。

T12

把“守纪律”改写成学生能执行的一句期待，并教会提问、暂停或求助的具体方式。先用最小足够回应，再检查学生能否安全回到任务。下一次比较重复中断的情境线索，避免用服从度替代学习参与。
