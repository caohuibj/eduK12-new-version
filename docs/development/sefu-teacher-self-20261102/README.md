## 母工具、子项和标签

[inventory.json](inventory.json) 是开发交接记录，不是新增runtime schema。统一名称前缀“SEfU｜…”，共同稳定tag为 `family:sefu`；分别记录 `role:teacher_self`／`role:student`、`perspective:teacher_experience`／`student_experience`／`student_importance`、德语、中学段、发展性反思及原版待核状态。标签值拟写入已有 `tags: String[]`，目录如将来需要登记则使用现有constructOverlapTags；当前没有实际写标签。

| 课堂体验 | 学生 | 现行短版15特征目录；历史15句另存版本事实 | 未创建 |

15个特征不等于15个经验证子量表。没有核到现行短版的完整题项—维度—计分键，不虚构总分或子量表。无常模、独立施测效度未建立**本身不阻止**采用原文允许处理的无分表单；真正缺的是完整原文和复用依据。当前C/P/R及官方源版本均未建立，不把抓取日期或metadataRevision1当问卷版本。

可选普通组合按角色分别准备：教师仅填教师自述；学生的体验／重要性／背景／开放部分可在既有普通组合中分节。不同填答者不混装进同一份个人作答。共同tag用于筛选和获授权的并列分析，不保证师生等值，不做“重要性×不足”、教师减学生分或跨工具总分。
