# SEfU：已核事实与计分边界

当前没有可执行定义。本文件区分来源中的描述性反馈、旧研究分量表与尚未取得的现行短版规则，不建立新计分协议。

## 三视角不是一个分数

教师自评是教师对自己课堂实践的看法；学生体验是其实际感受；重要性表达学生重视什么。重要性低不能解释为教师教学差，也不是学生缺乏学习动机。教师自评高不证明学生实际受益，师生不一致不说明某方说谎。共同分析需先核同一教师／班级、学科、时间窗和精确版本；共同tag只帮助找到这些记录。

本轮不创建同伴观察版或理想教师版，不将三视角加权，不算“重要性×不足”、满意度缺口、教师准确性或优先级排名。角色不同不能让教师填学生体验，也不能让学生读取教师私有自评。

## 原资料实际说明到哪里

- 现行公开页示例为四级符合度与四级重要性；完整题文与编码键需要账号，目录并不提供计分键。不能只凭选项显示顺序决定数值方向。
- 2009原作者论文的脚注用1代表更赞同／更重要，4代表相反端。2016官方指南的报告说明则按较大数字代表较赞同解释。历史方向不同，应锁定精确源版本后核原码，不倒推现行值，也不对所有题一律反转。
- 2016指南p21说明逐项学生回答分布、该项班级均值及重要性均值；这不是15个特征相加的教师质量分。2.5是四级编码1–4的理论中点，不能冒称经验常模、实际中位数或问卷有一个“中立”作答选项。本轮不采用它作自动好坏分级。
- 2009研究提到理论分组和可靠性，但没有因此取得当前短版的完整题目到分数映射；2012反馈会议15项选表也不能证明独立15题量表结构。

现行教师15项的反向键、缺失规则、总分范围均未核；应记未知，不能写“无反向、总分15–60、漏一题全无效”来补齐。原生FORM无数值结果时这些字段不适用，逐项保留原选项和未答null；未填不是0、不同意或不重要。若用户取得允许处理的全题本，即使没有总分／常模／独立施测验证，也可直接沿普通无分表单准备，明确是描述性记录。

## 拆分和原生路径

拟保留教师自述、学生体验、学生重要性三个独立身份与角色；背景和开放反馈另作无分部分。未核教师有相同背景／开放部分，不从学生表复制。可选普通组合只在同一填答者内部组卷，三视角结果仅在已有授权内并列。现行源版本缺失时不强行分成15个单题“量表”，也不把旧四维名称当成现行子量表。

原完整文本和使用依据尚未齐，所以没有可供真实schema、选项边界、报告运行或隔离库安装的payload；这些项目为NOTRUN。没有用占位文本或一项公开示例伪造原生施测。未来有合法完整材料时，只验证实际新增内容、选项合法值、漏答保留、对应报告及一次真实隔离导入回读；不重建表单、量表或权限引擎。
