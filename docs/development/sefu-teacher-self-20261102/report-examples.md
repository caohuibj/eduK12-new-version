# SEfU 报告编辑草稿：教师成长与学生保密

以下均为项目原创的**条件场景稿**，不是SEfU原版报告翻译、真实作答结果、自动得分档位或冻结R版本。没有合法完整题本和实际原生结果，系统当前不会显示这些分析。中文文案也不构成经验证中文题本。

## 接收者与可见条件

教师自评版面向作答教师本人，解释其对课堂的自述；无权查看时不呈现。学生数据只能按现有授权、匿名、发布和最小人数规则向相应教师提供群体结果；不得将个体回答或可识别开放文字直接披露。校领导或其他教师不因这次报告而取得访问权。

SEfU官方流程把结果报告保留在教师受保护账号，因此学生端默认只有完成提示。下列适龄学生文字是**不依赖结果的说明**；不据此开放学生分数、教师自评、全班分布或敏感回答。未来若合法来源与既有配置明确允许学生反馈，仍须按接收者授权独立处理，不能套教师稿。

## 教师自评：较顺利的场景

你的回答记录了你认为目前较顺利的课堂做法。这是值得保留的线索，也需要与课堂证据一起理解，不能单凭自评判断整体教学质量或学生的实际体验。可以挑一个最近的教学片段，记下你做了什么、学生随后如何回应；下一次保留其中一个有效安排。是否听取学生反馈按既有自愿和保密安排，不追问个人评价。

## 教师自评：遇到困难的场景

你提到的困难可以作为寻找支持的起点，不是给自己贴上能力不足的标签。先选一处影响学习的具体环节，例如任务开始后学生还不清楚下一步：尝试缩短一次说明，或增加一个示例，再观察一次学生如何开始任务。班级构成、时间和资源限制也需要被考虑；如果条件不够，可以与合适的同事协商一种支持，不要求自己一人解决所有问题。

## 教师自评：信息不足或只有自评

现有信息还不足以判断课堂变化或师生差异。空白没有按零处理；只有教师自述时，不推测学生是否满意，也不生成差异图或精确改进顺序。你可以先用一个真实片段整理已有证据和仍想了解的问题；是否补充反馈按原有安排，无需为“补齐报告”反复测量。

## 获授权的师生并列反馈

**体验相近的场景。** 在可比较、同版本且已满足群体披露规则的反馈中，师生对某方面的描述较接近。这不证明双方的判断客观等值，也不代表所有学生都有同样体验。可以保留一个双方都觉得有帮助的做法，并留意群体中的差异。

**体验不同或学生遇到困难的场景。** 师生从不同位置经历课堂，感受不一致是进一步了解具体场景的起点。学生重视某方面而体验尚未满足时，可以把它作为讨论需要的线索，不乘成“紧急度”或认定教师失职。建议选择一种可行调整，并在不追查个人、不给低评价者施压的条件下说明你准备怎样回应。

**不足以披露或比较。** 目前没有可报告的群体比较。不降低最小人数要求、不拼接不同班级／版本凑数，也不披露学生个人回答来补充解释。只显示现有规则允许的状态；若人数也保密，人数不显示。教师仍可做独立反思，但不能声称它来自本轮群体数据。

## 背景与开放部分：不计分

背景答案帮助了解情境，不加进课堂特征分或教师质量分。开放回答是反馈者表达经历的机会，不能按词语多少、情绪正负或是否表扬自动评分；未填也不代表满意或不满。只有合法、获授权且符合原有匿名规则的呈现才可使用，需处理可识别的细节。本轮没有开放原文，更没有将论文中的真实学生评论带入示例。

## 中学生说明示例：不开放保密结果

**完成提示。** 谢谢你按自己的经历提供反馈。不同同学的感受可以不同，没有需要迎合的“正确评价”。这次不会给你的能力、态度或老师好坏打分；结果如何使用，按本次已告知的安排。

**觉得学习有困难时。** 如果有些课堂经历让你难以理解或参与，这不等于你能力差。你可以在合适的时候提出一个具体需要，例如请再解释一步，或请可信的成人帮你表达。改善不公平或让人不安的处境不是你必须独自承担的任务，也不要求你与教师对抗。

**未填或信息不足时。** 空着的地方保留为未填，不算成差，也不会被当作你不重视学习。若你愿意，可向可信的成人说出一个需要帮助的地方；获得支持不以填满问卷为条件。

本轮只做文案内容检查，没有报告组件渲染、真实结果生成、学生接收者授权或教师群体披露测试。当前没有运行时内容，不用这些草稿冒称路径已验收。
