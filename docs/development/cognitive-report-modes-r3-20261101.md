## 实质发现与处理

1. logicdeduce旧摘要误称“类比推理”，已改为按题内条件推断；不是另一项测验的能力指标。
2. 体验版不再承诺长版自动给出“更稳”结果；按实际短样本只作本次描述。矩阵6题不比较规则族／最高难度，旋转12次不解释角度代价或镜像错误率，塔式4关不把首步时长当规划水平。
3. 塔式最短步解题率的分母为全部关卡，不是已解关卡；额外步数的均值才只在已解关卡中计算。新摘要明确分母。
4. ICAR推荐C2.1/S1.1的中位RT含合格错答，已标“有效作答的典型用时（含答错）”；没有统一套用“正确反应时间”。七题matRiks素材不是ICAR标准全套，也不是Raven标准版。
5. 估算是有范围提示的自编四选一数量级判断，不能叫原版自由回答CET，也不把题库预设区间说成临床合理性阈值。
6. 实际运行前端纯序列：matrix研究24、rotation研究80、tower研究18都含各4个练习素材（overlap=4）。练习记录不进分母，但熟悉效应仍存在；新R明确披露，不能称所有正式刺激都未见过。本轮不擅改这3项已存在C，独立练习池需未来明确C修订。
7. R-only新增方法附注时，数列与估算原草稿未有完整professional字段；首次真实投影12通过/2报错。本轮补齐这两个新R的construct/configFields/metricNotes，定向2项复验通过；未改公共投影器。

所有版本均不提供虚构百分位、年龄等级、IQ、人格标签或临床结论。原始数值、单位、null、现有质量门、公开投影和冻结身份均保留；仅为体验版收敛报告推断，不添加准入门禁。
