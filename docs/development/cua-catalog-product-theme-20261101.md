# 分类检索沿用各入口主题

基线为 #483 `9dcded9e05ef83aacf86b136a033480aba052ae7`，与管理员 #488 分开。本批只修改共享分类检索 CSS 和 Training 原有深色编制规则，复用各入口现有主题变量；Survey 保留原蓝色变量，不新增设计系统或改变检索、分页、授权及计分。

## 真实界面发现

- School：深色任务面板与原固定版本选择器为绿色，新检索区却出现浅色蓝灰字段、低对比字段标题。
- Teacher：原铜色深色任务面板旁，新“检索”按钮浅底浅字，标题、更多筛选和说明文字仍为蓝灰色。
- Training：现有米白/绿色目录中的新标签使用 Survey 蓝色。真实教师工具页的通用按钮样式还会覆盖共享按钮，在深色模式下导致浅底低对比；本批用局部选择器保留本控件主题，不更改整站按钮规则。
- Training 编制页：实际添加量表后，“工具配置与报告”、单元配置及认知不可用说明仍为浅底，继承的深色文字为浅色，难以阅读。仅将这三个具体容器纳入现有深色表面规则，不改布局或浅色规则。

本批把边框、表面、次级底色、正文、辅助文字、强调和焦点颜色映射到各产品既有变量。主题切换继续由原入口负责。仅影响分类检索、分类标签和“尚未分类”提示。

## 验证边界

实际用 Chrome/CUA 操作两套本机隔离预览，不访问生产：

- 组件及本地合成 HTTP 预览：Training 管理员在第二页应用后页标签，真实请求变为 `page=1&tags=SYNTHETIC_LATE_DOMAIN`，命中第32项；School 已选精确版本在应用分类后清空，加入按钮禁用；Survey 关键词命中未在第一页加载的第32项，保留精确版本，双击加入只产生一条合成选用请求。
- 真实候选应用、隔离 PostgreSQL16/Redis 和仓库既有合成 Training 夹具：登录培训师账户，从成熟课程管理页进入工具页，对照已有字号/层级、卡片和按钮；实看浅色、深色及 393×852 手机视口。没有替换这些页面的业务接口或认证客户端。
- School/Teacher 目前的主题前后截图来自实际组件及入口原样式，目录为合成适配器；不冒充其完整登录、组织、历史、报告或作答者业务闭环。
- CSS 用现有 PostCSS 解析，`git diff --check` 通过；没有 TypeScript、接口、依赖、数据库、后端、工作流或门禁修改，不重复原业务测试或启动全平台 CI。

此问题影响可读性和风格衔接，建议进入前端轻量修补批；本批没有证明它会使服务器无法完成关键业务动作，不将普通美化增加为主线合并阻塞。完整角色流程继续独立巡检，功能性复杂问题另记复现与影响。
