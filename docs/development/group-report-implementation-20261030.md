## 指标、样本和子群

- Scale 只使用已定义总分/维度，展示独立有效 N、mean、适用样本 SD、真实量尺或明确描述的分布；不新造维度、常模或阈值。
- Cognitive 只读持久化正式指标、质量和单位，不重算试次，不混协议/profile。SJT 只汇总定义指标和已有可用选项，绝不平均选项编号。
- Form 汇总单/多选频数比例与真正数值题。多选分母是有效作答，比例合计可超过 100%；自由文本不新增 AI 总结，不伪造心理分数。
- null 与 0 分开；有符号差保留，每指标独立 N。复用已有质量结果，不另建异常值剔除/重测体系。匿名答卷不能冒称去重人数，assignedN 不可知为 null。
- 默认 ALL 是所选任务/来源的合格参与范围，不是今日学校全部名单或全部历史答卷；第一版不拼多个独立 Run 作为全校。
- 同轮重做先确定最新正式完成父结果/epoch，再投影全部指标；最新缺失不回退旧高分，未完成不覆盖旧完成。不新增 Survey 重做，不删原研究数据。
- Survey 为当前项目有权研究者；Training 为当前课程/任务有权培训师；School 为有权心理教师/管理者；Teacher 为有权管理员。不顺带新建协作者体系。
- 用户已确认 **所有 School 工具类别允许子群**。要改原严格 API 限制，不只前端过滤。保留原适用人数下限与差分保护，子群仅缩小已有授权。
- 首版一个筛选维度、同字段可多选 OR：School 年级/班级/已有人员标签；Teacher 任教年级/已有人员标签，学科可用实际维护的组织标签；Survey/Training 使用已有真实分组。无任意 SQL/ANDOR/姓名挑人/按结果筛选，不预生成组合。
- 教师班级适配用 staff-class 关系并按 membership 去重；年级经 Grade→Class 解析。用历史有效关系/标签，不用今天层级重写过去。工具分类标签不是人员标签。
- gender 没有统一可靠字段时不展示；sexAtBirth 和研究自报不能混作同一字段，不为报告增采资料。
- 冻结筛选、实际成员、来源与叶指标；披露身份须绑定真实叶测量，不能仅绑父容器而允许换问卷绕差分。授权/披露检查放在生成、读取、导出边界，不对每次 UI 切图扫描数据库。
