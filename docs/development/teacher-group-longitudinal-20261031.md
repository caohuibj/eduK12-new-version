# Teacher numeric group longitudinal

Teacher administrators use the existing published SELF longitudinal plan, concrete per-wave bindings, existing single-wave GROUP producer/reader, shared independent-wave projection, and immutable encrypted task artifacts. An on-demand activity panel opens saved reports/history and loads spec/group choices only for explicit generation. Ordinary teachers get no group access.

`groupLongitudinalReport.service.ts` owns the thin plan/leaf/time/projection adapter. `groupLongitudinalReport.routes.ts` keeps existing admin-session and POST MFA middleware. `TeacherGroupLongitudinal.tsx` supplies existing spec and class/label choices to the shared Panel. The only storage change adds TEACHER to the existing product CHECK. It does not add a table, duplicate FINAL, aggregate on answer save, or rebuild reports while paging.

Necessary checks and unique execution positions:

- Local service and HTTP contracts: catch absent later-wave plan copies, wrong slot/C/unit, lost current manager rights, strict cursor/body/MFA wiring. Existing common longitudinal math and original authority implementations are reused.
- One isolated PG source lifecycle: proves new formal plan → two actual waves/20 FINAL → own/single/group/saved outputs; prior unlinked group facts cannot prove this connection. Completed FINALs reused across two failure continuations.
- Two local jsdom panel cases: new configuration/body wiring and stale event response; existing history/projection implementation is unchanged, no full browser matrix.
- Existing CI qualification: new TEACHER CHECK must upgrade nonempty exact main and survive native dump/restore. Current frontend types/changed lint, production builds/scans and scoped SAST remain where existing workflow already executes them. Full backend compiler runs once in the image build. Audit only reuse exact locks and fresh official successes. No extra gate or framework.

The shared producer from merged Group #443 now supports the internal partial-source option, and this adapter opts in only after resolving a real frozen longitudinal plan/leaf. A two-wave A/B→onlyA contract retains A and suppresses B and its delta. Default single-report calls remain strict. Private education-composition group sources consume the merged #446 adapter directly, with one new real two-wave source/suppression/read boundary and no duplicate collector. Native Teacher Form numeric longitudinal is explicitly excluded this round, with its existing completion-only versions unchanged.

Supported evidence currently: new registered original Teacher GROUP Scale, 2 published waves/20 FINALs and saved longitudinal output. Existing library and native Cognitive/SJT/Bundle use the same frozen binding/source contracts but are not claimed as newly exercised full journeys. Bundle Profile, arbitrary old task pairing, baseline-fixed/paired inference and unscored Forms are out of this implementation.
