# 培训版学员课程导航（本地）

用户确认：培训版学员通过课程参与测评，暂不提供跨课程自由选测入口；已有授权任务和历史报告保留。

## 行为

- 课程栏目保存在 `section=assignments|checkins|assessments`，刷新、返回和重试不重置栏目。
- 课程任务与报告链接携带非秘密的 `courseId`、`courseSection`。不使用跨课程共享的“上次课程”状态，不新增后台请求或缓存。
- 组合单项优先返回已授权服务器响应中的父级测评；已有服务器课程信息优先于地址提示。认知的完成、恢复和版本不支持分支采用同一返回规则。
- 独立任务／报告返回来源课程对应栏目；无法确定来源时返回“我的课程”。直接打开无上下文的历史报告仍读取原报告。
- 培训版 STUDENT 打开旧认知、情境判断、量表、问卷、练习、打卡汇总／历史列表或量表库时，以 replace 返回课程／我的课程，列表组件不挂载。
- `/my-assessments` 的已有任务、历史报告和多次反馈保留；培训版学员不显示或请求自由选测目录。组织任务、匿名、教师及其他产品入口保持原用途。
- 练习、打卡返回使用实际任务课程信息，避免依赖浏览器上一页；子页面已有返回操作时，外壳不再追加相互冲突的返回链接。

## 边界

仅调整前端展示与导航。网址参数不是授权凭据；所有任务资格、继续原作答、次数、FINAL、历史报告及反馈开放规则仍由现有后端负责。没有修改后端、数据库、附件、计分或权限策略，没有推送或触发 CI。

## 本地验证

- 导航定向测试：旧链接、跨课程来源隔离、刷新、新标签返回、服务器父级优先、结果读取失败及反馈未开放、已有授权报告深链保留。
- 认知壳层／恢复、组合测评／报告、情境判断报告的受影响测试；外壳及教师三项工作台导航兼容检查。
- AppShell 集成断言确认旧自由选测页面在重定向之前不会挂载；不借导航创建或重启作答。
- 前端 app TypeScript 与变化文件 ESLint；不运行全量测试、构建、CI 或生产部署。

本地运行日志保留在独立运行目录的 logs 中。测试使用合成数据和既有 mock，不代表完整的真实学员浏览器权限验收。
