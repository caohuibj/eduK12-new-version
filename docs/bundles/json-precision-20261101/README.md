# Bundle installer JSON fraction preservation

Observed on Prisma 5.22 and PostgreSQL 16.15: a newly installed package fixture `cpt.omission_rate.value` changed from `0.027777777777777776` to `0.02777777777777778` in stored `content::text`. The ordinary JSON stringify/parse roundtrip preserves the original value. This documents the observed write-path behavior without asserting Prisma internals.

The existing installer now binds `JSON.stringify(p)` as a SQL parameter cast to `jsonb`, inside the same transaction and advisory lock. It keeps the existing admin check, exact identity, fixture/dependency validation, immutable version behavior, DRAFT/default lifecycle and content hash algorithm. The insert supplies a UUID and update timestamp that were previously supplied by Prisma. It does not round scoring values or alter package definitions.
