# 认知测验视觉语言

Training、Survey、School、Teacher 使用同一套认知界面。入口只负责身份与导航。说明、练习、解析和正式作答固定使用同一套浅色蓝灰配色和全屏布局，不响应入口或系统的明暗主题。这样减少非题目视觉差异对作答的额外干扰；报告页继续使用自己的主题。

## 组成

- `cognitive-design-tokens.css`：语义颜色、字号、间距、圆角、内容宽度。正文 18px，操作说明 16px，辅助标签 14px；按钮至少 48px，正式作答按钮至少 52px。
- `CognitiveTaskIntro`：一页显示规则、图示、操作方法、一个开始练习按钮。任务已有图示优先；其余按精确任务身份从 `task-guides.ts` 读取说明示例。历史版本存在不同规则时显式区分版本。示例不参与试次生成或评分。
- `CognitivePracticeFeedback`：持久反馈面板，区分正确、错误、观察和中性操作反馈。任务提供解析和继续按钮；组件不启动计时器、不自动进入下一题。偏好和决策题不标记对错。
- `CognitivePracticeResult` / `CognitiveTaskTransition`：共享练习总结和阶段切换，继续使用任务原有通过标准。
- `CognitiveFocusStage`：顶部为紧凑进度，主要视区留给题目，操作说明紧邻作答区。内容最大 66rem；反馈最大 60rem。长内容自然滚动；窄屏说明图示改为纵向。
- `CognitiveProgress`：完成数从零开始，只随已接受的作答更新。固定题量显示完成/总量；自适应广度显示本级完成/2；限时任务显示已用/总时间，并标注完成题数。练习与正式进度分开。

## 接入边界

说明、练习和正式作答的间距、字体、控件反馈由共享组件维护，不新增各入口的专属覆盖。题目按原版协议保留刺激颜色、形状、尺寸、时序、键位、计分与保存流程；不可对刺激添加缩放、位移或进出场动画。正式题是否呈现反馈由任务协议决定。减少动态效果设置应关闭装饰过渡。

新任务接入时提供具体的核心规则、操作方法与示例；使用共享说明、练习反馈、总结、作答舞台和进度组件。共享组件不解释权限、数据库或运行时内部状态。

## 已完成的题型细化

首批已将 Stroop、算术验证、句图验证、数量大小比较、符号匹配、序列反应、线条方向、视觉工作记忆、听觉反应的练习接入共享作答舞台和真实完成进度。

这九种题型通过 `CognitivePracticeAnswer` 展示任务提供的本题依据、正确做法、实际选择与具体解释；反馈保留到用户按原有按钮继续。组件只呈现任务已经判定的练习结果，不计算分数、不修改通过门槛。本轮进一步补齐 Go/No-Go、CPT（含帧计时分支）、SST、任务切换、Flanker、卡片分类、图形比较、心理旋转、矩阵与 Corsi 的手动继续解析；数字记忆、图片序列、配对、词汇、表情和词表补足本题对照，旧式练习总结接入共享面板。听觉 N-back 的建立记忆阶段显示观察提示。偏好、概率奖励、无反馈版本保留原协议的中性反馈，不添加虚假的对错或提前泄露正式答案。
