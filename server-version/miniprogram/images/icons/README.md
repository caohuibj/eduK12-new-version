# TabBar 图标文件说明

本目录存放微信小程序底部导航栏（TabBar）的图标文件。

## 所需图标文件列表

| 文件名 | 说明 | 状态 |
|--------|------|------|
| course.png | 课程图标 | 默认状态 |
| course-active.png | 课程图标 | 选中状态 |
| assignment.png | 作业图标 | 默认状态 |
| assignment-active.png | 作业图标 | 选中状态 |
| checkin.png | 打卡图标 | 默认状态 |
| checkin-active.png | 打卡图标 | 选中状态 |
| profile.png | 我的图标 | 默认状态 |
| profile-active.png | 我的图标 | 选中状态 |

## 图标规格要求

- **尺寸**: 81px × 81px（推荐）
- **格式**: PNG（支持透明背景）
- **默认状态颜色**: #999999（灰色）
- **选中状态颜色**: #5bc0de（青色）

## 图标设计建议

### course（课程）
- 建议使用书本、毕业帽或课程表图标
- 简洁的线条风格

### assignment（作业）
- 建议使用文档、清单或铅笔图标
- 简洁的线条风格

### checkin（打卡）
- 建议使用日历、打卡机或勾选图标
- 简洁的线条风格

### profile（我的）
- 建议使用人物头像或用户图标
- 简洁的线条风格

## 获取图标资源

推荐从以下网站获取图标：

1. [阿里巴巴矢量图标库](https://www.iconfont.cn/) - 搜索对应关键词下载PNG
2. [Flaticon](https://www.flaticon.com/) - 免费图标资源
3. [Icons8](https://icons8.com/) - 提供多种风格图标

## 使用方法

1. 下载图标后，使用图片编辑工具调整为81×81px
2. 创建默认状态版本（颜色 #999999）
3. 创建选中状态版本（颜色 #5bc0de）
4. 将文件放入本目录

## 注意事项

- 图标应保持风格统一
- 确保图标在小尺寸下清晰可辨
- 透明背景可以更好地适配不同主题
