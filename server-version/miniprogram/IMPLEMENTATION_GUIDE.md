## 🔧 关键技术说明

### 1. Socket通信

**网页版**：使用 `socket.io-client`

**小程序版**：使用微信 `wx.connectSocket`

**封装类**：`utils/classroom-socket.js`

**使用方法**：
```javascript
const socket = new ClassroomSocket({
  classroomId: 'xxx',
  role: 'student',
  studentId: 'xxx' // 可选，未登录时不传
})

socket.connect()
socket.on('broadcast:question', (data) => {
  // 接收题目
})
socket.emit('student:submit', {
  questionId: 'xxx',
  answer: 'xxx'
})
```

### 2. 临时学生模式

课堂功能支持未登录用户参与：
- 自动生成临时学生ID
- 格式：`temp_时间戳_随机字符串`
- 无需登录即可答题

### 3. 答题倒计时

- 教师设置题目时限
- 学生端实时倒计时
- 超时自动提交答案
- 支持剩余时间（后加入课堂）
