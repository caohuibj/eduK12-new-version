## 问题与题量

原 pf-04/09/10/12/13/18 含多处错误，pf-08/24 无唯一错误却设了答案，pf-21 选项给出了改正后的词而不是原句字词；说明和报告误写成词对类比。

原题池 24 题，练习直接复用其中 1 题；种子配置18题，但 profile 要求 18/30/36，随机器静默截断为题池长度，较长 profile 无法交齐。审订版 **36 道正式题 + 1 道独立练习**；沿用 18/30/36 profile、400ms 注视、15s 上限、300ms RT 下限，不降低要求。超过容量或错误题库版本在启动前明确报错。

逐题修订为恰好一处错别字或“的／地”用法错误；四选项取自原句，正确项指出原错误，不展示改正答案。保留可用材料并修复歧义，补12个不同语境的新题；每题附唯一目标、改正句及解释。

练习使用独立内容和 ID，错误后先完整重读说明，再重新练习；答对才可进入正式。正式不提供答案反馈。当前前端题库不携带正式答案和编辑解释；旧版原件仍保留其原内容，不能将此改进追溯到旧版。条目 band 仅为编辑分组，不是校准难度。

## 版本与计分

1.0.0 bank、runner、scorer、fixtures、metadata、seed 与报告保留在 `.v1`/`TaskV1` 等任务内模块；原版本可按精确身份读取，未将旧数据重算成新结果。新版 C/engine、config、scoring、report/presentation 均为 **1.1.0**；新 config 只接受 `proofread-zh-v1.1.0` 与 `reportVersion=1.1.0/referenceMode=none`。沿用已有 task-package/registry/seeds/report 链，没有新增平台。

准确率仍为正确题数 / 全部齐全的正式题数（含超时分母）。额外记录 correctCount、answeredCount。错误与超时分别统计；全部错选有回应仍保留真实0正确率，不因没有正确RT而抹成缺失。全部未回应有 noResponses 标记，不解释为能力零分；无合格RT为 null。中断及过快反应不进入正确RT中位数。拒绝额外/缺失/重复/未知/练习条目及不匹配响应时间；失败重试保留同一首次答案和RT。报告只用自然指标，关闭产品指数，不提供模拟常模、等级或诊断。低正确率/少RT仍需谨慎解释。

两种长短配置仍共用运行器；估计时长为 2–6 / 3–9 / 4–11 分钟，依据15s逐题上限加说明练习余量作保守估计，并非实测。下限不是保证；自由练习重试可延长总时长。短长版不宣称等值、信效度或稳定性已经建立，重复施测仍有练习效应。
