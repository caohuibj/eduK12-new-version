# Maze 1.1.0：操作练习与正式图分离

基线为 #480 `b42393cffe1c4364c1fc5568b656ed612fc60849`。这是项目可见网格导航变式，不是标准化空间能力测验或水迷宫复刻。

原C1.0.1在practice和formal都调用`generateMaze(randomSeed, trialIndex, cols, rows)`，首次trialIndex均为0。参与者在练习中完成了整条路线，正式第一题又显示相同墙图。正式评分将该首题计入完成数、步数效率与完成用时均值；重复格数也受熟悉路线影响。故首题混入预先见过并走通路线的经验，不能与后续首次见图作等同解释。体验只有2张，首题占一半。这里确认的是设计风险，没有声称测得影响大小。

没有发现本项目故意采用同图练习作为学习条件的协议：正式各轮换图，报告汇总各图导航，并无同图学习曲线设计。不能仅换一句报告文案消除该风险。

一手参照为[官方PEBL Maze源码，固定版本eb22a0725d765a0597a4905920ad3c603b1c9ae8](https://github.com/stmueller/pebl/blob/eb22a0725d765a0597a4905920ad3c603b1c9ae8/battery/maze/maze.pbl)：第88–117行单独构建5×5 `PRACTICE`，第21–30行默认正式15×15，第142行后进入正式题循环。这里只借鉴分离操作练习与正式图的原则；未复制其迷宫、Kruskal算法、规划阶段、正式题组或参数，亦不据此宣称本版效度或可靠性。

新版身份：C1.1.0 / scoring1.0.1 / config1.1.0 / presentation及R1.1.0。先用专属种子域`practice-only-v1.1.0`生成3×3小图，仍用同一方向键/按钮与目标标记。正式schema最小5×5，默认7×7，因此练习不可能直接重复任何正式墙图。练习不上传trial；没有强制练习用时截止，正式每张最多120秒。正式轮数保持体验2、常规4、研究8；练习较小只用于熟悉操作，不作为等难度指标。

正式生成器、种子/mazeIndex映射、尺寸、时限、raw payload、scorer与公式完全不变。旧C1.0.1及seed1.0.1保留原练习和报告；新建推荐指向C1.1.0，新增seed为DRAFT，没有安装或发布。算法身份`maze-independent-practice-v1.1.0`区别训练条件；正式生成仍为原回溯算法。两版本之间不得把首图熟悉条件当成相同测量条件。

验证：Node24.21.0，4个定向DOM用例通过（确定性与尺寸隔离、正式第0/1题练习不上传且payload保留原路径、旧C练习原图保留）；体验/研究冻结及推荐绑定通过，原1个黄金输出与2个预期拒绝保持一致；前端认知闭包类型检查通过。Chromium通过本地HTTP实际完成3×3练习→7×7首题，两模式预算2/8分别查看390/1440px，未提交练习、正式路径正确、无异常或横向溢出。未重跑原全部scorer套件、完整2/8轮施测、真实HTTP持久化、原生设备、可靠性/效度实验或CI。

剩余边界：隔离练习不自动证明两轮数据稳定；不同正式图不是同图学习曲线。报告仍须区分未完成与完成后的步数效率，不能据一次表现给智力/年龄/空间能力等级。旧指标键名`medianCompletionTimeMs`实为均值、`totalDeadEnds`实为重复访问格子，新的报告修订须据实命名，本次不改公式或旧键。
