# Auditory n-back：固定机会修订 1.1.0

旧身份 `engine1.0.1/scoring1.0.0/config1.0.1` 保留。新身份 `engine1.1.0/scoring1.1.0/config1.1.0` 为 DRAFT/PILOT，无人口常模；新创建推荐转新身份，旧冻结/续做不迁移。R阅读与呈现版本1.1.0，不改旧报告；数值公式、Hautus加0.5修正、MIN_TARGETS=6等阈值均不变。新scoring身份明确使用新种子序列，旧score入口仍走原算法。

最小旧反例：seed=`r2-counterexample`、12音、n2、ratio.3、5音高，旧算法生成`[3,3,4,2,3,2,3,4,2,0,2,2]`。前2音后只有3次匹配/7次非匹配。即使所有目标都命中且无误报，仍触发insufficientTargets，不满足原6目标门槛；增加报告措辞不能消除此结构性不足。

修订只将正式生成改成固定目标机会：`round((totalTrials−nLevel)×targetRatio)`，目标位置按seed随机且最多连2次。每一步只选仍能完成剩余数量的目标/非目标，有限循环恰好消耗所有机会，无拒绝重抽或自动无限加题；不是全部受约束序列的均匀采样。非目标音强制不同于n-back音，不意外增加目标。前后端同算法镜像，服务端仍权威计算匹配，回显不一致仍保留原质量旗标。

| 新档位 | 总音 / 比较机会 | 目标 / 非目标 | 名义正式声音等待 |
|---|---|---|---|
| 体验 | 22 / 20 | 6 / 14 | 44秒，比旧12音增加20秒 |
| 标准 | 40 / 38 | 11 / 27 | 80秒，原时序不变 |
| 研究 | 60 / 58 | 17 / 41 | 120秒，原时序不变 |

施测前只告知总音数/操作，不透露固定目标总数以供计数猜测；实际目标数在完成后报告展示。

所有档位仍n2、五音高262/330/392/494/587Hz、500ms音+1500ms空档；8音练习/全对最多三轮、按键映射、首按、保存重试、缺失及FINAL规则不改。配置仍冻结原字段，没有新增通用框架；新配置拒绝无法提供至少6目标和至少1非目标、或无法避免连3目标的设置，不降低原门槛。

一手方法依据：[Gao et al. (2020), Speech in noise perception improved by training fine auditory discrimination: far and applicable transfer of perceptual learning](https://pmc.ncbi.nlm.nih.gov/articles/PMC7653913/)，DOI10.1038/s41598-020-76295-9，方法“Auditory working memory task”。原方法每序列40+n音、固定12随机目标、100ms音/2.5s每项、八频音集、60dB SPL；本修订借鉴固定目标机会，保留本项目原频率与时序，**仍是研究变式，不是完整复刻**。未复制原音集，浏览器无声压/物理音频时序校准。

6目标满足既有计数门槛，绝不等于信度、效度或个体估计稳定。短版优先机会数与本次反应描述；不按目标是漏按，不按非目标是正确拒绝，起始音不进命中/误报分母。没有改变旧冻结或补零。

定向验证：BE `src/__tests__/cognitive/auditorynback-v11.test.ts` 3/3（旧反例与旧golden、三档计数/FE镜像/最大连击、配置与缺少FINAL拒绝）；FE `AuditorynbackTaskV11.test.tsx` 1/1（真实组件练习结束→播放新正式音→保存原始未按payload）。Node24.21/Vitest4.1.11。新fixture是合成工程原件，不是被试或信效度数据。浏览器/实际新冻结身份集成由三工具父交付记录单列；没有CI/安装/发布/生产。
