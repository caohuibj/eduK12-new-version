# Visualwm 版本边界

`visualwm/1.1.0/1.0.0` 只修复练习向正式首题泄漏刺激和答案。旧
`1.0.1/1.0.0` 身份、seed、定义、展示原件和评分fixture仍保留；旧runner
默认 `independentPractice=false`，保留练习重复正式当前题的既有行为以支持冻结会话。

新版wrapper为共享runner传入 `independentPractice=true`。练习使用固定2方块
示例，正式刺激仅有3–6项，因此不可能与任一正式题重复。练习仍只有1题、
无成绩门槛、给答案反馈、不持久化。正式仍使用原 `visualwmTrial(seed,index)`，
没有改变seed、挪动index或消耗额外正式题；400ms注视、500ms学习、900ms保持、
不限时探测、按键1/2与保存重试均沿用原实现。

配置/引擎/报告/展示新版本均为1.1.0，评分仍为1.0.0。新身份使用独立元数据
原件，纠正有效RT口径：未中断、已答、RT达到下限，包括正确和错误作答。
总体正确率的分母仍是计划正式试次数；命中/误报分别只以未中断且已答的
变化/未变题为分母，条件无记录则缺失。练习不进入任何分母。

这是全阵列、带位置线索的颜色变化检测项目变式，不是标准测验复刻；本版
不计算容量K或d′，不提供人群常模或诊断。公共历史dual-contract旧条目未在
此局部修复中改写，不能据其中的指标名称声称新身份实际生成了这些指标。

定向检查：前端旧1.0.1的实际DOM重复复现、新版练习与正式首题隔离及原
seed/index/时序/payload；后端新旧身份重放原正式fixture、计划/条件分母与
错误RT纳入。真实浏览器关键呈现和公共generated/registry集成由父任务统一完成。
