## 语义与版本

原1.0.0存在位置、缩放和轮廓线索：目标沿用答案场坐标，预览和搜索SVG物理尺度不同；生成题只有目标是三角形；练习点击任意图形均提示成功。分离多边形并未真正嵌入背景。

新 engine/config/scorer/presentation/report 均为1.1.0，stimulusSet为 `embeddedfigures-zh-v1.1.0`，randomization为 `embeddedfigures-gen-v1.1.0`。新生成器全部按冻结seed/index产生原创线条图块，取消首4题跨seed固定答案。七个图块同线数、颜色、线宽和命中规则，恰一个图块含目标的完整同形、同尺度、同方向轮廓；边延伸到背景，目标预览居中，不携带答案位置。生成时检查真实线段与交点，防止干扰线意外构成第二个目标。

这是自编七选择匹配变式，包含短时目标保持、视觉查找和选择操作，不是GEFT/L-EFT原版或纯粹场独立性的测量。方法参考 [de-Wit等，2017，PeerJ5:e2862](https://doi.org/10.7717/peerj.2862) 对嵌入和线条延伸的讨论；没有复制其刺激或常模。

练习使用独立seed，只在回答后显示教学高亮；错误/超时须重读说明后再练习，练习不写正式试次。正式题无答案高亮，只记录首次选择。保存结果不确定时重试相同payload，不允许重选或改反应时；下一题依赖真实父级trialIndex推进。结束判断也使用真实末题index，不按本次挂载的提交次数计数。末题已保存但完成确认失败时显示独立重试，不重复提交末题，完成请求进行中阻止重复调用。

体验6题、科研16题共用同一规则，原已有standard保留10题；显示3秒、响应15秒、有效RT下限400毫秒是本项目配置。时长区间仅估计，不是实测容量或测量精度承诺。无常模参考，report.referenceMode=none。准确率、错误/超时次数和正确有效RT分别报告；有效零值保留，未答与RT缺失为null，空序列不生成完整结果，不提供能力指数、IQ、诊断或职业推断。

V1生成器、scorer、配置/试次schema及原fixture逐字节保留，并有独立legacy Runner与旧identity；V1不推荐新建。旧冻结作答和报告不迁移到1.1.0，也不按新刺激重算。两个版本的表现不直接比较。
