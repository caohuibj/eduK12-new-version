# Memory literature validation v1

- Construct: Digit Span Forward / short-term serial information retention.
- Literature protocol: start length two, two trials per length, approximately one digit onset per second; advance after at least one correct response across both trials and stop after zero correct.
- Commercial candidate: presentation uses 800 ms digit display plus 200 ms interval, maximum length eleven, and the same two-trial progression.
- Scoring: maximum span, passed levels, first-try passes and response-duration summary; Product Index is `maxSpan / maxLength * 100`.
- Limitations: developmental age effects prevent unstratified K12 norm claims; the online short form needs pilot floor/ceiling review.
- Approved candidate: literature reference remains unavailable until protocol, language and cohort matching are approved.
- Sources: Woods et al., 2011, DOI 10.1080/13803395.2010.493149; Treviño et al., 2021, DOI 10.1186/s41235-021-00313-1; Gur et al., 2012, DOI 10.1037/a0026712; Ahmed et al., 2022, DOI 10.1037/dev0001396.
