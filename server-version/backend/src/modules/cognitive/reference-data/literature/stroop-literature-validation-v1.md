# Stroop literature validation v1

- Construct: color-word interference and response accuracy.
- Literature protocol: fifteen practice trials, one hundred twenty formal trials, balanced congruent/incongruent conditions, 400 ms fixation, 3000 ms maximum stimulus, valid RT above 200 ms.
- Commercial candidate: two-round competency practice and twenty-four formal trials with exact 12/12 balance, 500 ms fixation, 2000 ms maximum stimulus and 200 ms RT floor.
- Scoring: overall/condition accuracy, condition RT medians, interference and timeout counts; Product Index is overall accuracy × 100.
- Limitations: short-form difference scores are sensitive to local trial count, stimuli and administration; no strong inhibition conclusion is made.
- Approved candidate: literature reference remains unavailable until exact protocol and cohort matching is approved.
- Sources: Forte et al., 2024, DOI 10.1186/s40359-024-01844-0; Hedge et al., 2018, DOI 10.3758/s13428-017-0935-1; Green et al., 2016, DOI 10.3758/s13423-015-0968-3.
