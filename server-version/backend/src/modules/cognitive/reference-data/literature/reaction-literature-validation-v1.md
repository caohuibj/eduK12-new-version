# Reaction literature validation v1

- Construct: simple reaction time and response variability.
- Literature protocol: three practice trials, thirty formal trials, 700–1500 ms foreperiod, 2000 ms timeout; median/mean/SD/ICV are retained.
- Commercial candidate: twenty formal trials, same foreperiod and timeout; this short form requires local pilot reliability review.
- Scoring: server-derived valid RT, miss rate, premature count and variability; Product Index is product-defined, not a norm position.
- Limitations: device and input method can affect RT; no device correction or norm claim is made.
- Approved candidate: literature reference remains unavailable until protocol and cohort matching is approved.
- Sources: Rutter et al., 2020, DOI 10.3389/fnagi.2020.00062; Passell et al., 2021, DOI 10.3758/s13428-021-01597-3.
