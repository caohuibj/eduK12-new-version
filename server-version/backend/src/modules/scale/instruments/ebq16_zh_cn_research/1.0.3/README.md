# EBQ-16 中文研究工作译稿（生产试用版）1.0.3

## 本版结论

- 身份：Becerra、Preece 与 Gross（2020）Emotion Beliefs Questionnaire 的 16 题成人版；不是平台临时合成量表。
- 来源：PLOS ONE 原文表 3 与作者提供的 16 题计分页已交叉核对，原文采用 CC BY 4.0。
- 状态：题本、计分、试用量尺、报告、配图和许可说明已闭环，标记为 `PUBLISHED`，可由总管理员直接审批并以「中文研究工作译稿／试用版」上线。人工译审、认知访谈和中国成人验证尚未完成，界面不得省略这些限制，也不得宣传为已验证中文版。
- 适用：18 岁及以上成人研究和低风险自我反思；不是中小学生量表、诊断工具或情绪调节能力测验。

## 题本与计分

- 16 题，固定顺序；七档同意度。原作者只有 1「非常不同意」、4「既不同意也不反对」、7「非常同意」三个文字锚点，2、3、5、6 保持为数字。
- 四个 4 题和分：负面情绪可控性、积极情绪可控性、负面情绪作用、积极情绪作用。
- 两个 8 题组合和分：总体可控性、总体作用。
- 一个 16 题总和分。七个分数共用题目，不能再次相加，也不能理解为七种彼此独立的特质。
- 分数越高，表示越认同情绪难以改变、没有用或有害；不表示当前情绪更多，也不表示实际调节能力更差。

## 试用量尺

本版只为四个主报告分数提供理论范围分段：总体可控性、负面情绪作用、积极情绪作用和总分。边界直接对应原 1／4／7 响应锚点：

- 4 题分数：4–12、>12–20、>20–28。
- 8 题分数：8–24、>24–40、>40–56。
- 16 题总分：16–48、>48–80、>80–112。

这些分段必须显示为「试用量尺」「非人群位置」。它们不是常模、百分位、临床阈值、诊断界线或能力等级，也不引用样本统计量。
