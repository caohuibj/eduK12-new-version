# IPIP-50 简体中文研究工作译稿（生产试用版）1.1.1

## 本版结论

- 身份：International Personality Item Pool 官网公开的 50 题大五因素标记样例；不是平台临时合成量表。
- 来源：官网题本、五维计分键、计分说明和公有领域许可已逐项核对。题项可用于商业或非商业项目，但中文为平台独立工作译稿，不声称作者认可或已完成本地验证。
- 状态：题本、计分、试用量尺、五维报告、16 幅原创配图和许可说明已闭环，标记为 `PUBLISHED`，可由总管理员直接审批并以「未验证中文工作译稿／生产试用版」上线。
- 适用：18 岁及以上成人研究和低风险自我反思；不用于 K12、诊断、招聘、升学、岗位匹配、排名或其他高风险决定。

## 题本、选项与计分

- 50 题，固定使用官网样例顺序；五档为「非常不符合、比较不符合、既谈不上符合也谈不上不符合、比较符合、非常符合」，记 1–5 分。
- 五个维度各 10 题、各自 10–50 分；没有人格总分，也不把五项再相加或平均。
- 负向题按 `6 - 原分` 反向计分：
  - 外向性：正向 01、11、21、31、41；反向 06、16、26、36、46。
  - 宜人性：正向 07、17、27、37、42、47；反向 02、12、22、32。
  - 尽责性：正向 03、13、23、33、43、48；反向 08、18、28、38。
  - 情绪稳定性：正向 09、19；反向 04、14、24、29、34、39、44、49。
  - 智性／想象力：正向 05、15、25、35、40、45、50；反向 10、20、30。
- 每个维度要求所属 10 题完整；不补值、不折算。任一题缺失时平台采用保守策略抑制整份解释，这一策略不是官网规定。

## 试用量尺

五个维度均只提供理论范围分段：10–25、>25–35、>35–50。它们必须显示为「试用量尺」「非人群位置」，不是中文常模、百分位、人格类型、好坏等级或能力界线；没有经验样本、诊断阈值或招聘效度。

## 报告与配图

- 报告版本：`1.3.0`；配图键：`ipip50_zh_cn_research/1.1.1/1.3.0`。
- 五个维度分别提供低／中／高三段科普化解释与一个可选行动，不生成总人格结论，也不从一个维度推断其他维度。
- 16 幅原创插画由 1 幅总览图和五维各 3 幅分档图组成；图片只帮助阅读，不参与计分、分档或授权。
