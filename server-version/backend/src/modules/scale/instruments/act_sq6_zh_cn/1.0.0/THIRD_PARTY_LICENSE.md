## Changes in this package

- AI-assisted **Chinese working translation** of all six English items,
  the instruction and all five response labels; not an established Chinese form.
- Digital content/scoring metadata, an adult-only ACT post-session scope and a
  complete-response rule. These conservative platform policies are not claimed
  as the authors' validated age cutoff or missing-data algorithm.
- New plain-language report text and synthetic, non-patient examples.
