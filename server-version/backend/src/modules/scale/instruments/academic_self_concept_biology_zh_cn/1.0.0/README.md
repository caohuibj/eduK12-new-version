# 学科自我概念｜生物 1.0.0 内容审定

## 身份、来源与权利

- 工具身份：`academic_self_concept_biology_zh_cn@1.0.0`，源码执行状态为 `PUBLISHED`，目录科学成熟度维持 `PILOT`。
- 性质：Huisurvey 第一波学习动机项目的四题学科替换版。它是项目自编版本，不是某个外部经典量表的逐字中文授权版，也不借用研究论文为自身效度背书。
- 原始记录：[Learning Motivation Canonical Data Package / Huisurvey Wave1 范围确认](https://app.notion.com/p/3e5d27635a3881e2a904cbc9dcf39bf8)。
- 权利：源码记录为 `self_authored`、允许再分发；项目作者于 2026-10-25 确认自编并要求正式入库。报告内的心理学研究仅用于构念科普，不改变题本权利来源。

## 题本与选项核对

题序固定，不随机；四题均为必答的正向题，没有反向计分。

| 题号 | 题干 | 方向 |
| --- | --- | --- |
| LM-01 | 我的生物成绩很好 | 正向 |
| LM-02 | 生物是我学得最好的科目之一 | 正向 |
| LM-03 | 我学习生物的速度很快 | 正向 |
| LM-04 | 在生物课上，我理解最难的问题 | 正向 |

所有题共用同一组选项：1＝完全不同意，2＝不同意，3＝中性，4＝同意，5＝完全同意。选项顺序固定，选项值与计分值一一对应。

## 计分与缺失规则

- 唯一分数为 `academic_self_concept`，计算四题算术平均值，不计算四题总和，也不另建分量表。
- 四题权重均为 1，全部使用原始分数，无反向、重编码或隐藏加权。
- 回答 4 题时取 4 题均分；回答 3 题时按 3 题均分并标记为有限质量；少于 3 题时不计算分数，缺失不会被当作 0 分。
- 页面保留两位小数。内置计分样例覆盖全选 1 得 1.00、全选 5 得 5.00、三题均选 2 得 2.00。

## 阈值与证据等级

生物版没有与本题本、计分版本完全一致的经验样本。当前五档仅将 1—5 分可选范围等距切分，用于选择不同表述，属于试用估算：

| 分档 | 运行时区间 | 证据 |
| --- | --- | --- |
| very_low | 1.0—1.8 | 理论量尺范围 |
| low | 大于 1.8，至 2.6 | 理论量尺范围 |
| middle | 大于 2.6，至 3.4 | 理论量尺范围 |
| high | 大于 3.4，至 4.2 | 理论量尺范围 |
| very_high | 大于 4.2，至 5.0 | 理论量尺范围 |

这些区间不是常模、百分位、能力等级、临床阈值或升学标准。初中与高中目前使用同一量尺切分，但仍按学段分别匹配，不能据此宣称跨学段等值。

## 报告、配图与标签

- 报告版本 `1.2.0` 只解释本量表的生物学习自我看法。主叙事以显微观察为线索，把“我会不会”转成“看见了什么、怎样解释、还想验证什么”，不逐题解读，也不推断能力或天赋。
- 五个区间分别提供不同的行动建议；整体建议包含“观察—解释—疑问”三格卡。分数名称明确标记“试用版”。
- 配图为一张显微观察课堂主图和五张分档行动图，均为本轮原创生成并经联系表逐张复核；无外部品牌、可读文字或真实人物，六张图不复用其他量表素材。
- 标签：`academic_self_concept`、`biology`、`student_self_report`、`subject_specific_self_concept`、`learning_motivation`、`secondary_education`、`reflective_learning`。

## 审定结论与定向检查

题干、选项、题序、计分、缺失规则和来源权利结构完整。源码继续保持 `PUBLISHED`，科学成熟度保持 `PILOT`；新增报告和配图需在通用声明内容底座合入、生成注册文件并完成管理员审批后才能成为可选生产组合。

定向检查覆盖：同身份历史轴不漂移；三个内置计分样例；2 题不足与 3 题折算边界；初中、高中各 1—5 分的五档映射；报告五档文本唯一性；配图键、文件、尺寸和替代文字一致性。

构念科普参考：Marsh 等的纵向研究提示学科自我概念与成绩可能存在双向关系，但不能据此从一次个体得分推出因果（[doi:10.1111/j.1467-8624.2005.00853.x](https://doi.org/10.1111/j.1467-8624.2005.00853.x)）；Jansen 等提示科学领域的生物、化学、物理自我概念应按学科区分（[doi:10.1016/j.lindif.2013.12.003](https://doi.org/10.1016/j.lindif.2013.12.003)）。
