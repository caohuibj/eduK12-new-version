# 学科自我概念｜数学 1.0.0 内容审定

## 身份、来源与权利

- 工具身份：`academic_self_concept_mathematics_zh_cn@1.0.0`，源码执行状态为 `PUBLISHED`，目录科学成熟度为项目范围内的 `RESEARCH_READY`。
- 性质：Huisurvey 第一波学习动机项目的四题学科版。它是项目自编版本，不是某个外部经典量表的逐字中文授权版；“项目范围内可研究”不等于已建立全国常模或跨学段测量等值性。
- 原始记录：[Learning Motivation Canonical Data Package / Huisurvey Wave1 范围确认](https://app.notion.com/p/3e5d27635a3881e2a904cbc9dcf39bf8)。
- 权利：源码记录为 `self_authored`、允许再分发；项目作者于 2026-10-25 确认自编并要求正式入库。报告引用的研究只用于构念科普，不改变题本权利来源。

## 题本与选项核对

题序固定，不随机；四题均为必答的正向题，没有反向计分。

| 题号 | 题干 | 方向 |
| --- | --- | --- |
| LM-01 | 我的数学成绩很好 | 正向 |
| LM-02 | 数学是我学得最好的科目之一 | 正向 |
| LM-03 | 我学习数学的速度很快 | 正向 |
| LM-04 | 在数学课上，我理解最难的问题 | 正向 |

所有题共用同一组选项：1＝完全不同意，2＝不同意，3＝中性，4＝同意，5＝完全同意。选项顺序固定，选项值与计分值一一对应。

## 计分与缺失规则

- 唯一分数为 `academic_self_concept`，计算四题算术平均值，不计算四题总和，也不另建成绩、速度或难题理解分量表。
- 四题权重均为 1，全部使用原始分数，无反向、重编码或隐藏加权。
- 回答 4 题时取 4 题均分；回答 3 题时按 3 题均分并标记为有限质量；少于 3 题时不计算分数，缺失不会被当作 0 分。
- 页面保留两位小数。内置计分样例覆盖全选 1 得 1.00、全选 5 得 5.00、三题均选 2 得 2.00。

## 报告、配图与标签

- 报告版本 `1.2.0` 只解释本量表的数学学习自我看法。主叙事从一道未做完的几何题出发，把“我数学不行”拆成已知条件、可说明的一步和仍需证据的一步；不逐题解读，也不把均分当作数学能力。
- 五个区间对应冻结参考中的同名分档，分别提供不同的行动建议；整体建议包含“变一个条件”练习。相同报告版本覆盖全部年级，学段差异来自管理员选定的参数版本和冻结上下文，不在入库时另造年级报告。
- 配图为一张几何推理课堂主图和五张分档行动图，均为本轮原创生成并经联系表逐张复核；无可读公式、外部品牌或真实人物，六张图不复用其他量表素材。
- 标签：`academic_self_concept`、`mathematics`、`student_self_report`、`subject_specific_self_concept`、`mathematics_learning`、`learning_motivation`、`secondary_education`、`reflective_learning`。

## 审定结论与定向检查

题干、选项、题序、计分、缺失规则、来源权利和项目参考结构完整。源码继续保持 `PUBLISHED`，科学成熟度保持项目范围内的 `RESEARCH_READY`；新增报告和配图需在通用声明内容底座合入、生成注册文件并完成管理员审批后才能成为可选生产组合。

定向检查覆盖：同身份历史轴不漂移；三个内置计分样例；2 题不足与 3 题折算边界；初中、高中各 1—5 分的学段专属映射；报告五档文本唯一性；配图键、文件、尺寸和替代文字一致性。实测映射显示，同一原始均分在两学段可能进入不同区间，这是冻结参考的预期结果，不应被报告版本选择覆盖。

构念科普参考：Marsh 等的纵向研究提示数学自我概念、兴趣与成绩可能存在双向关系，但不能据此从一次个体得分推出因果（[doi:10.1111/j.1467-8624.2005.00853.x](https://doi.org/10.1111/j.1467-8624.2005.00853.x)）；学科自我概念应与具体学科和学习经历对应，不能等同于一般自尊（[doi:10.1111/j.1745-6916.2006.00010.x](https://doi.org/10.1111/j.1745-6916.2006.00010.x)）。
