# PR4：匿名研究身份与波次

基线：PR3 1a49c571。实现身份码方案；研究身份没有 users、organization_memberships、class 或关系绑定。身份不是跨研究通用账号。

## 功能与边界

| 场景 | 当前实现 |
|---|---|
| A：无需登录，单次访客 | 沿用公开测评当次 recovery 凭证和内容允许的个人反馈；不创建研究身份，不建立长期个人档案。 |
| B：非实名多次参加 | 显式选择研究内关联后生成 256 位身份码，数据库只存 SHA-256。身份码可换设备恢复本人任务和多波次历史。短显示码不能登录。 |
| 匿名关系 | SELF 作答，不进入组织关系 Run，不成为教师的学生或组织成员。研究身份只关联本研究内的匿名作答。 |
| 后续任务 | 研究主页列出同一研究后续开放波次；同身份同波次只创建一次，并发重试不会重复扣配额。 |
| 本人报告 | 恢复已有 attempt，继续使用原 canonical runtime 和内容报告权限。历史列表不是自动计算的心理变化报告。 |
| 发布者统计 | 严格研究所有者可查看各波次参与/完成人数、作答次数及放弃次数。访客人数是随机参与身份数，不能识别同人跨设备重答。 |
| 波次 CSV | 普通公开 Composite 的已完成匿名作答，按 exact accessTokenId 过滤；保留既有字段投影，只额外提供不具登录能力的研究内显示码。 |
| 撤销与关闭 | 停用身份码同时撤销已有 parent 和 Cognitive child 恢复凭证，保留已提交研究数据。关闭研究停止新加入/作答，本人历史仍受原内容权限控制。 |

B 模式覆盖公开 Composite 的原有 FORM / SCALE / COGNITIVE / SITUATIONAL 单元。单独旧版 Questionnaire/Cognitive 链接仍是 A 模式；可用 Composite 承载研究波次。只支持绑定全新、本人发布且尚未使用的公开链接，不把旧访客作答追溯关联成 B 身份。

测评包 ASSESSMENT_BUNDLE 不开放通用 CSV，继续使用既有包报告导出。新的研究受众原始题目/trial 数据权限、科学有效的跨波次比较、机构群体心理报告、外部家长本人纵向 artifact 均留置；没有通过绕过原内容权限补齐。正式关系内容 registry 仍待科学发布和真实七受众验收。

## 权限与凭证

- 发布者接口沿用 cookie 身份与 CSRF；当前教师/管理员仍只能管理自己的研究与内容，平台管理员无研究数据越权通道。
- 公开接口只接受 Authorization Bearer 身份码，客户端 credentials=omit；cookie、短显示码、别的研究身份及任意 attemptId 不提供权限。
- 身份码仅在当前创建页面显示，浏览器会话保存。主动退出清理身份码与已知 attempt 恢复凭证，刷新失败立即清空历史。
- study → participant 锁顺序与 close/revoke/admission 一致，映射和配额扣减在同一事务。
- DATA_PSEUDONYM_KEY 是现有配置；轮换会影响派生恢复凭证，应按既有密钥迁移流程执行，不能静默换钥。
- API no-store、公开限流；不改评分、FINAL、minimumN 或冻结科学定义。

## 验证

真实 PostgreSQL+HTTP 回归：A/B 完整 FORM FINAL 提交、跨研究/跨身份隔离、同波次并发幂等、配额/过期、历史不可追溯绑定、精确波次导出、所有者限制、关闭后恢复、撤销后旧能力失效。

前端新增 7 项行为回归：A/B 分流、明确同意、本人报告恢复、退出清理、刷新权限失败、列表初次加载与跨资源迟到响应、过期入口恢复。390/768/1440 浏览器矩阵覆盖完整身份创建→主页历史→刷新失败，检查无横向溢出和运行错误。
