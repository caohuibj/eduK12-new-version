## 系统简介

欢迎使用教育平台教师端！本系统为教师提供完整的在线教学管理工具，包括课程管理、作业发布、打卡任务、视频资源管理等功能。

### 访问入口
- **门户**: `/`
- **教师登录**: `/teacher/account-login`
- **教师注册**: `/teacher/login`（验证教师码后进入 `/teacher/register`）
- **管理员登录**: `/admin/login`

### 管理员账号
管理员账号来自部署环境中的 `ADMIN_USERNAME` / `ADMIN_PASSWORD`。教师需先用教师码注册，再由管理员在「用户管理」中审核通过。

## 登录与注册

### 教师注册
1. 访问 `/teacher/login`，输入管理员发放的教师码
2. 进入 `/teacher/register` 填写用户名、密码和姓名
3. 提交后**不会立即登录**，需管理员在「用户管理」中点通过
4. 审核通过后再到 `/teacher/account-login` 登录

### 教师登录
1. 访问 `/teacher/account-login`
2. 输入用户名和密码
3. 进入教师工作台。待审账号会提示正在等待管理员审核。

### 教师账号延期
教师账号有有效期限制，到期前请联系管理员延期。

## 课程管理

### 创建课程
1. 进入课程列表页面
2. 点击"新建课程"按钮
3. 填写课程信息：
   - 课程名称（必填）
   - 课程描述（选填）
   - 课程封面（选填，支持上传图片）
4. 点击"创建"
5. 系统自动生成课程码（如：ABC123）

### 管理课程
课程卡片操作：
- **编辑**: 修改课程名称、描述、封面
- **删除**: 删除课程（有学生时会有警告提示）
- **结束课程**: 课程标为已结束并停止招募；**不会**冻结学生账号，学生仍可登录并参加其他课
- **查看学生**: 查看选课学生列表
- **复制课程码**: 快速复制课程码分享给学生

### 课程状态
- 🟢 **进行中**: 正常教学状态
- 🔴 **已结束**: 本课关闭、停止招募；学生账号保持可用

### 课程码使用
将课程码分享给学生，学生通过课程码加入课程。

## 作业管理

### 创建作业
1. 进入作业列表页面
2. 点击"新建作业"按钮
3. 填写作业信息：
   - **选择课程**: 选择所属课程
   - **作业名称**: 输入作业标题
   - **作业描述**: 简要说明作业要求
   - **详细内容**: 富文本编辑详细要求
   - **截止时间**: 设置提交截止时间
4. 添加作业内容：
   - **视频**: 从视频库选择或添加外部链接
   - **图片**: 上传参考图片
   - **选择题**: 添加单选/多选题目

### 作业题目类型

#### 选择题
- 支持单选题和多选题
- 设置题目和选项
- 标记正确答案
- 学生提交后自动评分

#### 文字题
- 学生自由输入文字答案
- 教师手动批改
- 支持添加评语

### 批改作业
1. 在作业列表点击"查看提交"
2. 查看学生提交列表
3. 点击学生查看详情
4. 选择题已自动评分
5. 对文字题添加评语
6. 保存批改结果

### 批量批改
1. 在提交列表选择多个学生
2. 点击"批量评语"
3. 输入统一评语
4. 确认批量添加

### 导出数据
支持导出作业提交数据，便于备份和分析。

## 打卡管理

### 创建打卡
1. 进入打卡列表页面
2. 点击"新建打卡"按钮
3. 填写打卡信息：
   - **选择课程**: 选择所属课程
   - **打卡名称**: 输入标题
   - **打卡内容**: 详细说明
   - **截止时间**: 设置打卡结束时间
   - **查看权限**: 是否允许学生查看他人打卡
4. 添加多媒体：
   - 上传视频
   - 上传图片
5. 点击"创建"

### 查看打卡提交
1. 在打卡列表点击"查看提交"
2. 查看所有学生打卡记录
3. 查看打卡内容和图片
4. 查看提交时间

### 打卡设置
- **允许查看他人**: 开启后学生可互相查看打卡内容
- **截止时间**: 超过时间学生无法打卡

## 视频库

### 上传视频
1. 进入视频库页面
2. 点击"上传视频"按钮
3. 选择本地视频文件
   - 支持格式：MP4、WebM、OGG、MOV
   - 大小限制：500MB
4. 输入视频标题
5. 等待上传和转码完成

### 视频状态
- ⏳ **处理中**: 视频正在转码
- ✅ **已完成**: 视频可正常使用
- ❌ **失败**: 转码失败，需重新上传

### 管理视频
- **播放**: 预览视频内容
- **编辑**: 修改视频标题
- **删除**: 删除视频（作业中使用的视频无法删除）
- **复制链接**: 获取视频链接

### 使用视频
创建作业时可直接从视频库选择视频，无需重复上传。

### 外部视频
支持添加外部视频链接（如B站视频），系统自动嵌入播放。

## 常见问题

### Q1: 教师码是什么？
教师码是注册教师账号的凭证，需向管理员申请。

### Q2: 如何获得教师权限？
1. 向管理员申请教师码
2. 使用教师码注册账号
3. 等待管理员审核通过

### Q3: 学生加入课程失败？
- 确认课程码正确
- 确认课程处于"进行中"状态
- 确认学生账号未过期

### Q4: 视频上传失败？
- 检查文件格式（MP4/WebM/OGG/MOV）
- 检查文件大小（不超过500MB）
- 检查网络连接
- 等待转码完成（大文件需要更长时间）

### Q5: 作业无法删除？
已有学生提交的作业无法删除，如需删除请先删除所有提交记录。

### Q6: 图片预览不显示？
- 检查图片是否上传成功
- 刷新页面重试
- 检查浏览器网络请求

### Q7: 如何延期账号？
联系管理员，提供用户名和延期时长。

### Q8: 结束课程后能否恢复？
结束课程后无法恢复，请谨慎操作。
