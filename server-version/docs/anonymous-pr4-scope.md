# 匿名被试现状与 PR4 范围

核对基线：PR2 `f57a08b7` 及其后的 PR3 开发。此文记录实现证据和下一 PR 的验收范围，不代表 PR4 已实现。

| 需求 | 当前情况 | PR4 工作 |
|---|---|---|
| 无教师—学生关联，只完成本人作答 | 公开链接通过单次匿名身份/恢复凭证进入，不能据此获得成员、班级或关系作答权限 | 统一匿名入口限制 SELF；禁止身份码升级为学生/观察者关系 |
| A：不登录，完成后看个人反馈 | Composite/公开认知等已有恢复凭证；个人反馈仍受内容报告政策控制，不保证每种内容都给分数 | 统一“继续作答/本次反馈”体验，不建立跨测验个人档案 |
| B：非实名登录，多次作答 | 现有学生注册需要课程码，教师注册需要教师码且界面要求姓名；没有独立研究被试账户路径。昵称未校验实名不能据此称为匿名账户 | 新增独立的假名被试身份，既可用账号认证，也可用高熵身份恢复凭证；不自动绑定组织成员、学生或教师 |
| 作答后身份码，多波次、多测试 | 当前 recovery token 绑定 attempt/公开链接，restart 会产生新凭证；不是跨波次登录身份。`ANON-xxxxxxxx` 只是显示标识 | 为选择 B 的被试发持久身份凭证；短显示码不得独立作为认证凭证。凭证找回只显示本人的报告及有授权的研究任务 |
| 研究者人数统计和导出 | Composite 发布者有 attemptCounts/结果列表，按测评和完成时间筛选导出，匿名行采用 anonymousCode；并不等于完整研究波次模型 | 明确 study/wave 与入口绑定；区分参与人数、完成作答次数、重复作答；发布者当前权限控制统计及 CSV/SAV 导出 |
| 群体反馈 | 匿名被试不因参与而获得群体报告；研究端能读取已授权统计，不自动获得关系/个体保护结果 | 人数统计与群体心理指标分开；后者继续走既有最小人数、字段授权和科学报告规则 |

代码证据：`backend/src/services/anonymousAccess.ts`；`backend/src/modules/composite/composite.service.ts` 的 `startPublicAttempt`、`restartPublicAttempt`、`listAttemptsForTeacher`；`composite-export.service.ts` 的筛选与 `anonymousCode`；`backend/src/controllers/authController.ts` 的学生/教师注册约束。

## 实施原则

A 是单次访客模式。B 是可链接的假名身份，不应在文案中承诺多次作答无法关联。B 的身份库与实名组织关系库分离；既有 A 作答不得根据设备、昵称、IP 或显示码自动合并到 B。只有本人提供有效旧凭证并明确选择后才考虑导入，无法证明所有权的记录不关联。

内容在匿名入口必须明确允许 SELF、公开参与、报告和研究导出。身份凭证不赋予其他研究项目的读取或作答权。研究任务邀请和波次访问另行授权；失效或撤销邀请不可用于开始新作答。本人长期反馈仍需内容明确允许、既有可比性规则支持，不能复用研究 artifact 作为 HTTP 响应。

低风险工作包括入口文案、恢复流程一致性、波次筛选、完成数统计及原有导出权限收口。持久身份生命周期、A→B 导入、跨研究链接、删除/撤销后的报告保留范围需在 PR4 形成具体方案后评估；缺少本人授权或科学可比性依据的路径保持关闭。

## 验收

- A 只能恢复本次作答，不产生教师/学生关系，也不枚举其他波次。
- B 可以重复作答、读取本人允许的单次与长期反馈，换设备后凭有效认证恢复。
- 丢失短显示码不会造成账号接管；无效/撤销身份凭证一律拒绝。
- 更换研究者、波次或被试身份时，缓存和列表清空，不残留上一身份报告。
- 同一波次统计与导出的筛选范围一致，分别报告人数和作答次数。
- 研究者不能跨发布者/研究范围读数据；公开人数统计不绕过心理指标最小人数保护。
