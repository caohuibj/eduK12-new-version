## 系统简介

欢迎使用教育平台学生端！本系统为学生提供在线学习、作业提交、打卡互动等功能，方便学生随时随地参与课程学习。

### 访问入口
- **学生登录**: `/student/login`
- **学生注册**: `/student/register`

### 默认测试账号
| 用户名 | 密码 | 角色 |
|--------|------|------|
| student01 | 123456 | 学生 |

## 登录与注册

### 注册新账号
1. 访问注册页面 `/student/register`
2. 填写注册信息：
   - 用户名（必填，唯一标识）
   - 密码（必填）
   - 昵称（选填）
3. 点击"注册"按钮
4. 注册成功后自动跳转登录页面

### 登录系统
1. 访问登录页面 `/student/login`
2. 输入用户名和密码
3. 点击"登录"按钮
4. 登录成功后进入学生主页

### 忘记密码
请联系管理员或教师重置密码。

## 我的课程

### 查看已加入的课程
登录后进入学生主页，页面显示所有已加入的课程列表，包括：
- 课程封面
- 课程名称
- 课程描述
- 授课教师

### 加入新课程
1. 在主页点击"加入课程"按钮
2. 输入教师提供的课程码（如：ABC123）
3. 点击"确认加入"
4. 加入成功后课程显示在列表中

### 查看课程详情
点击课程卡片进入课程详情页，可查看：
- 课程基本信息
- 作业列表
- 打卡列表
- 课程成员

### 退出课程
如需退出课程，请联系授课教师。

## 作业管理

### 查看作业列表
在课程详情页点击"作业"标签，查看所有作业：
- 作业名称
- 截止时间
- 提交状态（未提交/已提交/已批改）
- 得分（如已批改）

### 提交作业
1. 点击作业卡片进入作业详情页
2. 查看作业要求：
   - 作业说明
   - 相关视频
   - 参考图片
   - 选择题
3. 根据要求完成作业：
   - 选择题：直接选择答案
   - 文字答案：在文本框中输入
4. 点击"提交作业"按钮

### 查看作业反馈
提交后可查看：
- 提交时间
- 批改状态
- 教师评语
- 得分情况

### 注意事项
- 请在截止时间前提交作业
- 提交后可在截止时间前修改
- 选择题提交后自动评分

## 打卡任务

### 查看打卡列表
在课程详情页点击"打卡"标签，或访问 `/student/checkins`，查看所有打卡任务：
- 打卡名称
- 截止时间
- 打卡状态
  - 🟢 进行中：可以打卡
  - 🔵 已打卡：已完成
  - ⚫ 已截止：无法打卡

### 提交打卡
1. 点击打卡卡片进入打卡页面
2. 填写打卡内容（文字描述）
3. 上传打卡图片（可选，支持多张）
   - 点击"添加图片"
   - 选择本地图片
   - 支持预览和删除
4. 点击"提交打卡"按钮

### 查看他人打卡
如果教师开启"允许查看他人打卡"，你可以：
- 查看其他同学的打卡内容
- 查看同学上传的图片
- 互相学习交流

### 打卡时间
- 请在截止时间前完成打卡
- 截止后无法补打卡

## 个人中心

### 查看个人信息
访问 `/student/profile` 查看个人信息：
- 用户名
- 昵称
- 头像
- 账号有效期

### 修改个人信息
1. 进入个人中心
2. 点击"编辑资料"
3. 修改昵称或头像
4. 点击"保存"

### 修改密码
1. 进入个人中心
2. 点击"修改密码"
3. 输入原密码和新密码
4. 点击"确认修改"

## 常见问题

### Q1: 无法登录怎么办？
- 检查用户名和密码是否正确
- 确认账号是否已过期
- 联系管理员确认账号状态

### Q2: 课程码错误怎么办？
- 确认课程码输入正确（注意大小写）
- 联系教师确认课程码是否有效
- 确认课程是否已结束

### Q3: 作业提交失败怎么办？
- 检查网络连接
- 确认所有必填项已填写
- 刷新页面后重试

### Q4: 图片上传失败怎么办？
- 确认图片格式（支持 JPG、PNG、GIF）
- 检查图片大小（单张不超过 5MB）
- 尝试压缩图片后重新上传

### Q5: 视频无法播放怎么办？
- 检查网络连接
- 尝试刷新页面
- 更换浏览器重试
- 联系教师确认视频是否正常

### Q6: 账号过期怎么办？
- 联系管理员或教师延期账号
- 提供用户名和延期需求
