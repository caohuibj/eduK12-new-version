## 范围与流程结论

在 PR #154（初始 head `4a2c5f2edaf54abdd4a1277245992d121625c3d1`）上继续完善。当前尚无服务器部署，因此这里的 PUBLISHED/DRAFT 指仓库 seed 定义，不是线上数据库状态。

标准导入流程可行：task-owned 内容 → manifest/contract → onboarding/fixtures → 页面验收 → 人工审核 → 显式发布。不要以改 seed 状态代替发布。本 PR 原本就含 seed 生命周期和批量发布工具维护，本轮还包含 CLI 无效输入快速失败修复；整支 PR 不应标记为纯 content-only，也未增加新 runtime primitive。普通后续内容包仍按原 content-only 边界校验。

## 清单

除框架占位任务 fake 外，共 24 类真实认知任务：9 类有 PUBLISHED seed（reaction、memory、stroop、gonogo、cpt、nback、corsi、sst、taskswitch），15 类候选仍 DRAFT。9 类已发布任务均有 experience / standard / research 配置。15 类候选也已有三档，无需复制三个独立 scorer 或手写 registry。

按配置而非任务类型统计：12 个真实 PUBLISHED seed、16 个 DRAFT seed（BART 保留 1.0.0，候选使用修正后的 1.1.0）；另有 1 个 fake PUBLISHED seed，不计入实际测验。发布清单精确选择 15 个候选配置。

## 本轮修复

- 15 个候选任务都有三档独立结果说明、真实题量和解释限制。图形比较/Flanker 不再把正式档写成 Pilot 版、把研究档写成 Research Ready 版。
- 补齐任务指标中文解释，包括学习增益、规则转换、反转学习、气球充气和延迟回忆；去掉 Switch、Acquisition、balloon 等参与者标签中的内部术语。
- 候选报告不显示缺乏常模支持的 0–100 产品指数；保留具体任务指标和数据质量判断。历史快照不被重新解释。
- Trail Making 原本将 A/B 目标混在同一板面，重复数字不可区分；现在按当前部分显示，明确 A/B 顺序、超时和下一目标。小屏幕板面保持目标大小，允许区域内横向滚动；忽略非主键和长按重复键盘事件。
- 塔式规划补清选柱操作方式，圆盘宽度按柱宽缩放；心理旋转缩小窄屏间距，避免按钮和刺激超出容器。
- 词汇判断和词表回忆移除“冻结配置”“生成器”等内部说明，改为练习门槛、等待与回忆操作说明。
- onboarding CLI 对未发现任务直接返回 fail-closed 结果，不加载无关 runtime 或扫描全部依赖；有效目标仍经过全部门槛。CLI 测试预算覆盖原有子进程超时上限。
