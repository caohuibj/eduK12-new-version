## 课程问卷与权限

新接口：`GET /api/courses/:id/questionnaires`。先通过真实认证和教师/管理员角色检查，再检查课程内容访问权限。未关联当前课程、未发布的新问卷和普通综合测评不会计入投放问卷。

只返回投放元数据，不返回题目答案、个体报告或报告授权。共享课程的教师可查看该课程的投放元数据，但不能由此取得问卷编辑权；只有问卷作者或管理员获得管理链接。旧版管理链接与新版管理链接分别指向各自编辑器。接口失败时页面提示加载失败并提供重试，不把失败伪装为“问卷 0 / 暂无问卷”。

审计查询继续受组织治理守卫保护。成员对象姓名关联同时校验对象属于该组织，避免将其他组织的成员对象映射到本组织日志。
