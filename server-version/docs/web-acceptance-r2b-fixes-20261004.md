# Huisurvey 第二轮网页验收修复复核（2026-10-04）

本轮合并教师阶段报告和后续串行角色报告，以后者的新证据为准，避免重复计算问题。修复范围是以下三项明确缺陷、两项有源码依据的统计候选，以及相关中文说明和窄屏展示。提交到既有草稿 PR #233，继续暂缓 GitHub Actions。这里记录代码及本地验证，不能替代生产部署后的验收。

## 相关体验修复

- 审计主文案显示中文操作和对象类别，姓名优先；原事件、账号与对象 ID 保留于标题和可展开技术标识。
- 组织导出页使用安全事项、报告类型、报告版本编号和下载时限等业务说明；不改变安全事项可见范围、报告权限或下载复核。
- 普通问卷空内容提示指导添加表单题或测评项；报告的 Context/Modules 标签改为中文。传统综合测评的发布条件保持不变。
- 视频来源 library 改为“素材库”；课堂创建说明统一为学生扫码/课堂码加入，无需先加入课程。
- 文档库沿用已有小屏记录卡片规则（CSS 宽度 ≤767px），操作区域随卡片展示。769px 仍使用表格；更宽表格的滚动不是本轮必修功能缺陷。
