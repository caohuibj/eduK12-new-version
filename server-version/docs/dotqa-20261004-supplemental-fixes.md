| I05 空问卷草稿提示 | 源码与新错误态截图确认可改进 | 新版编辑器增加名称与公开截止时间的字段级提示、aria-invalid、错误关联和焦点移动；保留 API 返回的 message 对象，避免吞成笼统“操作失败”。后端名称校验返回中文提示。实际规则允许课程问卷草稿暂不选课程，发布前才要求至少一个课程，已显示该说明。 |

| I07 入课提示冲突 | 当前后端规则确认 | Socket、Web 课堂会话及移动课堂加入逻辑均未要求课程成员关系；教师准备页改为“课程用于归属和管理课堂；学生凭课堂码参与，无需先加入课程”。不修改加入权限。 |

I01 的浏览器测试采用 CSS 视口模拟。640/720 是常见桌面放大后的重排宽度检查，不能替代原生 Ctrl+plus 200% 及其 DPR/字体缩放验证。本轮没有宣称完成真实 200% 或手机真机验收；生产复核时还应使用普通桌面原生 200%、360/390，以及原报告的 250×422/DPR2 条件。

I02 的受保护图片依赖限时签名能力和服务器访问校验；将签名写进长期保存的工作簿会很快失效，也会扩大能力的传播范围。此补丁选择原清单明确允许的“无链接说明”方案，没有把图片开放为永久匿名地址。历史非 HTTP(S) 字符串同样显示无链接说明，不会执行或拼接对象。若未来产品需要离线图片，可单独设计受授权的带图片归档导出。
