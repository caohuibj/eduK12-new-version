## 验证范围

- 前端 ESLint（错误级别）、`npm run typecheck`（含路由清单和会话鉴权门禁）。
- 前端和后端 `npm run build`；后端包含内容 manifest、onboarding 和资格门禁。

- 本地生产构建的 Chrome 浏览器 9 个场景，桌面和移动视口；所有 API 请求为测试响应，未写入生产服务。二维码像素绘制在真实浏览器中检查，非 jsdom 模拟。
- 基础与 monitoring Docker Compose 配置检查通过，使用进程内虚拟配置值；没有启动数据库或执行容器部署。
