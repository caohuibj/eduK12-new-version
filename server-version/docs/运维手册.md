## 系统架构

### 技术栈
- **后端**: Node.js + Express + TypeScript + Prisma
- **前端**: React + TypeScript
- **数据库**: PostgreSQL 14
- **缓存/队列**: Redis + Bull
- **Web服务器**: Nginx
- **进程管理**: PM2
- **视频处理**: FFmpeg

### 服务器配置
- **推荐配置**: 2核4G5M 云服务器
- **操作系统**: Ubuntu 22.04 LTS
- **存储**: 50GB+ (根据视频存储需求调整)

### 目录结构
```
/opt/ptool/server-version/
├── backend/              # 后端代码
├── frontend/             # 前端代码
├── nginx/                # Nginx配置
├── scripts/              # 运维脚本
│   ├── monitoring/       # 监控脚本
│   └── ops/              # 运维脚本
├── uploads/              # 上传文件
└── docs/                 # 文档
```

## 运维脚本概览

### 核心监控脚本

| 脚本 | 功能 | 频率 | 位置 |
|------|------|------|------|
| `health-monitor.sh` | 系统健康检查(CPU/内存/磁盘/服务) | 5分钟 | `scripts/monitoring/` |
| `auto-heal.sh` | 自动故障恢复 | 1分钟 | `scripts/monitoring/` |
| `security-monitor.sh` | 安全监控(登录/文件完整性) | 5分钟 | `scripts/ops/` |
| `performance-monitor.sh` | 性能监控(慢查询/API响应) | 10分钟 | `scripts/ops/` |
| `backup-enhanced.sh` | 数据备份(全量/增量) | 每天/每小时 | `scripts/monitoring/` |
| `log-manager.sh` | 日志管理(轮转/分析) | 每天 | `scripts/monitoring/` |
| `ops-dashboard.sh` | 运维仪表盘 | 手动 | `scripts/monitoring/` |

### 使用方法

```bash
# 健康检查
sudo /opt/ptool/server-version/scripts/monitoring/health-monitor.sh

# 安全监控
sudo /opt/ptool/server-version/scripts/ops/security-monitor.sh

# 性能监控
sudo /opt/ptool/server-version/scripts/ops/performance-monitor.sh

# 运维仪表盘
/opt/ptool/server-version/scripts/monitoring/ops-dashboard.sh
```

## 故障排查指南

### 1. 网站无法访问

**排查步骤:**

```bash
# 1. 检查Nginx状态
systemctl status nginx

# 2. 检查后端服务
pm2 status
curl http://localhost:3000/health

# 3. 检查端口监听
netstat -tlnp | grep -E "80|3000"

# 4. 检查防火墙
ufw status

# 5. 查看错误日志
tail -50 /var/log/nginx/error.log
pm2 logs ptool-api --lines 50
```

**常见问题:**
- Nginx配置错误: `nginx -t` 测试配置
- 后端服务崩溃: `pm2 restart ptool-api`
- 端口被占用: `lsof -i :3000`

### 2. 数据库连接失败

**排查步骤:**

```bash
# 1. 检查PostgreSQL状态
systemctl status postgresql

# 2. 检查连接数
sudo -u postgres psql -c "SELECT count(*) FROM pg_stat_activity;"

# 3. 检查最大连接数
sudo -u postgres psql -c "SHOW max_connections;"

# 4. 检查数据库日志
tail -50 /var/log/postgresql/postgresql-14-main.log
```

**解决方案:**
```bash
# 重启数据库
sudo systemctl restart postgresql

# 终止空闲连接
sudo -u postgres psql -c "SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE state = 'idle' AND state_change < now() - interval '1 hour';"
```

### 3. 视频上传/播放失败

**排查步骤:**

```bash
# 1. 检查磁盘空间
df -h

# 2. 检查上传目录权限
ls -la /opt/ptool/server-version/backend/uploads/

# 3. 检查FFmpeg
which ffmpeg
ffmpeg -version

# 4. 检查视频处理队列
redis-cli llen "bull:video-processing:wait"

# 5. 查看视频处理日志
grep -i "ffmpeg\|video" /var/log/ptool/monitoring/health.log
```

### 4. 系统负载过高

**排查步骤:**

```bash
# 1. 查看资源使用
top
htop

# 2. 查看进程详情
ps aux --sort=-%cpu | head -20

# 3. 检查视频处理进程
pgrep -a ffmpeg

# 4. 检查数据库查询
sudo -u postgres psql ptool -c "SELECT pid, usename, query_start, query FROM pg_stat_activity WHERE state = 'active' ORDER BY query_start;"
```

**解决方案:**
```bash
# 限制FFmpeg并发数
# 编辑 scripts/monitoring/monitor-config.env
FFMPEG_MAX_PROCESSES=3

# 清理内存缓存
sync && echo 3 > /proc/sys/vm/drop_caches

# 重启服务释放内存
pm2 reload all
```

### 5. 502 Bad Gateway

**原因:** 后端服务异常

**解决方案:**
```bash
# 重启后端服务
pm2 restart ptool-api

# 检查后端日志
pm2 logs ptool-api --lines 100

# 检查数据库连接
curl http://localhost:3000/health
```

## 应急响应流程

### 1. 服务完全不可用

**立即执行:**
```bash
# 1. 检查服务状态
pm2 status
systemctl status nginx postgresql

# 2. 尝试自动恢复
sudo /opt/ptool/server-version/scripts/monitoring/auto-heal.sh

# 3. 如果仍不可用，手动重启
pm2 restart all
sudo systemctl restart nginx postgresql redis
```

### 2. 疑似被攻击

**立即执行:**
```bash
# 1. 查看当前连接
netstat -ant | grep ESTABLISHED | awk '{print $5}' | cut -d: -f1 | sort | uniq -c | sort -rn

# 2. 查看失败登录
grep "Failed password" /var/log/auth.log | tail -20

# 3. 封禁可疑IP
sudo iptables -A INPUT -s <IP地址> -j DROP

# 4. 运行安全扫描
sudo /opt/ptool/server-version/scripts/ops/security-monitor.sh
```

### 3. 数据损坏/丢失

**立即执行:**
```bash
# 1. 停止服务
pm2 stop all

# 2. 从备份恢复
sudo /opt/ptool/server-version/scripts/monitoring/backup-enhanced.sh list
sudo /opt/ptool/server-version/scripts/monitoring/backup-enhanced.sh restore <备份文件>

# 3. 重启服务
pm2 start all
```

### 4. 磁盘空间不足

**立即执行:**
```bash
# 1. 查看磁盘使用
df -h
du -sh /opt/ptool/server-version/backend/uploads/* | sort -rh | head -20

# 2. 清理日志
find /var/log -name "*.log" -mtime +7 -delete
find /var/log/ptool -name "*.log" -mtime +30 -delete

# 3. 清理旧备份
find /backup/ptool -name "*.enc" -mtime +7 -delete

# 4. 清理视频缓存
find /opt/ptool/server-version/backend/uploads/videos -name "*.tmp" -delete
```

## 性能优化

### 1. 数据库优化

```sql
-- 查看慢查询
SELECT query, calls, mean_time, total_time 
FROM pg_stat_statements 
ORDER BY mean_time DESC 
LIMIT 10;

-- 添加索引
CREATE INDEX idx_assignments_course_id ON assignments(course_id);
CREATE INDEX idx_checkins_course_id ON checkins(course_id);
CREATE INDEX idx_videos_course_id ON videos(course_id);

-- 清理表膨胀
VACUUM ANALYZE;
VACUUM FULL;  -- 谨慎使用，会锁表
```

### 2. Nginx优化

```nginx
# 在 nginx.conf 中添加
worker_processes auto;
worker_connections 2048;

# 启用gzip
gzip on;
gzip_vary on;
gzip_min_length 1024;
gzip_types text/plain text/css application/json application/javascript;

# 缓存静态资源
location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
    expires 30d;
    add_header Cache-Control "public, immutable";
}
```

### 3. Node.js优化

```bash
# 设置环境变量
export NODE_OPTIONS="--max-old-space-size=2048"

# PM2集群模式
pm2 start dist/index.js -i max --name ptool-api
```

## 安全加固

### 1. SSH安全

```bash
# 编辑SSH配置
sudo nano /etc/ssh/sshd_config

# 修改以下配置
PermitRootLogin no
PasswordAuthentication no
Port 2222  # 修改默认端口
MaxAuthTries 3

# 重启SSH
sudo systemctl restart sshd
```

### 2. 防火墙配置

```bash
# 允许必要端口
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 2222/tcp  # SSH新端口

# 启用防火墙
sudo ufw enable

# 查看状态
sudo ufw status
```

### 3. 文件权限

```bash
# 设置敏感文件权限
chmod 600 /opt/ptool/server-version/backend/.env
chmod 600 /opt/ptool/server-version/scripts/monitoring/monitor-config.env
chmod 755 /opt/ptool/server-version/backend/uploads
chown -R www-data:www-data /opt/ptool/server-version/backend/uploads
```

### 4. 定期安全扫描

```bash
# 初始化安全基线
sudo /opt/ptool/server-version/scripts/ops/security-monitor.sh init

# 运行安全扫描
sudo /opt/ptool/server-version/scripts/ops/security-monitor.sh

# 查看安全报告
cat /var/log/ptool/security/security-report-$(date +%Y%m%d).json
```
