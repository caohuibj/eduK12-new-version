## 正常纵向管理流程

平台管理员导航增加“测量与报告方案”，路径 `/admin/reporting-content`。正常流程为：

1. 创建并发布原创、允许再分发的描述性学生自评计分量表。
2. 在管理页显式注册个人自评或群体汇总资源，分别审核、发布。注册生成私有组织运行载体；不改变原课程量表、成员关系或材料授权。
3. 选择已发布资源，创建带版本的个人纵向、多时间点群体描述或同主体群体纵向方案，审核、发布。
4. 有现行材料授权与组织投放权限的成员，在组织批次中对同一主体发布至少两次测量并实际作答。报告分析选择实际测量和匹配方案；高级设置可将实际测量资源绑定到系列与时间点。

此入口仅支持原创描述性学生自评，固定 PILOT 解释上限、可解释结果门控、缺失排除、重复观察拒绝。比较证据绑定相同资源版本与实际计分定义指纹，不声称不同版本可比较、科学效度、诊断或因果结论。群体资源隐藏个人分数，群体和指标保护人数至少 3。第三方标准量表、家长/教师代评和固定测评包保持原审核流程。

资源目录和管理页当前有明确数量上限；方案列表提供分页。普通课程问卷不会自动变成组织测量，也不对历史问卷做无依据回填。
