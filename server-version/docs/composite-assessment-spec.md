# 综合测评实现说明

## 范围

综合测评（Composite Assessment）是一个按教师配置顺序执行的容器，可以组合：

- 已发布心理量表；
- 已发布认知任务；
- 简单表单项（文本、填空、单选、多选）。

量表、认知任务和表单仍各自保留独立的数据和评分逻辑。综合测评只负责编排、进度和完成状态，不做跨模块综合计分。

## 完成与续答

一次综合测评对应一条 `CompositeAssessmentAttempt`。模块全部完成后，服务端才将记录标记为 `COMPLETED`；未完成时保持 `IN_PROGRESS`。

- 登录学生：记录绑定 `userId`，可以从课程详情进入，服务端按已保存的认知试次索引继续；
- 匿名参与：`userId` 为空，创建时返回一次恢复凭证和匿名编号；数据库只保存恢复凭证哈希；
- “保存并退出”会更新 `lastSavedAt`，量表答案、表单答案和认知试次在各自保存动作完成后立即落库；
- 认知任务的运行会话属于综合测评模块，完成后返回综合测评容器继续下一个模块。

恢复凭证通过 `X-Recovery-Token` 请求头用于读取和查询；写入接口只在请求体中提交凭证，凭证不进入 URL。

## 公开链接和匿名参与

教师只能为已发布综合测评生成公开入口令牌。令牌支持：

- `expiresAt`：有效期；
- `maxUses`：最大参与次数，`0` 表示不限制；
- 原子计数：并发开始时通过条件更新避免超额使用。

公开参与不会创建学生账号绑定。教师导出或查看记录时可以看到匿名编号（如 `ANON-XXXXXXXX`）及原始数据。公开链接令牌和参与者恢复凭证是两种不同凭证：前者控制入口，后者恢复一条具体参与记录。

单个认知任务也提供同样的公开入口和匿名会话接口，以兼容不经过综合测评的认知任务。

## 报告

综合测评完成后返回分模块报告：

- 量表：各维度得分和量表反馈；
- 认知任务：任务得分、指标、质量标记和任务自身参考信息；
- 表单：表单答案。

报告明确不计算量表与认知任务之间的综合分数。

## 导出

教师可按综合测评模板导出所有已完成参与记录：

- `summary`：参与者编号、完成时间、用时、表单答案、量表维度分数、认知任务得分/质量/服务端汇总指标；
- `full`：在摘要基础上增加量表逐题答案及作答时间，并展开认知任务每个试次的原始 payload，包括反应时等逐次数值，不使用平均值替代；
- 支持 CSV 和 SAV；动态指标和试次字段会在导出前稳定成列；
- 教师导出默认使用匿名编号，避免将“导出脱敏”误认为“匿名参与”。

## 本 PR 暂不包含

教师统计、跨模块统计图表和聚合分析留到后续 PR；本 PR 只提供单次综合测评容器、统一完成流程、个人分模块报告、公开/匿名访问和逐次原始数据导出。
