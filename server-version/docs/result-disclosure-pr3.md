# PR3：结果权限与本人长期反馈（开发阶段）

依赖 PR2 `f57a08b7`，以叠加草稿提交；不合并、不部署、不发布科学内容。

## 已实现

- SELF、OBSERVER、RELATIONAL 三类完成反馈，均不序列化原始作答或被评价者排名。
- 已发布关系内容必须提供七类受众的结果声明。NONE、完成确认、个体摘要、班级/机构群体、被评价者群体及延迟群体分别授权；长期指标必须是即时可见指标的子集。
- 内容声明冻结进 Run 资源政策及其哈希。新的机构报告生成、读取、成员导出按当前内容、冻结合同和当前权限再次收窄；旧源仍使用原有内容运行时政策，不把新声明作为放宽旧权限的依据。
- ORG_ADMIN 不再自动取得个人长期报告权限；专业能力或当前教师/咨询师关系仍独立校验。
- 新声明的 Run 从独立的本次摘要入口读取内容允许的 canonical 指标。旧 Composite/子量表报告和通用批量导出拒绝这些结果，避免绕过摘要字段限制。原有研究导出不被当作作答者反馈。
- 本人长期反馈提供独立的 no-store API 与“我的测评”界面。只接受自己的 SELF，逐波次校验单一被试、精确 execution、冻结合同、当前发布合同、组织权限及已审核报告方案；指标取各波次内容白名单交集。保留既有引擎的可比性，只有已许可的数值差异可展示。研究 artifact、波次身份、输入清单及证据哈希不进入本人响应。
- 被评价者群体报告收窄为明确字段，并继续使用原有最小人数与快照验证；不足人数的指标不返回细分人数。延迟机构报告需服务端 Run 关闭时间和内容规定的等待时间。

评分、canonical FINAL、报告计算、可比性规则及科学快照没有变更。没有新增生产关系内容，也没有改变最小人数算法。

## 留置与未完成验收

1. 生产关系注册表仍为空，科学内容发布及十个正式 Journey 继续 HOLD。因此这些测试是工程与测试夹具验收，不能替代正式内容的七受众端到端验收。
2. `INDIVIDUAL_SUMMARY` 已有内容合同与作答者摘要支持；观察结果直接向被评价者公开仍需明确的接收者/同意依据及拥有该源的受控适配器。此阶段不增加通用 subject 代读入口。
3. 旧课程 episode 没有权威收集窗口关闭事件，DELAYED_AGGREGATE 在此入口保持关闭。机构 Run 可以根据已持久化的关闭时间执行延迟门禁。
4. 本人长期读取当前只支持具有冻结披露合同的 SELF Run 和既有审核后生成的单人长期 artifact。不会把旧 Scale 历史或研究群体报告自动提升为本人长期报告；未具备该内容合同的其他原生家族需通过各自内容拥有者的适配器逐项接入。
5. 新受控 Run 的逐题/原始数据研究导出尚不开放；本次仅允许既有机构报告投影范围内的授权导出。需要新的科学/同意声明才能讨论扩展。

匿名能力的现状与 PR4 工作范围见 `anonymous-pr4-scope.md`。

最终复核补正：即时数字报告读取 canonical 结果后再次核对执行撤销、冻结合同、当前内容发布状态和显式报告拒绝，避免读取期间撤销后仍返回指标。单测覆盖读取期间撤销。
