## 系统简介

欢迎使用教育平台管理端！本系统为管理员提供完整的平台管理功能，包括用户管理、课程监控、教师码管理、系统配置等。

### 管理员职责
- 管理平台用户（教师和学生）
- 审核教师注册
- 管理教师码
- 监控系统运行状态
- 处理账号延期申请

### 访问入口
- **门户**: `/`
- **管理登录**: `/admin/login`
- 不要访问 `/login`（已废弃，会回到门户）

### 默认管理员账号
用户名/密码以环境变量 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 为准（未设置时为 `admin` / `admin123`）。

## 登录系统

### 管理员登录
1. 访问登录页面 `/admin/login`
2. 输入管理员用户名和密码
3. 点击"登录"按钮
4. 进入管理后台

### 安全建议
- 首次登录后请修改默认密码
- 定期更换密码
- 不要将账号密码告知他人

## 用户管理

### 查看用户列表
进入用户管理页面，可查看所有用户信息：

#### 教师列表
- 用户名
- 昵称
- 注册时间
- 账号有效期
- 状态（正常/已过期）

#### 学生列表
- 用户名
- 昵称
- 所属课程
- 账号有效期
- 状态（正常/已过期）

### 搜索用户
在搜索框输入用户名或昵称，快速查找用户。

### 账号延期
当用户账号即将过期或已过期时：
1. 在用户列表找到该用户
2. 点击"延期"按钮
3. 选择延期时长（1个月/3个月/6个月/12个月）
4. 确认延期

### 删除用户
如需删除用户账号：
1. 在用户列表找到该用户
2. 点击"删除"按钮
3. 确认删除操作

⚠️ **注意**: 删除用户将同时删除其所有相关数据，请谨慎操作！

## 教师码管理

### 生成教师码
1. 进入教师码管理页面
2. 点击"生成教师码"
3. 设置有效期
4. 点击"确认生成"
5. 系统生成唯一教师码

### 管理教师码
- **查看**: 查看所有教师码列表
- **状态**: 查看使用情况（未使用/已使用）
- **有效期**: 查看教师码有效期
- **删除**: 删除未使用的教师码

### 分发教师码
将教师码提供给需要注册教师账号的用户，一个教师码只能使用一次。

## 常见问题

### Q1: 忘记管理员密码怎么办？
联系系统部署人员重置密码。

### Q2: 如何批量延期账号？
目前仅支持单个账号延期，批量功能后续版本支持。

### Q3: 教师注册后需要审核吗？
使用有效教师码注册的教师自动通过审核，无需人工干预。

### Q4: 如何查看系统日志？
通过 Docker 查看后端日志：
```bash
docker-compose logs -f backend
```

### Q5: 数据如何备份？
- 数据库数据通过 Docker Volume 持久化
- 上传文件保存在 `./uploads` 目录
- 建议定期备份这些目录

### Q6: 如何导出平台数据？
通过数据库管理工具连接 PostgreSQL 导出数据。

### Q7: 学生/教师反馈功能异常？
1. 收集具体问题描述
2. 查看系统日志
3. 尝试复现问题
4. 联系技术支持

## 数据备份与恢复

### 备份数据
```bash
# 进入项目目录
cd server-version

# 备份数据库
docker-compose exec postgres pg_dump -U postgres ptool > backup.sql

# 备份上传文件
cp -r uploads uploads_backup
```

### 恢复数据
```bash
# 恢复数据库
docker-compose exec -T postgres psql -U postgres ptool < backup.sql

# 恢复上传文件
cp -r uploads_backup uploads
```
