## 📈 实际场景分析

### 场景1: 50人班级 (轻度使用)

```
使用模式:
- 上课期间同时在线: 40人
- 并发操作: 15-20人
- 图片浏览: 10人
- 视频播放: 2-3人

套餐A (2C2G4M):
├── 内存: 2GB ÷ 30MB = 66用户 ✅
├── 带宽: 4M÷100KB = 4人刷图 ⚠️
├── 视频: 4M÷500KB = 0.8路 ❌
└── 结论: 勉强可用，视频卡顿

套餐B (2C4G6M):
├── 内存: 4GB ÷ 30MB = 133用户 ✅
├── 带宽: 6M÷100KB = 6人刷图 ✅
├── 视频: 6M÷500KB = 1.2路 ✅
└── 结论: 流畅运行，支持1路视频

套餐C (2C4G5M):
├── 内存: 4GB ÷ 30MB = 133用户 ✅
├── 带宽: 5M÷100KB = 5人刷图 ✅
├── 视频: 5M÷500KB = 1路 ⚠️
└── 结论: 基本流畅，视频紧张
```

### 场景2: 100人班级 (中度使用)

```
使用模式:
- 同时在线: 80人
- 并发操作: 30-40人
- 图片上传: 5-8人
- 视频播放: 5-10人

套餐A (2C2G4M):
└── ❌ 不可用 (内存不足 + 带宽不足)

套餐B (2C4G6M):
├── 内存: 80人 × 30MB = 2.4GB ✅ (够用)
├── 带宽: 6M÷500KB = 12路视频 ⚠️
├── 流量: 600GB/月 ÷ 30天 = 20GB/天 ⚠️
└── 结论: 需配合COS，否则流量紧张

套餐C (2C4G5M):
├── 内存: 80人 × 30MB = 2.4GB ✅
├── 带宽: 5M÷500KB = 10路视频 ⚠️
├── 流量: 500GB/月 ÷ 30天 = 16GB/天 ❌
└── 结论: 必须配合COS使用
```

### 场景3: 150人班级 (重度使用)

```
结论: 三个套餐都需要配合COS+CDN使用

推荐配置:
- 服务器: 处理API请求 (2C4G足够)
- COS: 存储所有静态资源
- CDN: 加速图片/视频分发
- 带宽: 仅传输API数据 (大幅降低)
```

## 🎬 视频规格建议

### 本地视频限制建议

| 规格项 | 建议值 | 说明 |
|-------|-------|------|
| **分辨率** | **720p (1280×720)** | 教学场景足够清晰 |
| **码率** | **800-1200kbps** | 平衡清晰度和大小 |
| **帧率** | **24-30fps** | 教学视频不需要高帧率 |
| **时长** | **≤15分钟** | 单文件大小可控 |
| **格式** | **MP4 (H.264)** | 兼容性最好 |
| **文件大小** | **≤150MB** | 15分钟约100-150MB |
| **音频** | **AAC 128kbps** | 清晰且节省空间 |

### 视频规格对比

| 规格 | 分辨率 | 码率 | 15分钟大小 | 4M带宽播放 | 6M带宽播放 |
|-----|-------|------|-----------|-----------|-----------|
| 标清480p | 854×480 | 500kbps | ~60MB | ✅ 流畅 | ✅ 流畅 |
| **高清720p** | **1280×720** | **1000kbps** | **~120MB** | ⚠️ 缓冲 | ✅ 流畅 |
| 超清1080p | 1920×1080 | 2000kbps | ~240MB | ❌ 卡顿 | ⚠️ 缓冲 |
| 2K | 2560×1440 | 4000kbps | ~480MB | ❌ 不可用 | ❌ 卡顿 |

### 推荐的视频压制参数

```bash
# FFmpeg 压制命令示例
ffmpeg -i input.mp4 -c:v libx264 \
  -preset medium -crf 23 \
  -maxrate 1000k -bufsize 2000k \
  -vf "scale=1280:720:force_original_aspect_ratio=decrease,pad=1280:720:(ow-iw)/2:(oh-ih)/2" \
  -c:a aac -b:a 128k \
  -movflags +faststart \
  output_720p.mp4
```

### 视频大小计算公式

```
文件大小(MB) = (码率(kbps) × 时长(秒)) ÷ 8192

示例 (720p, 15分钟):
大小 = (1000 × 900) ÷ 8192 = 110MB

上传时间预估 (4M带宽):
时间 = 110MB ÷ 400KB/s = 275秒 ≈ 4.5分钟

上传时间预估 (6M带宽):
时间 = 110MB ÷ 600KB/s = 183秒 ≈ 3分钟
```

## ⚠️ 重要提醒

### 流量使用预估

```
100人班级月流量消耗:
├── API请求: 50GB
```

```
50GB磁盘使用:
```
