# 功能测试清单

## 环境准备

### 1. 安装 Docker
```bash
# 使用 Homebrew 安装
brew install --cask docker

# 或从官网下载
# https://www.docker.com/products/docker-desktop
```

### 2. 启动 Docker Desktop
- 打开 Applications/Docker.app
- 等待状态栏显示 "Docker Desktop is running"

### 3. 运行测试脚本
```bash
cd /Users/Qiang/CodeBuddy/ptool/server-version
./test-local.sh
```
