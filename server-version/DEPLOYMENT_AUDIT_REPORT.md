## 4️⃣ 云端部署性能分析

### 🖥️ 硬件配置方案对比

#### 方案 A: 2C2G + 3M 带宽

| 指标 | 数值 | 说明 |
|-----|------|------|
| **理论并发** | 30-50 用户 | CPU 限制 |
| **带宽瓶颈** | 375KB/s | 3M = 375KB/s |
| **图片加载** | 10-20并发 | 每张图片100KB |
| **视频播放** | ❌ 不可用 | 带宽不足 |
| **适用场景** | 小班级 (<50人) | 文字为主 |

#### 方案 B: 2C4G + 5M 带宽 ⭐推荐

| 指标 | 数值 | 说明 |
|-----|------|------|
| **理论并发** | 50-100 用户 | 内存充足 |
| **带宽瓶颈** | 625KB/s | 5M = 625KB/s |
| **图片加载** | 30-50并发 | 配合CDN后100+ |
| **视频播放** | ⚠️ 1-2路 | 需COS分流 |
| **适用场景** | 中大型班级 (100-200人) | 多媒体教学 |

### 📈 性能预估模型

```
并发用户数 = min(CPU限制, 内存限制, 带宽限制)

CPU限制: 2核 = 约50个活跃请求
内存限制: 4G = 约100个活跃会话 (40MB/会话)
带宽限制: 5M = 约50个并发图片请求 (100KB/图)

实际并发 = 50% * min(50, 100, 50) ≈ 25-50 真实并发
```

### 🎯 优化建议 (云端)

#### 1. 必须配置 COS + CDN

```
成本预估 (月度):
├── COS 存储 (100GB): ¥12
├── COS 流量 (500GB): ¥40
├── CDN 流量 (500GB): ¥25
└── 合计: ¥77/月

收益:
├── 服务器带宽压力降低 80%
├── 静态资源加载速度提升 5-10倍
└── 支持并发提升到 200+
```

#### 2. 推荐架构

```
┌─────────────────────────────────────────────┐
│                  CDN (静态资源)                │
│         图片/视频/JS/CSS/字体                │
└──────────────┬──────────────────────────────┘
               │
┌──────────────▼──────────────────────────────┐
│           Nginx (反向代理)                   │
│    负载均衡 + 静态缓存 + HTTPS               │
└──────────────┬──────────────────────────────┘
               │
┌──────────────▼──────────────────────────────┐
│         Node.js (2C4G 服务器)               │
│    API服务 + 内存缓存 + 业务逻辑             │
└──────────────┬──────────────────────────────┘
               │
┌──────────────▼──────────────────────────────┐
│      PostgreSQL (建议RDS或独立服务器)        │
│         主从复制 + 自动备份                  │
└─────────────────────────────────────────────┘
```

#### 3. 配置优化清单

**Nginx 配置**:
```nginx
# 静态资源缓存
gzip on;
gzip_types text/plain application/json application/javascript text/css;

# 图片缓存 7天
location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
    expires 7d;
    add_header Cache-Control "public, immutable";
}

# 反向代理
location /api {
    proxy_pass http://localhost:3000;
    proxy_buffering off;
}
```

**Node.js 优化**:
```javascript
// 使用 PM2 集群模式
pm2 start dist/index.js -i max

// 环境变量优化
NODE_ENV=production
UV_THREADPOOL_SIZE=128
```

**数据库优化**:
```sql
-- 添加常用索引
CREATE INDEX idx_course_creator ON courses(creator_id);
CREATE INDEX idx_assignment_course ON assignments(course_id);
CREATE INDEX idx_submission_student ON submissions(student_id);
CREATE INDEX idx_checkin_course ON checkins(course_id);
```
